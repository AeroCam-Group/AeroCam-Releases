# AeroCam Beta

AeroCam은 카메라의 사진을 Android 휴대폰으로 바로 전송하고, 휴대폰에서 카메라를 제어할 수 있게 해줍니다. 현재 Nikon Z 카메라를 지원합니다. 이 버전은 **AeroCam Beta 공개 테스트**로, Pro 및 Cine의 모든 기능을 무료로 체험해 볼 수 있습니다.

## 다운로드 및 설치

1. [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest)에서 최신 Beta APK(`…-Beta-xx.xx.xx.apk`)를 다운로드합니다.
2. 휴대폰에서 APK를 엽니다. 처음 설치할 때 Android에서 "출처를 알 수 없는 앱 설치" 허용을 요청하면 허용해 주세요.
3. 새 버전이 출시되면 다운로드 후 그대로 설치하여 덮어쓰면 되며, 페어링 정보와 설정은 그대로 유지됩니다.

Android 10 이상이 필요합니다.

## 테스트 키

Beta는 기본적으로 **무료 버전**(블루투스 전송 및 USB를 통한 수동 원본 선택 다운로드)으로 시작됩니다. 테스트 키를 입력하면 **Pro 및 Cine의 모든 기능**이 잠금 해제됩니다.

**입력 방법**: AeroCam Beta → 설정 → 지원 → "테스트 키 입력"을 누른 뒤 전체 텍스트를 붙여넣습니다. 잠긴 기능을 탭해도 안내 대화상자에 "테스트 키 입력"이 표시됩니다.

## Beta 종료 후

정식 버전이 출시되면 Beta 업데이트가 중단됩니다. 마지막 키가 만료된 후에는 무료 버전으로 전환되므로, 그때 정식 버전을 설치해 주세요.
