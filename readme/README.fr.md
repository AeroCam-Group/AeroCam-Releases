# AeroCam Beta

AeroCam transfère les photos de votre appareil photo directement vers votre téléphone Android et vous permet de contrôler l'appareil photo depuis votre téléphone. Les appareils photo Nikon Z sont pris en charge pour le moment. Ceci est le **test public AeroCam Beta** : toutes les fonctionnalités Pro et Cine peuvent être essayées gratuitement.

## Téléchargement et installation

1. Téléchargez le dernier APK Beta (`…-Beta-xx.xx.xx.apk`) depuis [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest).
2. Ouvrez l'APK sur votre téléphone. La première fois, Android vous demandera d'autoriser « Installer des applications inconnues » — autorisez-le.
3. Lorsqu'une nouvelle version sort, téléchargez-la et installez-la simplement par-dessus l'ancienne ; l'appairage et les paramètres sont conservés.

Nécessite Android 10 ou version ultérieure.

## À la fin de la Beta

Lorsque la version complète sortira, la Beta cessera de recevoir des mises à jour. Après l'expiration de la dernière clé, elle reviendra à la version gratuite ; veuillez alors installer la version complète.

## Signaler un problème

Ouvrez un formulaire dans [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) (bug, demande de fonctionnalité, erreur de traduction, rapport d'appareil photo) et indiquez le modèle de votre téléphone, le modèle de votre appareil photo et la version Beta (en haut à gauche de l'écran d'accueil). Les Issues sont publiques — veuillez ne pas publier d'informations personnelles. Les signalements dans toutes les langues sont les bienvenus.

`update.json` contient les informations de version lues par l'application ; veuillez ne pas le modifier manuellement.
