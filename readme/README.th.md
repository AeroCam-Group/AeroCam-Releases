# AeroCam Beta

AeroCam ส่งภาพถ่ายจากกล้องไปยังโทรศัพท์ Android ของคุณโดยตรง และให้คุณควบคุมกล้องได้จากโทรศัพท์ ปัจจุบันรองรับกล้อง Nikon Z นี่คือ**การทดสอบสาธารณะ AeroCam Beta**: สามารถทดลองใช้ฟีเจอร์ Pro และ Cine ทั้งหมดได้ฟรี

## ดาวน์โหลดและติดตั้ง

1. ดาวน์โหลด Beta APK ล่าสุด (`…-Beta-xx.xx.xx.apk`) จาก [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest)
2. เปิดไฟล์ APK บนโทรศัพท์ของคุณ ในครั้งแรก Android จะขอให้คุณอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" — โปรดกดอนุญาต
3. เมื่อมีเวอร์ชันใหม่ออกมา เพียงดาวน์โหลดและติดตั้งทับเวอร์ชันเดิม การจับคู่และการตั้งค่าทั้งหมดจะยังคงอยู่

รองรับ Android 10 ขึ้นไป

## คีย์ทดสอบ

เวอร์ชัน Beta เริ่มต้นเป็น**เวอร์ชันฟรี** (การโอนถ่ายผ่าน Bluetooth และการเลือกดาวน์โหลดไฟล์ต้นฉบับด้วยตนเองผ่าน USB) กรอกคีย์ทดสอบเพื่อปลดล็อก**ฟีเจอร์ Pro และ Cine ทั้งหมด**

**วิธีกรอกคีย์**: AeroCam Beta → ตั้งค่า → ช่วยเหลือ → "กรอกคีย์ทดสอบ" จากนั้นวางข้อความทั้งหมด การแตะที่ฟีเจอร์ที่ถูกล็อกอยู่จะแสดงปุ่ม "กรอกคีย์ทดสอบ" ในหน้าต่างแจ้งเตือนเช่นกัน

## เมื่อสิ้นสุดช่วง Beta

เมื่อเปิดตัวเวอร์ชันเต็ม เวอร์ชัน Beta จะหยุดอัปเดต หลังจากคีย์ชุดสุดท้ายหมดอายุ แอปจะกลับไปเป็นเวอร์ชันฟรี โปรดติดตั้งเวอร์ชันเต็มในเวลานั้น
