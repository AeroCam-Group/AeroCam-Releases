# AeroCam Beta

AeroCam 可以将相机拍摄的照片直接发送到 Android 手机，也能通过手机遥控相机。目前支持 Nikon Z 系列。这里发布的是 **AeroCam Beta 公开测试版**：Pro 和 Cine 的全部功能均可免费试用。

## 下载与安装

1. 前往 [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest) 下载最新的 Beta APK（`…-Beta-xx.xx.xx.apk`）。
2. 在手机上打开 APK。首次安装时，Android 会要求允许“安装未知应用”，请予以允许。
3. 后续有新版本时，直接下载安装即可覆盖更新，配对信息和设置都会保留。

需要 Android 10 或更高版本。
