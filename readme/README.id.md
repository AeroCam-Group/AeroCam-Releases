# AeroCam Beta

AeroCam mengirim foto dari kamera langsung ke ponsel Android Anda dan memungkinkan Anda mengontrol kamera dari ponsel. Saat ini kamera Nikon Z sudah didukung. Ini adalah **uji coba publik AeroCam Beta**: setiap fitur Pro dan Cine dapat dicoba secara gratis.

## Unduh dan pasang

1. Unduh APK Beta terbaru (`…-Beta-xx.xx.xx.apk`) dari [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest).
2. Buka APK di ponsel Anda. Untuk pertama kalinya, Android akan meminta Anda mengizinkan "Instal aplikasi yang tidak dikenal" — izinkan.
3. Saat versi baru keluar, cukup unduh dan pasang menimpa versi lama; pemasangan (pairing) dan pengaturan tetap tersimpan.

Memerlukan Android 10 atau yang lebih baru.

## Kunci uji

Beta dimulai sebagai **versi gratis** (transfer Bluetooth, serta memilih dan mengunduh file asli secara manual melalui USB). Masukkan kunci uji untuk membuka **semua fitur Pro dan Cine**.

**Cara memasukkannya**: AeroCam Beta → Pengaturan → Dukungan → "Masukkan kunci uji", lalu tempel seluruh teks. Mengetuk fitur yang terkunci juga akan menampilkan "Masukkan kunci uji" di dialognya.

## Saat Beta berakhir

Saat versi lengkap dirilis, Beta akan berhenti mendapatkan pembaruan. Setelah kunci terakhir kedaluwarsa, aplikasi akan kembali ke versi gratis; silakan pasang versi lengkap saat itu.

## Panduan pengguna

[Panduan pengguna](https://github.com/AeroCam-Group/AeroCam-Releases/blob/main/manual/zh-TW/README.md) (saat ini hanya dalam bahasa Mandarin Tradisional): pemasangan, menghubungkan kamera, setiap fitur, setiap pengaturan, dan FAQ.

## Laporkan masalah

Buka formulir di [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) (bug, permintaan fitur, kesalahan terjemahan, laporan kamera) dan sertakan model ponsel, model kamera, serta versi Beta Anda (pojok kiri atas layar utama). Issues bersifat publik — harap jangan memposting informasi pribadi. Laporan dalam bahasa apa pun diterima.
