# AeroCam Beta

AeroCam はカメラの写真を Android スマートフォンへ直接転送し、スマートフォンからカメラを操作できるアプリです。現在は Nikon Z シリーズに対応しています。これは **AeroCam Beta 公開テスト版**で、Pro と Cine のすべての機能を無料でお試しいただけます。

## ダウンロードとインストール

1. [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest) から最新の Beta APK（`…-Beta-xx.xx.xx.apk`）をダウンロードします。
2. スマートフォンで APK を開きます。初回インストール時に Android から「不明なアプリのインストール」の許可を求められた場合は許可してください。
3. 新しいバージョンが公開されたら、そのままダウンロードしてインストールするだけで上書き更新され、ペアリング情報や設定は保持されます。

Android 10 以降が必要です。

**入力方法**：AeroCam Beta → 設定 → サポート →「テストキーを入力」から、テキスト全体を貼り付けます。ロックされた機能をタップした際に表示されるダイアログにも「テストキーを入力」があります。

- キーの検証はスマートフォン上で行われ、外部にデータが送信されることはありません。

## Beta テスト終了後

正式版がリリースされると、Beta の更新は停止します。最後のキーの有効期限が切れると無料版に戻りますので、その際は正式版をインストールしてください。
