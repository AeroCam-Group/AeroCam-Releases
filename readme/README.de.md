# AeroCam Beta

AeroCam überträgt Fotos direkt von Ihrer Kamera auf Ihr Android-Smartphone und ermöglicht die Steuerung der Kamera vom Smartphone aus. Derzeit werden Nikon Z Kameras unterstützt. Dies ist der **öffentliche AeroCam Beta-Test**: Alle Pro- und Cine-Funktionen können kostenlos ausprobiert werden.

## Herunterladen und installieren

1. Laden Sie die neueste Beta-APK (`…-Beta-xx.xx.xx.apk`) unter [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest) herunter.
2. Öffnen Sie die APK auf Ihrem Smartphone. Beim ersten Mal fragt Android nach der Berechtigung „Unbekannte Apps installieren“ — bitte erlauben Sie dies.
3. Wenn eine neue Version erscheint, laden Sie sie einfach herunter und installieren Sie sie über die alte Version; Kopplung und Einstellungen bleiben erhalten.

Erfordert Android 10 oder neuer.
