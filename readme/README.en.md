# AeroCam Beta

AeroCam sends photos from your camera straight to your Android phone and lets you control the camera from the phone. Nikon Z cameras are supported for now. This is the **AeroCam Beta public test**: every Pro and Cine feature can be tried for free.

## Download and install

1. Download the latest Beta APK (`…-Beta-xx.xx.xx.apk`) from [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest).
2. Open the APK on your phone. The first time, Android asks you to allow "Install unknown apps" — allow it.
3. When a new version comes out, just download and install it over the old one; pairing and settings are kept.

Requires Android 10 or later.

## When the Beta ends

When the full version is released, the Beta stops getting updates. After the last key expires it goes back to the Free tier; please install the full version then.

## Report a problem

Open a form in [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) (bug, feature request, translation error, camera report) and include your phone model, camera model and Beta version (top-left of the home screen). Issues are public — please don't post personal information. Reports in any language are welcome.
