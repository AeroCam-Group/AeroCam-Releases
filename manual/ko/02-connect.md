# 2. 카메라 연결하기

AeroCam은 네 가지 연결 방식을 지원합니다. 여러 방식을 동시에 설정해 두면 앱이 현재 사용 가능한 방식을 자동으로 선택합니다. 홈 화면의 네 개 타일(Wi‑Fi, USB, Bluetooth, FTP)에서 각 연결 상태를 확인할 수 있습니다.

> 연결 방법이 헷갈릴 때는 홈 화면 연결 상태 옆 또는 '카메라 추가' 각 단계 오른쪽 위의 **ⓘ**를 누르세요. 휴대폰 핫스팟, 동일 Wi‑Fi, 원탭 연결, USB, Bluetooth, FTP 각각에 대한 단계별 그림 가이드(휴대폰과 카메라 화면 스크린샷 포함)와 마지막 '연결되지 않을 때 확인 사항'이 열립니다.

## 연결 방식 선택 가이드

| 원하는 사용 방식 | 추천 연결 방식 |
|---|---|
| 카메라 전원을 꺼도 신경 쓰지 않고 자동으로 사진 받기 | **Bluetooth**(축소판 JPEG, 무료) |
| 야외에서 핫스팟 켜기 번거로울 때 원본, 앨범, 원격 촬영 쓰기 | **원탭 연결**(Pro) |
| 찍자마자 가장 빠른 무선 속도로 휴대폰에 자동 전송하기 | **[FTP 수신](08-ftp.md)**(Pro, 핫스팟 필요) |
| 가장 안정적인 연결, 비디오 모니터, 장시간 원격 촬영 | **USB 케이블**(수동 선택 다운로드는 무료) |
| 집이나 스튜디오에서 사용하기 | **동일 Wi‑Fi**(Pro) |

## 속도 참고(Nikon Zf, Pixel 10 Pro 실측)

| 연결 방식 | RAW 1장(약 18 MB) 전송 시간 |
|---|---|
| FTP 수신 | 약 1초(약 17 MB/s) |
| Wi‑Fi 앨범 다운로드 | 약 1.3초(약 13 MB/s) |
| USB | 보통 Wi‑Fi보다 빠름, 케이블 사양에 따라 다름(USB 2.0 케이블 약 35 MB/s) |
| Bluetooth | 축소판 JPEG(약 2 MB), 장당 15~20초 |

## 홈 화면의 연결 표시등
Wi‑Fi, USB, Bluetooth, FTP 네 개의 버튼은 상태에 따라 색상이 바뀌며, 연결되지 않았을 때는 회색입니다:

| 색상 | 의미 |
|---|---|
| 🟢 초록 | 연결됨 또는 준비 완료(Bluetooth 연한 초록 = 대기 중, 전원 꺼짐 중 전송 준비 완료) |
| 🔵 파랑 | 전송 중 |
| 🟠 주황 | 연결 중(깜빡임), 또는 조치 필요(권한, 멈춤, 오류) |
| 🔴 빨강 | 휴대폰의 Wi‑Fi 또는 Bluetooth가 꺼져 있음 |

## Bluetooth(무료, SnapBridge 대체)

### 페어링
1. 카메라: **MENU → 네트워크 메뉴 → 스마트 장치와 연결 → 페어링(Bluetooth) → 페어링 시작**.
2. 카메라가 기존에 SnapBridge와 페어링되어 있었다면 먼저 SnapBridge에서 등록을 삭제하고, 휴대폰 Bluetooth 목록에서도 기기 등록을 해제하세요(두 앱이 동시에 한 카메라에 페어링될 수 없습니다).
3. AeroCam 홈 화면 'Bluetooth' → **카메라 페어링** → 시작. 휴대폰과 카메라에 같은 인증 번호가 표시되면 양쪽 모두 확인을 누릅니다. 카메라에는 `AeroCam_휴대폰모델명`으로 표시됩니다.

📷 스크린샷: Bluetooth 카드

### 페어링 이후
한 번 페어링하면 계속 활성화 상태로 유지되며, 페어링 해제를 누르기 전까지 유지됩니다(해제 시 확인창 표시).
- AeroCam은 평소 백그라운드에서 카메라의 Bluetooth 신호만 **수신 대기**하므로 절전 상태의 카메라를 깨우지 않습니다.
- **카메라 전원을 켤 때**: 한 번 연결하여 시간과 휴대폰 위치 정보를 동기화한 뒤(촬영 시 카메라가 사진에 위치를 기록함) 연결을 끊습니다.
- **카메라에 보낼 사진이 있을 때**: 카메라의 '스마트 장치와 연결' 메뉴에서 **전원 꺼짐 중 전송**(Send while off)을 켜 두면, 카메라 전원을 끈 상태에서도 자동으로 Bluetooth로 사진을 전송합니다.
- 수신되는 파일은 카메라가 생성한 약 2 MB 크기의 JPEG입니다(RAW로 촬영해도 카메라가 JPEG로 변환하여 전송). 장당 약 15~20초 걸리며, 원본 파일은 Wi‑Fi, USB 또는 FTP를 이용하세요.
- 바로 사진을 받으려면 Bluetooth 카드의 **지금 수신**을 누르세요.
- 휴대폰 Bluetooth를 껐다 켜거나, 휴대폰 재부팅, 앱 업데이트 후에도 자동으로 복구됩니다. 대기 중에는 Android 정책에 따라 낮은 우선순위의 상단 알림이 하나 표시되며, 시스템 설정에서 숨길 수 있습니다.

### Bluetooth 카드 상태 표시
🟢 카메라가 근처에 있음 · 켜짐 / 🟢 연한 초록 대기 중(전원 꺼짐 중 전송 준비) / ⚪ 카메라를 찾을 수 없음(마지막 확인 시간 표시) / 🔵 전송 중 / 🟠 멈춘 것 같음 / 🔴 휴대폰 Bluetooth 꺼짐.

Bluetooth는 상시 연결된 상태가 아니므로, 이 카드는 '카메라 신호가 감지되는지'와 '현재 동작 상태'를 보여줍니다.

### 전송이 멈췄을 때
- 전송 중 30초 동안 데이터가 없으면 앱이 자동으로 연결을 끊고 카메라가 나중에 재전송합니다. 20초간 반응이 없으면 카드가 노란색으로 바뀌며 '멈춘 것 같음'이 표시됩니다.
- **연결 끊고 다시 연결**: 현재 전송 세션만 끊었다가 다시 연결합니다.
- **⋮ → Bluetooth 서비스 재시작**: 페어링 정보를 유지한 채 전체 Bluetooth 백그라운드 서비스를 다시 시작합니다.
- RAW 촬영 시 카메라가 먼저 JPEG로 변환한 뒤 전송합니다. 전송 중에 카메라를 조작(반셔터, 촬영 등)하면 카메라가 전송을 취소합니다. 촬영을 마친 뒤 바로 전원을 꺼 두면 백그라운드에서 안정적으로 전송됩니다.

## Wi‑Fi(Pro): 세 가지 연결 방식

| 방식 | 작동 원리 | 추천 상황 |
|---|---|---|
| **원탭 연결**(추천) | Bluetooth로 카메라 자체 Wi‑Fi를 켜게 한 뒤 휴대폰이 자동 연결 | 야외에서 핫스팟을 켜기 번거로울 때 |
| **휴대폰 핫스팟**(가이드 추천) | 휴대폰이 연 핫스팟에 카메라가 접속 | 원탭 연결이 불안정하거나 FTP, 카드 없이 촬영을 쓸 때 |
| **동일 Wi‑Fi** | 휴대폰과 카메라가 같은 공유기에 접속 | 집, 스튜디오 |

### 원탭 연결
1. 먼저 **Bluetooth 페어링**을 완료합니다.
2. 홈 화면 Wi‑Fi → '원탭 연결'을 누릅니다.
3. 처음 한 번 카메라 Wi‑Fi **비밀번호**를 입력합니다(네트워크 이름 `NIKON_…`은 자동 입력됨). 비밀번호는 내 휴대폰에만 저장됩니다.
4. Android에서 Wi‑Fi 연결 허용을 물으면 허용을 누릅니다.
5. '카메라 Wi‑Fi에 연결됨'이 표시되면 앨범, 원격 촬영, 자동 수신 모두 이 연결을 사용합니다. '연결 해제'를 누르면 원래 Wi‑Fi로 돌아갑니다.

앨범이나 원격 촬영에 아직 연결되지 않았을 때도 화면에 '카메라 Wi‑Fi로 연결' 버튼이 바로 나타납니다.

> - 카메라 Wi‑Fi에 연결된 동안 휴대폰 인터넷은 모바일 데이터를 사용합니다.
> - 원탭 연결은 **FTP와 함께 사용할 수 없으며**, **카드 없이 촬영도 지원하지 않습니다**(카메라에 메모리카드가 없을 때는 휴대폰 핫스팟이나 동일 Wi‑Fi를 사용하세요).

📷 스크린샷: 원탭 연결 카드 및 연결됨 상태

### 휴대폰 핫스팟 / 동일 Wi‑Fi(최초 1회 페어링 필요)
1. 카메라: **MENU → 네트워크 메뉴 → PC에 연결**에서 네트워크 프로파일을 만듭니다(휴대폰 핫스팟 또는 집 Wi‑Fi에 연결).
   - 최신 기종(메뉴에 '연결 유형'이 있는 기종): '연결 유형'을 **화상 전송**으로 선택합니다.
   - 이전 기종: 'PC에 연결'만 선택하면 됩니다.
2. AeroCam: **홈 → '＋' 카메라 추가**에서 연결 방식(동일 Wi‑Fi 또는 휴대폰 핫스팟)을 선택합니다. 앱이 네트워크를 확인하고 카메라를 자동으로 검색하며, 찾지 못하면 IP를 직접 입력할 수도 있습니다.
3. 카메라 화면에 **4자리 PIN 번호**가 나타나면 휴대폰에 입력한 뒤 카메라에서 OK를 누릅니다.
4. 완료되면 '카메라 프로파일'로 저장되어 다음부터는 앱을 열기만 해도 바로 연결됩니다. 여러 대의 카메라와 여러 네트워크를 저장할 수 있고, 앱 업데이트 후에도 **다시 페어링할 필요가 없으며**, 카메라 IP가 바뀌어도 자동으로 찾습니다.

> 카메라에 '이미 다른 장치와 페어링되었습니다'라고 표시되면 해당 카메라 네트워크 설정을 다른 앱이 사용 중이라는 뜻입니다. 카메라에서 새 연결 설정을 추가한 뒤 다시 페어링하세요.

📷 스크린샷: 카메라 추가 마법사 및 인증 번호 화면

### 연결 전 자동 점검
- '수신 시작'을 누르거나 앨범, 원격 촬영에 들어갈 때 앱이 먼저 네트워크 상태를 확인합니다. 프로파일이 '휴대폰 핫스팟'인데 핫스팟이 꺼져 있거나, '동일 Wi‑Fi'인데 해당 Wi‑Fi에 연결되어 있지 않으면 노란색 안내 배너(예: '먼저 휴대폰 핫스팟을 켜주세요')와 함께 '핫스팟 설정', 'Wi‑Fi 설정' 버튼이 나타납니다. 켠 뒤 AeroCam으로 돌아오면 배너가 사라집니다.
- Wi‑Fi와 핫스팟 모두에서 카메라를 찾지 못하면 홈 화면에 '네트워크에서 카메라를 찾을 수 없음'이 표시됩니다. 대부분 카메라의 'PC에 연결'이 켜져 있지 않은 경우이며, 옆의 '연결 가이드 보기'를 눌러 확인할 수 있습니다.

### 카메라의 '연결 유형'(Connection type)
최신 기종(Z9, Z8, Z6III, Zf, Z5II, Z50II…): **MENU → 네트워크 메뉴 → PC에 연결 → 연결 유형**
- **화상 전송**(Image transfer): 자동 수신, 카메라 메모리 카드 탐색용.
- **카메라 제어**(Camera control): 원격 촬영, 카드 없이 촬영용.

모드를 바꾸면 카메라 Wi‑Fi가 잠시 끊겼다가 AeroCam이 자동으로 다시 연결하므로 재페어링이 필요 없습니다. 카메라가 '화상 전송' 상태일 때 원격 촬영에 들어가면 앱이 전환 방법을 안내해 줍니다.

## USB 케이블
Wi‑Fi보다 빠르고 안정적이며, **페어링이 필요 없고** 미리 카메라를 추가하지 않아도 됩니다.
1. 카메라 USB 설정을 **MTP/PTP**로 선택합니다('iPhone'이나 'UVC/UAC'로 두지 마세요).
2. **데이터 전송이 가능한** USB‑C 케이블을 사용합니다(일부 케이블은 충전 전용입니다). 5Gbps / 10Gbps 표기가 있는 USB 3 케이블이 더 빠릅니다.
3. 홈 화면 USB 카드에 'Z f 감지됨 · 액세스 권한 필요'가 뜨면 '액세스 허용'을 누르고 Android 권한 창을 한 번 승인합니다.

### USB 카드 색상
| 색상 | 의미 |
|---|---|
| ⚪ 회색 | 카메라 없음(또는 충전 전용 케이블) |
| 🟠 주황 | 카메라가 감지되었으며 액세스 권한 허용이 필요함 |
| 🔴 빨강 | USB 설정이 MTP/PTP가 아니거나 권한 거부됨, 또는 테스트 실패(원인 표시) |
| 🟢 초록 | USB 케이블로 연결됨 |

### 케이블 연결 중 동작
- 앨범, 원격 촬영, 자동 수신이 모두 **자동으로 USB 경로로 전환**되며, 케이블을 뽑으면 자동으로 Wi‑Fi로 돌아갑니다. Wi‑Fi 원격 촬영 도중 케이블을 꽂아도 바로 USB로 전환됩니다(인터벌 촬영, 브라케팅, 벌브 노출 진행 중에는 전환되지 않음).
- **USB 수신**(Pro): USB 카드의 '수신 시작'을 누르면 새로 찍은 사진과 카메라에서 'PC로 전송'한 사진이 휴대폰에 저장됩니다. 기본값은 케이블을 꽂으면 자동 시작입니다(**설정 → 촬영 → 'USB 케이블 연결 시 자동 수신 시작'**).
- **시간 동기화**: 케이블을 꽂을 때 카메라 시계를 한 번 동기화합니다(2초 이상 차이가 날 때만 수정하며, 1일 이상 차이가 나면 먼저 물어봅니다).
- **절전 방지**: 앨범이나 원격 촬영을 열어 둔 동안 10초마다 작은 신호를 보내 카메라가 잠들지 않게 유지합니다. 30분간 조작이 없거나 카메라 배터리가 부족하면 중지됩니다.
- USB 연결 중 휴대폰에서 카메라로 전원이 공급될 수 있으므로 장시간 사용 시 보조배터리 연결을 권장합니다.
- **USB 테스트**(USB 카드 오른쪽 위 ⋮): 연결 상태, 카메라 정보, 메모리 카드, 라이브 뷰 프레임 레이트, 읽기 속도를 테스트합니다.

📷 스크린샷: USB 카드
