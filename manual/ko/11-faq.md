# 11. 자주 묻는 질문 및 문제 해결

## 일반
**Pro로 업그레이드하지 않아도 카메라 사진을 휴대폰으로 옮길 수 있나요?**
네, 가능합니다. 무료 버전에서도 Bluetooth로 약 200만 화소 축소판 JPEG를 자동 수신할 수 있고, USB 케이블을 연결해 카메라 앨범에서 원본 파일을 직접 골라 다운로드할 수 있습니다.

**Beta나 테스트 키는 유료인가요?**
아니요, 무료입니다. GitHub의 AeroCam-Releases에서만 무료로 배포합니다. 누군가 비용을 요구한다면 공식 경로가 아닙니다.

**앱을 열면 '공식 버전이 아닙니다'라고 뜹니다**
제3자가 다시 패키징한 비공식 앱으로, 테스트 키가 작동하지 않으며 악성 코드가 들어 있을 수 있습니다. 앱을 삭제한 뒤 AeroCam-Releases에서 다시 다운로드하세요.

**업데이트 후 등록된 카메라와 테스트 키가 사라졌습니다**
92.03.09 버전부터 새 빌드는 별도의 앱으로 설치되므로 구버전 데이터가 이전되지 않습니다. 카메라를 다시 페어링하고 테스트 키를 새로 입력해 주세요.

**사진은 어디에 저장되나요?**
사진은 `Pictures/AeroCam`, 동영상은 `Movies/AeroCam`, 기타 파일은 `Download/AeroCam`에 저장되며 Google 포토 등 다른 앱에서도 보입니다. 92.03.09 이전 구버전에서 저장된 파일은 기존 폴더에 그대로 남아 있으며 이동되지 않습니다.

**휴대폰에서 지운 사진을 다시 전송받고 싶습니다**
카메라에서 해당 사진을 다시 전송하면 앱이 휴대폰에 파일이 없음을 인식하고 새로 저장합니다.

**휴대폰 휴지통에서 복원하거나 앱 재설치 후 앨범에 사진이 안 보입니다**
**설정 → 저장 공간 및 배터리 → '휴대폰 사진 다시 스캔'**을 실행하세요.

## 연결
**Wi‑Fi로 카메라에 계속 연결되지 않습니다**
1. 카메라가 'PC에 연결' 화면에 머물러 있고 화면에 Wi‑Fi 아이콘이 떠 있는지 확인하세요(화면이 꺼졌으면 반셔터로 깨움).
2. 연결 유형이 맞는지 확인하세요: 자동 수신, 앨범 = 화상 전송 / 원격 촬영, 카드 없이 촬영 = 카메라 제어.
3. 휴대폰 핫스팟 방식: 핫스팟이 켜져 있고 카메라가 해당 핫스팟에 연결되어 있는지 확인하세요.
4. 동일 Wi‑Fi 방식: 휴대폰과 카메라가 같은 Wi‑Fi 이름에 연결되어 있는지 확인하세요(휴대폰이 다른 Wi‑Fi나 모바일 데이터로 자동 전환되는 경우가 있음).
5. 핫스팟이나 공유기가 필요 없는 **원탭 연결**을 사용해 보세요.
6. **ⓘ**를 눌러 연결 가이드를 처음부터 차근차근 따라 해 보세요.

**호텔이나 전시장 Wi‑Fi에서 카메라를 전혀 찾지 못합니다**
공용 Wi‑Fi는 보통 기기 간 통신을 차단합니다. 휴대폰 핫스팟이나 원탭 연결을 사용하세요.

**카메라에 '이미 다른 장치와 페어링되었습니다'라고 표시됩니다**
해당 카메라 네트워크 설정이 다른 앱과 연결되어 있습니다. 카메라에서 새 네트워크 설정을 추가한 뒤 다시 페어링하세요.

**원탭 연결에서 카메라 Wi‑Fi를 찾지 못합니다**
카메라가 Bluetooth 명령을 받은 뒤 자체 Wi‑Fi를 켜는 데 10~30초가 걸리며 앱이 자동으로 재시도합니다. 계속 실패하면 카메라 Wi‑Fi 비밀번호가 맞는지 확인하세요.

**핫스팟이 자꾸 꺼집니다**
일부 휴대폰은 연결된 기기가 인터넷 데이터를 쓰지 않으면 핫스팟을 자동으로 끕니다. 휴대폰 핫스팟 설정에서 '자동으로 핫스팟 끄기'를 끄거나 원탭 연결을 사용하세요.

**핫스팟을 껐다 켠 뒤 카메라가 다시 연결되지 않습니다**
휴대폰 핫스팟의 IP 주소가 바뀌었을 수 있습니다. Wi‑Fi 자동 수신은 앱이 알아서 다시 찾지만, FTP는 카메라에 입력한 서버 주소를 새로 맞춰 주어야 합니다.

**USB 케이블을 꽂아도 반응이 없습니다**
1. 카메라 USB 설정이 **MTP/PTP**인지 확인하세요.
2. 데이터 전송이 가능한 케이블인지 확인하세요(충전 전용 케이블 불가).
3. 휴대폰에 '액세스 허용' 팝업이 뜨면 허용을 누르세요.
4. USB 카드 오른쪽 위 `⋮` → **USB 테스트**에서 어느 단계가 실패하는지 확인하세요.

**백그라운드 수신이 자주 끊깁니다**
**설정 → 저장 공간 및 배터리**에서 배터리 최적화를 끄세요. Xiaomi, OPPO 등 일부 기기는 시스템 설정에서도 AeroCam을 '배터리 사용 제한 없음'으로 설정해야 합니다.

## Bluetooth
**Bluetooth 사진 전송이 중간에 멈춥니다**
- RAW로 촬영한 경우 카메라가 먼저 JPEG로 변환한 뒤 전송하며, 전송 중 카메라를 조작하면 전송이 취소됩니다. 촬영 후 바로 카메라 전원을 꺼 두면 백그라운드에서 안정적으로 전송됩니다.
- Bluetooth 카드의 **연결 끊고 다시 연결** 또는 **⋮ → Bluetooth 서비스 재시작**을 누르세요(페어링은 유지됨).

**Bluetooth 리모컨에서 AF 버튼을 눌러도 초점이 잡히지 않습니다**
카메라가 반셔터 초점을 허용하도록 설정되어 있어야 합니다. AF‑ON 버튼을 주로 사용하시는 분은 카메라 사용자 설정에서 **AF 작동**(AF activation)이 **셔터/AF-ON**으로 켜져 있는지 확인하세요.

**Bluetooth와 Wi‑Fi로 같은 사진을 받으면 두 장이 저장되나요?**
기본값으로는 한 장만 남습니다. Wi‑Fi로 원본을 받으면 Bluetooth 축소판은 자동 삭제됩니다. **설정 → 수신 및 알림 → 'Bluetooth로 이미 받은 사진'**에서 바꿀 수 있습니다.

## 원격 촬영
**셔터 속도나 ISO가 조절되지 않습니다**
- 셔터 속도는 S/M 모드, 조리개는 A/M 모드에서만 조절되며, ISO를 수동으로 바꾸려면 먼저 자동 ISO를 꺼야 합니다.
- Zf 등 물리 다이얼이 있는 기종은 셔터 속도 다이얼을 **1/3 STEP**, ISO 다이얼을 **C**로 돌려 두세요.

**화면을 터치해도 초점 포인트가 움직이지 않습니다**
카메라의 AF 영역 모드를 초점 이동이 가능한 모드(싱글 포인트 AF 등)로 선택하세요. 자동 영역 AF에서는 카메라가 자동으로 초점을 결정합니다.

**홈 화면 대시보드에 일부 항목(렌즈, 남은 매수, 셔터 카운트)이 안 보입니다**
일부 정보는 특정 모드에서만 카메라가 제공하므로 '카메라 제어'로 전환한 뒤 원격 촬영에 들어가면 읽어 올 수 있습니다. 셔터 카운트는 메모리 카드에 사진이 최소 한 장 있어야 표시됩니다.

**색온도(K 값)는 어디서 보나요?**
Nikon은 실제 측정된 색온도를 사진 내부에 암호화된 형식으로만 기록하므로 '상세 정보'에는 화이트 밸런스 설정 모드만 표시됩니다.

## 저장 위치 및 카드 없이 촬영
**카메라에 카드가 없을 때 셔터를 눌러도 반응이 없습니다**
카메라의 **슬롯이 비었을 때 릴리즈 잠금**이 **릴리즈 허용**으로 되어 있는지, 그리고 AeroCam이 연결되어 상태 표시줄에 '휴대폰에만 저장'이 뜨는지 확인하세요.

**사진에 'DEMO' 표시가 뜹니다**
카메라에 카드가 없고 AeroCam의 '휴대폰에만 저장' 수신도 연결되지 않은 상태에서 촬영하면 카메라가 사진을 'DEMO'로 표시하고 저장하지 않습니다. 카드를 꽂거나 AeroCam을 연결한 상태로 촬영하세요.

**사진이 휴대폰으로 들어오지 않고 홈 상단에 빨간 배너가 뜹니다**
- '카메라가 "화상 전송" 모드입니다' 표시: 카드 없이 촬영은 **카메라 제어** 모드를 써야 합니다. 전환하면 카메라가 다시 연결되면서 이미 찍은 사진이 자동 전송됩니다.
- '원탭 Wi‑Fi: 메모리 카드가 없습니다' 표시: 원탭 연결은 카드 없이 촬영을 지원하지 않으므로 카드를 꽂거나 핫스팟 / 동일 Wi‑Fi를 사용하세요.

**'연결 끊김' 알림이 뜹니다**
휴대폰에만 저장 모드에서 연결이 10초 이상 끊어지면 알림을 띄웁니다. 끊긴 동안 찍은 사진은 메모리 카드에 저장되지 않으며, 다시 연결되면 앱이 자동으로 복구합니다.

## 편집 및 스타일
**NEF가 열리지 않거나 편집할 수 없습니다**
고효율 / 고효율★ 압축 NEF는 내장된 원본 해상도 JPEG를 꺼내 편집하며, 작은 미리보기 이미지만 있는 파일은 편집할 수 없습니다. 휴대폰에서 직접 RAW 현상을 하려면 카메라를 **무손실 압축**으로 설정하세요 — [제6장](06-edit.md#휴대폰에서-편집-가능한-raw카메라-raw-압축-방식-전환) 참고.

**.np3 적용 색감이 카메라와 다릅니다**
휴대폰에서는 톤 커브와 채도를 시뮬레이션하며 컬러 블렌더와 컬러 그레이딩은 아직 미지원이라 근사치로 표현됩니다. 또한 JPEG 촬영 시 이미 카메라 스타일이 입혀진 사진에 적용하면 효과가 중첩됩니다.

**.np3를 카메라에 기록한 뒤 색감이 다르게 나옵니다**
카메라 커스텀 슬롯은 **기본 + 커브 + 샤프닝**만 받아들이며 채도, 컬러 블렌더, 컬러 그레이딩은 연결을 통해 기록되지 않습니다. 100% 동일한 효과를 원하면 메모리 카드에 `.np3`를 넣어 카메라 메뉴에서 불러오세요.

**파노라마 스티칭이 실패하거나 몇 장이 빠집니다**
각 사진이 인접한 사진과 약 30% 정도 겹쳐야 합니다. 이어지지 않은 사진은 파일명이 표시되며, 격자 파노라마는 한 칸이라도 빠지면 출력되지 않습니다.

## FTP
**카메라에 Err.31 또는 Err.32가 표시됩니다**
최신 Beta로 업데이트한 뒤 카메라에 입력한 주소, 포트 `2121`, 사용자 이름 `aerocam`, 비밀번호가 모두 정확한지, 그리고 패시브 모드가 켜져 있는지 확인하세요.

**카메라에 로그인 실패가 뜹니다**
비밀번호는 AeroCam FTP 화면에 표시된 것과 대소문자까지 정확히 일치해야 합니다. '비밀번호 다시 생성'을 눌렀다면 카메라 쪽 설정도 함께 수정하세요.

**FTP를 켜 둔 상태에서 앨범이나 원격 촬영이 연결되지 않습니다**
카메라가 FTP 모드일 때는 앨범과 원격 촬영용 Wi‑Fi 연결을 지원하지 않습니다. USB 케이블을 연결하거나 FTP 수신을 중지한 뒤 카메라를 'PC에 연결'로 되돌리세요.

## 기타
**앱이 강제 종료(크래시)됩니다**
앱을 다시 연 뒤 **설정 → 지원 → '진단 정보 복사'**를 눌러 [문제 신고](12-report.md) 시 붙여넣어 주세요. 마지막 비정상 종료 오류 위치가 포함되어 있습니다.

**익명 사용 통계는 어떻게 끄나요?**
**설정 → 지원 → '익명 사용 통계 전송'**을 끄면 됩니다 — [개인정보 보호 및 익명 통계](10-privacy.md) 참고.
