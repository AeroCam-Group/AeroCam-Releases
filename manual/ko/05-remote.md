## 원격 촬영(Pro)
휴대폰으로 카메라의 라이브 뷰 화면을 보면서 화면을 터치해 초점을 맞추고 설정을 조절하며 사진과 동영상을 촬영합니다. **Wi‑Fi와 USB 모두 지원**하며, USB 케이블을 꽂으면 자동으로 USB로 전환됩니다.

**필요 조건**
1. 메뉴에 '연결 유형'이 있는 카메라 기종([지원 카메라](README.md#지원-카메라) 참고).
2. Wi‑Fi 연결 시 카메라의 '연결 유형'을 **카메라 제어**로 전환해야 합니다([카메라 연결하기](02-connect.md#카메라의-연결-유형connection-type) 참고). 아직 '화상 전송' 상태라면 앱이 전환 절차를 안내하며, 변경 후 자동으로 다시 연결됩니다.

원격 촬영은 전체 화면으로 실행되어 하단 탭이 숨겨지며, 왼쪽 위의 **←** 또는 휴대폰 뒤로가기 버튼을 누르면 홈으로 돌아갑니다.

📷 스크린샷: 원격 촬영 화면(세로, 가로)

### 화면 구성
| 위치 | 내용 |
|---|---|
| 상단 | 카메라 설정: 노출 모드, 셔터 속도, 조리개, ISO, 자동 ISO, 노출 보정, 화이트 밸런스, 초점 모드, AF 영역, 측광, Picture Control, 화질. 세로 모드에서는 2줄, 가로 모드에서는 1줄(좌우 스크롤 가능) |
| 상단 세 번째 줄 | 뒤로가기, 동영상 녹화, 클린 화면, 화면 잠금, 저장 위치, 배터리 잔량 |
| 중앙 | 라이브 뷰 화면(크롭 없는 전체 화면), 초점 프레임, 수평계, 노출계 등이 위에 겹쳐 표시됨 |
| 하단 | 사용자 지정 가능한 6개 빠른 토글 + '더보기' |
| 맨 아래 | '촬영'(촬영 방식 선택), 셔터 버튼, AF 버튼, 최신 사진 썸네일 및 남은 촬영 가능 매수 |

휴대폰을 가로로 돌리면 빠른 토글은 왼쪽 검은 여백으로 이동하고 셔터 버튼은 오른쪽 아래에 배치됩니다. **왼손 모드**(설정 → 촬영)를 켜면 셔터 버튼이 왼쪽 아래로 이동합니다.

### 카메라 설정 조절
상단의 수치를 누르면 라이브 뷰를 가리지 않도록 아래쪽에 조절 바가 나타납니다.
- 노출 모드는 표시 전용입니다(P / S / A / M 전환은 카메라에서 조작). 셔터 속도는 S, M에서 조절 가능하고 조리개는 A, M에서 조절 가능합니다.
- 자동 ISO가 켜져 있으면 ISO에 `AUTO`가 표시됩니다. 노출 보정 옆에는 한 번에 0으로 되돌리는 `0` 버튼이 있습니다.
- 화이트 밸런스에서 `K`를 선택하면 색온도를 세밀하게 조절할 수 있습니다. Picture Control에는 사용자 지정 이름을 포함해 카메라에 설정된 이름이 표시됩니다.
- **조절할 수 없는 설정**은 그 이유를 안내해 줍니다. Zf, Zfc처럼 물리 다이얼이 있는 기종은 셔터 속도 다이얼을 **1/3 STEP**으로, ISO 다이얼을 **C**로 돌려 두세요.

### 초점 및 셔터
- **화면 터치 초점**: 원하는 곳을 터치하면 그 위치에 초점을 맞춥니다. 카메라의 AF 영역 모드를 초점 포인트를 이동할 수 있는 모드(싱글 포인트 AF 등)로 설정해 두세요. 자동 영역 AF에서는 카메라가 자동으로 결정합니다.
- 화면에 카메라의 실제 초점 프레임이 그려지며(싱글 포인트, 다이내믹 영역, 자동 영역, 추적 모두 표시), 초점이 맞으면 초록색, 실패하면 빨간색으로 변합니다.
- **셔터 버튼**: 한 번 누르면 바로 촬영합니다. **길게 누르기 = 반셔터 초점**(테두리가 초록색으로 변함), 손을 떼면 촬영됩니다.
- **AF 버튼**: 현재 초점 위치에서 다시 초점을 잡습니다.
- **촬영 전 초점**(기본 켜짐): 끄면 AF를 기다리지 않고 셔터를 누르는 즉시 촬영되므로 수동 초점이나 미리 초점을 맞춰 둔 상황에서 빠르게 찍을 수 있습니다.
- **터치 촬영**: 켜 두면 미리보기 화면을 터치할 때 해당 지점에 초점을 맞추고 바로 한 장 촬영합니다.
- 화면 좌우 가장자리(Android 뒤로가기 제스처 영역) 터치는 초점 이동을 무시하므로 스와이프 뒤로가기 시 오작동하지 않습니다.

### 하단 빠른 토글(사용자 지정 가능)
기본값은 피킹, 지브라, 수평계, 그리드, 확대와 빈 슬롯 하나이며, 맨 오른쪽은 '더보기'로 고정되어 있습니다.
- **한 번 탭**하면 켜거나 끄고, **0.5초 길게 누르면** 세부 옵션(피킹 감도, 지브라 임계값, 그리드 종류, 확대 배율)이 열립니다.
- **사용자 지정**: '더보기' 오른쪽 위의 톱니바퀴 아이콘에서 바꿀 수 있습니다. 배치 가능 항목: 피킹, 지브라, 수평계, 그리드, 확대, 히스토그램, 노출계, 터치 촬영, 촬영 전 초점, 휴대폰으로 복사, 스크린샷, 별밤 모드, 라이브 미리보기, 셀프 타이머.

### '더보기' 서랍 메뉴
'더보기'는 반투명 서랍 패널(세로 화면에서는 아래에서, 가로 화면에서는 옆에서 열림)로, 구도 화면이 항상 보입니다. 세 개의 탭으로 나뉩니다:
- **보조 도구**: 라이브 미리보기, 피킹, 노출 과다 경고(지브라), 수평계, 구도선, 히스토그램, 노출계, 확대 초점, 별밤 모드.
- **촬영**: 촬영 전 초점, 터치 촬영, AF 영역, 촬영할 때마다 휴대폰으로 복사, 미리보기 스크린샷.
- **도구**: 고스트 오버레이, 다중 촬영 체크리스트, 팁.

### 촬영 보조 도구(휴대폰 화면에만 표시되며 실제 사진에는 저장되지 않음)
| 기능 | 설명 |
|---|---|
| 수평계 | 카메라의 기울기 센서를 읽어 오차가 0.5° 미만이면 초록색으로 바뀌며 좌우 기울기와 앞뒤 앙각을 표시합니다 |
| 히스토그램 | 누를 때마다 '휘도 + RGB 오버레이'와 'RGB 분리 표시' 간에 전환됩니다 |
| 지브라(노출 과다 경고) | 밝기가 기준치를 넘는 영역에 빗금을 표시합니다. 기준치 85 / 90 / 95 / 100%(기본 95%) |
| 초점 피킹 | 초점이 정확히 맞은 윤곽선에 색상을 입혀(빨강, 노랑, 파랑, 하양) 수동 초점을 돕습니다. 감도 낮음 / 중간 / 높음 선택 가능 |
| 노출계 | Nikon 뷰파인더와 같은 세로형 노출 표시기(1/3 EV 눈금). M 모드에서는 적정 노출과의 차이를, P / A / S 모드에서는 노출 보정값을 표시합니다 |
| 구도선 | 3분할, 4×4 분할, 황금비율, 황금나선, 대각선, 중앙 십자선 |
| 확대 | 카메라가 지원하는 경우(예: Zf) **카메라 자체에서 확대**하여 실제 픽셀을 확인합니다(50% / 100% / 200% / 400%). 화면 터치나 ◀ ▲ ▼ ▶ 버튼으로 위치를 옮기고 하단 `근거리 ◀◀ ◀ ▶ ▶▶ 원거리`로 수동 초점을 미세 조정할 수 있습니다. 미지원 카메라는 앱 디지털 확대(2× / 4× / 8×)를 사용합니다 |

> 라이브 뷰는 카메라에서 압축된 영상이므로 보조 도구는 참고용으로만 활용하고, 최종 노출은 촬영된 원본 사진의 히스토그램으로 확인하세요.

### 촬영 방식
셔터 옆의 **촬영**을 눌러 선택합니다. 선택하면 버튼이 노란색으로 바뀌고 셔터 위에 설정 바(예: `인터벌 촬영　5초마다 · 10장`)가 나타납니다. 설정 바를 누르면 세부 조절과 **시작** 버튼이 열리며, 옆의 ×를 누르면 일반 촬영으로 돌아갑니다. 실행 중에는 화면 상단에 진행 상황이 표시되고 **중지**를 눌러 언제든 멈출 수 있습니다.

| 촬영 방식 | 설정 | 설명 |
|---|---|---|
| 일반 촬영 | 매수 1~9 | 셀프 타이머와 함께 쓰면 카운트다운 후 약 1초 간격으로 연속 촬영합니다 |
| **셀프 타이머** | 끔, 2, 5, 10초 | '촬영' 메뉴 맨 윗줄에 있으며 모든 촬영 방식 및 동영상 녹화에 함께 쓸 수 있습니다. 화면 중앙에 큰 숫자가 표시되며 셔터를 다시 누르면 취소됩니다 |
| 벌브(Bulb) | 노출 시간 1~3600초 | 카메라를 M 모드로 두고 셔터 속도를 Bulb 또는 Time으로 설정해야 하며, 설정 시간이 지나면 자동 종료됩니다 |
| 인터벌 촬영(Interval timer shooting) | 매수 2~999, 간격 1~3600초 | 일정 간격으로 연속 촬영하며 총 소요 시간을 표시합니다. '촬영할 때마다 휴대폰으로 복사'와 함께 쓰면 타임랩스 확인이 편리합니다 |
| 노출 브라케팅 | 매수 3 / 5 / 7 / 9, 간격 0.3~3.0 EV | 현재 노출 보정값을 기준으로 단계별로 노출을 바꿔 찍은 뒤 원래 값으로 복원합니다 |
| 초점 시프트 촬영(Focus shift shooting) | 매수 2~300, 초점 스텝 폭 | 가장 가까운 피사체에 먼저 초점을 맞추면 앱이 한 장 찍을 때마다 원거리 방향으로 초점을 조금씩 이동합니다. AF 렌즈가 필요하며 심도 합성은 PC에서 진행합니다 |
| 파노라마 | 격자 수 또는 '자유' | 여러 장을 겹쳐 찍어 파노라마 사진으로 이어 붙입니다 — 아래 참고 |
| 흔들림 합성(노이즈 감소 합성) | 4장 또는 8장 | 손으로 들고 연사한 여러 장을 합성해 노이즈가 적은 한 장으로 만듭니다 — 아래 참고 |

> 다중 촬영 도구가 작동하는 동안에는 AF와 화면 터치 초점이 일시 중지됩니다. 원격 촬영 화면을 나가기 전에는 확인 창이 뜹니다.

#### 파노라마(스티칭)
- **격자 모드**: 격자 칸 수를 고르면 각 칸마다 카메라를 돌려야 할 각도를 계산해 주며, 사용자가 카메라를 돌려 셔터를 누릅니다. 패널에서 겹침 정도가 충분한지('촬영 가능 / 조금 더 회전 가능 / 겹침 부족 가능성') 알려주고 이전 사진의 가장자리를 반투명하게 겹쳐 보여 정렬을 돕습니다.
- **자유 모드**: 정해진 격자 없이 이전 사진과 약 30%씩만 겹치게 촬영하면 어느 방향이든 원하는 매수만큼 자유롭게 찍을 수 있습니다(최대 30장).
- 2장 이상 찍으면 **스티칭**을 눌러 휴대폰에서 바로 한 장의 큰 사진으로 합칠 수 있으며, 한 바퀴를 다 돌면 360° 파노라마로 출력됩니다. 촬영 시 기록된 수평계 데이터를 바탕으로 수평이 자동으로 맞춰집니다.
- 촬영된 사진들은 휴대폰 앨범의 같은 묶음(스택)에 정리되며 나중에 다시 스티칭할 수도 있습니다 — [제6장](06-edit.md#이미지-처리-파노라마-스티칭-및-노이즈-감소-합성pro) 참고.

#### 흔들림 합성(노이즈 감소 합성)
- 픽셀 시프트 기능이 없는 기종에서도 '다중 프레임 합성으로 화질 개선'을 구현합니다. 손으로 들고(또는 삼각대로) 4장 또는 8장을 연사하면 앱이 위치를 정밀하게 정렬해 평균 합성함으로써 디테일은 유지하면서 노이즈를 약 3분의 1(8장 기준)로 줄여 줍니다.
- 촬영이 끝나면 백그라운드에서 자동 합성되며('합성 중 %' 표시), 원본과 동일한 해상도 및 촬영 정보가 담긴 `SHAKE_<시간>.JPG` 파일로 저장됩니다.
- 움직이는 피사체(차량, 사람, 나뭇잎)는 가장 선명한 한 프레임만 사용하여 잔상(고스트)이 생기지 않으며, 너무 심하게 흔들린 사진은 자동으로 제외됩니다.
- 야경, 어두운 실내, 고감도 ISO 촬영에 매우 적합합니다.

### 고스트 오버레이(Pro)
**더보기 → 도구 → 고스트 오버레이**: 참고 이미지를 라이브 뷰 위에 **반투명 겹치기** 또는 **좌우 분할** 형태로 띄워 줍니다. 투명도 조절과 '현재 화면 캡처' 기능을 지원해 정위치 재촬영, 복사 촬영, 구도 맞추기에 유용합니다.

### 기타 기능
- **촬영할 때마다 휴대폰으로 복사**: 'RAW에서 JPEG만 저장'을 포함한 수신 규칙에 따라 자동 저장합니다.
- **최신 사진**: 오른쪽 아래 썸네일에 방금 찍은 사진과 실제 셔터 속도, 조리개, ISO가 표시되며, 누르면 이번 세션에서 촬영한 모든 사진을 보고 원본이나 JPEG를 휴대폰에 저장할 수 있습니다.
- **클린 화면**: 미리보기 영상만 남기고 모든 조작 버튼을 숨깁니다. 구석의 흐릿한 버튼을 누르면 다시 나타납니다. **화면 잠금**: 오작동을 방지하며 화면 아무 곳이나 길게 누르면 잠금이 해제됩니다.
- **동영상 녹화**: 상단 녹화 버튼을 누릅니다. 시작 전 카메라를 '애플리케이션 모드'로 전환하며(Zf 필수), 중지 후 원래대로 되돌립니다. 녹화할 수 없는 경우 원인을 안내합니다. USB 연결 시에는 [비디오 모니터](#비디오-모니터cine) 사용을 권장합니다.
- **미리보기 스크린샷**: 라이브 뷰 화면을 `Pictures/AeroCam/Snapshots/`에 저장합니다(미리보기 화질).
- **USB 원격 촬영**: Wi‑Fi보다 라이브 뷰가 훨씬 부드러우며(기본 30 fps, 60 fps 또는 무제한으로 조절 가능), 고해상도 미리보기와 오른쪽 아래 실시간 프레임 레이트 표시를 지원합니다. **설정 → 촬영**에서 조절할 수 있습니다.
- 원격 촬영 중에는 기본값으로 화면이 항상 켜져 있습니다.

## Bluetooth 리모컨(무료)
Wi‑Fi가 필요 없으며 라이브 뷰 화면은 표시되지 않습니다. 홈 화면 Bluetooth 카드 → **Bluetooth 리모컨**으로 들어갑니다. 먼저 [Bluetooth 페어링](02-connect.md#페어링)이 완료되어 있어야 합니다.
- 셔터를 한 번 누르면 1장 촬영하고, 길게 누르면 카메라 자체 연사(CL / CH)가 작동합니다.
- AF를 누른 상태에서 셔터를 연타하면 빠르게 연속 촬영할 수 있으며, 3장 / 5장 연사 버튼도 있습니다.
- AF 버튼: 길게 눌러 초점을 맞춥니다. 카메라에서 반셔터 AF가 허용되어 있어야 합니다(AF‑ON 버튼을 주로 쓰는 분은 카메라 사용자 설정을 확인하세요).
- 셀프 타이머(카운트다운), 동영상 녹화 시작/중지, 남은 촬영 가능 매수를 지원합니다.
- **인터벌 촬영**은 Pro 기능입니다.

## 비디오 모니터(Cine)
휴대폰을 전문 동영상 촬영용 필드 모니터로 활용합니다. USB를 연결하면 홈 화면 USB 영역에 **🎥 비디오 모니터**가 표시되며(가장 부드럽고 최대 약 60 fps 지원), Wi‑Fi 버전은 홈 화면 Wi‑Fi 영역에서 실험 기능으로 제공됩니다.
- Zf는 카메라의 사진/동영상 셀렉터를 **동영상**으로 돌려 두어야 합니다.
- **상단 바**: `● REC` 녹화 시간, 동영상 규격(예: `1080 60p`, 누르면 변경 가능), 파일 형식(예: `H.265 10bit`, N‑Log 촬영 시 H.265 10비트 선택 필수), 남은 녹화 가능 시간, 배터리 잔량.
- **하단 바**: 동영상 전용 셔터 속도, 조리개, ISO, 자동 ISO, 노출 보정, 화이트 밸런스, 초점 모드, 측광(동영상 ISO는 M 모드에서만 작동).
- **녹화 버튼**: 녹화 중에는 오작동 방지를 위해 **1초간 길게 눌러야**(빨간 링이 한 바퀴 채워질 때까지) 녹화가 중지됩니다. 녹화 중 뒤로가기를 누르면 확인 창이 뜹니다.
- **모니터링 도구**: 노출계, 히스토그램, 파형(Waveform) / RGB 퍼레이드, 폴스 컬러(False Color), 지브라(피부 톤용 2단계 지브라 포함), 초점 피킹, 구도선, 세이프 프레임, 화면비 마스크(`2.39:1`, `1.85:1`, `16:9`, `9:16`, `4:5`), 탈리(Tally) 빨간 테두리, 셔터 앵글 표시.
- **LUT**(Android 13 이상): 미리보기 화면에 모니터링 LUT(기본 내장 N‑Log → 표준 변환 및 `.cube` 파일 불러오기 지원)를 입혀 볼 수 있으며 실제 녹화 영상에는 저장되지 않습니다. 이중 적용을 피하려면 카메라의 **뷰 어시스트**(View assist)를 꺼 주세요.
- **아나모픽 디스퀴즈**(`1.33x`~`2.0x`), **A/B 랙 포커스**(두 초점 지점을 지정해 부드럽게 초점 이동), **고스트 오버레이**.
- 녹화 중에는 초점 이동이 영상에 찍히는 것을 막기 위해 화면 터치 초점이 기본 비활성화되어 있으며, 메뉴에서 켤 수 있습니다.
- **스크린샷**: '미리보기 스크린샷'은 영상만 저장하고, '스크린샷(보조 도구 포함)'은 LUT, 지브라, 폴스 컬러, 화면비 마스크까지 함께 저장합니다.

## 별밤 모드(무료)
천체 촬영 시에는 눈이 어둠에 적응해야 하므로 흰 화면 불빛에 동공이 수축되는 것을 막아야 합니다. 별밤 모드는 앱 전체 화면을 어두운 붉은색으로 바꿉니다.
1. 켜기: **설정 → 화면 및 언어 → 테마 → '별밤(적색광)'**을 선택하거나, 원격 촬영 하단 빠른 토글 또는 **더보기 → 보조 도구**에서 '별밤 모드'를 켭니다.
2. 더 어둡게 하려면: **앱 화면 밝기 최소로 낮추기**를 켭니다.
3. 사진의 실제 색상을 보려면: **'길게 눌러 원래 색상 보기'를 누르고 있는 동안** 원래 색으로 보이고, 손을 떼면 다시 붉은 화면으로 돌아옵니다. 원격 촬영, 비디오 모니터, 사진 크게 보기 화면에 이 버튼이 있습니다.
4. 별밤 모드는 화면 표시 색상만 바꿀 뿐 저장되는 사진 자체에는 영향을 주지 않습니다. QR Code 공유 시에는 상대방이 스캔할 수 있도록 일시적으로 원래 색상으로 돌아옵니다.
