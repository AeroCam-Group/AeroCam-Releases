# 8. FTP 수신(Pro)

카메라로 사진을 찍자마자 **카메라가 직접 FTP로 휴대폰에 사진을 밀어 넣어 주므로**, 카메라에서 사진을 고르거나 앨범을 열어 둘 필요가 없습니다. Nikon Zf 실측 기준 RAW 한 장(약 18 MB)이 약 1초 만에 휴대폰에 도착합니다.

AeroCam 자체가 FTP 서버 역할을 하므로 **별도의 서버를 구축할 필요가 전혀 없습니다.**

## 추천 상황
- 행사, 웨딩, 스포츠 촬영: 찍는 즉시 실시간으로 사진을 휴대폰에 받아야 할 때.
- 촬영 직후 휴대폰 큰 화면에서 바로 결과물을 확인하거나 SNS에 올리고 싶을 때.

## 준비 사항
- 내장 FTP 업로드 기능을 지원하는 카메라(Nikon Z f, Z 8, Z 9, Z 6III 등).
- 휴대폰에서 **모바일 핫스팟**을 켜고 카메라를 해당 핫스팟에 연결(또는 휴대폰과 카메라를 같은 공유기에 연결).
- 카메라에 메모리 카드가 삽입되어 있어야 합니다(FTP는 메모리 카드에 기록된 파일을 전송함).

## 처음 설정하기
1. 휴대폰 핫스팟을 켭니다.
2. AeroCam 홈 화면 **FTP** → 맨 위 **수신 시작**을 누릅니다. 카메라에 입력해야 할 설정값이 표시되며 각 항목을 누르면 바로 복사됩니다:
   - 서버 주소(예: `10.14.29.30`)
   - 포트: `2121`
   - 사용자 이름: `aerocam`
   - 비밀번호: 앱이 생성한 8자리 비밀번호('다시 생성' 가능)
   - 패시브 모드(PASV): **켜짐**
3. 카메라: **MENU → 네트워크 메뉴 → FTP 서버에 연결 → 네트워크 설정 → 프로파일 작성**:
   - Wi‑Fi는 휴대폰 핫스팟을 선택합니다.
   - 서버 유형에서 `FTP`를 고르고 위의 주소, 포트, 사용자 이름, 비밀번호를 입력한 뒤 패시브 모드를 켭니다.
4. 카메라에서 이 FTP 연결을 활성화합니다. AeroCam의 FTP 상태가 '연결됨'으로 바뀌면 설정이 완료됩니다.
5. 카메라의 FTP 메뉴에서 **촬영 후 자동 전송**(Auto send)을 켜면 이후 셔터를 누를 때마다 자동으로 전송됩니다.

설정이 헷갈릴 때는 FTP 카드 옆의 **ⓘ**를 누르면 그림 가이드를 볼 수 있습니다.

## 사용 중 안내
- 상태 표시등: 꺼짐, 실행 중 · 카메라 대기 중, 연결됨, 수신 중, 오류.
- 상단 알림바에 'FTP 수신 중 · N장 수신됨'과 함께 현재 파일명 및 전송 속도가 표시됩니다.
- 사진은 **설정 → 수신 및 알림**의 규칙(폴더, 파일명, JPEG만 수신, RAW에서 JPEG만 저장 등)에 따라 저장되며 기록에는 출처가 `FTP`로 남습니다.
- 전송 도중 연결이 끊기거나 카메라 전원이 꺼지면 덜 받아진 불완전한 파일은 자동 삭제되어 앨범에 깨진 파일이 남지 않습니다.
- 카메라 전원을 끄면 약 1분 안에 미연결 상태로 바뀌며, 다시 전원을 켜서 접속하면 자동으로 수신을 이어갑니다.
- **유휴 자동 종료**: **설정 → 수신 및 알림 → 'FTP 사진 미수신 시 자동 종료'**(자동 종료 안 함, 5, 10, 30분). 마지막 사진을 받은 시점부터 계산하며 전송 중에는 꺼지지 않고, 종료 시 알림을 보냅니다.

## 주의 사항
- **핫스팟을 계속 켜 두세요.** 일부 휴대폰은 인터넷 데이터 사용이 없으면 핫스팟을 자동으로 끄므로, 휴대폰 핫스팟 설정에서 '자동으로 핫스팟 끄기'를 해제해 주세요.
- 핫스팟을 껐다 다시 켜면 휴대폰 IP 주소가 바뀔 수 있으니 카메라에 입력된 주소와 일치하는지 확인하세요.
- FTP 수신과 **Wi‑Fi 자동 수신은 동시에 켤 수 없으며**, 한쪽을 켜면 다른 쪽은 자동으로 중지됩니다.
- FTP가 켜져 있는 동안 카메라는 FTP 모드로 동작하므로 **앨범과 원격 촬영을 Wi‑Fi로 연결할 수 없습니다.** 사용하려면 USB 케이블을 꽂거나 FTP 수신을 중지한 뒤 카메라를 'PC에 연결' 모드로 되돌리세요.
- FTP 서버는 핫스팟이나 로컬 Wi‑Fi 내부 네트워크에서만 열리며 외부 인터넷에는 절대 노출되지 않습니다.
- '원탭 연결'은 FTP와 함께 쓸 수 없습니다(원탭 연결은 카메라가 자체 Wi‑Fi를 여는 방식이고, FTP는 카메라가 휴대폰 네트워크에 접속해야 하기 때문).

## NAS로 직접 전송하기
카메라의 FTP 설정에 집 NAS 주소를 직접 입력하면 휴대폰을 거치지 않고 NAS로 바로 보낼 수도 있습니다. 이는 카메라 자체 기능으로 AeroCam이 필요하지 않습니다.
