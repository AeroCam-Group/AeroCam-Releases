# AeroCam 사용 설명서(한국어)

> **Beta 92.04.08.10**(2026-11-15 업데이트) 기준입니다. 📷 표시가 있는 줄은 추후 스크린샷이 추가될 자리입니다.

AeroCam은 카메라로 찍은 사진을 Android 휴대폰으로 바로 전송하는 앱입니다. 휴대폰에서 카메라를 원격 제어하고, 사진을 편집하며, 커스텀 스타일을 카메라에 직접 저장할 수도 있습니다. 현재 **Nikon Z 시리즈**를 지원하며, 추후 더 많은 브랜드를 지원할 예정입니다.

AeroCam은 독립적으로 개발된 서드파티 앱이며, Nikon 및 기타 카메라 제조사와 어떠한 제휴나 승인 관계도 없습니다.

## 지원 카메라

| 기종 | 자동 수신, 카메라 앨범 | 원격 촬영 | 상태 |
|---|---|---|---|
| Z9, Z8, Z6III, Zf, Z5II, Z50II, ZR 등 메뉴에 '연결 유형'(Connection type)이 있는 기종 | ✅ | ✅ | Zf 실기 테스트 완료, 기타 기종 제보 환영 |
| Z6, Z7, Z6II, Z7II, Z5, Z50, Zfc, Z30 등 이전 기종 | ✅ | ❌(해당 기종의 연결 방식 미지원) | 제보 환영 |
| Canon, Sony, Fujifilm | 준비 중 | 준비 중 | |

다른 기종으로 테스트해 보셨다면 [기종 제보](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose)를 통해 어떤 기능이 작동하고 어떤 기능이 안 되는지 알려주세요.

## 필요 사항
- Android 10 이상의 스마트폰.
- Nikon Z 시리즈 카메라.

## 용어 안내
| 본 설명서의 용어 | 의미 |
|---|---|
| 카메라 앨범 / 카메라 메모리 카드 | 연결을 통해 휴대폰에서 카메라 메모리 카드의 사진을 탐색하는 기능 |
| 휴대폰 앨범 | 이미 휴대폰에 저장된 사진 |
| RAW | Nikon의 NEF 파일 |
| JPEG.S | 압축된 JPEG(RAW에서 추출한 JPEG, 휴대폰에서 재압축한 JPEG, Bluetooth로 전송된 축소판). 파일명 끝이 `_S.JPG`로 저장됨 |
| Picture Control | 카메라의 색감 프로필(표준, 플랫 등). 커스텀 프로필은 C1~C9에 저장됨 |
| Pro / Cine | 유료 등급. Beta 기간에는 무료 테스트 키를 입력해 모든 기능을 사용할 수 있음 — [제9장](09-tiers.md) 참고 |
