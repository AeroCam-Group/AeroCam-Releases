# 9. 무료 / Pro / Cine

| 등급 | 기능 |
|---|---|
| **무료** | Bluetooth 사진 전송, Bluetooth 리모컨(초점, 촬영, 녹화, 연사, 셀프 타이머), USB 카메라 앨범(수동 선택 원본 다운로드), 휴대폰 앨범, 별점 평가, 사진 편집(.np3 스타일 미리보기, 휴대폰에서 RAW 편집, 무손실 RAW 전환 포함), 사진 위치 정보, QR Code 공유(축소판), 별밤 모드 |
| **Pro** | 무료 버전의 모든 기능에 더해: Wi‑Fi(원탭 연결, Wi‑Fi 앨범 포함), FTP 수신, 자동 수신(Wi‑Fi, USB), 원격 촬영, 촬영 보조 도구, 촬영 도구(벌브, 인터벌 촬영, 노출 브라케팅, 초점 시프트), 원격 촬영 셀프 타이머, 고스트 오버레이, Bluetooth 리모컨 인터벌 촬영, RAW에서 JPEG만 저장, 압축 JPEG 저장, 메모리 카드 백업, 카메라에서 삭제, 카드 없이 촬영(휴대폰에만 저장), 카메라 스타일 C1~C9, QR Code 원본 해상도 및 RAW 공유, 파노라마 스티칭, 흔들림 합성(노이즈 감소 합성) |
| **Cine** | Pro 버전의 모든 기능에 더해: 비디오 모니터, LUT, 아나모픽 디스퀴즈, A/B 랙 포커스, 비디오 모니터 고스트 오버레이 |

잠긴 기능을 누르면 필요한 등급과 함께 '테스트 키 입력' 버튼이 표시됩니다.

## Beta 기간 안내
- Beta는 기본적으로 무료 버전입니다. [테스트 키](01-install.md#테스트-키pro-cine-잠금-해제)를 입력하면 Pro와 Cine의 모든 기능을 무료로 사용할 수 있습니다.
- 테스트 키는 매주 업데이트되며 각 키는 14일간 유효하고, GitHub의 AeroCam-Releases에서만 무료로 배포됩니다.
- 테스트 기간이 종료되면 마지막 키가 만료된 후 무료 버전으로 돌아갑니다.
