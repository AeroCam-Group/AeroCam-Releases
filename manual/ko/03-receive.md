# 3. 자동 수신 및 저장

## 카메라 대시보드
카메라가 연결되면 홈 화면 상단에 현재 카메라 상태가 표시됩니다:

| 항목 | 내용 |
|---|---|
| 기종, 렌즈 | 예: 'Nikon Z f', 'NIKKOR Z 24–120 mm f/4' |
| 배터리 | 잔량 백분율(20% 이하 시 빨간색 표시) |
| 연결 방식 | 휴대폰 핫스팟, 동일 Wi‑Fi, 카메라 Wi‑Fi, USB |
| 메모리 카드 | 각 카드의 사용량/전체 용량 및 남은 촬영 가능 매수(듀얼 슬롯은 각각 표시) |
| 화질 | 예: `RAW`, `JPEG FINE★ L`(카메라에서 화질을 바꾸거나 카드를 빼고 꽂으면 자동 갱신) |
| 저장 위치 | 예: '저장 위치: 메모리 카드 ✓' — 아래 [저장 위치 및 카드 없이 촬영](#저장-위치-및-카드-없이-촬영) 참고 |
| 전송 | 현재 상태, 오른쪽 위 '기록 ›' |
| 카메라 스타일 | 마지막으로 읽어 온 C1~C9 정보 — [제6장](06-edit.md#카메라-스타일-c1c9pro) 참고 |

현재 카메라 모드에서 제공하지 않는 항목은 표시되지 않습니다. '카메라 제어'로 전환해 원격 촬영에 들어가면 보통 더 많은 항목을 읽어 올 수 있습니다.

### 카메라 관리
대시보드 아래의 **카메라 관리 (n)**를 펼치면 카메라를 편집, 삭제하거나 새로 추가할 수 있습니다. 각 카메라의 '상세 정보' 페이지에는 다음 내용이 표시됩니다:
- 모델명, 일련번호(가운데 자리는 가려지며 누르면 전체 표시), 펌웨어 버전, **셔터 카운트** 및 읽은 날짜.
- **월별 셔터 수**: 최근 6개월 막대그래프(기록을 시작한 이후 데이터부터 표시).
- 마지막 연결 시간, 방식, 렌즈, 배터리 잔량, 메모리 카드 남은 용량.
- 휴대폰으로 전송한 파일 수, 첫 연결 날짜, 저장된 네트워크 설정.

셔터 카운트는 메모리 카드에 있는 가장 최근 사진의 정보에서 읽어 오므로, 카드에 사진이 최소 한 장 이상 있어야 합니다.

### 배터리 부족 알림
카메라 배터리가 설정한 기준치(기본 15%) 이하로 떨어지면 알림을 보냅니다. 배터리가 기준치 +5% 이상으로 다시 올라가야 다음 알림이 울립니다. 기준치는 **설정 → 수신 및 알림**에서 조절하거나 끌 수 있습니다.

## 자동 수신(Pro)
1. 홈 화면 Wi‑Fi → **수신 시작**을 누릅니다. 앱이 백그라운드에서 카메라와의 연결을 유지합니다(상단 알림바에서 확인 가능).
2. 카메라에서 사진 재생 중 **i 버튼 → PC로 전송 / 전송할 화상 선택**(Send to PC / Select to send, 기종에 따라 메뉴명 상이)을 누르면 사진이 휴대폰으로 전송됩니다.

셔터를 누르자마자 즉시 자동으로 밀어 넣고 싶다면 [FTP 수신](08-ftp.md)을 사용하세요. USB 케이블이 꽂혀 있을 때는 수신 경로가 자동으로 USB로 전환됩니다.

### 수신 일시정지
Wi‑Fi 자동 수신 연결 중일 때 홈 화면 '전송' 카드 오른쪽 위의 **⏸ 일시정지** 또는 알림창의 '일시정지'를 누르면 잠시 멈출 수 있습니다:
- Wi‑Fi 연결은 그대로 유지되므로 앨범과 원격 촬영은 정상적으로 사용할 수 있습니다.
- 카메라에서 보낼 사진은 카메라에 대기 상태로 남으며, **수신 재개**를 누르면 순서대로 마저 전송됩니다. 현재 전송 중인 사진은 끝까지 받은 뒤 멈춥니다.
- '재개'를 누르거나, 수신을 중지하거나, 최근 앱 목록에서 앱을 밀어서 닫거나, Wi‑Fi가 끊기거나, 카메라 전원을 끄거나, USB를 꽂으면 자동으로 해제됩니다.

### 연결이 끊겼을 때
- 연결이 끊어지면 자동으로 재연결을 시도합니다. 여러 번 실패하면 카메라 고유 ID로 다시 검색하므로 카메라 IP가 바뀌었더라도 찾아냅니다.
- **카메라가 Bluetooth 전송으로 전환한 경우**: 카메라에는 무선 칩이 하나뿐이라 Bluetooth로 사진을 보낼 때 Wi‑Fi를 잠시 끕니다. 이때 홈 화면에 '카메라가 Bluetooth로 사진을 전송 중입니다… 완료 후 Wi‑Fi에 자동 재연결됩니다'라고 표시되며 연결 오류로 처리되지 않습니다.
- **앨범/원격 촬영이 카메라 연결을 빌려 쓸 때**: 카메라는 한 번에 하나의 연결만 허용합니다. 앨범이나 원격 촬영에 들어가면 자동 수신이 연결을 양보하고, 화면을 나오면 자동으로 다시 이어받습니다.
- **Wi‑Fi에서 카메라를 찾지 못할 때**: 설정된 시간(기본 3분)이 지나면 배터리 소모를 막기 위해 자동으로 수신을 중지하고 알림을 보냅니다. 시간은 **설정 → 수신 및 알림**에서 조절할 수 있습니다.

## 수신 규칙
**설정 → 수신 및 알림**에서 설정하며, Wi‑Fi, USB, FTP 모두 동일한 규칙으로 저장됩니다.

### 수신 파일 형식
저장할 파일 종류를 선택합니다: 모든 파일, JPG만, JPG + RAW, 사진 + 동영상, 또는 사용자 지정(JPEG, RAW, HEIF, TIFF, 동영상, 기타).

추가 세 가지 스위치(Pro):

| 스위치 | 설명 |
|---|---|
| **RAW에서 JPEG만 저장** | RAW를 수신할 때 파일 내부에 포함된 원본 해상도 JPEG(20~50 MB의 RAW 대신 보통 2~5 MB)만 추출하여 저장합니다. 해상도는 그대로 유지되고 촬영 정보(EXIF)도 모두 보존되며 `DSC_1234_S.JPG`로 저장됩니다. SNS 공유나 일상 감상에 적합합니다 |
| **JPEG 압축본 저장** | 카메라에서 받은 JPEG를 휴대폰에서 다시 압축해 저장합니다(`_S.JPG`, 해상도는 유지되며 화질은 앨범 설정을 따름) |
| **원본 수신 시 압축본 대체** | 원본 JPEG가 저장되면 휴대폰에 있던 같은 사진의 압축본을 자동으로 삭제합니다 |

> RAW 파일을 받으려면 카메라의 화질 설정을 RAW 또는 RAW+JPEG로 맞추고, 카메라 'PC에 연결'의 전송 옵션에서도 RAW+JPEG를 선택해야 합니다('JPEG만'으로 두지 마세요). 메뉴 이름은 기종마다 다를 수 있습니다.

### 기타 규칙
| 규칙 | 설명 |
|---|---|
| 수신 모드 | 연속 수신, 또는 파일 하나를 받으면 중지 |
| 대용량 동영상 | 기준 용량(기본 1024 MB)을 넘는 동영상은 자동 수신하지 않고 '필터됨'으로 기록하며, 필요시 수동으로 다운로드합니다 |
| 저장 폴더 | 카메라별, 날짜별, 카메라 및 날짜별, 파일 형식별 |
| 파일명 | 카메라 원본 파일명(`DSC_1234.NEF`), 날짜 접두사 추가(`20261011_DSC_1234.NEF`), 날짜 및 시간 접두사 추가(`20261011_153012_DSC_1234.NEF` — 여러 대의 카메라 사진도 촬영 시간순으로 정렬됨). 설정 이후 저장되는 파일부터 적용됩니다 |

### 저장 위치
- 사진: `Pictures/AeroCam/…`
- 동영상: `Movies/AeroCam/…`
- 기타 파일: `Download/AeroCam/…`

Google 포토 등 다른 갤러리 앱에서도 바로 보입니다. 앱을 삭제했다가 다시 설치한 경우 **설정 → 저장 공간 및 배터리 → '휴대폰 사진 다시 스캔'**을 실행하면 기존 사진을 앨범으로 다시 불러올 수 있습니다.

### 중복 파일 판별
- 카메라 일련번호, 파일명, 용량, 촬영 시간, 파일 해시값을 기준으로 판별하여 중복 파일은 다시 저장하지 않고 기록에 '중복'으로 표시합니다.
- 휴대폰에서 삭제(휴지통 이동 포함)한 사진은 카메라에서 다시 보내면 새로 저장됩니다.
- 같은 사진을 다시 보내기 위해 수신을 멈췄다가 다시 시작할 필요는 없습니다.

### Bluetooth와 Wi‑Fi로 같은 사진을 받았을 때
Wi‑Fi 파일이 더 온전하므로(원본 해상도) Wi‑Fi가 우선합니다:
- Wi‑Fi로 먼저 받고 나중에 Bluetooth로 넘어온 경우: Bluetooth 버전은 저장하지 않습니다.
- Bluetooth로 먼저 받고 나중에 Wi‑Fi로 같은 사진을 받은 경우, **설정 → 수신 및 알림 → 'Bluetooth로 이미 받은 사진'** 설정에 따릅니다:
  - **Wi‑Fi 수신 시 원본으로 교체**(추천): 원본 해상도 파일을 저장하고 휴대폰의 Bluetooth 축소판을 자동 삭제합니다.
  - **Wi‑Fi로 다시 다운로드하지 않음**.
  - **둘 다 유지**.
- RAW 원본 파일은 항상 그대로 수신합니다.

## 저장 위치 및 카드 없이 촬영
셔터를 눌렀을 때 사진이 어디에 저장될지 결정합니다. 앱이 카메라에 메모리 카드가 꽂혀 있는지 읽어 자동으로 선택합니다:
- **카메라에 카드가 있을 때**: **설정 → 촬영 → 저장 위치**에서 선택한 방식을 따릅니다:
  - **메모리 카드**: 카메라의 메모리 카드에 저장합니다.
  - **메모리 카드 + 휴대폰**(Pro): 메모리 카드에 저장하면서 동시에 휴대폰으로도 한 장 복사합니다.
- **카메라에 카드가 없을 때**(Pro): 자동으로 **휴대폰에만 저장(카드 없이 촬영)**으로 바뀝니다. 평소처럼 셔터를 누르면 사진이 휴대폰으로 바로 전송되며 촬영 시간 기준 파일명(예: `AC_20261025_193805.JPG`)으로 저장됩니다. 카드를 꽂으면 자동으로 원래 설정으로 돌아갑니다.

홈, 앨범, 원격 촬영 어디서든 쓸 수 있으며 Wi‑Fi와 USB 모두 지원합니다.

**처음 한 번 필요한 카메라 설정:**
1. 카메라 사용자 설정 메뉴의 **슬롯이 비었을 때 릴리즈 잠금**(Slot empty release lock)을 **릴리즈 허용**(Enable release)으로 변경합니다. 그렇지 않으면 카드가 없을 때 셔터가 눌리지 않습니다.
2. Wi‑Fi 연결 시 카메라의 연결 유형을 **카메라 제어**(Camera control)로 설정해야 합니다. '화상 전송' 상태라면 첫 장을 찍고 약 3초 뒤 앱이 모드 전환을 안내합니다(사진은 카메라 버퍼에 남아 있다가 전환 후 자동 전송됨). USB 연결에는 이 제한이 없습니다.
3. 원탭 연결은 카드 없이 촬영을 지원하지 않으므로 휴대폰 핫스팟이나 동일 Wi‑Fi를 사용해 주세요.

**상태 표시줄 안내**(홈과 앨범 상단):

| 표시 문구 | 의미 |
|---|---|
| 저장 위치: 메모리 카드 ✓ | 카메라 메모리 카드에 저장됨 |
| 저장 위치: 메모리 카드 + 휴대폰 ✓ | 메모리 카드와 휴대폰 양쪽에 저장됨 |
| 저장 위치: 휴대폰에만 저장(카메라에 메모리 카드 없음) | 사진이 휴대폰으로 직접 전송됨 |
| 카메라가 '화상 전송' 모드입니다…(빨간 글씨) | 연결 유형을 '카메라 제어'로 전환하세요 |
| 원탭 Wi‑Fi: 메모리 카드가 없어 촬영할 수 없습니다(빨간 글씨) | 카드를 꽂거나 핫스팟 / 동일 Wi‑Fi로 전환하세요 |
| 메모리 카드가 가득 찼습니다(빨간 글씨) | 카드를 교체하거나 공간을 확보하세요(자동으로 휴대폰 전용 저장으로 바뀌지 않음) |
| 카메라에 메모리 카드가 없어 촬영할 수 없습니다(빨간 글씨) | 무료 버전이거나 휴대폰 남은 공간이 1 GB 미만임 |

> 카드가 없을 때는 동영상 녹화가 불가능하며, 한 장씩 휴대폰으로 전송을 기다리므로 연사 속도가 느려집니다.

## 사진 위치 정보(GPS)
**설정 → 수신 및 알림 → 사진 위치 정보**에 두 개의 스위치가 있습니다:
- **카메라로 위치 전송(Bluetooth)**(기본 켜짐): 카메라 전원을 켜거나 Bluetooth로 사진을 보낼 때 휴대폰 위치를 카메라에 전달하여 카메라가 촬영 시 사진에 직접 기록합니다.
- **수신된 JPEG에 위치 추가(휴대폰)**: Wi‑Fi, USB, FTP, 앨범 다운로드, 원격 촬영으로 받은 JPEG에 촬영 시간을 기준으로 휴대폰이 기록한 당시 위치를 기록합니다. 처음 수신을 시작할 때 한 번 확인합니다.
  - RAW 파일은 수정되지 않으며, 이미 위치 정보가 있는 사진은 기존 좌표를 유지합니다.
  - 수신 중 휴대폰에 기록된 위치 데이터는 이 휴대폰에만 저장되며 24시간 후 자동 삭제됩니다.
  - 촬영 시간과 일치하는 위치 기록이 없으면 잘못된 위치를 넣지 않도록 비워 둡니다.
  - 위치를 기록하려면 AeroCam이 열린 상태에서 수신을 시작해야 합니다.

> 사진에 기록된 촬영 위치는 원본 파일을 공유할 때 상대방도 볼 수 있습니다. QR Code 공유 시에는 기본값으로 위치 정보가 제거됩니다 — [제4장](04-gallery.md#qr-code-공유) 참고.

## 기록
홈 화면 '전송' 카드 오른쪽 위의 **기록 ›**을 누르면 모든 수신, 앨범 다운로드, 원격 촬영 저장 결과(성공, 중복, 건너뜀, 실패)가 썸네일과 함께 표시됩니다.
- 항목을 누르면 앱 내에서 전체 화면으로 미리 볼 수 있습니다.
- 검색, 카메라별 필터링, 기록 지우기가 가능하며, 기록을 지워도 휴대폰에 저장된 사진 파일은 삭제되지 않습니다.
