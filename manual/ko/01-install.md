# 1. 설치 및 시작하기

## 설치
1. [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest)에서 최신 Beta APK(`…-Beta-xx.xx.xx.apk`)를 다운로드합니다.
2. 휴대폰에서 APK 파일을 엽니다. 처음 설치할 때 Android에서 '출처를 알 수 없는 앱 설치' 허용을 요청하면 허용해 주세요.
3. 이후 새 버전이 나오면 그대로 다운로드해 설치하면 덮어쓰기로 업데이트되며, 페어링 정보와 설정은 모두 유지됩니다.

> 반드시 AeroCam-Releases에서만 다운로드하세요. 다른 경로의 APK는 변조되었을 수 있습니다. 앱을 열었을 때 '공식 버전이 아닙니다'라는 메시지가 표시되면 제3자가 다시 패키징한 앱입니다. 테스트 키가 작동하지 않으며 악성 코드가 포함되었을 가능성이 있으므로 삭제한 뒤 AeroCam-Releases에서 다시 다운로드하세요.

> **92.03.09 이전 구버전 Beta** 사용자 안내: 새 버전은 별도의 앱으로 설치됩니다. 카메라를 다시 페어링하고 테스트 키를 재입력한 뒤, 정상 작동을 확인하고 구버전을 삭제하세요.

## 권한
앱은 해당 기능을 사용할 때만 권한을 요청하며, 필요하지 않은 권한은 허용하지 않아도 됩니다:

| 권한 | 용도 |
|---|---|
| Bluetooth, 근처 기기 | Bluetooth 페어링, Bluetooth 사진 전송, Bluetooth 리모컨, Android 13 이상에서 Wi‑Fi 카메라 검색 시 필요 |
| 위치 | 휴대폰 위치를 카메라로 보내 사진에 기록하거나 수신된 JPEG에 위치 추가, Android에서 Wi‑Fi 이름을 읽을 때도 필요 |
| 알림 | 수신 진행률, 사진 수신 완료, 전송 문제, 카메라 배터리 부족 알림 |
| 사진 및 동영상 | 휴대폰에 저장된 사진 표시 및 정리 |

각 권한의 자세한 설명은 [개인정보 보호 및 익명 통계](10-privacy.md)를 참고하세요.

하단에 네 개의 탭이 있습니다:

| 탭 | 내용 |
|---|---|
| **홈** | 카메라 대시보드(배터리, 렌즈, 메모리 카드, 연결 상태), 네 가지 연결 방식(Wi‑Fi, USB, Bluetooth, FTP), 전송 상태 및 기록, 카메라 스타일, 카메라 관리 |
| **카메라 앨범** | '휴대폰 앨범'과 '카메라 메모리 카드' 두 개의 하위 탭 — [제4장](04-gallery.md) 참고 |

## 테스트 키(Pro, Cine 잠금 해제)
Beta는 기본적으로 무료 버전으로 시작합니다.
1. [AeroCam-Releases 홈 페이지](https://github.com/AeroCam-Group/AeroCam-Releases)에서 현재 테스트 키를 복사합니다. 앱의 **설정 → 지원 → '무료 키 받기'**를 누르면 해당 페이지가 바로 열립니다.
2. **설정 → 지원 → '테스트 키 입력'**에서 복사한 문자열 전체를 붙여넣고 '적용'을 누릅니다. 잠긴 기능을 눌렀을 때 나타나는 대화상자에서도 '테스트 키 입력'을 누를 수 있습니다.
3. 각 키는 14일간 유효하며 매주 새 키로 교체됩니다. 만료되면 무료 버전으로 돌아가므로 새 키를 다시 붙여넣으면 됩니다.

> Beta와 테스트 키는 모두 **무료**이며, GitHub의 AeroCam-Releases에서만 배포됩니다. 누군가 비용을 요구한다면 공식 경로가 아닙니다.

## 업데이트 확인
Beta는 매일 앱을 처음 열 때 자동으로 업데이트를 확인합니다. **설정 → 지원 → '업데이트 확인'**에서 수동으로 확인할 수도 있습니다.

## 언어
인터페이스는 번체 중국어, 간체 중국어, 일본어, 영어, 한국어, Deutsch, Français, Español, Tiếng Việt, ไทย, Bahasa Indonesia를 지원합니다. 기본값은 휴대폰 시스템 언어를 따르며, **설정 → 화면 및 언어 → 언어**에서 직접 바꿀 수 있습니다.

영어, 번체 중국어, 일본어는 항상 100% 번역이 완료되어 있습니다. 다른 언어는 새 기능이 먼저 영어로 표시된 뒤 일괄 번역될 수 있습니다. 어색하거나 잘못 번역된 부분은 '번역 오류' 양식으로 [문제 신고](12-report.md)해 주시면 감사하겠습니다.

## 익명 사용 통계
카메라에 처음 연결한 후 '익명 사용 통계 전송'에 대한 안내가 한 번 표시됩니다. '확인' 또는 '끄기'를 선택할 수 있으며, **응답하기 전에는 아무 데이터도 전송되지 않습니다.** 이후 언제든지 **설정 → 지원**에서 끌 수 있습니다. 어떤 항목이 전송되고 어떤 항목이 절대 전송되지 않는지는 [개인정보 보호 및 익명 통계](10-privacy.md)를 확인하세요.
