# 12. 문제 신고

[Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose)로 이동해 해당 양식을 선택하세요:

| 양식 | 용도 |
|---|---|
| 버그 신고 | 기능 오작동, 앱 강제 종료 |
| 기능 제안 | 새로운 기능이나 개선 아이디어, 기본값 제안 |
| 번역 오류 | 오역이나 부자연스러운 표현 제보 |
| 기종 제보 | 다른 카메라 기종으로 테스트한 결과 공유 |

## 함께 첨부해 주세요
- AeroCam 버전(홈 화면 왼쪽 위, 또는 설정 → 지원)
- 휴대폰 모델명, Android 버전
- 카메라 모델명, 펌웨어 버전
- 연결 방식(Bluetooth / 원탭 연결 / 휴대폰 핫스팟 / 동일 Wi‑Fi / USB / FTP)
- 재현 방법, 예상 결과, 실제 결과
- **진단 정보**: 설정 → 지원 → '진단 정보 복사'를 눌러 양식에 붙여넣기

## 주의 사항
- Issue는 **공개**되므로 Wi‑Fi 비밀번호, 카메라 전체 일련번호, 계정 정보 등 개인정보는 절대 올리지 마세요.
- 공개하기 어려운 내용(데이터 삭제 요청, 보안 취약점 제보 등)은 **aerocam.lab@gmail.com**으로 이메일을 보내 주세요.
