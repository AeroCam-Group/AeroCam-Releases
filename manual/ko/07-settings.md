# 7. 설정 항목별 안내

**설정**은 다섯 가지 카테고리로 나뉘며 각 항목을 눌러 세부 설정으로 들어갑니다. 무료 버전에서는 사용하지 않는 설정이 표시되지 않습니다. 기능 제안이나 기본값 개선 의견이 있다면 언제든 [문제 신고](12-report.md)로 알려주세요.

## 수신 및 알림

### 수신
| 설정 | 옵션 | 기본값 | 설명 |
|---|---|---|---|
| 수신 파일 형식 | 모든 파일 / JPG만 / JPG + RAW / 사진 + 동영상 / 사용자 지정. 추가로 RAW에서 JPEG만 저장, JPEG 압축본 저장, 원본 수신 시 압축본 대체(Pro) | 모든 파일 | [제3장](03-receive.md#수신-파일-형식) 참고 |
| 저장 폴더 | 카메라별 / 날짜별 / 카메라 및 날짜별 / 파일 형식별 | 카메라 및 날짜별 | 사진은 `Pictures/AeroCam`, 동영상은 `Movies/AeroCam` 아래 분류 방식 |
| 파일명 | 카메라 원본 파일명 / 날짜 접두사 추가 / 날짜 및 시간 접두사 추가 | 카메라 원본 파일명 | 설정 이후 저장되는 파일에만 적용되며, 중복 판별은 항상 카메라 원본 파일명 기준 |
| 수신 모드(Pro) | 연속 수신 / 단일 파일 수신 | 연속 수신 | 단일 파일 = 파일 하나를 받으면 자동 중지 |
| 대용량 동영상 자동 수신 안 함(Pro) | 용량 수치(MB) | 1024 MB | 기준을 넘는 동영상은 '필터됨'으로 기록되며 수동 다운로드 필요 |
| Wi‑Fi에서 카메라를 찾지 못할 때 | 30초 / 1 / 2 / 3 / 5 / 10분 / 무제한 | 3분 | 제한 시간을 넘기면 재시도로 인한 배터리 소모를 막기 위해 자동 중지 |
| FTP 사진 미수신 시 자동 종료 | 자동 종료 안 함 / 5 / 10 / 30분 | 자동 종료 안 함 | 마지막 사진을 받은 시점부터 계산하며 전송 중에는 꺼지지 않음 |
| Bluetooth로 이미 받은 사진 | Wi‑Fi 수신 시 원본으로 교체 / Wi‑Fi로 다시 다운로드하지 않음 / 둘 다 유지 | 원본으로 교체 | Bluetooth로 받은 파일은 약 2 MB의 축소판임 |

### 사진 위치 정보
| 설정 | 기본값 | 설명 |
|---|---|---|
| 카메라로 위치 전송(Bluetooth) | 켜짐 | 카메라 전원을 켜거나 Bluetooth로 사진을 보낼 때 휴대폰 위치를 카메라에 보내 사진에 기록 |
| 수신된 JPEG에 위치 추가(휴대폰) | 꺼짐(첫 수신 시 질문) | Wi‑Fi, USB, FTP로 받은 JPEG에 촬영 시간 기준으로 휴대폰이 위치를 기록(RAW는 변경 안 함) |

자세한 내용은 [제3장 사진 위치 정보](03-receive.md#사진-위치-정보gps)를 참고하세요.

## 촬영

### 저장 위치
| 설정 | 옵션 | 설명 |
|---|---|---|
| 저장 위치 | 메모리 카드 / 메모리 카드 + 휴대폰(Pro) | 카메라에 카드가 있을 때 적용되는 방식이며, 카드가 없으면 자동으로 휴대폰에만 저장(Pro)으로 전환됨. 카메라 연결 시 현재 카드 유무가 표시됨. [제3장](03-receive.md#저장-위치-및-카드-없이-촬영) 참고 |

### 원격 촬영
| 설정 | 옵션 | 기본값 | 설명 |
|---|---|---|---|
| 원격 촬영 진입 시 기본 켜짐 | 촬영 전 초점, 히스토그램, 노출 과다 경고, 초점 피킹, 노출계 | 촬영 전 초점, 노출계 | 촬영 중에도 언제든 켜고 끌 수 있음 |
| 노출계 색상 | 자동 / 하양 / 검정 | 자동 | 자동 = 배경 영상 밝기에 맞춰 자동 전환 |
| 초점 피킹 색상 | 빨강 / 노랑 / 파랑 / 하양 | 빨강 | 붉은색 피사체를 찍을 때는 다른 색으로 바꾸면 잘 보임 |
| 원격 촬영 중 화면 항상 켜짐 | 켜짐 / 꺼짐 | 켜짐 | 인터벌 촬영이나 장노출 촬영 중 휴대폰 화면이 꺼지지 않도록 유지 |
| 왼손 모드 | 켜짐 / 꺼짐 | 꺼짐 | 가로 화면에서 셔터 버튼을 왼쪽 아래로 이동 |

### 유선 연결(USB‑C)
| 설정 | 옵션 | 기본값 | 설명 |
|---|---|---|---|
| USB 미리보기 프레임 레이트 | 30 / 60 fps / 무제한 | 30 fps | 30 fps는 배터리를 아끼고 발열이 적으며, 60 fps는 화면이 더 부드러움 |
| USB 고해상도 미리보기 | 켜짐 / 꺼짐 | 켜짐 | 화질이 더 선명해지나 프레임 레이트가 약간 낮아질 수 있음(미지원 기종은 자동 복귀) |
| USB 케이블 연결 시 자동 수신 시작(Pro) | 켜짐 / 꺼짐 | 켜짐 | 케이블을 꽂으면 자동으로 USB 수신 시작 |
| 연결 시 카메라 시간 동기화 | 켜짐 / 꺼짐 | 켜짐 | 2초 이상 차이 날 때만 보정하며, 1일 이상 차이 나면 먼저 물어봄 |
| 유선 연결 시 카메라 절전 방지 | 켜짐 / 꺼짐 | 켜짐 | 10초마다 작은 신호를 보내 절전을 막으며, 30분 무조작 또는 배터리 부족 시 중지 |
