# 10. 개인정보 보호 및 익명 통계

AeroCam에는 계정 시스템이 없으며 사진은 카메라와 휴대폰 사이에서만 직접 전송되고 **어떠한 서버에도 업로드되지 않습니다.** 아래 나열된 최소한의 데이터만 휴대폰 밖으로 전송됩니다.

## 인터넷에 연결되는 기능
| 기능 | 전송 내용 | 끌 수 있는지 여부 |
|---|---|---|
| 업데이트 확인(Beta) | GitHub에서 최신 버전 정보만 조회 | 매일 자동으로 1회 실행 |
| 익명 사용 통계 | 아래 내용 참고 | 가능, 설정 → 지원 |
| QR Code 공유 | 내 로컬 네트워크(동일 Wi‑Fi 또는 휴대폰 핫스팟) 안에서만 스캔한 사람에게 선택한 사진을 보여줌 | 중지를 누르거나 제한 시간이 지나면 종료 |

## 익명 사용 통계
대략 얼마나 많은 사용자가 이용하는지, 어떤 카메라와 기능을 주로 쓰는지, 어디서 문제가 자주 발생하는지 파악해 다음 개발 우선순위를 정하는 데 사용합니다. **누구에게도 판매하지 않으며 광고 목적으로도 사용하지 않습니다.**

- **스위치**: **설정 → 지원 → '익명 사용 통계 전송'**, 기본값 켜짐.
- 처음 카메라에 연결한 후 한 번 안내가 표시되며 '확인' 또는 '끄기'를 고를 수 있습니다. **응답하기 전에는 아무것도 전송하지 않습니다.**
- **끈 후**: 즉시 전송을 중단하며 아래 설명된 무작위 ID와 아직 전송되지 않은 데이터를 삭제합니다. 다시 켜면 새로운 ID가 생성됩니다.
- 인터넷이 없을 때(예: 카메라 자체 Wi‑Fi에 연결된 상태)는 휴대폰에 임시 저장했다가 인터넷이 연결되면 전송합니다.
- Dev 개발자 빌드에서는 기록도 전송도 하지 않습니다.

### 전송되는 데이터
- **앱이 자체적으로 무작위 생성한 ID**: 휴대폰이나 카메라에서 추출한 값이 아니며, 앱을 재설치하거나 통계를 끄면 새 ID로 바뀝니다.
- 카메라 모델명(예: Nikon Z f) — 모델명만 전송.
- 연결 방식(Bluetooth, Wi‑Fi, USB, FTP) 및 Wi‑Fi 종류(카메라 자체 Wi‑Fi, 휴대폰 핫스팟, 공유기).
- 매일 사용한 기능(기능 이름만 하루 1회 기록), 잠긴 기능을 눌러 본 기록 포함.
- 연결 성공 또는 실패 횟수, 실패 시에는 분류 코드(예: '시간 초과')만 보내고 오류 메시지 본문은 보내지 않음.
- 카메라 추가 단계: 시작, 성공, 카메라 찾지 못함, 실패 원인 분류.
- 매일 수신한 사진 수(JPEG, RAW, 동영상 각각의 개수만 기록).
- 권한 허용 또는 거부 여부.
- 현재 요금제(무료, Beta 키 등), 앱 버전, 앱 언어, Android 메이저 버전.
- 국가: 연결에서 판별하며 국가 코드만 저장.

### 절대 전송하지 않는 항목
카메라 일련번호, 카메라에 설정된 소유자 또는 저작권 이름, 위치(GPS), 사진 및 동영상, 파일명, 촬영 메타데이터(EXIF), Wi‑Fi 이름 및 비밀번호, 휴대폰 고유 ID(IMEI, Android ID, 광고 ID), 이름, 이메일, 계정, 오류 메시지 원문.

### 보관 기간
- 기기별 일일 세부 기록은 90일간 보관되며, 이후에는 일별 전체 합계 수치만 남습니다.
- 약 13개월 이상 활동이 없는 무작위 ID는 삭제됩니다.
- 서버가 연결을 처리할 때 구조상 IP 주소를 확인하게 되지만 국가 판별과 악용 방지 용도로만 쓰이며 **통계 데이터에는 절대 저장되지 않습니다.**

## 위치 정보
- **카메라로 위치 전송(Bluetooth)**: 휴대폰 위치를 카메라에 전달하여 카메라가 사진에 기록합니다.
- **수신된 JPEG에 위치 추가(휴대폰)**: 기본 꺼짐. 켜 두면 수신 세션 동안 휴대폰이 기록한 위치는 이 기기에만 저장되며 24시간 후 삭제됩니다.
- 두 스위치 모두 **설정 → 수신 및 알림 → 사진 위치 정보**에 있습니다 — [제3장](03-receive.md#사진-위치-정보gps) 참고.
- 사진에 기록된 위치는 파일과 함께 저장되므로 원본 파일을 공유하면 상대방도 볼 수 있습니다. **QR Code 공유는 기본값으로 위치 정보를 제거합니다.**

## 권한 용도
| 권한 | 용도 |
|---|---|
| Bluetooth, 근처 기기 | 카메라 페어링, Bluetooth 사진 전송, Bluetooth 리모컨, Wi‑Fi 카메라 검색 |
| 위치 | 카메라로 위치 전송 또는 사진에 위치 추가, Android에서 Wi‑Fi 이름을 읽을 때도 필요 |
| 알림 | 수신 진행률, 사진 수신 완료, 전송 문제, 카메라 배터리 부족 알림 |
| 사진 및 동영상 | 휴대폰 앨범에서 사진 표시 및 정리 |

## 진단 정보
**설정 → 지원 → '진단 정보 복사'**는 내용을 클립보드에 복사할 뿐이며 **전송 여부는 사용자가 직접 결정합니다.** 앱 버전, 휴대폰 및 네트워크 상태, 카메라 기능 정보, 최근 연결 기록이 포함되며 카메라 일련번호는 끝 4자리만 남습니다. 공개된 GitHub Issue에 붙여넣기 전에 공개하고 싶지 않은 내용이 없는지 한 번 더 확인해 주세요.
