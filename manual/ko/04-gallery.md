# 4. 앨범

하단 '카메라 앨범' 탭 위쪽에는 **휴대폰 앨범**(이미 휴대폰에 저장된 사진)과 **카메라 메모리 카드**(카메라 속 사진을 직접 탐색) 두 개의 하위 탭이 있습니다.

## 카메라 메모리 카드
휴대폰에서 카메라 메모리 카드를 직접 탐색할 수 있으며(듀얼 슬롯 지원), **미리 카메라에서 사진을 고르거나** '수신 시작'을 먼저 누를 필요가 없습니다.
- USB 케이블 연결은 무료이며, Wi‑Fi 연결은 Pro 기능입니다.
- 탭에 들어가자마자 카메라를 점유하지 않고 '연결하여 메모리 카드 탐색'을 눌러야 연결됩니다. 카메라는 한 번에 하나의 연결만 허용하므로 탐색 중에는 자동 수신이 잠시 멈췄다가 화면을 나가면 자동으로 재개됩니다.
- 다른 탭으로 이동하거나 큰 사진을 볼 때도 20초 동안 연결이 유지되어 돌아오면 바로 이어서 볼 수 있습니다. 앱을 백그라운드로 내리면 즉시 카메라 연결을 해제합니다(다운로드 중인 파일은 완료 후 해제).
- 앨범을 열어 둔 상태에서 카메라로 사진을 찍으면 약 1~2초 안에 새 사진이 맨 위에 자동으로 나타납니다(USB가 가장 빠름).

### 탐색 및 필터
- 촬영 날짜별로 묶여서 표시되며, 오른쪽 위 달력 아이콘을 누르면 특정 날짜(연 → 월 → 일)로 빠르게 이동할 수 있습니다.
- 필터: 전체, RAW, JPEG, 동영상, **미다운로드**(아직 휴대폰에 없는 사진만 표시), 별점 있음. '미다운로드'나 '별점 있음'을 선택하면 하단에 '이 N장 모두 선택' 버튼이 나타납니다.
- **한 줄 표시 장수**: 오른쪽 위 격자 아이콘에서 2~7열을 고르거나 두 손가락 핀치 줌으로 바꿀 수 있습니다. 가로 모드에서는 열 수가 1.5배 늘어납니다.
- 동영상은 전체 파일을 받지 않고 헤더 정보만 읽어 옵니다. 썸네일 왼쪽 아래 `▶ 0:12`는 재생 길이, 왼쪽 위 `1080 24p`는 해상도와 프레임 규격입니다.

### 썸네일 배지 안내
필터 줄 맨 오른쪽의 **ⓘ**를 누르면 전체 설명을 볼 수 있습니다:

| 위치 | 의미 |
|---|---|
| 왼쪽 위 | 두 번째 카드(`SD2`) 또는 동영상 규격 |
| 오른쪽 위 | 별점 표시 |
| 왼쪽 아래 | 파일 형식: `RAW`(황갈색), `JPEG`(회색), `▶` 동영상 길이 |
| 오른쪽 아래 | 휴대폰에 이미 있는 버전: **✓RAW**, **✓JPEG**, **✓JPEG.S**(여러 개 겹쳐 표시 가능). 초록색 = 카메라 원본, 파란색 = 사본, 배지 없음 = 아직 휴대폰에 없음 |

### 선택하기
- 사진 한 장을 길게 누른 채 **그대로 드래그**하면 한 번에 여러 장을 연속 선택할 수 있으며, 화면 가장자리로 끌면 자동 스크롤됩니다.
- 각 날짜 제목 오른쪽의 '선택'을 누르면 해당 날짜 전체가 선택됩니다.
- 선택 모드에서는 하단 내비게이션 바가 숨겨지고 작업 표시줄(다운로드, 별점, 삭제)로 바뀝니다. 왼쪽 위 **✕**를 누르면 선택이 취소됩니다.

### 다운로드
사진을 선택한 뒤 **다운로드**를 누르면 각 옵션 옆에 **차지할 휴대폰 저장 공간**이 표시되고, 맨 아래에 휴대폰 남은 공간이 표시됩니다:
- **원본 파일**: 무손실 RAW, JPEG 또는 동영상 파일 그대로 저장합니다.
- **JPEG만 저장**(Pro): RAW에서는 내장된 원본 해상도 JPEG를 추출하고, JPEG 원본은 휴대폰에서 다시 압축합니다(해상도 유지). 모두 `DSC_1234_S.JPG`로 저장되며 촬영 정보가 그대로 유지됩니다. 압축 품질은 **설정 → 수신 및 알림 → 앨범**에서 60 / 70 / 80 / 90%(기본 80%) 중 선택할 수 있습니다.
- 다운로드는 대기열에 추가되어 진행률을 보거나 언제든 중지할 수 있으며, 이미 휴대폰에 있는 파일은 자동으로 건너뛰고 결과는 '기록'에 남습니다.
- 다운로드가 끝나면 '선택을 유지할까요?'라고 묻고 카운트다운이 끝나면 자동으로 선택을 해제하여 실수로 '카메라에서 삭제'를 누르는 것을 방지합니다. '내 선택 기억'에 체크할 수도 있습니다.

### 카메라에서 삭제(Pro)
사진을 선택한 뒤 **빨간색** '카메라에서 삭제(N)' 버튼을 누르고 확인하면 메모리 카드에서 **영구 삭제**되며 복구할 수 없습니다. 아직 휴대폰에 다운로드하지 않은 사진은 별도의 경고가 한 번 더 표시됩니다. 카메라에서 보호 잠금(🔑)이 걸린 사진은 삭제되지 않습니다.

> 빨간색 실선 버튼만 카메라 메모리 카드를 건드립니다. 그 외의 모든 삭제 기능은 휴대폰 내 파일만 삭제합니다.

### 크게 보기(전체 화면 뷰어)
썸네일을 누르면 전체 화면으로 열리며, 좌우로 밀어 사진을 넘기고 두 손가락 핀치 또는 더블 탭으로 확대합니다.
- **세로 화면**: 상단에 파일명, 시간, 용량이 나오고 사진 아래에 촬영 정보(`셔터 속도 · 조리개 · ISO · 초점 거리`), 맨 아래에 작업 버튼이 배치됩니다.
- **가로 화면**: 사진이 화면을 가득 채우고 정보는 오른쪽에 표시되며, 사진을 탭하면 정보 창을 숨기거나 다시 띄울 수 있습니다.
- **상세 정보** 켜기: RGB 히스토그램, Picture Control, 화이트 밸런스, 렌즈, 해상도, 파일 용량을 먼저 다운로드하지 않고도 카메라의 파일에서 직접 읽어 보여줍니다.

### 별점 평가
앨범에서 사진에 1~5점 별점을 매긴 뒤 '별점 있음' 필터로 골라 원하는 사진만 다운로드할 수 있습니다. 별점은 다운로드된 파일의 EXIF Rating에 기록되어 Lightroom 등의 편집 프로그램에서도 그대로 인식됩니다.

## 휴대폰 앨범
이미 휴대폰에 저장된 사진을 보여주며 카메라 연결이 필요 없습니다.
- 현재 휴대폰에 남아 있는 파일만 표시됩니다. Google 포토 등 다른 앱에서 삭제한 사진은 여기에서도 사라지며, 휴지통에서 복원하면 자동으로 다시 나타납니다.
- 촬영 시간순으로 정렬되며, 필터 줄에서 '편집됨', '파노라마', '흔들림 합성' 등으로 걸러 볼 수 있습니다.
- **크게 보기**: 촬영 정보와 **상세 정보**(촬영 시간, 전송 시간, RGB 히스토그램, Picture Control, 화이트 밸런스, 렌즈, 해상도, 파일 형식, 출처)를 확인할 수 있으며, 하단에 **공유**, **다른 앱으로 열기**, **편집**, **삭제** 버튼이 있습니다.
- **삭제**: 선택 후 **삭제**를 누르면 '휴대폰에서 모두 삭제', 'RAW만 삭제', 'JPEG만 삭제(.S 포함)', '동영상만 삭제' 중 고를 수 있습니다. 파일은 휴대폰 **휴지통**으로 이동하여 30일 이내에 시스템 갤러리에서 복원할 수 있으며, **카메라 메모리 카드는 전혀 영향을 받지 않습니다.**
- **이미지 처리**: 여러 장을 선택한 상태에서 하단 작업 표시줄을 위로 밀어 올리면 '이미지 처리'가 열리며 **스티칭(파노라마)**과 **노이즈 감소 합성(흔들림 합성)**을 실행할 수 있습니다 — [제6장](06-edit.md#이미지-처리-파노라마-스티칭-및-노이즈-감소-합성pro) 참고.
- 사진이 보이지 않을 때: **설정 → 저장 공간 및 배터리 → '휴대폰 사진 다시 스캔'**을 실행하세요.

## 메모리 카드 백업(Pro)
카메라 메모리 카드를 휴대폰으로 백업합니다. USB 카드의 '메모리 카드 백업' 또는 앨범 오른쪽 위 메뉴의 '백업'에서 실행할 수 있습니다.
- **범위**: 카드 전체, 또는 사용자 지정(촬영 날짜, 아직 휴대폰에 없는 파일만, SD1 / SD2).
- **파일 형식**: RAW + JPEG, RAW만, JPEG만, RAW에서 JPEG만 저장(동영상 포함 여부 선택 가능).
- **계산**을 누르면 파일 개수, 총 용량, 예상 소요 시간, 휴대폰 남은 용량을 확인할 수 있습니다. Wi‑Fi로 RAW나 동영상을 백업할 때는 시간이 오래 걸린다는 안내가 먼저 표시됩니다.
- 백그라운드에서 실행되며(상단 알림바에서 일시정지 가능), 중단되더라도 다음에 열 때 이어서 진행할지 물어봅니다.
- 저장된 모든 파일은 다시 읽어 무결성을 검증합니다. 오류 없이 전체 백업이 완료되면 **백업된 파일을 카메라에서 삭제**할 수 있으며(이번에 검증된 파일만 삭제, 두 번 확인), 안전하게 카드를 비울 수 있습니다.

## QR Code 공유
주변 사람이 휴대폰 카메라로 QR Code를 스캔하기만 하면 웹 브라우저에서 바로 사진을 보고 다운로드할 수 있으며, **상대방은 앱을 설치할 필요가 없습니다.**

### 공유 방법
1. **휴대폰 앨범**에서 길게 눌러 사진을 선택한 뒤 작업 표시줄 첫 번째 버튼인 **공유**를 누릅니다. 이미 휴대폰에 저장된 사진(JPEG, RAW)만 공유할 수 있으며 동영상은 아직 지원하지 않습니다.
2. 화면에 큰 QR Code와 짧은 주소(예: `192.168.43.1:8080/k7Qx2mPa`)가 표시됩니다. 상대방이 휴대폰 카메라로 스캔하면 바로 열립니다.
3. **링크 복사** 또는 **링크 보내기**(LINE, Messenger 등)도 이용할 수 있습니다.

> **상대방이 같은 Wi‑Fi에 연결되어 있거나 내 휴대폰 핫스팟에 연결되어 있어야 합니다.** 호텔이나 카페의 공용 Wi‑Fi는 기기 간 통신을 차단하는 경우가 많으므로, 열리지 않을 때는 휴대폰 핫스팟을 켜서 연결하세요.

### 공유 옵션
- **비밀번호 설정**(기본 꺼짐): 상대방이 4자리 비밀번호를 입력해야 볼 수 있습니다. 전송되는 메시지에는 비밀번호가 포함되지 않으니 구두로 직접 알려주세요.
- **화질**: 무료 버전은 축소판 JPEG(긴 변 2048 px)를 한 장씩 다운로드합니다. Pro 버전에서는 **원본 해상도**와 **RAW 파일 함께 제공**을 켤 수 있으며, 상대방이 여러 장을 선택해 한 번에 ZIP 파일로 다운로드할 수 있습니다.
- **위치 정보(GPS) 유지**(기본 꺼짐): 기본 설정에서는 다운로드되는 JPEG에서 촬영 위치가 제거되며 웹 페이지에도 위치가 표시되지 않습니다. 휴대폰의 원본 파일은 수정되지 않습니다.
- 자동 종료 시간: **설정 → 수신 및 알림 → 앨범**(15 / 30 / 60분, 기본 30분)에서 설정합니다.

### 공유 중 동작
- 화면을 벗어나거나 화면을 꺼도 공유는 계속 유지되며, 상단 알림바에서 'QR Code 표시'와 '공유 중지'를 누를 수 있습니다.
- 네트워크가 잠시 끊기면 30초간 대기하며, 휴대폰 IP 주소가 바뀌어도 동일한 링크 코드를 유지하면서 화면에 다시 스캔하도록 안내합니다.
- 상대방에게 보이는 웹 페이지는 상대방 휴대폰 언어에 맞춰 번체 중국어, 간체 중국어, 일본어 또는 영어로 자동 표시되며, 크게 보기, 촬영 정보 확인, 다운로드 실패 시 원탭 재시도를 지원합니다.
- **보안**: 주소에 8자리 무작위 토큰이 포함되어 무작위 대입 시 차단되며, 선택한 사진만 공개됩니다. 상대방은 보기와 다운로드만 가능하고 업로드나 삭제는 불가능합니다. **공유 중지**를 누르면 주소가 즉시 만료됩니다.

> Xiaomi, OPPO 등 일부 스마트폰은 백그라운드 앱을 강제 종료하므로, 공유 화면에서 AeroCam의 배터리 사용량을 '제한 없음'으로 설정하도록 안내합니다.
