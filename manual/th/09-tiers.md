# 9. ฟรี / Pro / Cine

| ระดับ | ฟังก์ชัน |
|---|---|
| **ฟรี** | ส่งภาพผ่าน Bluetooth, รีโมท Bluetooth (โฟกัส, ถ่ายภาพ, บันทึกวิดีโอ, ถ่ายรัว, ตั้งเวลาถ่าย), คลังภาพผ่าน USB บนกล้อง (เลือกและดาวน์โหลดไฟล์ต้นฉบับด้วยตนเอง), คลังภาพในโทรศัพท์, ให้คะแนนดาว, แต่งภาพ (รวมถึงดูตัวอย่างสไตล์ .np3, แก้ไข RAW บนโทรศัพท์, สลับเป็น RAW แบบไม่สูญเสีย), ตำแหน่งภาพ, แชร์ผ่าน QR Code (เวอร์ชันย่อ), โหมดดูดาว |
| **Pro** | ทุกฟังก์ชันของระดับฟรี พร้อมทั้ง: Wi‑Fi (รวมถึงเชื่อมต่อหนึ่งแตะ, คลังภาพผ่าน Wi‑Fi), รับภาพผ่าน FTP, รับภาพอัตโนมัติ (Wi‑Fi, USB), ถ่ายภาพระยะไกล, ตัวช่วยถ่ายภาพ, เครื่องมือถ่ายภาพ (Bulb, ถ่ายภาพอินเตอร์วัล, คร่อมแสง, ขยับโฟกัส), ตั้งเวลาถ่ายภาพระยะไกล, โหมดซ้อนภาพเปรียบเทียบ (Ghost overlay), ถ่ายอินเตอร์วัลบนรีโมท Bluetooth, RAW บันทึกเฉพาะ JPEG, บันทึก JPEG บีบอัด, สำรองข้อมูลการ์ดหน่วยความจำ, ลบออกจากกล้อง, ถ่ายภาพโดยไม่ใส่การ์ด (บันทึกบนโทรศัพท์เท่านั้น), สไตล์กล้อง C1–C9, แชร์ QR Code ขนาดเต็มและ RAW, ต่อภาพพาโนรามา, Shake (รวมภาพลดสัญญาณรบกวน) |
| **Cine** | ทุกฟังก์ชันของระดับ Pro พร้อมทั้ง: จอมอนิเตอร์วิดีโอ, LUT, ถอดรหัสเลนส์ Anamorphic, เลื่อนโฟกัส A/B, โหมดซ้อนภาพเปรียบเทียบในจอมอนิเตอร์วิดีโอ |

เมื่อแตะที่ฟีเจอร์ที่ถูกล็อก จะแสดงระดับที่จำเป็นต้องใช้และปุ่ม «กรอกคีย์ทดสอบ»

## ช่วงเวลาระหว่าง Beta
- เวอร์ชัน Beta เริ่มต้นที่ระดับฟรี ป้อน [คีย์ทดสอบ](01-install.md#คีย์ทดสอบ-ปลดล็อก-pro-และ-cine) เพื่อใช้งานฟังก์ชัน Pro และ Cine ทั้งหมดได้ฟรี
- คีย์ทดสอบจะอัปเดตใหม่ทุกสัปดาห์ แต่ละชุดมีอายุการใช้งาน 14 วัน และเผยแพร่ฟรีบน GitHub ที่ AeroCam-Releases เท่านั้น
- เมื่อสิ้นสุดช่วงทดสอบ Beta แอปจะกลับสู่ระดับฟรีหลังจากคีย์ชุดสุดท้ายหมดอายุลง
