# 10. ความเป็นส่วนตัวและสถิติที่ไม่ระบุตัวตน

AeroCam ไม่มีระบบบัญชีผู้ใช้ รูปภาพจะถูกส่งตรงระหว่างกล้องและโทรศัพท์ของคุณเท่านั้น **และจะไม่มีการอัปโหลดไปยังเซิร์ฟเวอร์ใดๆ ทั้งสิ้น** มีเพียงข้อมูลจำนวนเล็กน้อยที่ระบุด้านล่างเท่านั้นที่จะออกจากโทรศัพท์ของคุณ

## เมื่อแอปเชื่อมต่ออินเทอร์เน็ต
| ฟังก์ชัน | ส่งข้อมูลอะไรบ้าง | ปิดได้ไหม |
|---|---|---|
| ตรวจสอบการอัปเดต (Beta) | สอบถามข้อมูลเวอร์ชันล่าสุดจาก GitHub เท่านั้น | ทำงานอัตโนมัติวันละ 1 ครั้ง |
| สถิติการใช้งานที่ไม่ระบุตัวตน | ดูด้านล่าง | ได้ ที่ การตั้งค่า → ช่วยเหลือ |
| แชร์ผ่าน QR Code | ทำงานเฉพาะในเครือข่ายท้องถิ่นของคุณ (Wi‑Fi หรือฮอตสปอตมือถือเดียวกัน) เพื่อให้ผู้สแกนดูรูปที่คุณเลือกได้ | สิ้นสุดเมื่อคุณกดหยุดหรือหมดเวลา |

## สถิติการใช้งานที่ไม่ระบุตัวตน
ใช้เพื่อทำความเข้าใจคร่าวๆ ว่ามีผู้ใช้งานจำนวนเท่าใด ใช้กล้องรุ่นใดและฟังก์ชันไหนบ้าง และมักพบปัญหาที่ใด เพื่อใช้ตัดสินใจว่าควรพัฒนาสิ่งใดก่อน **จะไม่นำไปขายให้ใครเด็ดขาด และไม่ใช้เพื่อการโฆษณา**

- **สวิตช์เปิด/ปิด**: **การตั้งค่า → ช่วยเหลือ → «ส่งสถิติการใช้งานที่ไม่ระบุตัวตน»** เปิดเป็นค่าเริ่มต้น
- จะมีคำอธิบายแสดงหนึ่งครั้งเมื่อเชื่อมต่อกล้องครั้งแรก โดยคุณสามารถเลือก «ตกลง» หรือ «ปิด» ได้ **จะไม่ส่งข้อมูลใดๆ จนกว่าคุณจะตอบ**
- **หลังจากปิด**: การส่งข้อมูลจะหยุดทันที พร้อมทั้งลบ ID สุ่มที่กล่าวถึงด้านล่างและข้อมูลที่ยังไม่ได้ส่งทิ้งทั้งหมด หากเปิดใหม่อีกครั้งจะสร้าง ID ใหม่
- เมื่อไม่มีอินเทอร์เน็ต (เช่น กำลังเชื่อมต่อ Wi‑Fi ของกล้อง) ข้อมูลจะถูกเก็บไว้ชั่วคราวบนโทรศัพท์ และจะถูกส่งไปเมื่อเชื่อมต่ออินเทอร์เน็ตได้
- รุ่นพัฒนา (Dev) จะไม่บันทึกและไม่ส่งสถิติใดๆ

### ข้อมูลที่จะถูกส่ง
- **ID สุ่มที่แอปสร้างขึ้นเอง**: ไม่ได้ดึงมาจากโทรศัพท์หรือฮาร์ดแวร์กล้อง หากติดตั้งแอปใหม่หรือปิดสถิติ ID นี้จะเปลี่ยนใหม่
- รุ่นกล้อง (เช่น Nikon Z f) ระบุเฉพาะรุ่นเท่านั้น
- วิธีการเชื่อมต่อ (Bluetooth, Wi‑Fi, USB, FTP) และประเภทของ Wi‑Fi (Wi‑Fi ของกล้อง, ฮอตสปอตมือถือ, เร้าเตอร์)
- ฟังก์ชันใดบ้างที่ถูกใช้งานในแต่ละวัน (บันทึกเฉพาะชื่อฟังก์ชัน วันละ 1 ครั้ง) รวมถึงการแตะใช้งานฟังก์ชันที่ถูกล็อกไว้
- จำนวนครั้งที่เชื่อมต่อสำเร็จหรือล้มเหลว หากล้มเหลวจะส่งเฉพาะรหัสหมวดหมู่ (เช่น «หมดเวลา») โดยไม่ส่งข้อความข้อผิดพลาด
- ขั้นตอนการเพิ่มกล้อง: เริ่มต้น, สำเร็จ, ไม่พบกล้อง, และสาเหตุที่ล้มเหลว
- จำนวนรูปภาพที่ได้รับในแต่ละวัน (นับจำนวน JPEG, RAW และวิดีโอแยกกัน นับเฉพาะจำนวนเท่านั้น)
- สถานะสิทธิ์ว่าอนุญาตหรือปฏิเสธ
- แพ็กเกจปัจจุบัน (ฟรี, คีย์ Beta…), เวอร์ชันแอป, ภาษาของแอป และเวอร์ชันหลักของ Android
- ประเทศ: ตรวจจากการเชื่อมต่อ บันทึกเฉพาะรหัสประเทศเท่านั้น

### สิ่งที่จะไม่มีวันส่งเด็ดขาด
หมายเลขซีเรียลของกล้อง, ชื่อเจ้าของหรือลิขสิทธิ์ที่ตั้งไว้ในกล้อง, ตำแหน่ง (GPS), รูปภาพและวิดีโอ, ชื่อไฟล์, ข้อมูลการถ่ายภาพ (EXIF), ชื่อและรหัสผ่าน Wi‑Fi, รหัสประจำตัวอุปกรณ์ (IMEI, Android ID, Advertising ID), ชื่อ, อีเมล, บัญชีผู้ใช้, หรือข้อความข้อผิดพลาด

### ระยะเวลาการเก็บรักษา
- รายละเอียดรายวันของอุปกรณ์แต่ละเครื่องจะถูกเก็บไว้ 90 วัน หลังจากนั้นจะเหลือเพียงยอดรวมสถิติรายวันเท่านั้น
- ID สุ่มที่ไม่มีการใช้งานเกินประมาณ 13 เดือนจะถูกลบออก
- เซิร์ฟเวอร์จำเป็นต้องเห็น IP address ของคุณเมื่อจัดการคำขอ แต่จะใช้สำหรับระบุประเทศและป้องกันการละเมิดเท่านั้น **และจะไม่ถูกบันทึกลงในฐานข้อมูลสถิติเด็ดขาด**

## ข้อมูลตำแหน่งที่ตั้ง
- **ส่งตำแหน่งไปยังกล้อง (Bluetooth)**: โทรศัพท์ส่งตำแหน่งไปยังกล้อง เพื่อให้กล้องบันทึกลงในรูปภาพ
- **เพิ่มตำแหน่งให้กับไฟล์ JPEG ที่รับมา (โทรศัพท์)**: ปิดเป็นค่าเริ่มต้น เมื่อเปิดใช้งาน ตำแหน่งที่โทรศัพท์บันทึกไว้ระหว่างช่วงเวลารับภาพจะเก็บไว้บนโทรศัพท์เครื่องนี้เท่านั้น และจะถูกลบออกหลังจากผ่านไป 24 ชั่วโมง
- สวิตช์ทั้งสองตัวอยู่ที่ **การตั้งค่า → รับและแจ้งเตือน → ตำแหน่งภาพ** — ดู [บทที่ 3](03-receive.md#ตำแหน่งภาพ-gps)
- ตำแหน่งที่ฝังอยู่ในรูปภาพจะติดไปกับไฟล์เมื่อคุณแชร์ไฟล์ต้นฉบับ **การแชร์ผ่าน QR Code จะลบตำแหน่งออกโดยค่าเริ่มต้น**

## การใช้สิทธิ์
| สิทธิ์ | วัตถุประสงค์ |
|---|---|
| Bluetooth, อุปกรณ์ใกล้เคียง | จับคู่กับกล้อง, โอนภาพผ่าน Bluetooth, รีโมท Bluetooth, ค้นหากล้อง Wi‑Fi |
| ตำแหน่งที่ตั้ง | ส่งตำแหน่งไปยังกล้องหรือเพิ่มลงในรูปภาพ และ Android ยังจำเป็นต้องใช้เพื่ออ่านชื่อเครือข่าย Wi‑Fi |
| การแจ้งเตือน | ความคืบหน้าการรับภาพ, รูปภาพที่ได้รับ, ปัญหาการรับส่ง, แจ้งเตือนแบตเตอรี่กล้องใกล้หมด |
| รูปภาพและวิดีโอ | แสดงและจัดระเบียบรูปภาพในคลังภาพโทรศัพท์ |

## ข้อมูลการวินิจฉัย
**การตั้งค่า → ช่วยเหลือ → «คัดลอกข้อมูลวินิจฉัย»** เป็นการคัดลอกข้อความลงคลิปบอร์ดเท่านั้น **คุณเป็นผู้ 1 ตัดสินใจเอง** ว่าจะส่งให้เราหรือไม่ ข้อมูลประกอบด้วยเวอร์ชันแอป, สถานะโทรศัพท์และเครือข่าย, ความสามารถของกล้อง, ประวัติคำสั่งล่าสุด, และบันทึกข้อผิดพลาดการปิดตัวกะทันหันครั้งล่าสุด โดยหมายเลขซีเรียลกล้องจะเก็บไว้เฉพาะ 4 หลักสุดท้ายเท่านั้น ก่อนที่จะวางลงใน GitHub Issue ที่เป็นสาธารณะ โปรดตรวจสอบอีกครั้งว่ามีข้อมูลส่วนตัวที่คุณไม่ต้องการเปิดเผยหรือไม่
