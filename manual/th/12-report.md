# 12. รายงานปัญหา

ไปที่ [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) และเลือกแบบฟอร์มที่เหมาะสม:

| แบบฟอร์ม | วัตถุประสงค์ |
|---|---|
| รายงานข้อผิดพลาด (Bug report) | ฟังก์ชันทำงานไม่ปกติ หรือแอปปิดตัวกะทันหัน |
| ขอฟีเจอร์ใหม่ (Feature request) | ไอเดียฟังก์ชันใหม่, การปรับปรุง, หรือค่าเริ่มต้นที่ดีกว่า |
| ข้อผิดพลาดในการแปล (Translation error) | ข้อความแปลผิด หรือภาษาอ่านไม่เป็นธรรมชาติ |
| รายงานรุ่นกล้อง (Camera report) | ผลการทดสอบการใช้งานกับกล้องรุ่นอื่นๆ |

## โปรดแนบข้อมูลเหล่านี้มาด้วย
- เวอร์ชัน AeroCam (มุมบนขวาของหน้าแรก หรือ การตั้งค่า → ช่วยเหลือ)
- รุ่นโทรศัพท์มือถือ, เวอร์ชัน Android
- รุ่นกล้อง, เวอร์ชันเฟิร์มแวร์
- วิธีการเชื่อมต่อ (Bluetooth / เชื่อมต่อหนึ่งแตะ / ฮอตสปอตมือถือ / Wi‑Fi เดียวกัน / USB / FTP)
- ขั้นตอนการทำซ้ำปัญหา, ผลลัพธ์ที่คาดหวัง, และผลลัพธ์จริง
- **ข้อมูลการวินิจฉัย**: **การตั้งค่า → ช่วยเหลือ → «คัดลอกข้อมูลวินิจฉัย»**, วางลงในแบบฟอร์ม

## หมายเหตุ
- ข้อมูลใน Issues จะเป็น**สาธารณะ** — โปรดอย่าโพสต์รหัสผ่าน Wi‑Fi, หมายเลขซีเรียลกล้องเต็ม, บัญชีผู้ใช้, หรือข้อมูลส่วนบุคคลอื่นๆ
- สำหรับเรื่องที่เป็นความลับ (เช่น ขอให้ลบข้อมูล หรือปัญหาด้านความปลอดภัย) โปรดส่งอีเมลไปที่ **aerocam.lab@gmail.com**
