# 3. รับและบันทึกอัตโนมัติ

## แดชบอร์ดกล้อง
หลังจากเชื่อมต่อกล้องแล้ว ส่วนบนสุดของหน้าจอแรกจะแสดงสถานะปัจจุบันของกล้อง:

| รายการ | เนื้อหา |
|---|---|
| รุ่น, เลนส์ | ตัวอย่าง «Nikon Z f», «NIKKOR Z 24–120 mm f/4» |
| แบตเตอรี่ | เปอร์เซ็นต์ (เปลี่ยนเป็นสีแดงเมื่อต่ำกว่า 20%) |
| วิธีการเชื่อมต่อ | ฮอตสปอตมือถือ, Wi‑Fi เดียวกัน, Wi‑Fi กล้อง, USB |
| การ์ดหน่วยความจำ | พื้นที่ใช้งาน/ความจุทั้งหมด และจำนวนภาพที่ถ่ายได้ของแต่ละการ์ด แสดงแยกช่องใส่การ์ดคู่ |
| คุณภาพภาพ | ตัวอย่าง `RAW`, `JPEG fine★ L`; อัปเดตอัตโนมัติเมื่อเปลี่ยนคุณภาพบนกล้องหรือถอด/ใส่การ์ด |
| ตำแหน่งบันทึก | ตัวอย่าง «บันทึกไปที่: การ์ด ✓» — ดู [ตำแหน่งบันทึกและการถ่ายภาพโดยไม่ใส่การ์ด](#ตำแหน่งบันทึกและการถ่ายภาพโดยไม่ใส่การ์ด) ด้านล่าง |
| การถ่ายโอน | สถานะปัจจุบัน มุมบนขวาคือ «ประวัติ ›» |
| สไตล์กล้อง | ข้อมูล C1–C9 ที่อ่านพบล่าสุด — ดู [บทที่ 6](06-edit.md#สไตล์กล้อง-c1c9-pro) |

ข้อมูลที่กล้องไม่รองรับในโหมดนั้นๆ จะถูกซ่อนไว้ เมื่อเปลี่ยนเป็น «Camera control» (ควบคุมกล้อง) และเข้าสู่โหมดถ่ายภาพระยะไกล มักจะอ่านข้อมูลได้มากขึ้น

### จัดการกล้อง
ขยายหัวข้อ **จัดการกล้อง (n)** ใต้แดชบอร์ด เพื่อแก้ไข ลบ หรือเพิ่มกล้องได้ หน้า «รายละเอียด» ของกล้องแต่ละตัวจะแสดง:
- รุ่น, หมายเลขซีเรียล (ซ่อนตัวเลขตรงกลาง แตะเพื่อดูเต็ม), เวอร์ชันเฟิร์มแวร์, **จำนวนครั้งที่ชัตเตอร์ทำงาน (Shutter count)** และวันที่อ่านข้อมูล
- **จำนวนชัตเตอร์รายเดือน**: กราฟแท่งย้อนหลัง 6 เดือน (มีข้อมูลนับตั้งแต่เริ่มใช้งาน AeroCam)
- เวลา, วิธีการเชื่อมต่อ, เลนส์, ระดับแบตเตอรี่ และพื้นที่ว่างในการ์ดของการเชื่อมต่อครั้งล่าสุด
- จำนวนไฟล์ที่ส่งไปยังโทรศัพท์, วันที่เชื่อมต่อครั้งแรก และโปรไฟล์เครือข่ายที่บันทึกไว้

จำนวนชัตเตอร์อ่านมาจากข้อมูลของภาพล่าสุดบนการ์ดหน่วยความจำ ดังนั้นต้องมีรูปภาพบนการ์ดอย่างน้อย 1 รูป

### แจ้งเตือนแบตเตอรี่ต่ำ
ส่งการแจ้งเตือนเมื่อแบตเตอรี่กล้องลดลงถึงเกณฑ์ (ค่าเริ่มต้น 15%) และจะไม่แจ้งเตือนอีกจนกว่าแบตเตอรี่จะเพิ่มขึ้นสูงกว่าเกณฑ์ +5% สามารถปรับหรือปิดเกณฑ์นี้ได้ที่ **การตั้งค่า → รับและแจ้งเตือน**

📷 ภาพหน้าจอ: แดชบอร์ดกล้อง

## รับภาพอัตโนมัติ (Pro)
1. หน้าแรก Wi‑Fi → **เริ่มรับภาพ** แอปจะรักษากล้องให้อยู่ในสถานะเชื่อมต่อเบื้องหลัง (สังเกตได้จากแถบแจ้งเตือน)
2. เมื่อเปิดดูรูปย้อนหลังบนกล้อง ให้กด **i → Send to PC / Select to send** (ส่งไปยัง PC / เลือกเพื่อส่ง, ชื่อเมนูต่างกันตามรุ่นกล้อง) รูปภาพจะถูกส่งมายังโทรศัพท์ทันที

หากต้องการให้ถ่ายเสร็จแล้วส่งเข้าโทรศัพท์อัตโนมัติทันที ให้ใช้ [รับภาพผ่าน FTP](08-ftp.md) เมื่อเสียบสาย USB การรับภาพจะสลับไปใช้ USB โดยอัตโนมัติ

### พักการรับภาพ
ขณะที่กำลังเชื่อมต่อรับภาพอัตโนมัติผ่าน Wi‑Fi อยู่ คุณสามารถแตะ **⏸ พักชั่วคราว** ที่มุมบนขวาของการ์ด «ถ่ายโอน» หรือปุ่ม «พักชั่วคราว» บนการแจ้งเตือนเพื่อหยุดพักชั่วคราวได้:
- การเชื่อมต่อ Wi‑Fi ยังคงอยู่ ใช้งานคลังภาพและถ่ายภาพระยะไกลได้ตามปกติ
- รูปที่ค้างส่งจะรออยู่บนกล้อง เมื่อแตะ **รับต่อ** รูปจะถูกส่งต่อตามลำดับ โดยรูปที่กำลังส่งอยู่จะส่งให้เสร็จก่อน
- การรับภาพจะกลับมาทำงานอัตโนมัติเมื่อกดดำเนินการต่อ, หยุดรับภาพ, ปัดแอปทิ้งจากหน้าแอป Lot, หลุด Wi‑Fi, ปิดกล้อง หรือเสียบสาย USB

### เมื่อขาดการเชื่อมต่อ
- หากการเชื่อมต่อหลุด แอปจะพยายามเชื่อมต่อใหม่อัตโนมัติ หากลองหลายครั้งไม่สำเร็จ จะค้นหาใหม่ด้วยรหัสประจำตัวกล้อง ต่อให้ IP กล้องเปลี่ยนไปก็ยังหาเจอ
- **กล้องเปลี่ยนไปส่งภาพผ่าน Bluetooth**: เนื่องจากกล้องมีชิปไร้สายตัวเดียว ตอนส่งภาพผ่าน Bluetooth จึงต้องปิด Wi‑Fi ชั่วคราว หน้าแรกจะแสดง «กล้องกำลังส่งภาพผ่าน Bluetooth… ส่งเสร็จจะเชื่อมต่อ Wi‑Fi ให้อัตโนมัติ» และไม่นับเป็นข้อผิดพลาด
- **คลังภาพ / ถ่ายภาพระยะไกลยืมการเชื่อมต่อกล้อง**: กล้องรับได้ทีละหนึ่งการเชื่อมต่อเท่านั้น เมื่อคุณเข้าคลังภาพหรือถ่ายภาพระยะไกล ระบบรับภาพอัตโนมัติจะสลับหลีกทางให้ และจะกลับมาทำงานต่ออัตโนมัติเมื่อคุณออก
- **เมื่อหา Wi‑Fi ของกล้องไม่พบ**: เกินเวลาที่ตั้งไว้ (ค่าเริ่มต้น 3 นาที) ระบบจะหยุดรับภาพอัตโนมัติและแจ้งเตือนเพื่อประหยัดแบตเตอรี่ ปรับตั้งเวลาได้ที่ **การตั้งค่า → รับและแจ้งเตือน**

## กฎการรับภาพ
ตั้งค่าได้ที่ **การตั้งค่า → รับและแจ้งเตือน** โดย Wi‑Fi, USB และ FTP จะใช้กฎการบันทึกเดียวกันนี้

### ประเภทไฟล์ที่รับ
เลือกประเภทไฟล์ที่ต้องการบันทึก: ทุกไฟล์, เฉพาะ JPG, JPG + RAW, ภาพ + วิดีโอ, หรือกำหนดเอง (JPEG, RAW, HEIF, TIFF, วิดีโอ, อื่นๆ)

และมีสวิตช์เพิ่มเติมอีก 3 ตัว (Pro):

| สวิตช์ | การทำงาน |
|---|---|
| **RAW บันทึกเฉพาะ JPEG** | เมื่อได้รับไฟล์ RAW จะดึงเฉพาะภาพ JPEG ขนาดเต็มที่ฝังมาในไฟล์ (มักจะ 2–5 MB แทนที่จะเป็น RAW 20–50 MB) ความละเอียดเท่าเดิม ข้อมูลการถ่ายภาพครบถ้วน บันทึกเป็น `DSC_1234_S.JPG` เหมาะสำหรับแชร์โซเชียลหรือดูประจำวัน |
| **บันทึก JPEG ฉบับบีบอัด** | เมื่อรับภาพ JPEG จากกล้อง โทรศัพท์จะทำการบีบอัดซ้ำแล้วค่อยบันทึก (`_S.JPG`, พิกเซลเท่าเดิม คุณภาพตามการตั้งค่าคลังภาพ) |
| **แทนที่ฉบับบีบอัดเมื่อได้รับไฟล์ต้นฉบับ** | เมื่อบันทึกไฟล์ JPEG ต้นฉบับสำเร็จ จะลบไฟล์บีบอัด `_S.JPG` ที่มีชื่อเดียวกันบนโทรศัพท์ทิ้ง |

> หากต้องการรับไฟล์ RAW ให้ตั้งค่าคุณภาพภาพบนกล้องเป็น RAW หรือ RAW+JPEG และเลือก RAW+JPEG ในตัวเลือกอัปโหลด «Connect to PC» ของกล้อง (อย่าเลือก «JPEG only») ชื่อเมนูอาจต่างกันตามรุ่นกล้อง

### กฎอื่นๆ
| กฎ | รายละเอียด |
|---|---|
| โหมดการรับ | รับต่อเนื่อง หรือหยุดทันทีเมื่อได้รับ 1 ไฟล์ |
| วิดีโอขนาดใหญ่ | วิดีโอที่เกินเกณฑ์ (ค่าเริ่มต้น 1024 MB) จะไม่รับอัตโนมัติแต่บันทึกเป็น «ถูกกรอง» ให้ดาวน์โหลดด้วยตนเอง |
| โฟลเดอร์จัดเก็บ | ตามกล้อง, ตามวันที่, ตามกล้องและวันที่, ตามประเภทไฟล์ |
| ชื่อไฟล์ | ชื่อเดิมจากกล้อง (`DSC_1234.NEF`), เติมคำนำหน้าวันที่ (`20261011_DSC_1234.NEF`), เติมคำนำหน้าวันและเวลา (`20261011_153012_DSC_1234.NEF` — ช่วยให้กล้องหลายตัวเรียงลำดับตามเวลาถ่ายได้ถูกต้อง) มีผลเฉพาะไฟล์ที่บันทึกหลังจากนี้ |

### ตำแหน่งจัดเก็บ
- รูปภาพ: `Pictures/AeroCam/…`
- วิดีโอ: `Movies/AeroCam/…`
- ไฟล์อื่นๆ: `Download/AeroCam/…`

แอปอื่นๆ เช่น Google Photos สามารถมองเห็นได้ทันที หากถอนการติดตั้งและติดตั้ง AeroCam ใหม่ สามารถใช้ **การตั้งค่า → พื้นที่เก็บข้อมูลและแบตเตอรี่ → «สแกนหารูปภาพในโทรศัพท์อีกครั้ง»** เพื่อดึงรูปเก่ากลับเข้าคลังภาพได้

### การตรวจสอบไฟล์ซ้ำ
- ตรวจสอบโดยใช้หมายเลขซีเรียลกล้อง, ชื่อไฟล์, ขนาด, เวลาถ่าย และแฮชไฟล์ ไฟล์ที่ซ้ำจะไม่บันทึกซ้ำและระบุในประวัติว่า «ซ้ำ»
- ภาพที่คุณลบออกจากโทรศัพท์ (รวมถึงย้ายลงถังขยะ) หากส่งมาจากกล้องอีกครั้งจะถูกบันทึกใหม่
- การส่งภาพเดิมซ้ำ ไม่จำเป็นต้องกดหยุดแล้วเริ่มรับใหม่

### เมื่อได้รับภาพเดียวกันผ่านทั้ง Bluetooth และ Wi‑Fi
ไฟล์จาก Wi‑Fi มีความสมบูรณ์กว่า (ความละเอียดเต็ม) จึงยึด Wi‑Fi เป็นหลัก:
- Wi‑Fi มาถึงก่อนแล้ว Bluetooth ส่งตามมา: ละเว้นฉบับ Bluetooth ไม่บันทึก
- Bluetooth มาถึงก่อน แล้วภายหลัง Wi‑Fi ได้รับภาพเดียวกัน ขึ้นอยู่กับ **การตั้งค่า → รับและแจ้งเตือน → «รูปภาพที่ได้รับผ่าน Bluetooth แล้ว»**:
  - **แทนที่ด้วยไฟล์ต้นฉบับเมื่อได้รับผ่าน Wi‑Fi** (แนะนำ): บันทึกไฟล์ขนาดเต็มและลบไฟล์ย่อ Bluetooth บนโทรศัพท์ทิ้งอัตโนมัติ
  - **ไม่ต้องดาวน์โหลดผ่าน Wi‑Fi อีก**
  - **เก็บไว้ทั้งสองฉบับ**
- ไฟล์ต้นฉบับ RAW จะรับเข้ามาเสมอไม่มีเงื่อนไข

## ตำแหน่งบันทึกและการถ่ายภาพโดยไม่ใส่การ์ด
กำหนดว่าเมื่อกดชัตเตอร์แล้วรูปจะบันทึกไปที่ใด แอปจะอ่านว่ากล้องใส่การ์ดหรือไม่แล้วเลือกให้อัตโนมัติ:
- **กล้องใส่การ์ดอยู่**: ทำตามวิธีที่เลือกไว้ที่ **การตั้งค่า → การถ่ายภาพ → ตำแหน่งบันทึก**:
  - **การ์ดหน่วยความจำ**: บันทึกลงการ์ดของกล้อง
  - **การ์ดหน่วยความจำ ＋ โทรศัพท์** (Pro): บันทึกลงการ์ด และคัดลอกอีกชุดมาที่โทรศัพท์พร้อมกัน
- **กล้องไม่ใส่การ์ด** (Pro): เปลี่ยนเป็น **บันทึกเฉพาะบนโทรศัพท์ (ถ่ายแบบไม่ใส่การ์ด)** โดยอัตโนมัติ คุณยังคงกดชัตเตอร์ได้ตามปกติ รูปจะส่งตรงมายังโทรศัพท์ ตั้งชื่อตามเวลาที่ถ่าย (เช่น `AC_20261025_193805.JPG`) เมื่อใส่การ์ดแล้วจะเปลี่ยนกลับให้อัตโนมัติ

ใช้งานได้จากหน้าแรก, คลังภาพ และการถ่ายภาพระยะไกล รองรับทั้ง Wi‑Fi และ USB

**ต้องตั้งค่าก่อนในครั้งแรก:**
1. ในเมนูการตั้งค่ากำหนดเองของกล้อง เปลี่ยน **Slot empty release lock** (ล็อกการลั่นชัตเตอร์เมื่อช่องใส่การ์ดว่าง) เป็น **Enable release** (อนุญาตให้ลั่นชัตเตอร์ได้) มิฉะนั้นกล้องจะไม่ยอมให้กดชัตเตอร์เมื่อไม่มีการ์ด
2. เมื่อเชื่อมต่อ Wi‑Fi ประเภทการเชื่อมต่อของกล้องต้องเป็น **Camera control** (ควบคุมกล้อง) หากยังเป็น «Image transfer» (ถ่ายโอนภาพ) ประมาณ 3 3 วินาทีหลังถ่ายภาพแรก แอปจะเตือนให้สลับ ภาพจะยังค้างอยู่ในบัฟเฟอร์ของกล้อง และจะถูกส่งมาอัตโนมัติหลังสลับแล้ว สำหรับ USB ไม่มีข้อจำกัดนี้
3. เชื่อมต่อหนึ่งแตะไม่รองรับการถ่ายภาพโดยไม่ใส่การ์ด โปรดใช้ฮอตสปอตมือถือหรือ Wi‑Fi เดียวกันแทน

**วิธีอ่านสถานะแถบสถานะ** (ด้านบนของหน้าแรกและคลังภาพ):

| ข้อความแสดง | ความหมาย |
|---|---|
| บันทึกไปที่: การ์ด ✓ | บันทึกลงการ์ดหน่วยความจำของกล้อง |
| บันทึกไปที่: การ์ด + โทรศัพท์ ✓ | บันทึกลงการ์ดและคัดลอกมาที่โทรศัพท์ด้วย |
| บันทึกไปที่: โทรศัพท์เท่านั้น (ไม่มีการ์ดในกล้อง) | รูปภาพส่งตรงมายังโทรศัพท์ |
| กล้องอยู่ในโหมด «Image transfer»… (ตัวหนังสือสีแดง) | โปรดเปลี่ยนเป็น «Camera control» |
| Wi‑Fi หนึ่งแตะ: ไม่มีการ์ดความจำ ถ่ายภาพไม่ได้ (ตัวหนังสือสีแดง) | โปรดใส่การ์ด หรือเปลี่ยนไปใช้ฮอตสปอต / Wi‑Fi เดียวกัน |
| การ์ดหน่วยความจำเต็ม (ตัวหนังสือสีแดง) | โปรดเปลี่ยนการ์ดหรือเคลียร์พื้นที่ (จะไม่เปลี่ยนเป็นบันทึกเฉพาะโทรศัพท์ให้อัตโนมัติ) |
| ไม่มีการ์ดความจำในกล้อง ถ่ายภาพไม่ได้ (ตัวหนังสือสีแดง) | เป็นรุ่นฟรี หรือพื้นที่ว่างบนโทรศัพท์เหลือน้อยกว่า 1 GB |

> เมื่อไม่ใส่การ์ด กล้องจะไม่สามารถบันทึกวิดีโอได้ และการถ่ายภาพต่อเนื่องจะช้าลง (เพราะแต่ละภาพต้องรอส่งมายังโทรศัพท์)

## ตำแหน่งภาพ (GPS)
ที่ **การตั้งค่า → รับและแจ้งเตือน → ตำแหน่งภาพ** มีสวิตช์ 2 ตัว:
- **ส่งตำแหน่งไปยังกล้อง (Bluetooth)** (เปิดเป็นค่าเริ่มต้น): เมื่อเปิดกล้องหรือส่งภาพผ่าน Bluetooth โทรศัพท์จะส่งพิกัด GPS ไปยังกล้องเพื่อให้กล้องบันทึกพิกัดลงในภาพขณะถ่าย
- **เพิ่มตำแหน่งให้กับไฟล์ JPEG ที่รับมา (โทรศัพท์)**: ภาพ JPEG ที่รับผ่าน Wi‑Fi, USB, FTP, ดาวน์โหลดจากคลังภาพ หรือถ่ายจากระยะไกล จะถูกโทรศัพท์จับคู่เวลาถ่ายแล้วเขียนพิกัดสถานที่ลงไป จะถามยืนยันหนึ่งครั้งเมื่อเริ่มรับภาพครั้งแรก
  - ไฟล์ RAW จะไม่ถูกแก้ไข; ภาพที่มีพิกัดอยู่แล้วจะคงพิกัดเดิมไว้
  - ประวัติตำแหน่งที่โทรศัพท์บันทึกไว้ในระหว่างรับภาพจะอยู่บนเครื่องนี้เท่านั้น และจะถูกลบออกหลังผ่านไป 24 ชั่วโมง
  - หากเวลาถ่ายไม่ตรงกับจุดพิกัดใดเลยจะไม่เขียนทับ ยอมไม่มีพิกัดดีกว่าใส่ผิด
  - ต้องเปิด AeroCam ค้างไว้ตอนเริ่มรับภาพ จึงจะบันทึกพิกัดได้

> พิกัด GPS ที่ฝังในภาพจะติดไปกับไฟล์ต้นฉบับเมื่อคุณแชร์ภาพนั้น การแชร์ผ่าน QR Code จะลบพิกัดออกโดยค่าเริ่มต้น — ดู [บทที่ 4](04-gallery.md#แชร์ผ่าน-qr-code)

## ประวัติ
แตะ **ประวัติ ›** ที่มุมบนขวาของการ์ด «ถ่ายโอน» บนหน้าแรก เพื่อดูผลลัพธ์ทั้งหมดของการรับอัตโนมัติ, ดาวน์โหลดจากคลังภาพ และบันทึกจากการถ่ายภาพระยะไกล: สำเร็จ, ซ้ำ, ข้าม, ล้มเหลว พร้อมภาพตัวอย่างย่อ
- แตะหนึ่งครั้งเพื่อดูภาพเต็มจอภายในแอป
- สามารถค้นหา, กรองตามกล้อง และล้างประวัติได้ การล้างประวัติจะไม่ลบไฟล์ภาพบนโทรศัพท์
