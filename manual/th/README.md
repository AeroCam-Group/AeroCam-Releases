# คู่มือผู้ใช้ AeroCam (ไทย)

> ตรงกับเวอร์ชัน **Beta 92.04.08.10** (อัปเดตเมื่อ 2026-11-15) บรรทัดที่มีเครื่องหมาย 📷 คือตำแหน่งที่เตรียมไว้สำหรับใส่ภาพหน้าจอในภายหลัง

AeroCam ช่วยส่งรูปภาพจากกล้องของคุณไปยังโทรศัพท์ Android ได้โดยตรง นอกจากนี้ยังช่วยให้คุณควบคุมกล้องจากโทรศัพท์ แก้ไขรูปภาพ และเขียนสไตล์ภาพลงในกล้องได้อีกด้วย ปัจจุบันรองรับ **Nikon Z series** และจะมีแผนรองรับแบรนด์อื่นๆ เพิ่มเติมในอนาคต

AeroCam เป็นแอปพลิเคชันบุคคลที่สามที่พัฒนาขึ้นอย่างอิสระ ไม่มีส่วนเกี่ยวข้องหรือได้รับอนุญาตจาก Nikon หรือผู้ผลิตกล้องรายอื่นใดทั้งสิ้น

## สารบัญ

1. [การติดตั้งและเริ่มต้นใช้งาน](01-install.md): การติดตั้ง, สิทธิ์การใช้งาน, ทัวร์หน้าจอ, คีย์ทดสอบ, การอัปเดต, ภาษา
2. [เชื่อมต่อกล้องของคุณ](02-connect.md): Bluetooth, Wi‑Fi (เชื่อมต่อหนึ่งแตะ / ฮอตสปอตมือถือ / Wi‑Fi เดียวกัน), สาย USB, วิธีเลือก, คู่มือการเชื่อมต่อ
3. [รับและบันทึกอัตโนมัติ](03-receive.md): เริ่ม/หยุดพักการรับ, กฎการรับ, โฟลเดอร์และชื่อไฟล์, ถ่ายภาพโดยไม่ใส่การ์ด, ตำแหน่งภาพ, แดชบอร์ดกล้อง, ประวัติ
4. [แกลเลอรี](04-gallery.md): การ์ดหน่วยความจำกล้อง, รูปภาพในโทรศัพท์, ดาวน์โหลดและลบ, ให้คะแนนดาว, สำรองข้อมูลการ์ดหน่วยความจำ, แชร์ผ่าน QR Code
5. [การถ่ายภาพระยะไกลและการควบคุม](05-remote.md): ถ่ายภาพระยะไกลผ่าน Wi‑Fi/USB, วิธีการถ่ายภาพ, ตัวช่วยในการถ่ายภาพ, รีโมท Bluetooth, จอมอนิเตอร์วิดีโอ, โหมดดูดาว
6. [การแต่งภาพและสไตล์ภาพ](06-edit.md): โปรแกรมแก้ไขภาพ, ดูตัวอย่างสไตล์ .np3, แก้ไข RAW บนโทรศัพท์, สไตล์กล้อง C1–C9, ต่อภาพพาโนรามา, รวมภาพลดสัญญาณรบกวน (Shake)
7. [อ้างอิงการตั้งค่า](07-settings.md)
8. [รับภาพผ่าน FTP](08-ftp.md): กล้องส่งภาพตรงเข้าโทรศัพท์โดยอัตโนมัติหลังถ่ายเสร็จ
9. [ฟรี / Pro / Cine](09-tiers.md)
10. [ความเป็นส่วนตัวและสถิติที่ไม่ระบุตัวตน](10-privacy.md)
11. [คำถามที่พบบ่อยและการแก้ปัญหา](11-faq.md)
12. [รายงานปัญหา](12-report.md)

## กล้องที่รองรับ

| รุ่น | รับอัตโนมัติ, คลังภาพในกล้อง | ถ่ายภาพระยะไกล | สถานะ |
|---|---|---|---|
| Z9, Z8, Z6III, Zf, Z5II, Z50II, ZR และรุ่นอื่นๆ ที่มี «Connection type» (ประเภทการเชื่อมต่อ) ในเมนู | ✅ | ✅ | ทดสอบแล้วบน Zf ยินดีรับรายงานจากรุ่นอื่นๆ |
| Z6, Z7, Z6II, Z7II, Z5, Z50, Zfc, Z30 และรุ่นเก่ากว่า | ✅ | ❌ (โปรโตคอลการเชื่อมต่อของรุ่นเหล่านี้ไม่รองรับ) | ยินดีรับรายงาน |
| Canon, Sony, Fujifilm | กำลังเตรียมการ | กำลังเตรียมการ | |

หากคุณทดสอบ AeroCam กับกล้องรุ่นอื่น โปรดแจ้งให้เราทราบว่าฟังก์ชันใดใช้งานได้หรือไม่ได้ผ่าน [รายงานรุ่นกล้อง](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose)

## คำศัพท์ที่ใช้ในคู่มือนี้
| คำศัพท์ในคู่มือ | ความหมาย |
|---|---|
| คลังภาพในกล้อง / การ์ดหน่วยความจำกล้อง | รูปภาพบนการ์ดหน่วยความจำของกล้อง ซึ่งเรียกดูจากโทรศัพท์ผ่านการเชื่อมต่อ |
| รูปภาพในโทรศัพท์ / แกลเลอรีโทรศัพท์ | รูปภาพที่บันทึกไว้ในโทรศัพท์ของคุณแล้ว |
| RAW | ไฟล์ NEF ของ Nikon |
| JPEG.S | JPEG ที่บีบอัดแล้ว (JPEG ที่ดึงมาจาก RAW, JPEG ที่บีบอัดใหม่บนโทรศัพท์ หรือไฟล์ย่อที่ส่งผ่าน Bluetooth) ลงท้ายด้วยชื่อไฟล์ `_S.JPG` |
| Picture Control | โปรไฟล์สีของกล้อง เช่น Standard หรือ Flat โดยสไตล์กำหนดเองจะเก็บไว้ที่ C1–C9 |
| Pro / Cine | ระดับที่ต้องชำระเงิน ในช่วง Beta คุณสามารถป้อนคีย์ทดสอบฟรีเพื่อปลดล็อกทุกอย่างได้ — ดู [บทที่ 9](09-tiers.md) |
