# 1. การติดตั้งและเริ่มต้นใช้งาน

## การติดตั้ง
1. ดาวน์โหลด Beta APK ล่าสุด (`…-Beta-xx.xx.xx.apk`) จาก [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest)
2. เปิดไฟล์ APK บนโทรศัพท์ของคุณ ในครั้งแรก Android จะขออนุญาต «ติดตั้งแอปที่ไม่รู้จัก» — โปรดกดอนุญาต
3. เมื่อมีเวอร์ชันใหม่ออกมา เพียงดาวน์โหลดและติดตั้งทับเวอร์ชันเดิม ข้อมูลการจับคู่และการตั้งค่าทั้งหมดจะยังคงอยู่

> ดาวน์โหลดจาก AeroCam-Releases เท่านั้น APK จากแหล่งอื่นอาจถูกแก้ไขดัดแปลง หากเปิดแอปแล้วพบข้อความ «นี่ไม่ใช่เวอร์ชันอย่างเป็นทางการ» แสดงว่าแอปถูกนำไปแพ็กใหม่โดยบุคคลอื่น ซึ่งจะไม่รับคีย์ทดสอบและอาจมีโค้ดอันตรายแฝงอยู่ โปรดถอนการติดตั้งแล้วดาวน์โหลดใหม่จาก AeroCam-Releases

> หากคุณเคยใช้ **Beta เวอร์ชันเก่าก่อน 92.03.09**: เวอร์ชันใหม่จะถูกติดตั้งเป็นแอปแยกต่างหาก คุณต้องจับคู่กล้องใหม่และกรอกคีย์ทดสอบใหม่อีกครั้ง จากนั้นจึงค่อยถอนการติดตั้งเวอร์ชันเก่าออกเมื่อทุกอย่างทำงานปกติ

📷 ภาพหน้าจอ: หน้าจอระบบ «ติดตั้งแอปที่ไม่รู้จัก»

## สิทธิ์การใช้งาน
แอปจะขอสิทธิ์เฉพาะเมื่อคุณใช้งานฟีเจอร์ที่จำเป็นต้องใช้สิทธิ์นั้น คุณสามารถปฏิเสธสิทธิ์ที่ไม่ต้องการได้:

| สิทธิ์ | วัตถุประสงค์ |
|---|---|
| Bluetooth, อุปกรณ์ใกล้เคียง | จับคู่ Bluetooth, โอนภาพผ่าน Bluetooth, รีโมท Bluetooth; จำเป็นสำหรับ Android 13 ขึ้นไปในการค้นหากล้อง Wi‑Fi ด้วย |
| ตำแหน่งที่ตั้ง | ส่งตำแหน่งโทรศัพท์ไปยังกล้องเพื่อบันทึกในภาพ หรือเพิ่มตำแหน่งให้กับไฟล์ JPEG ที่รับมา; Android ยังใช้เพื่ออ่านชื่อเครือข่าย Wi‑Fi ด้วย |
| การแจ้งเตือน | ความคืบหน้าการรับภาพ, รูปภาพที่ได้รับ, ปัญหาการรับส่ง, แจ้งเตือนแบตเตอรี่กล้องใกล้หมด |
| รูปภาพและวิดีโอ | แสดงและจัดการรูปภาพบนโทรศัพท์ของคุณ |

อ่านรายละเอียดเพิ่มเติมเกี่ยวกับแต่ละสิทธิ์ได้ที่ [ความเป็นส่วนตัวและสถิติที่ไม่ระบุตัวตน](10-privacy.md)

## ทัวร์หน้าจอ
มีแท็บหลัก 4 แท็บที่ด้านล่าง:

| แท็บ | เนื้อหาภายใน |
|---|---|
| **หน้าแรก** | แดชบอร์ดกล้อง (แบตเตอรี่, เลนส์, การ์ดหน่วยความจำ, สถานะการเชื่อมต่อ), ช่องทางเชื่อมต่อ 4 แบบ (Wi‑Fi, USB, Bluetooth, FTP), สถานะและประวัติการรับส่ง, สไตล์กล้อง, จัดการกล้อง |
| **คลังภาพ** | แท็บย่อย 2 แท็บ: «รูปภาพในโทรศัพท์» และ «การ์ด SD ของกล้อง» — ดู [บทที่ 4](04-gallery.md) |
| **ถ่ายจากระยะไกล** | ดูภาพสดจากกล้องบนโทรศัพท์, ปรับตั้งค่า, ถ่ายภาพนิ่งและวิดีโอ — ดู [บทที่ 5](05-remote.md) |
| **การตั้งค่า** | แบ่งเป็น 5 หมวดหมู่ — ดู [บทที่ 7](07-settings.md) |

หากไม่แน่ใจว่าจะเชื่อมต่อกล้องอย่างไร ให้แตะ **ⓘ** ข้างสถานะการเชื่อมต่อบนหน้าแรก หรือที่มุมบนขวาของแต่ละขั้นตอนในหน้า «เพิ่มกล้อง» เพื่อเปิดคู่มือภาพประกอบทีละขั้นตอนสำหรับวิธีเชื่อมต่อนั้นๆ

📷 ภาพหน้าจอ: หน้าแรก

## คีย์ทดสอบ (ปลดล็อก Pro และ Cine)
เวอร์ชัน Beta เริ่มต้นที่ระดับฟรี
1. คัดลอกคีย์ทดสอบปัจจุบันจาก [หน้าแรก AeroCam-Releases](https://github.com/AeroCam-Group/AeroCam-Releases) ในแอป ให้ไปที่ **การตั้งค่า → ช่วยเหลือ → «รับคีย์ฟรี»** เพื่อเปิดหน้านั้นโดยตรง
2. ไปที่ **การตั้งค่า → ช่วยเหลือ → «กรอกคีย์ทดสอบ»** วางข้อความทั้งหมดแล้วแตะ «ปรับใช้» การแตะฟีเจอร์ที่ถูกล็อกอยู่จะแสดงปุ่ม «กรอกคีย์ทดสอบ» ในหน้าต่างแจ้งเตือนเช่นกัน
3. คีย์แต่ละชุดมีอายุการใช้งาน 14 วันและจะอัปเดตใหม่ทุกสัปดาห์ เมื่อหมดอายุ แอปจะกลับสู่ระดับฟรี ให้กลับมาคัดลอกคีย์ใหม่ไปวาง

> ทั้งเวอร์ชัน Beta และคีย์ทดสอบนั้น**ฟรี** และเผยแพร่บน GitHub ที่ AeroCam-Releases เท่านั้น หากมีผู้ใดเรียกเก็บเงินจากคุณ นั่นไม่ใช่ช่องทางอย่างเป็นทางการ

## ตรวจสอบการอัปเดต
Beta จะตรวจสอบโดยอัตโนมัติในครั้งแรกที่คุณเปิดแอปในแต่ละวัน หรือตรวจสอบด้วยตนเองได้ที่ **การตั้งค่า → ช่วยเหลือ → «ตรวจสอบการอัปเดต»**

## ภาษา
รองรับภาษาจีนตัวเต็ม, จีนตัวย่อ, ญี่ปุ่น, อังกฤษ, 한국어, Deutsch, Français, Español, Tiếng Việt, ไทย และ Bahasa Indonesia โดยค่าเริ่มต้นจะอ้างอิงตามภาษาของระบบโทรศัพท์ หรือเปลี่ยนได้ที่ **การตั้งค่า → รูปลักษณ์และภาษา → ภาษา**

ภาษาอังกฤษ, จีนตัวเต็ม และญี่ปุ่น แปลครบถ้วน 100% เสมอ ฟีเจอร์ใหม่ในภาษาอื่นๆ อาจแสดงเป็นภาษาอังกฤษก่อนแล้วจึงอัปเดตคำแปลภายหลัง หากพบคำแปลที่ไม่ถูกต้อง สามารถแจ้งให้เราทราบผ่านฟอร์ม «ข้อผิดพลาดในการแปล» ใน [รายงานปัญหา](12-report.md)

## สถิติการใช้งานที่ไม่ระบุตัวตน
ในการเชื่อมต่อกล้องครั้งแรก แอปจะอธิบายเรื่อง «ส่งสถิติการใช้งานที่ไม่ระบุตัวตน» หนึ่งครั้ง คุณสามารถเลือก «ตกลง» หรือ «ปิด» ได้ โดย**จะไม่ส่งข้อมูลใดๆ จนกว่าคุณจะตอบ** คุณสามารถปิดได้ตลอดเวลาที่ **การตั้งค่า → ช่วยเหลือ** ข้อมูลใดบ้างที่ส่งและข้อมูลใดบ้างที่ไม่เคยส่งเลย อ่านได้ที่ [ความเป็นส่วนตัวและสถิติที่ไม่ระบุตัวตน](10-privacy.md)
