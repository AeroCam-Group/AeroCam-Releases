# 8. รับภาพผ่าน FTP (Pro)

เมื่อถ่ายภาพเสร็จ กล้องจะ**ส่งภาพผ่าน FTP ตรงไปยังโทรศัพท์ของคุณเอง** โดยไม่ต้องเลือกรูปบนกล้องและไม่ต้องเปิดคลังภาพ ทดสอบจริงบน Nikon Zf ไฟล์ RAW หนึ่งไฟล์ (ประมาณ 18 MB) ใช้เวลาเดินทางมาถึงโทรศัพท์เพียงประมาณ 1 วินาทีเท่านั้น

AeroCam ทำหน้าที่เป็น FTP Server ในตัวอยู่แล้ว **จึงไม่ต้องตั้งค่าเซิร์ฟเวอร์ภายนอกใดๆ เพิ่มเติม**

## เหมาะสำหรับ
- งานอีเวนต์, งานแต่งงาน, กีฬา: ถ่ายไปส่งภาพเข้าโทรศัพท์ไปแบบเรียลไทม์
- ต้องการดูผลลัพธ์บนโทรศัพท์มือถือทันทีหลังถ่าย หรือแชร์ลงโซเชียลมีเดียอย่างรวดเร็ว

## สิ่งที่ต้องมี
- กล้องที่มีฟังก์ชันอัปโหลด FTP ในตัว (Nikon Z f, Z 8, Z 9, Z 6III เป็นต้น)
- เปิด **ฮอตสปอตมือถือ** บนโทรศัพท์ และให้กล้องเชื่อมต่อเข้ากับฮอตสปอตนี้ (หรือเชื่อมต่อโทรศัพท์และกล้องเข้ากับเร้าเตอร์ตัวเดียวกัน)
- กล้องต้องใส่การ์ดหน่วยความจำ: FTP ทำหน้าที่ส่งไฟล์ที่มีอยู่ในการ์ดหน่วยความจำ

## การตั้งค่า (ครั้งแรก)
1. เปิดฮอตสปอตมือถือบนโทรศัพท์
2. ที่หน้าแรกของ AeroCam ไปที่ **FTP** → ด้านบนสุด **เริ่มรับภาพ** หน้าจอจะแสดงค่าที่ต้องนำไปกรอกลงในกล้อง โดยแต่ละรายการสามารถแตะเพื่อคัดลอกได้ทันที:
   - ที่อยู่เซิร์ฟเวอร์ (เช่น `10.14.29.30`)
   - พอร์ต (Port): `2121`
   - บัญชีผู้ใช้ (Username): `aerocam`
   - รหัสผ่าน: รหัส 8 หลักที่แอปสร้างขึ้น (สามารถกด «สร้างใหม่» ได้)
   - โหมดพาสซีฟ (PASV): **เปิด**
3. บนกล้อง: **MENU → เมนูเครือข่าย (Network menu) → เชื่อมต่อกับเซิร์ฟเวอร์ FTP (Connect to FTP server) → การตั้งค่าเครือข่าย (Network settings) → สร้างโปรไฟล์ (Create profile)**:
   - Wi‑Fi เลือกฮอตสปอตของโทรศัพท์
   - ประเภทเซิร์ฟเวอร์เลือก `FTP` กรอกที่อยู่, พอร์ต, บัญชีผู้ใช้, รหัสผ่านด้านบน และเปิดโหมดพาสซีฟ
4. เปิดใช้งานการเชื่อมต่อ FTP นี้บนกล้อง เมื่อสถานะ FTP ของ AeroCam แสดง «เชื่อมต่อแล้ว» เป็นอันเสร็จสิ้น
5. ในเมนู FTP ของกล้อง ให้เปิด **ส่งอัตโนมัติหลังถ่าย** (Auto send) จากนั้นเวลาถ่ายภาพระบบจะส่งอัตโนมัติทันที

หากไม่แน่ใจขั้นตอนการตั้งค่า สามารถแตะที่ **ⓘ** ข้างการ์ด FTP เพื่อดูคู่มือภาพประกอบได้

📷 ภาพหน้าจอ: หน้าจอตั้งค่า FTP ที่ขยายออก

## ระหว่างใช้งาน
- ไฟแสดงสถานะ: ปิด, กำลังทำงาน·รอคอยกล้อง, เชื่อมต่อแล้ว, กำลังรับภาพ, ข้อผิดพลาด
- แถบแจ้งเตือนแสดง «กำลังรับผ่าน FTP · รับแล้ว N ภาพ» พร้อมชื่อไฟล์และความเร็วปัจจุบัน
- บันทึกภาพตามกฎใน **ตั้งค่า → การรับไฟล์และการแจ้งเตือน** (โฟลเดอร์, ชื่อไฟล์, รับเฉพาะ JPEG, RAW บันทึกเฉพาะ JPEG ฯลฯ) และบันทึกแหล่งที่มาในประวัติว่าเป็น `FTP`
- หากการส่งขาดตอนหรือกล้องดับกลางคัน ไฟล์ที่รับยังไม่เสร็จจะถูกลบอัตโนมัติ จะไม่มีไฟล์เสียหายตกค้างในคลังภาพ
- หลังจากปิดกล้อง สถานะจะเปลี่ยนเป็นยังไม่เชื่อมต่อภายในประมาณ 1 นาที; เมื่อเปิดกล้องเชื่อมต่อกลับมาจะรับช่วงต่อทันที
- **ปิดอัตโนมัติเมื่อไม่ได้ใช้งาน**: **การตั้งค่า → รับและแจ้งเตือน → «เวลาที่ไม่มีการรับภาพผ่าน FTP แล้วปิดอัตโนมัติ»** (ไม่ปิดอัตโนมัติ, 5, 10, 30 นาที) นับจากรูปสุดท้ายที่ได้รับ จะไม่ปิดขณะกำลังรับภาพ และจะมีแจ้งเตือนเมื่อปิดการทำงาน

## ข้อควรระวัง
- **ต้องเปิดฮอตสปอตค้างไว้เสมอ** โทรศัพท์บางรุ่นจะปิดฮอตสปอตเองอัตโนมัติเมื่อไม่มีการใช้อินเทอร์เน็ต โปรดไปที่การตั้งค่าฮอตสปอตของโทรศัพท์แล้วปิด «ปิดฮอตสปอตอัตโนมัติ»
- หลังจากปิดแล้วเปิดฮอตสปอตใหม่ IP ของโทรศัพท์อาจเปลี่ยนไป จำเป็นต้องอัปเดตค่าในกล้องให้ตรงกัน
- การรับผ่าน FTP และ **การรับอัตโนมัติผ่าน Wi‑Fi เปิดใช้งานได้ทีละอย่างเท่านั้น** เมื่อเปิดอย่างใดอย่างหนึ่ง อีกอย่างจะหยุดทำงานโดยอัตโนมัติ
- ในขณะที่เปิด FTP กล้องจะอยู่ในโหมด FTP ดังนั้น **คลังภาพและถ่ายภาพระยะไกลจะไม่สามารถเชื่อมต่อผ่าน Wi‑Fi ได้** หากต้องการใช้งาน ให้ใช้สาย USB หรือหยุดรับภาพผ่าน FTP แล้วเปลี่ยนกล้องกลับเป็น «Connect to PC»
- เซิร์ฟเวอร์ FTP เปิดให้บริการเฉพาะบนเครือข่ายฮอตสปอตหรือ Wi‑Fi ภายในเท่านั้น จะไม่มีการเปิดออกสู่สาธารณะบนอินเทอร์เน็ต
- «เชื่อมต่อหนึ่งแตะ» ไม่สามารถใช้ร่วมกับ FTP ได้ (เชื่อมต่อหนึ่งแตะคือกล้องเปิด Wi‑Fi เอง แต่ FTP ต้องให้กล้องเชื่อมต่อเข้าหาโทรศัพท์)

## ส่งตรงไปยัง NAS
คุณยังสามารถตั้งค่า FTP ของกล้องให้ส่งตรงไปยังอุปกรณ์ NAS ที่บ้านโดยไม่ต้องผ่านโทรศัพท์ได้ ฟังก์ชันนี้เป็นความสามารถที่มีอยู่แล้วในตัวกล้อง ไม่จำเป็นต้องใช้ AeroCam
