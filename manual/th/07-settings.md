# 7. อ้างอิงการตั้งค่า

**การตั้งค่า** แบ่งออกเป็น 5 หมวดหมู่ แตะเข้าไปเพื่อดูรายละเอียดการตั้งค่าปลีกย่อย ในเวอร์ชันฟรี การตั้งค่าระดับสูงที่ไม่จำเป็นจะถูกซ่อนไว้ หากมีข้อเสนอแนะหรือคิดว่าค่าเริ่มต้นควรเปลี่ยนไป โปรด [รายงานปัญหา](12-report.md) ให้เราทราบ

## รับและแจ้งเตือน

### การรับภาพ
| การตั้งค่า | ตัวเลือก | ค่าเริ่มต้น | รายละเอียด |
|---|---|---|---|
| ประเภทไฟล์ที่รับ | ไฟล์ทั้งหมด / เฉพาะ JPG / JPG + RAW / ภาพ + วิดีโอ / กำหนดเอง; พร้อม RAW บันทึกเฉพาะ JPEG, บันทึก JPEG ฉบับบีบอัด, แทนที่ฉบับบีบอัดเมื่อได้รับไฟล์ต้นฉบับ (Pro) | ไฟล์ทั้งหมด | ดู [บทที่ 3](03-receive.md#ประเภทไฟล์ที่รับ) |
| โฟลเดอร์จัดเก็บ | ตามกล้อง / ตามวันที่ / ตามกล้องและวันที่ / ตามประเภทไฟล์ | ตามกล้องและวันที่ | วิธีแบ่งโฟลเดอร์ย่อยใต้ `Pictures/AeroCam` และ `Movies/AeroCam` |
| ชื่อไฟล์ | ชื่อเดิมจากกล้อง / เติมคำนำหน้าวันที่ / เติมคำนำหน้าวันและเวลา | ชื่อเดิมจากกล้อง | มีผลเฉพาะไฟล์ที่บันทึกหลังจากนี้ การตรวจสอบไฟล์ซ้ำยังคงใช้ชื่อเดิมจากกล้อง |
| โหมดการรับ (Pro) | รับต่อเนื่อง / รับทีละไฟล์ | รับต่อเนื่อง | ทีละไฟล์ ＝ รับเสร็จ 1 ไฟล์แล้วหยุด |
| ไม่รับวิดีโอขนาดใหญ่อัตโนมัติ (Pro) | ค่าตัวเลข (MB) | 1024 MB | วิดีโอที่เกินเกณฑ์จะบันทึกเป็น «ถูกกรอง» ให้ดาวน์โหลดด้วยตนเอง |
| เมื่อหา Wi‑Fi ของกล้องไม่พบ | 30 วินาที / 1 / 2 / 3 / 5 / 10 นาที / ไม่จำกัด | 3 นาที | เกินเวลาจะหยุดรับอัตโนมัติ เพื่อไม่ให้พยายามเชื่อมต่อซ้ำๆ จนเปลืองแบต |
| เวลาที่ไม่มีการรับภาพผ่าน FTP แล้วปิดอัตโนมัติ | ไม่ปิดอัตโนมัติ / 5 / 10 / 30 นาที | ไม่ปิดอัตโนมัติ | นับจากรูปสุดท้ายที่ได้รับ จะไม่ปิดขณะกำลังถ่ายโอน |
| รูปภาพที่ได้รับผ่าน Bluetooth แล้ว | แทนที่ด้วยไฟล์ต้นฉบับเมื่อได้รับผ่าน Wi‑Fi / ไม่ดาวน์โหลดซ้ำผ่าน Wi‑Fi / เก็บไว้ทั้งสองฉบับ | แทนที่ด้วยไฟล์ต้นฉบับ | ภาพที่รับผ่าน Bluetooth เป็นไฟล์ย่อขนาดประมาณ 2 MB |

### ตำแหน่งภาพ
| การตั้งค่า | ค่าเริ่มต้น | รายละเอียด |
|---|---|---|
| ส่งตำแหน่งไปยังกล้อง (Bluetooth) | เปิด | เมื่อเปิดกล้องหรือส่งภาพผ่าน Bluetooth โทรศัพท์จะส่งพิกัด GPS ไปยังกล้องเพื่อบันทึกในภาพ |
| เพิ่มตำแหน่งให้กับไฟล์ JPEG ที่รับมา (โทรศัพท์) | ปิด (จะถามในการรับครั้งแรก) | JPEG ที่รับผ่าน Wi‑Fi, USB, FTP จะถูกเขียนพิกัดโดยโทรศัพท์ตามเวลาถ่าย; ไฟล์ RAW ไม่แก้ไข |

ดูรายละเอียดที่ [บทที่ 3 ตำแหน่งภาพ](03-receive.md#ตำแหน่งภาพ-gps)

### คลังภาพ
| การตั้งค่า | ตัวเลือก | ค่าเริ่มต้น | รายละเอียด |
|---|---|---|---|
| คุณภาพ JPEG ที่บีบอัด (Pro) | 60 / 70 / 80 / 90% | 80% | คุณภาพ JPEG ที่โทรศัพท์นำมาบีบอัดซ้ำ (24 MP ประมาณ 3–4 MB) |
| สถานะการเลือกหลังดาวน์โหลด / ลบ | ถามทุกครั้ง / คงไว้เสมอ / ล้างออกเสมอ | ถามทุกครั้ง | ป้องกันการค้างสถานะเลือกไว้แล้วเผลอกด «ลบออกจากกล้อง» |
| นับถอยหลังกล่องข้อความถาม | 3 / 5 / 8 / 10 วินาที | 5 วินาที | หากเลือก «ถามทุกครั้ง» แล้วหมดเวลาโดยไม่ตอบ จะล้างการเลือกออก |
| เวลาหยุดการแชร์ QR Code | 15 / 30 / 60 นาที | 30 นาที | หมดเวลาแล้วลิงก์จะใช้งานไม่ได้โดยอัตโนมัติ |

## การถ่ายภาพ

| การตั้งค่า | ตัวเลือก | รายละเอียด |
|---|---|---|
| ที่จัดเก็บภาพที่ถ่าย | การ์ดความจำ / การ์ดความจำ ＋ โทรศัพท์ (Pro) | วิธีที่ใช้เมื่อกล้องมีการ์ด หากไม่มีการ์ดจะเปลี่ยนเป็นบันทึกในโทรศัพท์เท่านั้นโดยอัตโนมัติ (Pro) และจะแสดงว่ามีการ์ดหรือไม่เมื่อเชื่อมต่อกล้อง ดู [บทที่ 3](03-receive.md#ตำแหน่งบันทึกและการถ่ายภาพโดยไม่ใส่การ์ด) |

|---|---|---|---|

| สีของมาตรวัดแสง | อัตโนมัติ / ขาว / ดำ | อัตโนมัติ | อัตโนมัติ ＝ เปลี่ยนตามความสว่างของฉากหลัง |
| สี Focus Peaking | แดง / เหลือง / น้ำเงิน / ขาว | แดง | ถ้าวัตถุมีสีแดง ให้เปลี่ยนเป็นสีอื่นเพื่อให้มองเห็นชัดเจน |
| เปิดหน้าจอค้างไว้เสมอขณะถ่ายภาพระยะไกล | เปิด / ปิด | เปิด | ป้องกันไม่ให้หน้าจอดับระหว่างถ่ายภาพอินเตอร์วัลหรือเปิดรับแสงนาน |
| โหมดมือซ้าย | เปิด / ปิด | ปิด | ย้ายปุ่มชัตเตอร์ไปมุมล่างซ้ายเมื่อถือแนวนอน |

| ซิงค์เวลากล้องตอนเชื่อมต่อ | เปิด / ปิด | เปิด | ปรับเฉพาะเมื่อเวลาเหลื่อมกันเกิน 2 วินาที; หากเหลื่อมกันเกิน 1 วันจะถามก่อน |

## พื้นที่เก็บข้อมูลและแบตเตอรี่
| รายการ | รายละเอียด |
|---|---|
| แคชภาพตัวอย่าง | แสดงพื้นที่ที่ใช้และล้างได้ (ระบบจะอ่านใหม่จากกล้องเมื่อจำเป็น) |
| ไฟล์ชั่วคราวที่ดาวน์โหลดไม่เสร็จ | แสดงพื้นที่และล้างได้ |
| สแกนหารูปภาพในโทรศัพท์อีกครั้ง | ค้นหารูปที่กลับมาอยู่บนโทรศัพท์ เช่น รูปที่กู้จากถังขยะหรือบันทึกไว้ก่อนติดตั้งแอปใหม่ |
| การเพิ่มประสิทธิภาพแบตเตอรี่ | แนะนำให้ปิด (แสดง «ไม่ได้เพิ่มประสิทธิภาพ ✓») มิฉะนั้นการรับภาพเบื้องหลังอาจถูกระบบตัด |

## สนับสนุน
| รายการ | รายละเอียด |
|---|---|
| คัดลอกข้อมูลวินิจฉัย | วางข้อมูลนี้เมื่อรายงานปัญหา: เวอร์ชันแอป, สถานะโทรศัพท์และเครือข่าย, ความสามารถของกล้อง, ประวัติคำสั่งล่าสุด, ข้อผิดพลาดจากการปิดตัวกะทันหันครั้งล่าสุด มีการเก็บหมายเลขซีเรียลกล้องไว้เพียง 4 หลักสุดท้าย |
| ล้างบันทึก (Logs) | ลบประวัติการทำงานและบันทึกข้อผิดพลาดของรอบนี้และรอบก่อนหน้า |
| ตรวจสอบการอัปเดต | ตรวจสอบเวอร์ชันใหม่ด้วยตนเอง แสดงเวอร์ชันปัจจุบันด้านล่าง |
| คีย์ทดสอบ | «รับคีย์ฟรี» เปิด AeroCam-Releases; «กรอกคีย์ทดสอบ» เพื่อวางคีย์; แสดงแพ็กเกจปัจจุบันและวันหมดอายุ |
| สัญญาอนุญาตโอเพนซอร์ส | องค์ประกอบของบุคคลที่สามที่ใช้ (เช่น LibRaw สำหรับแปลงไฟล์ RAW) |
| ส่งสถิติการใช้งานที่ไม่ระบุตัวตน | สวิตช์เปิด/ปิดเดี่ยว เปิดใช้งานตามค่าเริ่มต้น ดู [ความเป็นส่วนตัวและสถิติที่ไม่ระบุตัวตน](10-privacy.md) |
