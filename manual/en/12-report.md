# 12. Report a Problem

Go to [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) and pick a form:

| Form | Purpose |
|---|---|
| Bug report | Something isn't working properly or the app crashes |
| Feature request | Ideas for new features, improvements, or better defaults |
| Translation error | Mistranslated or awkward text |
| Camera report | Test results from other camera models |

## Please Include
- AeroCam version (top-left of Home, or Settings → Support)
- Phone model and Android version
- Camera model and firmware version
- Connection method (Bluetooth / One-tap connect / Phone hotspot / Same Wi‑Fi / USB / FTP)
- Steps to reproduce, expected result, and actual result
- **Diagnostic info**: **Settings → Support → "Copy diagnostic info"**, pasted into the form

## Notes
- Issues are **public** — do not post Wi‑Fi passwords, full camera serial numbers, accounts, or other personal data.
- For private matters (such as data deletion requests or security issues), email **aerocam.lab@gmail.com**.
