# 12. Laporkan Masalah

Buka [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) dan pilih formulir:

| Formulir | Tujuan |
|---|---|
| Laporan bug | Sesuatu tidak berfungsi dengan baik atau aplikasi mogok |
| Permintaan fitur | Ide untuk fitur baru, peningkatan, atau nilai default yang lebih baik |
| Kesalahan terjemahan | Teks salah terjemahan atau kaku |
| Laporan kamera | Hasil pengujian dari model kamera lain |

## Harap Sertakan
- Versi AeroCam (kiri atas Beranda, atau Pengaturan → Dukungan)
- Model ponsel dan versi Android
- Model kamera dan versi firmware
- Metode koneksi (Bluetooth / Koneksi satu ketukan / Hotspot ponsel / Wi‑Fi yang sama / USB / FTP)
- Langkah-langkah untuk mereproduksi, hasil yang diharapkan, dan hasil aktual
- **Info diagnostik**: **Pengaturan → Dukungan → «Salin info diagnostik»**, ditempelkan ke dalam formulir

## Catatan
- Issues bersifat **publik** — jangan memposting kata sandi Wi‑Fi, nomor seri kamera lengkap, akun, atau data pribadi lainnya.
- Untuk masalah pribadi (seperti permintaan penghapusan data atau masalah keamanan), kirim email ke **aerocam.lab@gmail.com**.
