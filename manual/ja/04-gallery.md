# 4. アルバム

画面下部の「カメラロール」タブの上部には、**スマホの写真**（すでにスマホに保存済みの写真）と **カメラのメモリーカード**（カメラ内の写真を直接閲覧）の 2 つのサブタブがあります。

## カメラのメモリーカード
スマホからカメラのメモリーカードの中身を直接閲覧できます（ダブルスロット対応）。**あらかじめカメラ側で写真を選ぶ必要も**、「受信を開始」を押しておく必要もありません。
- USB ケーブル接続なら無料、Wi‑Fi 接続は Pro 機能です。
- タブを開いただけではカメラを占有せず、「接続してメモリーカードを閲覧」をタップしたときに接続します。カメラは同時に 1 本の接続しか受け付けないため、自動受信中は一時停止し、アルバムを離れると自動で再開します。
- 別のタブに切り替えたり全画面プレビューを見たりしている間も、20 秒間は接続を維持するためすぐに元の位置から閲覧を続けられます。アプリをバックグラウンドへ移動すると即座にカメラを解放します（ダウンロード中のファイルは完了してから解放します）。
- アルバムを開いたままカメラでシャッターを切ると、新しい写真が約 1～2 秒で一番上に自動表示されます（USB が最速です）。

### 閲覧とフィルター
- 撮影日ごとにグループ分けされます。右上のカレンダーアイコンから特定の日付（年 → 月 → 日）へ素早くジャンプできます。
- フィルター：すべて、RAW、JPEG、動画、**未ダウンロード**（まだスマホに保存されていない写真だけを表示）、★付き。「未ダウンロード」または「★付き」を選んでいるときは、下部に「この N 枚をすべて選択」が表示されます。
- **1 行の表示枚数**：右上のグリッドアイコンから 2～7 列を選べるほか、ピンチイン／アウトでも切り替えられます。横画面では列数が 1.5 倍になります。
- 動画はファイル全体をダウンロードせずヘッダー情報だけを読み取ります。サムネイル左下に `▶ 0:12`（再生時間）、左上に `1080 24p`（解像度とフレームレート）が表示されます。

### サムネイルのバッジ表示
フィルターバー右端の **ⓘ** をタップすると詳しい凡例を確認できます。

| 位置 | 意味 |
|---|---|
| 左上 | 2 枚目のカード（`SD2`）または動画の記録形式 |
| 右上 | スターレーティング（★） |
| 左下 | ファイル形式：`RAW`（琥珀色）、`JPEG`（グレー）、`▶` 動画の長さ |
| 右下 | スマホに保存済みのバージョン：**✓RAW**、**✓JPEG**、**✓JPEG.S**（複数重ねて表示されます）。緑＝カメラのオリジナル、青＝コピー版、バッジなし＝まだスマホに未保存 |

### 選択操作
- 1 枚を長押ししてから**そのまま指をドラッグ**すると、連続して一括選択できます。画面の端までドラッグすると自動スクロールします。
- 各日付見出しの右側にある「選択」をタップすると、その日の写真をすべて選択できます。
- 選択中は下部のナビゲーションバーが隠れ、操作バー（ダウンロード、レーティング、削除）に切り替わります。左上の **✕** で選択を解除します。

### ダウンロード
写真を選んで **ダウンロード** をタップすると、各選択肢の横に**スマホで消費する空き容量**が表示され、一番下にスマホの残り空き容量が表示されます：
- **オリジナル**：無劣化の RAW、JPEG、または動画ファイル。
- **JPEG のみ**（Pro）：RAW からは内蔵のフルサイズ JPEG を抽出し、JPEG 元データはスマホ側で再圧縮します（解像度はそのまま）。どちらも `DSC_1234_S.JPG` として完全な撮影情報付きで保存されます。圧縮品質は **設定 → 受信と通知 → アルバム** で 60 / 70 / 80 / 90%（初期値 80%）から選べます。
- ダウンロードはキューに入り、進捗確認や途中停止が可能です。すでにスマホにあるファイルは自動でスキップされ、結果は「履歴」に記録されます。
- ダウンロード完了後、「選択を維持しますか？」と尋ねられ、カウントダウンが終わると自動で選択解除されます（選択が残ったまま誤って「カメラから削除」を押すのを防ぐためです）。「選択を記憶する」にチェックを入れることもできます。

### カメラから削除（Pro）
写真を選んで**赤い**「カメラから削除（N）」ボタンをタップし、確認画面で確定するとメモリーカードから**完全に削除**されます（元に戻せません）。まだスマホにダウンロードしていない写真が含まれる場合は追加の警告が表示されます。カメラ側でプロテクト（🔑）をかけている写真は削除されません。

> 赤い塗りつぶしボタンだけがカメラのメモリーカードを変更します。それ以外の削除操作はすべてスマホ内のファイルだけを対象とします。

### 全画面プレビュー（拡大表示）
サムネイルをタップすると全画面表示になり、左右スワイプで前後の写真へ移動、ピンチ操作やダブルタップで拡大できます。
- **縦画面**：上部にファイル名・日時・サイズ、写真の下に撮影パラメーター（シャッター速度 · 絞り · ISO · 焦点距離）、一番下に操作ボタンが並びます。
- **横画面**：写真が画面いっぱいに表示され、情報は右側に配置されます。写真をタップすると情報の表示／非表示を切り替えられます。
- **詳細** をオンにする：RGB ヒストグラム、ピクチャーコントロール、ホワイトバランス、レンズ名、画像サイズ、ファイル容量を、先にダウンロードすることなくカメラ上のファイルから直接読み取って表示します。

### レーティング（★評価）
アルバム内で写真に 1～5 の星を付け、「★付き」で絞り込んでお気に入りだけをダウンロードできます。付けた星はダウンロードしたファイルの EXIF Rating に書き込まれるため、Lightroom などの現像ソフトでもそのまま認識されます。

## スマホの写真
すでにスマホに保存されている写真を表示します（カメラとの接続は不要です）。
- スマホ内に現存するファイルだけを表示します。Google フォトなどの別アプリで削除した写真はここからも消え、ゴミ箱から復元すると自動で戻ります。
- 撮影日時順に並び、フィルターバーから「編集済み」「パノラマ」「手持ち連写合成」などで絞り込めます。
- **全画面プレビュー**：撮影パラメーターと **詳細**（撮影日時、転送日時、RGB ヒストグラム、ピクチャーコントロール、ホワイトバランス、レンズ、画像サイズ、ファイル種別、取得元）を確認できます。下部には **共有**、**他のアプリで開く**、**編集**、**削除** ボタンがあります。
- **削除**：選択後に **削除** をタップすると、「スマホ内のすべてを削除」「RAW のみ削除」「JPEG のみ削除（.S を含む）」「動画のみ削除」から選べます。ファイルはスマホの**ゴミ箱**へ移動し、30 日以内であればシステムアルバムから復元可能です。**カメラのメモリーカードには一切影響しません。**
- **画像処理**：複数枚を選択した状態で下部の操作バーを上にスワイプすると「画像処理」が開き、**パノラマ結合**と**ノイズ低減合成（手持ち連写合成）**を実行できます。詳しくは[第 6 章](06-edit.md#画像処理パノラマ結合ノイズ低減合成pro)をご覧ください。
- 写真が表示されない場合：**設定 → ストレージとバッテリー →「スマホの写真を再スキャン」** を実行してください。

## メモリーカードバックアップ（Pro）
カメラのメモリーカード内容を丸ごとスマホへバックアップします。USB タイルの「メモリーカードをバックアップ」またはアルバム右上のメニュー「バックアップ」から開けます。
- **対象範囲**：カード全体、またはカスタム（撮影日指定、まだスマホにないファイルのみ、SD1 / SD2）。
- **ファイル形式**：RAW＋JPEG、RAW のみ、JPEG のみ、RAW から JPEG のみ保存。動画を含めるかも選べます。
- **計算** をタップすると、ファイル数、合計サイズ、予想所要時間、スマホの残り空き容量が表示されます。Wi‑Fi 経由で RAW や動画をバックアップする場合は、時間がかかる旨の警告が表示されます。
- バックグラウンドで実行され（通知バーから一時停止可能）、中断した場合は次回起動時に続きから再開するか確認します。
- 保存したファイルは 1 つずつ読み戻してデータ照合を行います。エラーゼロでバックアップが完了した後は、**バックアップ済みファイルをカメラから削除** を実行できます（今回照合に成功したファイルだけを削除し、誤操作防止のため 2 回確認を行います）。

## QR Code 共有
近くにいる人のスマホカメラで QR Code を読み取ってもらうだけで、相手のブラウザ上で写真の閲覧・ダウンロードができます。**相手はアプリをインストールする必要がありません。**

### 共有の手順
1. **スマホの写真** で長押しして写真を選択し、操作バー最初の **共有** をタップします。共有できるのはスマホ内に保存済みの写真（JPEG、RAW）のみで、動画には現在対応していません。
2. 画面に大きな QR Code と短縮 URL（例：`192.168.43.1:8080/k7Qx2mPa`）が表示されます。相手はスマホのカメラアプリで読み取るだけで開けます。
3. **リンクをコピー** や **リンクを送信**（LINE、Messenger など）も使えます。

> **相手も同じ Wi‑Fi ネットワークに接続しているか、あなたのスマホのテザリングに接続している必要があります。** ホテルやカフェの公衆 Wi‑Fi は端末同士の通信を遮断していることが多いため、開けない場合はスマホのテザリングに切り替えてください。

### 共有オプション
- **パスワードを設定**（初期値オフ）：閲覧前に 4 桁の暗証番号の入力を求めます。送信メッセージ文面にはパスワードを含めないため、口頭で相手にお伝えください。
- **画質**：無料版は縮小版 JPEG（長辺 2048 px）を 1 枚ずつダウンロードする形式です。Pro 版では **オリジナルサイズ**、**RAW ファイルも同時に提供** が有効になり、相手側で複数選択してまとめて ZIP ダウンロードすることもできます。
- **位置情報（GPS）を残す**（初期値オフ）：初期設定ではダウンロードされる JPEG から撮影場所を削除し、Web ページ上にも一切表示しません。スマホ内の元ファイルは変更されません。
- 自動停止時間：**設定 → 受信と通知 → アルバム**（15 / 30 / 60 分、初期値 30 分）で設定できます。

### 共有中の動作
- 画面を離れたりスリープにしたりしても共有は継続し、通知バーに「QR Code を表示」と「共有を停止」が表示されます。
- ネットワークが一時的に途切れても 30 秒間待機します。スマホの IP アドレスが変わった場合は同じリンクコードを引き継ぎ、画面に再スキャンの案内を表示します。
- 相手が開く Web ページは相手のスマホ言語に合わせて繁体字中国語・簡体字中国語・日本語・英語で自動表示され、拡大表示や撮影情報の確認、ダウンロード失敗時のワンタップ再試行に対応しています。
- **セキュリティ**：URL には 8 桁のランダム文字列が含まれ、総当たり入力にはロックがかかります。選択した写真だけが公開され、相手は閲覧とダウンロードのみ可能です（アップロードや削除はできません）。**共有を停止** をタップすると URL は即座に無効になります。

> Xiaomi や OPPO などの一部スマートフォンではバックグラウンドアプリが強制終了されやすいため、共有画面に AeroCam のバッテリー設定を「制限なし」にする案内が表示されます。
