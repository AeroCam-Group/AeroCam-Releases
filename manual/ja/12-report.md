# 12. 問題の報告

[Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) にアクセスして、該当するフォームを選んでください：

| フォーム | 用途 |
|---|---|
| バグ報告 | 機能が正常に動かない、アプリが強制終了する |
| 機能リクエスト | 新機能の追加要望、改善案、初期設定に関する提案 |
| 翻訳ミス | 誤訳や不自然な日本語表現の報告 |
| 機種レポート | ほかのカメラ機種でテストした動作結果の報告 |

## 記載していただきたい情報
- AeroCam のバージョン（ホーム画面左上、または 設定 → サポート）
- スマートフォンの機種名、Android のバージョン
- カメラの機種名、ファームウェアのバージョン
- 接続方法（Bluetooth / ワンタップ接続 / スマホのテザリング / 同じ Wi‑Fi / USB / FTP）
- 操作手順、期待していた動作、実際の動作
- **診断情報**：設定 → サポート →「診断情報をコピー」でコピーした内容をフォームに貼り付けてください

## 注意事項
- Issue は**一般公開**されます。Wi‑Fi パスワード、カメラのシリアル番号全文、アカウント情報などの個人情報は絶対に貼らないでください。
- 公開の場には書きづらい内容（データ削除の依頼やセキュリティ上の問題など）は、**aerocam.lab@gmail.com** までメールでご連絡ください。
