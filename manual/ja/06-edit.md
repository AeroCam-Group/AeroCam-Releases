# 6. 写真編集とスタイル

## 写真編集（無料）
**スマホの写真** で画像を拡大表示し、**編集** をタップします。画面下部に **切り抜き**、**調整**、**.np3** の 3 つのタブがあります。

📷 スクリーンショット：エディター（切り抜き、調整、.np3）

### 切り抜き
- アスペクト比：オリジナル、フリー、1:1、4:5、3:2、16:9 に加え、シネマ比率の 1.66、1.85、2、2.20、2.39 を用意。縦位置の写真は自動で縦向き比率になります。
- 枠内をドラッグして移動、四隅をドラッグしてサイズ変更できます。
- 水平補正 ±45°、↺ 90° 回転。

### 調整
並んだツールアイコンから 1 つ選んでルーラーダイヤルで調整し、「完了」でツール一覧に戻ります（調整済みの項目には小さな点が付きます）：
- **ライト**：露光量、コントラスト、ハイライト、シャドウ、白レベル、黒レベル。
- **カラー**：色温度、色合い、彩度、自然な彩度。
- **ディテール**：明瞭度、シャープネス、周辺減光。

ルーラー操作：ドラッグすると目盛り単位（露光量は 0.1 EV、水平補正は 1°、その他は 1 刻み）に吸着し、1 目盛りごとに軽く振動します。両端を長押しすると連続増減し、数値をタップすると直接入力、ダブルタップまたは `↺` で 0 にリセットできます。

### 共通操作
- **↶ ↷** 元に戻す / やり直し。
- **オリジナル** を長押しすると編集前の画像を確認できます。
- **◧ 比較**：左右の分割スライダーで編集前後を見比べられます。2 本指での拡大操作も左右同時に連動します。
- 右下の「ヒストグラム」をタップするとヒストグラムを展開できます。

### 保存
- カメラの元データ（メモリーカードに残っている写真）：**保存するとスマホ内の写真が上書きされます。** アプリ側で元データのバックアップを 7 日間保持するため、その間は拡大画面の「オリジナルに戻す」から復元できます。カメラ未接続時は「上書き」か「別名で保存」かを事前に確認します。
- スマホ内のみにある写真（カードなし撮影、パノラマ、手持ち連写合成の完成画像）は常に `_E` を付けた別ファイルとして保存されます。
- 撮影情報（EXIF）を保持したまま JPEG 品質 95 で保存します。保存途中で中断された場合でも、次回アプリ起動時に自動で完了させます。
- スマホの写真のフィルターバーにある **編集済み** で編集した写真だけを絞り込め、サムネイル左下に小さな `✎` マークが付きます。
- 圧縮版（`JPEG.S`）を編集しようとすると、より高画質に仕上げるためカメラのオリジナル画像を編集するよう案内が表示されます。
- 動画の編集には対応していません。

## スマホでの RAW 編集（実験的機能）
NEF ファイルも同じエディターで編集でき、元のファイルと同じ場所に `DSC_xxxx_E.JPG` として保存されます（再度保存すると同じファイルが更新されます）。**元の NEF ファイルは一切変更されず**、撮影情報も引き継がれます。
- **ロスレス圧縮の NEF**：カメラのホワイトバランスを使用してスマホ上で直接現像します。
- **高効率 / 高効率★（High efficiency / High efficiency★）の NEF**：この圧縮形式はスマホ側で直接現像できないため、NEF 内に埋め込まれているフルサイズ JPEG を使って編集します。エディター上部には「埋め込み JPEG 8 bit」と「適用済みカメラスタイル：xxx」が表示されます。
- 小さなプレビュー画像しか入っておらずフルサイズ JPEG がないファイルは編集できません（画面に理由が表示されます）。

### スマホで編集可能な RAW（カメラの RAW 圧縮方式の切り替え）
これから撮影する NEF をすべてスマホで直接現像できるようにしたい場合、スマホからカメラ側の設定を「ロスレス圧縮」に切り替えられます：
- 入口：エディターの高効率警告バーにある「次回からロスレス RAW で撮影」、またはホーム画面のメモリーカードカード右上の画質バッジ（カメラが RAW 撮影に設定されているときのみタップ可能）。
- 書き込み前に必ず確認ダイアログが出て、カメラへ書き込んだ後に読み戻して照合します。成功すると残り撮影可能枚数の変化が表示されます（ロスレス圧縮はファイルサイズが大きいため、撮影可能枚数は少し減ります）。
- アプリがこのカメラの元の設定を記憶しているため、後からいつでも「元に戻す」ことができます。すでにカメラ本体側で変更済みの場合は上書きしません。

## .np3 スタイルプレビュー（無料）
エディターの **.np3** タブでは、Nikon ピクチャーコントロールファイル（`.np3`、`.ncp`）を写真に適用し、スマホ上で仕上がりをプレビューできます。
- スタイルをタップすると即座に適用され、適用度を 0～100% で調整できます。さらに「調整」タブで微調整することも可能です。
- 写真上を左右にスワイプするとスタイルを順番に切り替えられ、長押しでオリジナル画像を確認できます。下部には `★` お気に入り・最近使用フィルターがあります。
- **すべて N ▴** をタップするとスタイルライブラリ全体（下記参照）が展開し、検索や絞り込みができます。
- シミュレーション対象はトーンカーブと彩度です。カーブデータを含むファイルはそのカーブを使用し、フレキシブルカラー（Flexible Color）のスライダーで調整されたファイル（「スライダートーン」表示）は NX Studio の実測値から換算したカーブを使用します。**カラーブレンダーとカラーグレーディングはまだシミュレーション非対応**のため、近似的なプレビューとなります。
- NEF ファイルで最も効果を発揮します。撮影時にすでにピクチャーコントロールが適用済みの JPEG に重ねると効果が二重にかかるため、アプリが注意を表示します。

📷 スクリーンショット：エディターの .np3 タブ

## カメラスタイル C1～C9（Pro）
スマホからカメラ内のカスタムピクチャーコントロール C1～C9 を管理できます。ホーム画面の **カメラスタイル** カードをタップして開きます（Wi‑Fi または USB でカメラと接続している必要があります）。
- 各スロットにプレビュー、名称、および使用中・カーブあり・フレキシブルカラーなどのバッジが表示されます。
- **スロットをタップ**するとスタイルライブラリからレシピを選んでカメラへ書き込みます。書き込み後に読み戻して照合し、一致した場合のみ `✓` が付きます。**長押し**または `⋮` からスロットを空にできます。写真の受信中は、その 1 枚の転送が終わってから書き込みを実行します。
- カメラとの読み書きはこの画面を開いたとき、`↻` を押したとき、書き込み・消去を行ったときだけ実行されます。ホーム画面には前回読み込んだ内容と時刻が表示されます。
- 下部には Nikon Imaging Cloud の 9 種類のレシピが読み取り専用で表示されます（カメラへの追加は Nikon Imaging Cloud から行います）。

### カメラに書き込まれる内容
カメラのカスタムスロットが受け付けるのは **ベースとなるピクチャーコントロール＋調整値** であり、`.np3` ファイルそのものではありません：
- スタイルライブラリの **＋ 新規スタイル** では、ベース（スタンダード、フラット、クリエイティブピクチャーコントロールなど）と輪郭強調、明瞭度、コントラスト、明るさ、色の濃さ（彩度）、色合いを設定できます。
- **`.np3` / `.ncp` のカメラへの書き込み（近似）**：カーブを含むファイルおよび「スライダートーン」のファイル（カーブへ変換）は、選んだベースに **名称＋カーブ＋シャープネス（輪郭強調、ミドルレンジシャープ、明瞭度）** を組み合わせて C スロットへ書き込めます。**彩度、カラーブレンダー、カラーグレーディングは通信経由で書き込めない**ため、書き込み前にファイル内の全設定値と書き込めない項目が一覧で明示されます。
- 100% 完全な効果を反映したい場合は、これまでどおりメモリーカード経由でカメラメニューから `.np3` を読み込んでください。

### スタイルライブラリ
- 最大 256 個のスタイルを保存でき、`.np3` と `.ncp` に対応しています。
- `🔍` 検索バー、フィルター（すべて、`★`、最近使用、カーブあり、カメラ登録済み、書き込み可能）、**＋ 新規** を備えています。
- 各スタイルにはプレビューサムネイルが表示されます。サムネイルには自分で読み込んだ参考写真（`＋ →「プレビュー参考画像…」`）が使われ、未設定時はカラーチャートが表示されます。

📷 スクリーンショット：カメラスタイル C1～C9 とスタイルライブラリ

## 画像処理：パノラマ結合、ノイズ低減合成（Pro）
**スマホの写真** で複数枚を選択し、下部の操作バーを**上にスワイプ**（またはハンドルをタップ）すると「画像処理」が開きます。

### パノラマ結合
- 「パノラマ」スタック内で選択した場合：撮影時のグリッド位置に従って結合し、完成画像を同じスタック内に「パノラマ」ラベル付きで保存します。
- 通常アルバムから重なり合う写真を任意に選んだ場合：アプリが自動的に写真のつながりを判定して結合し、新しいスタックとして保存します。
- つながらない写真が混ざっていても全体がエラーになることはありません。結合できる最大のグループを合成し、結合できなかったファイル名を一覧表示します。グリッドパノラマでコマが欠けている場合は、穴空きを防ぐため出力しません。
- 1 周 360° 撮影すると 360° パノラマとして出力されます。撮影時に記録した水準器データにより水平が自動補正され、ゴーストのない仕上がりで撮影情報も保持されます。
- 撮影方法は[第 5 章 パノラマ](05-remote.md#パノラマ結合)をご覧ください。

### ノイズ低減合成（手持ち連写合成）
- 選択した複数枚の位置を精密に揃えて平均化し、ディテールを保ったままノイズを低減します。動いている部分は 1 枚だけを使うため残像が出ません。
- 「手持ち連写合成」スタック内で選択すると同じスタック内に保存され（完成画像に「合成」ラベルが付きます）、スタック上部の **合成** または **再合成** ボタンからも実行できます。
- 撮影方法は[第 5 章 手持ち連写合成](05-remote.md#手持ち連写合成ノイズ低減)をご覧ください。

> 結合と合成の処理は一度に 1 件ずつ実行されます。画面に進捗が表示され、完了通知をタップするとすぐに開けます。
