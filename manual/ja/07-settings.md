# 7. 設定項目の詳細

**設定**は 5 つのカテゴリーに分かれており、タップすると詳細項目が開きます。無料版では使えない設定項目は非表示になります。機能のご要望や初期値に関するご意見があれば、ぜひ[問題の報告](12-report.md)からお知らせください。

## 受信と通知

### 受信
| 設定 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 受信するファイル形式 | すべてのファイル / JPG のみ / JPG + RAW / 写真 + 動画 / カスタム。さらに RAW から JPEG のみ保存、JPEG を圧縮して保存、元データ受信時に圧縮版を置き換える（Pro） | すべてのファイル | 詳しくは[第 3 章](03-receive.md#受信するファイル形式)を参照 |
| 保存フォルダ | カメラ別 / 日付別 / カメラと日付別 / ファイル形式別 | カメラと日付別 | 写真は `Pictures/AeroCam`、動画は `Movies/AeroCam` 配下のフォルダ分け方法 |
| ファイル名 | カメラの元ファイル名 / 日付プレフィックス付き / 日時プレフィックス付き | カメラの元ファイル名 | 設定後に保存されるファイルから適用されます。重複判定は常にカメラの元ファイル名で行います |
| 受信モード（Pro） | 連続受信 / 1 ファイル受信 | 連続受信 | 1 ファイル＝1 つ受信したら自動停止します |
| 大容量動画を自動受信しない（Pro） | 数値（MB） | 1024 MB | しきい値を超えた動画は「フィルター済み」として記録され、手動でダウンロードします |
| Wi‑Fi でカメラが見つからないとき | 30 秒 / 1 / 2 / 3 / 5 / 10 分 / 無制限 | 3 分 | 制限時間を超えると自動停止し、再試行によるバッテリー消耗を防ぎます |
| FTP で写真を受信しない場合の自動停止 | 自動停止しない / 5 / 10 / 30 分 | 自動停止しない | 最後の 1 枚を受信してからの経過時間。転送中は停止しません |
| Bluetooth で受信済みの写真 | Wi‑Fi 受信時に元データへ置き換える / Wi‑Fi では再ダウンロードしない / 両方とも残す | 元データへ置き換える | Bluetooth で届くのは約 2 MB の縮小版です |

### 写真の位置情報
| 設定 | 初期値 | 説明 |
|---|---|---|
| カメラへ位置情報を送信（Bluetooth） | オン | カメラの電源オン時や Bluetooth 転送時に、スマホの位置情報をカメラへ送って写真に記録します |
| 受信した JPEG に位置情報を追加（スマホ） | オフ（初回受信時に確認） | Wi‑Fi、USB、FTP で受信した JPEG に撮影時刻をもとにスマホ側で位置を書き込みます。RAW は変更しません |

詳しくは[第 3 章 写真の位置情報](03-receive.md#写真の位置情報gps)をご覧ください。

### アルバム
| 設定 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 圧縮 JPEG の品質（Pro） | 60 / 70 / 80 / 90% | 80% | スマホで再圧縮する JPEG の品質（24 MP で約 3～4 MB） |
| ダウンロード・削除後の選択状態 | 毎回確認する / 常に維持する / 常に解除する | 毎回確認する | 選択が残ったまま誤って「カメラから削除」を押すのを防ぎます |
| 確認カウントダウン | 3 / 5 / 8 / 10 秒 | 5 秒 | 「毎回確認する」の場合、時間内に応答がないと自動で選択を解除します |
| QR Code 共有の自動停止時間 | 15 / 30 / 60 分 | 30 分 | 時間が来ると共有 URL が自動的に無効になります |

### 通知
| 設定 | 初期値 | 説明 |
|---|---|---|
| サイレント（通知オフ） | オフ | AeroCam の通知をすべてオフにします（「受信中」の常駐通知は Android の仕様上残ります） |
| 転送開始時 | オフ | |
| 写真の受信時 | オン | |
| 転送エラー | オン | 転送停止、カメラ側キャンセル、スマホ容量不足など |
| 常駐通知を非表示にする | — | Android の通知設定画面を開き、そこから非表示にできます（受信動作自体は継続します） |
| カメラのバッテリー低下アラート | オン、15% | しきい値は 10 / 15 / 20 / 30% から選択可能。カメラ接続中のみチェックします |

## 撮影

### 保存先
| 設定 | 選択肢 | 説明 |
|---|---|---|
| 保存先 | メモリーカード / メモリーカード＋スマホ（Pro） | カメラにカードが入っているときの保存先。カードがない場合は自動で「スマホのみ」に切り替わります（Pro）。カメラ接続中は現在のカード挿入状態が表示されます。詳しくは[第 3 章](03-receive.md#保存先とカードなし撮影)を参照 |

### リモート撮影
| 設定 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| リモート撮影開始時にデフォルトで有効にする機能 | 撮影前 AF、ヒストグラム、白飛び警告、フォーカスピーキング、露出インジケーター | 撮影前 AF、露出インジケーター | 撮影中もいつでも切り替えられます |
| 露出インジケーターの色 | 自動 / 白 / 黒 | 自動 | 自動＝背景映像の明るさに合わせて自動切り替え |
| フォーカスピーキングの色 | 赤 / 黄 / 青 / 白 | 赤 | 赤い被写体を撮るときは別の色にすると見やすくなります |
| リモート撮影中は画面を常にオン | オン / オフ | オン | インターバル撮影や長時間露光中にスマホ画面が消えるのを防ぎます |
| 左手モード | オン / オフ | オフ | 横画面時にシャッターボタンを左下に配置します |

### 有線接続（USB‑C）
| 設定 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| USB プレビューフレームレート | 30 / 60 fps / 無制限 | 30 fps | 30 fps は省電力で発熱が少なく、60 fps はより滑らかです |
| USB 高解像度プレビュー | オン / オフ | オン | より鮮明に表示されますが、フレームレートが少し下がる場合があります（非対応機種では自動で通常画質に戻ります） |
| USB ケーブル接続時に自動で受信を開始（Pro） | オン / オフ | オン | ケーブルを挿すと自動で USB 受信を開始します |
| 接続時にカメラの時計を同期 | オン / オフ | オン | 2 秒以上のずれがあるときだけ同期します。1 日以上ずれている場合は先に確認します |
| 有線接続中はカメラをスリープさせない | オン / オフ | オン | 10 秒ごとに小さな信号を送信します。30 分間無操作またはバッテリー低下時に停止します |

## ストレージとバッテリー
| 項目 | 説明 |
|---|---|
| サムネイルキャッシュ | 現在の容量を表示し、削除できます（必要に応じてカメラから再取得します） |
| 未完了ダウンロードの一時ファイル | 現在の容量を表示し、削除できます |
| スマホの写真を再スキャン | ゴミ箱から復元した写真や、アプリ再インストール前に保存した写真をアルバムへ再登録します |
| バッテリーの最適化 | バックグラウンド受信が中断されないよう、オフ（「最適化されていません ✓」表示）にすることを推奨します |

## サポート
| 項目 | 説明 |
|---|---|
| 診断情報をコピー | 問題報告時に貼り付ける情報（アプリバージョン、スマホとネットワークの状態、カメラ機能情報、直近のコマンド履歴、最後のクラッシュエラー）をコピーします。カメラのシリアル番号は下 4 桁のみ含まれます |
| ログを消去 | 今回および前回のログとクラッシュ記録を削除します |
| アップデートを確認 | 新しいバージョンを手動で確認します。下部に現在のバージョンが表示されます |
| テストキー | 「無料キーを取得」で AeroCam-Releases を開き、「テストキーを入力」で貼り付けます。現在のプランと有効期限も表示されます |
| オープンソースライセンス | 使用しているサードパーティ製ライブラリ（RAW 現像用の LibRaw など） |
| 匿名使用統計を送信 | 単一のオン／オフスイッチ（初期値オン）。詳しくは[プライバシーと匿名統計](10-privacy.md)をご覧ください |
