# 2. カメラとの接続

AeroCam には 4 つの接続方法があります。複数設定しておけば、そのとき使える方法をアプリが自動で選びます。ホーム画面の 4 つのタイル（Wi‑Fi、USB、Bluetooth、FTP）にそれぞれの状態が表示されます。

> 接続方法がわからないときは、ホーム画面の接続状態の横、または「カメラを追加」の各ステップ右上にある **ⓘ** をタップしてください。スマホのテザリング、同じ Wi‑Fi、ワンタップ接続、USB、Bluetooth、FTP の各 1 ページの図解ガイドが開き、スマホとカメラ両方の画面スクリーンショットと、最後に「つながらないときのチェックリスト」が載っています。

## 接続方法の選び方

| やりたいこと | おすすめの方法 |
|---|---|
| カメラの電源を切った後も手間なく写真を受け取りたい | **Bluetooth**（縮小版 JPEG、無料） |
| 屋外でテザリングを出さずに、元データ・アルバム・リモート撮影を使いたい | **ワンタップ接続**（Pro） |
| シャッターを切った直後に最速で自動転送したい | **[FTP 受信](08-ftp.md)**（Pro、テザリングが必要） |
| 一番安定した接続、ビデオモニター、長時間の連続リモート撮影 | **USB ケーブル**（手動選択ダウンロードは無料） |
| 自宅やスタジオで使う | **同じ Wi‑Fi**（Pro） |

## 転送速度の目安（Nikon Zf、Pixel 10 Pro での実測値）

| 接続方式 | RAW 1 枚（約 18 MB）あたり |
|---|---|
| FTP 受信 | 約 1 秒（約 17 MB/s） |
| Wi‑Fi アルバムダウンロード | 約 1.3 秒（約 13 MB/s） |
| USB | 通常は Wi‑Fi より高速（ケーブル性能による。USB 2.0 ケーブルで約 35 MB/s） |
| Bluetooth | 縮小版 JPEG（約 2 MB）1 枚あたり 15～20 秒 |

## ホーム画面の接続ランプ
Wi‑Fi、USB、Bluetooth、FTP の 4 つのタイルは状態に応じて色が変わります（未接続時はグレー）。

| 色 | 意味 |
|---|---|
| 🟢 緑 | 接続済み、または準備完了（Bluetooth の薄緑＝待機中・電源OFF中の送信に対応） |
| 🔵 青 | 転送中 |
| 🟠 オレンジ | 接続中（点滅）、または対処が必要（権限不足、停止、エラー） |
| 🔴 赤 | スマホの Wi‑Fi または Bluetooth がオフ |

## Bluetooth（無料・SnapBridge の代わりに使用）

### ペアリング
1. カメラ側：**MENU → ネットワークメニュー → スマートフォンと接続 → ペアリング（Bluetooth）→ ペアリング開始**。
2. カメラがすでに SnapBridge とペアリングされている場合は、先に SnapBridge 側でペアリングを削除し、スマホの Bluetooth 設定からもカメラの登録を解除してください（2 つのアプリを同時に同じカメラへペアリングすることはできません）。
3. AeroCam 側：ホーム画面「Bluetooth」→ **カメラをペアリング** → 開始。スマホとカメラに同じ認証コードが表示されたら、両方で OK を押します。カメラ側には `AeroCam_スマホ機種名` と表示されます。

📷 スクリーンショット：Bluetooth タイル

### ペアリング後
一度ペアリングすると、解除するまでずっと有効になります（解除時は確認画面が出ます）。
- 通常時、AeroCam はバックグラウンドでカメラからの Bluetooth 信号を**待ち受けるだけ**なので、スリープ中のカメラを勝手に起こすことはありません。
- **カメラの電源を入れたとき**：一度だけ接続して時刻とスマホの位置情報を同期し（撮影時にカメラが写真へ位置情報を記録できるようになります）、すぐに切断します。
- **カメラに送りたい写真があるとき**：カメラの「スマートフォンと接続」メニューで **電源OFF中の送信**（Send while off）をオンにしておくと、電源を切った後でもカメラが自動で Bluetooth 接続して写真を送ってきます。
- 受信するのはカメラ側で生成された約 2 MB の JPEG です（RAW で撮った場合もカメラ内で JPEG に変換されます）。1 枚あたり約 15～20 秒かかります。元データが必要な場合は Wi‑Fi、USB、または FTP を使ってください。
- すぐに受信したいときは、Bluetooth タイルの **今すぐ受信** をタップします。
- スマホの Bluetooth のオン／オフ、再起動、アプリアップデート後も自動で再開されます。待機中は Android の仕様上、優先度の低い常駐通知が 1 件表示されますが、システム設定から非表示にできます。

### Bluetooth タイルの状態表示
🟢 カメラが近くにあります・電源オン / 🟢 薄緑 待機中（電源OFF中の送信に対応）/ ⚪ カメラが見つかりません（最後に確認した時刻を表示）/ 🔵 転送中 / 🟠 停止している可能性があります / 🔴 スマホの Bluetooth がオフです。

Bluetooth は常時つながりっぱなしではないため、ここには「カメラの信号を検知しているか」と「いま何をしているか」が表示されます。

### 転送が止まったとき
- 転送中に 30 秒間データが来ない場合、アプリが自動で一度切断し、その後カメラ側から再送されます。20 秒間動きがないとタイルが黄色になり「停止している可能性があります」と表示されます。
- **切断して再接続**：今回の転送セッションだけを一度リセットします。
- **⋮ → Bluetooth サービスを再起動**：ペアリング情報を保ったまま、Bluetooth のバックグラウンドサービス全体を再起動します。
- RAW 撮影時は、カメラが先に JPEG へ変換してから送信します。転送中にカメラを操作（シャッター半押しや撮影）するとカメラ側で送信がキャンセルされます。撮影が終わったらそのまま電源を切り、バックグラウンドで送信させるのが一番確実です。

## Wi‑Fi（Pro）：3 つの接続方法

| 方法 | 仕組み | おすすめの場面 |
|---|---|---|
| **ワンタップ接続**（推奨） | Bluetooth 経由でカメラ自身の Wi‑Fi を起動させ、スマホが自動で接続します | 屋外でスマホのテザリングを使いたくないとき |
| **スマホのテザリング**（ガイド推奨） | スマホでテザリング（アクセスポイント）を開き、カメラから接続します | ワンタップ接続が不安定なとき、FTP やカードなし撮影を使うとき |
| **同じ Wi‑Fi** | スマホとカメラの両方を同じルーターに接続します | 自宅やスタジオ |

### ワンタップ接続
1. 先に **Bluetooth ペアリング** を済ませておきます。
2. ホーム画面の Wi‑Fi →「ワンタップ接続」をタップします。
3. 初回のみ、カメラの Wi‑Fi **パスワード**を入力します（ネットワーク名 `NIKON_…` は自動入力されます）。パスワードはこのスマホ内にのみ保存されます。
4. Android から Wi‑Fi 接続の許可を求められたら「許可」を選びます。
5. 「カメラの Wi‑Fi に接続しました」と表示されたら、アルバム閲覧・リモート撮影・自動受信のすべてがこの接続を使います。「切断」をタップすると元の Wi‑Fi に戻ります。

アルバムやリモート撮影で未接続のときも、画面上に「カメラの Wi‑Fi で接続」ボタンが直接表示されます。

> - カメラの Wi‑Fi に接続している間、スマホのインターネット通信はモバイルデータ通信に切り替わります。
> - ワンタップ接続は **FTP と併用できません**。また **カードなし撮影にも対応していません**（カメラにメモリーカードが入っていない場合は、スマホのテザリングか同じ Wi‑Fi を使ってください）。

📷 スクリーンショット：ワンタップ接続カードと接続済み状態

### スマホのテザリング / 同じ Wi‑Fi（初回はペアリングが必要）
1. カメラ側：**MENU → ネットワークメニュー → PCと接続** を開き、ネットワークプロファイルを作成します（スマホのテザリング、または自宅の Wi‑Fi に接続）。
   - 新しい機種（メニューに「接続タイプ」がある機種）：「接続タイプ」で **画像送信** を選びます。
   - 以前の機種：「PCと接続」を選べばそのまま使えます。
2. AeroCam 側：**ホーム →「＋」カメラを追加** をタップし、接続方法（同じ Wi‑Fi またはスマホのテザリング）を選びます。アプリがネットワーク状態を確認し、自動でカメラを検索します。見つからない場合は IP アドレスを手動入力することもできます。
3. カメラのモニターに **4 桁の認証コード**が表示されたら、スマホ側に入力し、カメラ側で OK を押します。
4. 完了すると「カメラプロファイル」として保存され、次回からはアプリを開くだけですぐ接続できます。複数台のカメラや複数のネットワークを保存でき、アプリアップデート後も**再ペアリングは不要**です。カメラの IP アドレスが変わっても自動で見つけ出します。

> カメラに「他の機器とペアリング済みです」と表示された場合は、そのネットワーク設定が別のアプリで使われています。カメラ側で新しい接続設定を追加してからペアリングしてください。

📷 スクリーンショット：カメラ追加ウィザードと認証コード画面

### 接続前の自動チェック
- 「受信を開始」をタップしたときや、アルバム・リモート撮影を開くとき、アプリが先にネットワークを確認します。「スマホのテザリング」設定なのにテザリングがオフ、または「同じ Wi‑Fi」設定なのにその Wi‑Fi につながっていない場合は、黄色い警告バナー（例：「先にスマホのテザリングをオンにしてください」）と「テザリング設定」「Wi‑Fi 設定」ボタンが表示されます。オンにして AeroCam に戻ると警告は消えます。
- Wi‑Fi でもテザリングでもカメラが見つからないときは、ホーム画面に「ネットワーク上にカメラが見つかりません」と表示されます。多くの場合、カメラ側の「PCと接続」が有効になっていません。横にある「接続ガイドを見る」で確認できます。

### カメラの「接続タイプ」（Connection type）
新しい機種（Z9、Z8、Z6III、Zf、Z5II、Z50II など）：**MENU → ネットワークメニュー → PCと接続 → 接続タイプ**
- **画像送信**（Image transfer）：自動受信、カメラのメモリーカード閲覧用。
- **カメラコントロール**（Camera control）：リモート撮影、カードなし撮影用。

切り替えるとカメラの Wi‑Fi が一度切れますが、AeroCam が自動で再接続します（再ペアリング不要）。カメラが「画像送信」のままリモート撮影に入ると、切り替え手順が画面に案内されます。

## USB ケーブル
Wi‑Fi より高速で安定しており、**ペアリング不要**、事前のカメラ追加もいりません。
1. カメラの USB 設定を **MTP/PTP** にします（「iPhone」や「UVC/UAC」にはしないでください）。
2. **データ通信に対応した** USB‑C ケーブルを使います（充電専用ケーブルでは認識しません）。5Gbps / 10Gbps 対応の USB 3 ケーブルを使うとより高速です。
3. ホーム画面の USB タイルに「Z f を検出しました・アクセス許可が必要です」と表示されたら「アクセスを許可」をタップし、Android の確認ダイアログを許可します。

### USB タイルの色
| 色 | 意味 |
|---|---|
| ⚪ グレー | カメラ未検出（または充電専用ケーブル） |
| 🟠 オレンジ | カメラを検出しました。アクセス許可が必要です |
| 🔴 赤 | カメラの USB 設定が MTP/PTP ではない、許可されていない、またはテスト失敗（理由が表示されます） |
| 🟢 緑 | USB ケーブルで接続済み |

### ケーブル接続中の動作
- アルバム、リモート撮影、自動受信はすべて**自動で USB 経由に切り替わります**。ケーブルを抜くと自動で Wi‑Fi に戻ります。Wi‑Fi でリモート撮影中にケーブルを挿した場合も自動で USB に切り替わります（インターバル撮影、ブラケティング、バルブ撮影の実行中は切り替わりません）。
- **USB 受信**（Pro）：USB タイルの「受信を開始」をタップすると、新しく撮影した写真やカメラ側で「PCへ送信」した写真がスマホに保存されます。初期設定ではケーブルを挿すと自動で受信が始まります（設定 → 撮影 →「USB ケーブル接続時に自動で受信を開始」）。
- **時刻同期**：ケーブル接続時にカメラの時計を一度同期します（2 秒以上ずれている場合のみ修正し、1 日以上ずれている場合は先に確認します）。
- **スリープ防止**：アルバムやリモート撮影を開いている間、10 秒ごとに小さな信号を送ってカメラがスリープするのを防ぎます。30 分間操作がないか、カメラのバッテリーが少なくなると自動停止します。
- USB 接続中はスマホからカメラへ給電されることがあるため、長時間の撮影ではモバイルバッテリー等の併用をおすすめします。
- **USB テスト**（USB タイル右上の ⋮）：接続状態、カメラ情報、メモリーカード、ライブビューのフレームレート、読み込み速度をテストできます。

📷 スクリーンショット：USB タイル

## FTP
カメラで撮影した後、カメラ自身からスマホへ直接写真をプッシュ送信します。詳しくは[第 8 章](08-ftp.md)をご覧ください。
