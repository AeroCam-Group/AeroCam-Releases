# 3. 自動受信と保存

## カメラダッシュボード
カメラに接続すると、ホーム画面の上部に現在のカメラ状態が表示されます。

| 項目 | 内容 |
|---|---|
| 機種・レンズ | 例：「Nikon Z f」「NIKKOR Z 24–120 mm f/4」 |
| バッテリー | 残量パーセント（20% 以下になると赤く表示） |
| 接続方法 | スマホのテザリング、同じ Wi‑Fi、カメラの Wi‑Fi、USB |
| メモリーカード | 各カードの使用容量 / 総容量、残り撮影可能枚数（ダブルスロットは別々に表示） |
| 画質 | 例：`RAW`、`JPEG FINE★ L`（カメラ側で画質を変えたりカードを抜き挿ししたりすると自動更新） |
| 保存先 | 例：「保存先：メモリーカード ✓」— 詳しくは下記の[保存先とカードなし撮影](#保存先とカードなし撮影)を参照 |
| 転送 | 現在の状態。右上の「履歴 ›」から履歴一覧へ移動 |
| カメラスタイル | 前回読み込んだ C1～C9 の内容。詳しくは[第 6 章](06-edit.md#カメラスタイル-c1c9pro)を参照 |

現在のカメラモードで取得できない項目は非表示になります。「カメラコントロール」に切り替えてリモート撮影に入ると、より多くの項目を読み取れるようになります。

### カメラの管理
ダッシュボードの下にある **カメラの管理 (n)** を開くと、カメラの編集・削除・追加ができます。各カメラの「詳細情報」ページでは以下を確認できます。
- 機種名、シリアル番号（中央部分は伏せ字、タップで全文表示）、ファームウェアバージョン、**総レリーズ回数（シャッター回数）**と読み取り日。
- **月別レリーズ回数**：直近 6 か月間の棒グラフ（記録開始後のデータが表示されます）。
- 前回の接続日時、接続方式、レンズ、バッテリー残量、メモリーカードの空き容量。
- スマホへ転送したファイル数、初回接続日、保存済みのネットワーク設定。

総レリーズ回数はメモリーカード内の最新写真のメタデータから読み取るため、カードに少なくとも 1 枚の写真が入っている必要があります。

### バッテリー低下アラート
カメラのバッテリー残量が設定したしきい値（初期値 15%）以下になると通知を出します。一度通知した後は、残量がしきい値 +5% 以上に回復するまで再通知しません。しきい値の変更やオフ設定は **設定 → 受信と通知** で行えます。

📷 スクリーンショット：カメラダッシュボード

## 自動受信（Pro）
1. ホーム画面の Wi‑Fi → **受信を開始** をタップします。アプリがバックグラウンドでカメラとの接続を維持します（通知バーに表示されます）。
2. カメラで画像を再生中に **i ボタン → PCへ送信 / 送信画像の選択**（Send to PC / Select to send、機種により表記が異なります）を押すと、写真がスマホに転送されます。

シャッターを切った瞬間に自動で送り込みたい場合は [FTP 受信](08-ftp.md)を使ってください。USB ケーブルを挿している間は、受信も自動で USB 経由に切り替わります。

### 受信の一時停止
Wi‑Fi 自動受信の接続中に、ホーム画面「転送」カード右上の **⏸ 一時停止**、または通知の「一時停止」をタップすると一時停止できます。
- Wi‑Fi 接続自体は維持されるため、アルバム閲覧やリモート撮影はそのまま使えます。
- カメラ側で送信待ちになっている写真はカメラに残り、**受信を再開** をタップすると順番に転送されます。現在転送中の 1 枚は最後まで完了してから一時停止します。
- 「再開」をタップしたとき、受信を停止したとき、タスク一覧からアプリをスワイプ終了したとき、Wi‑Fi が切れたとき、カメラの電源を切ったとき、USB を挿したときは自動的に解除されます。

### 切断されたとき
- 接続が途切れると自動で再接続を試みます。何度か失敗した場合はカメラ固有 ID で再検索するため、カメラの IP アドレスが変わっていても見つけられます。
- **カメラが Bluetooth 転送に切り替わった場合**：カメラには無線チップが 1 つしかないため、Bluetooth で写真を送る間は一度 Wi‑Fi をオフにします。この間ホーム画面には「カメラが Bluetooth で写真を送信中です…完了後に Wi‑Fi へ自動再接続します」と表示され、エラーにはなりません。
- **アルバムやリモート撮影でカメラを使う場合**：カメラは同時に 1 つの接続しか受け付けません。アルバムやリモート撮影を開くと自動受信が一時的に接続を譲り、画面を閉じると自動で復帰します。
- **Wi‑Fi でカメラが見つからない場合**：設定時間（初期値 3 分）を超えるとバッテリー消費を防ぐため自動停止し、通知でお知らせします。時間は **設定 → 受信と通知** で変更できます。

## 受信ルール
**設定 → 受信と通知** で設定します。Wi‑Fi、USB、FTP のすべてに同じ保存ルールが適用されます。

### 受信するファイル形式
保存する対象を選びます：すべてのファイル、JPG のみ、JPG + RAW、写真 + 動画、またはカスタム（JPEG、RAW、HEIF、TIFF、動画、その他）。

さらに 3 つの便利なスイッチ（Pro）があります：

| スイッチ | 説明 |
|---|---|
| **RAW から JPEG のみ保存** | RAW を受信した際、ファイル内に埋め込まれているフルサイズ JPEG（20～50 MB の RAW ではなく通常 2～5 MB）だけを抽出して保存します。解像度はそのまま、撮影情報（EXIF）も完全に保持され、`DSC_1234_S.JPG` として保存されます。SNS 投稿や日常の閲覧に最適です |
| **JPEG を圧縮して保存** | カメラから届いた JPEG をスマホ側で再圧縮して保存します（`_S.JPG`、ピクセル数は変わらず、画質はアルバム設定に従います） |
| **元データ受信時に圧縮版を置き換える** | オリジナルの JPEG を保存した際、スマホ内にある同じ写真の圧縮版を自動削除します |

> RAW ファイルを受信するには、カメラ側の画質モードを RAW または RAW+JPEG に設定し、カメラの「PCと接続」の送信オプションでも RAW+JPEG を選んでください（「JPEG のみ」にしないでください）。メニュー名は機種によって異なります。

### その他のルール
| ルール | 説明 |
|---|---|
| 受信モード | 連続受信、または 1 ファイル受信したら停止 |
| 大容量動画 | しきい値（初期値 1024 MB）を超える動画は自動受信せず「フィルター済み」として記録し、必要なものだけ手動ダウンロードできます |
| 保存フォルダ | カメラ別、日付別、カメラと日付別、ファイル形式別 |
| ファイル名 | カメラの元ファイル名（`DSC_1234.NEF`）、日付プレフィックス付き（`20261011_DSC_1234.NEF`）、日時プレフィックス付き（`20261011_153012_DSC_1234.NEF` — 複数台のカメラでも撮影日時順に並びます）。変更後に保存されるファイルから適用されます |

### 保存場所
- 写真：`Pictures/AeroCam/…`
- 動画：`Movies/AeroCam/…`
- その他のファイル：`Download/AeroCam/…`

Google フォトなどの他社製アプリからもそのまま閲覧できます。アプリをアンインストールして再インストールした後は、**設定 → ストレージとバッテリー →「スマホの写真を再スキャン」** を実行すると過去の写真をアルバムに戻せます。

### 重複ファイルの判定
- カメラのシリアル番号、ファイル名、サイズ、撮影日時、ファイル内容（ハッシュ値）で判定するため、同じ写真が二重に保存されることはありません（履歴には「重複」と記録されます）。
- スマホ上で削除した（ゴミ箱に入れた場合も含む）写真は、もう一度カメラから送れば再保存されます。
- 同じ写真を再送したい場合、一度受信を停止してやり直す必要はありません。

### Bluetooth と Wi‑Fi で同じ写真を受信した場合
Wi‑Fi の方が高画質（フルサイズ）なため、Wi‑Fi 版が優先されます：
- Wi‑Fi で先に受信し、後から Bluetooth で送られてきた場合：Bluetooth 版は保存しません。
- Bluetooth で先に受信し、後から Wi‑Fi で同じ写真を受信した場合は、**設定 → 受信と通知 →「Bluetooth で受信済みの写真」** の設定に従います：
  - **Wi‑Fi 受信時に元データへ置き換える**（推奨）：フルサイズ版を保存し、スマホ内の Bluetooth 縮小版を自動削除します。
  - **Wi‑Fi では再ダウンロードしない**。
  - **両方とも残す**。
- RAW の元データは常にそのまま受信・保存されます。

## 保存先とカードなし撮影
シャッターを切った後に写真をどこへ保存するかを決めます。アプリがカメラにメモリーカードが入っているかを読み取り、自動で切り替えます：
- **カードが入っている場合**：**設定 → 撮影 → 保存先** で選んだ方法に従います：
  - **メモリーカード**：カメラのメモリーカードに保存します。
  - **メモリーカード＋スマホ**（Pro）：メモリーカードに保存しつつ、同時にスマホにもコピーを転送します。
- **カードが入っていない場合**（Pro）：自動で **スマホのみに保存（カードなし撮影）** に切り替わります。普段どおりカメラのシャッターを切ることができ、写真は直接スマホに転送されて撮影日時のファイル名（例：`AC_20261025_193805.JPG`）で保存されます。カードを挿すと自動で元の設定に戻ります。

ホーム画面、アルバム、リモート撮影のどこからでも使え、Wi‑Fi と USB の両方に対応しています。

**初回のみ必要なカメラ側設定：**
1. カメラのカスタムメニューにある **カードなし時レリーズ**（Slot empty release lock）を **レリーズ許可**（Enable release）に変更します。これを行わないとカード未挿入時にシャッターが切れません。
2. Wi‑Fi 接続時は、カメラの接続タイプを **カメラコントロール**（Camera control）にしてください。「画像送信」のままだと、1 枚目を撮ってから約 3 秒後に切り替えを促す通知が出ます（写真はカメラ内に保持されており、切り替えると自動で転送されます）。USB 接続ではこの制限はありません。
3. ワンタップ接続はカードなし撮影に非対応のため、スマホのテザリングか同じ Wi‑Fi を使ってください。

**ステータスバーの表示**（ホーム画面とアルバム上部）：

| 表示 | 意味 |
|---|---|
| 保存先：メモリーカード ✓ | カメラのメモリーカードに保存します |
| 保存先：メモリーカード＋スマホ ✓ | メモリーカードに保存し、スマホにもコピーします |
| 保存先：スマホのみ（カメラにメモリーカードがありません） | 写真はスマホへ直接転送されます |
| カメラが「画像送信」モードになっています…（赤字） | 「カメラコントロール」に切り替えてください |
| ワンタップ Wi‑Fi：メモリーカードがないため撮影できません（赤字） | カードを入れるか、テザリング / 同じ Wi‑Fi に切り替えてください |
| メモリーカードがいっぱいです（赤字） | カードを交換するか空き容量を確保してください（自動で「スマホのみ」には切り替わりません） |
| カメラにメモリーカードがないため撮影できません（赤字） | 無料版であるか、スマホの空き容量が 1 GB 未満です |

> カードが入っていない状態では動画撮影はできません。また、1 枚ずつスマホへ転送を待つため連写速度は遅くなります。

## 写真の位置情報（GPS）
**設定 → 受信と通知 → 写真の位置情報** に 2 つのスイッチがあります：
- **カメラへ位置情報を送信（Bluetooth）**（初期値オン）：カメラの電源オン時や Bluetooth 転送時にスマホの GPS 情報をカメラへ送り、カメラ自身が撮影時に写真へ記録します。
- **受信した JPEG に位置情報を追加（スマホ）**：Wi‑Fi、USB、FTP、アルバムダウンロード、リモート撮影で受け取った JPEG に対し、撮影時刻をもとにスマホ側で記録していた位置情報を書き込みます。初回受信開始時に一度確認が出ます。
  - RAW ファイルは一切書き換えません。すでに位置情報が入っている写真は元の座標をそのまま残します。
  - 受信中にスマホが記録した位置情報履歴はこの端末内だけに保存され、24 時間後に自動削除されます。
  - 撮影時刻と一致する位置記録がない場合は書き込みません（誤った場所を書くより位置なしのままにします）。
  - 位置情報を記録するには、AeroCam を開いた状態で受信を開始する必要があります。

> 写真に埋め込まれた撮影場所は、元ファイルを共有すると相手にも見えます。QR Code 共有では初期設定で位置情報を削除して送信します。詳しくは[第 4 章](04-gallery.md#qr-code-共有)をご覧ください。

## 履歴
ホーム画面「転送」カード右上の **履歴 ›** をタップすると、自動受信・アルバムダウンロード・リモート撮影保存の全結果（成功、重複、スキップ、失敗）がサムネイル付きで一覧表示されます。
- タップするとアプリ内で全画面プレビューできます。
- 検索、カメラ別の絞り込み、履歴の消去ができます。履歴を消去してもスマホ内の写真ファイルは削除されません。
