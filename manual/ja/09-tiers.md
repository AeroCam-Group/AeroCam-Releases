# 9. 無料版 / Pro / Cine

| プラン | 機能 |
|---|---|
| **無料版** | Bluetooth 写真転送、Bluetooth リモコン（AF、撮影、録画、連写、セルフタイマー）、USB カメラアルバム（手動選択によるオリジナルダウンロード）、スマホの写真アルバム、★レーティング、写真編集（.np3 スタイルプレビュー、スマホでの RAW 編集、ロスレス RAW への切り替えを含む）、写真の位置情報、QR Code 共有（縮小版）、星空モード |
| **Pro** | 無料版の全機能に加え、Wi‑Fi（ワンタップ接続、Wi‑Fi アルバム）、FTP 受信、自動受信（Wi‑Fi、USB）、リモート撮影、撮影アシスト、撮影ツール（バルブ、インターバルタイマー、オートブラケティング、フォーカスシフト）、リモートセルフタイマー、ゴーストオーバーレイ、Bluetooth リモコンのインターバル撮影、RAW から JPEG のみ保存、圧縮 JPEG 保存、メモリーカードバックアップ、カメラから削除、カードなし撮影（スマホのみ保存）、カメラスタイル C1～C9、QR Code 共有（オリジナルサイズ・RAW 対応）、パノラマ結合、手持ち連写合成（ノイズ低減） |
| **Cine** | Pro の全機能に加え、ビデオモニター、LUT、アナモルフィックデスクイーズ、A/B ラックフォーカス、ビデオモニターでのゴーストオーバーレイ |

ロックされた機能をタップすると、必要なプランと「テストキーを入力」ボタンが表示されます。

## Beta 期間中について
- Beta 版は初期状態で無料版です。[テストキー](01-install.md#テストキーprocine-のロック解除)を入力すると、Pro と Cine のすべての機能を無料で利用できます。
- テストキーは毎週更新され、各キーの有効期間は 14 日間です。GitHub の AeroCam-Releases でのみ無料公開されています。
- Beta テスト期間が終了すると、最後のキーの有効期限が切れた時点で無料版に戻ります。
