# AeroCam ユーザーマニュアル（日本語）

> **Beta 92.04.08.10**（2026-11-15 更新）に対応しています。📷 が付いている行は、今後スクリーンショットを追加する予定の場所です。

AeroCam は、カメラで撮った写真を Android スマートフォンへ直接転送できるアプリです。スマートフォンからのリモート操作、写真編集、カスタムスタイルのカメラへの書き込みにも対応しています。現在は **Nikon Z シリーズ**に対応しており、今後ほかのメーカーにも順次対応していく予定です。

AeroCam は個人開発のサードパーティ製アプリであり、Nikon やその他のカメラメーカーとは一切提携・承認関係にありません。

## 対応カメラ

| 機種 | 自動受信・カメラアルバム | リモート撮影 | 状況 |
|---|---|---|---|
| Z9、Z8、Z6III、Zf、Z5II、Z50II、ZR などメニューに「接続タイプ」（Connection type）がある機種 | ✅ | ✅ | Zf で実機テスト済み。他機種の動作報告も歓迎します |
| Z6、Z7、Z6II、Z7II、Z5、Z50、Zfc、Z30 など以前の機種 | ✅ | ❌（これらの機種の通信仕様により非対応） | 動作報告を歓迎します |
| Canon、Sony、Fujifilm | 準備中 | 準備中 | |

ほかの機種でテストされた場合は、[機種レポート](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose)から動いた機能・動かなかった機能をお知らせください。

## 動作環境
- Android 10 以上のスマートフォン
- Nikon Z シリーズのカメラ

## このマニュアルで使われる用語
| 用語 | 意味 |
|---|---|
| カメラアルバム / カメラのメモリーカード | カメラのメモリーカード内の写真を、接続経由でスマホから閲覧すること |
| スマホの写真 | すでにスマートフォンに保存されている写真 |
| RAW | Nikon の NEF ファイル |
| JPEG.S | 圧縮された JPEG（RAW から抽出した JPEG、スマホで再圧縮した JPEG、Bluetooth で送られた縮小版）。ファイル名の末尾が `_S.JPG` になります |
| ピクチャーコントロール（Picture Control） | カメラの画作り・カラー設定（スタンダード、フラットなど）。カスタム設定は C1～C9 に登録されます |
| Pro / Cine | 有料プランです。Beta 期間中は無料のテストキーを入力するとすべて使えます。詳しくは[第 9 章](09-tiers.md)をご覧ください |
