| 方法 | 接続 | ライブビュー | プラン |

## リモート撮影（Pro）
スマホ画面でカメラのライブビューを見ながら、タップでピント合わせ、設定変更、静止画・動画の撮影ができます。**Wi‑Fi と USB の両方で使え**、USB ケーブルを挿すと自動で USB 接続に切り替わります。

**必要な条件**
1. メニューに「接続タイプ」がある機種（[対応カメラ](README.md#対応カメラ)を参照）。
2. Wi‑Fi 接続時は、カメラの「接続タイプ」を **カメラコントロール** に切り替えます（[カメラとの接続](02-connect.md#カメラの接続タイプconnection-type)を参照）。「画像送信」のままになっている場合は、切り替え手順がアプリに表示され、切り替えると自動で再接続します。

リモート撮影は全画面表示となり、画面下部のタブは隠れます。左上の **←** またはスマホの戻るボタンでホーム画面に戻ります。

📷 スクリーンショット：リモート撮影画面（縦画面・横画面）

### 画面構成
| 場所 | 内容 |
|---|---|
| 上部 | カメラ設定：露出モード、シャッター速度、絞り値、ISO、ISO オート、露出補正、ホワイトバランス、フォーカスモード、AF エリアモード、測光モード、ピクチャーコントロール、画質。縦画面では 2 行、横画面では 1 行（左右スクロール可能） |
| 上部 3 行目 | 戻る、録画、クリーン表示、画面ロック、保存先、バッテリー残量 |
| 中央 | ライブビュー映像（トリミングなしの全体表示）。フォーカス枠、水準器、露出インジケーターなどが重なって表示されます |
| 下部 | 6 個のクイックトグル（カスタマイズ可能）＋「その他」 |
| 最下部 | 「撮影」（撮影モード選択）、シャッターボタン、AF ボタン、最新写真のサムネイルと残り撮影可能枚数 |

スマホを横向きにするとクイックトグルは左側の黒帯へ移動し、シャッターボタンは右下に配置されます。**左手モード**（設定 → 撮影）をオンにするとシャッターボタンが左下に移動します。

### カメラ設定の変更
上部の数値をタップすると、ライブビューを隠さない位置に調整バーが表示されます。
- 露出モードは表示専用です（P / S / A / M の切り替えはカメラ側で行います）。シャッター速度は S・M で、絞りは A・M で調整できます。
- ISO オートがオンのとき、ISO は `AUTO` と表示されます。露出補正の横には `0` リセットボタンがあります。
- ホワイトバランスで `K` を選ぶと色温度を数値で調整できます。ピクチャーコントロールはカスタム登録名も含めカメラ上の名称を表示します。
- **変更できない設定**がある場合は理由が説明されます。Zf や Zfc のような物理ダイヤル搭載機では、シャッタースピードダイヤルを **1/3 STEP**、ISO 感度ダイヤルを **C** に合わせてください。

### ピント合わせとシャッター
- **タップでフォーカス**：ライブビュー上の好きな場所をタップするとそこにピントを合わせます。カメラ側の AF エリアモードはフォーカスポイントを移動できるモード（シングルポイント AF など）にしておいてください。オートエリア AF ではカメラが自動決定します。
- 画面上にはカメラ実際のフォーカス枠が描画されます（シングルポイント、ダイナミック、オートエリア、追尾に対応）。合焦すると緑色、失敗すると赤色に変わります。
- **シャッターボタン**：1 回タップで撮影。**長押し＝シャッター半押しフォーカス**（外枠が緑に変化）で、指を離すと撮影されます。
- **AF ボタン**：現在のフォーカスポイント位置で再度ピントを合わせます。
- **撮影前 AF**（初期値オン）：オフにすると AF を待たずに即シャッターが切れるため、マニュアルフォーカス時やピント固定時に素早く撮れます。
- **タップ撮影**：オンにすると、ライブビューをタップした位置にピントを合わせてそのまま 1 枚撮影します。
- 画面左右端（Android の戻るジェスチャー領域）のタップはフォーカス操作を無効化しているため、スワイプで戻る際に誤作動しません。

### 下段クイックトグル（カスタマイズ可能）
初期配置はピーキング、ゼブラ、水準器、グリッド、拡大、空きスロット 1 つで、一番右は「その他」で固定です。
- **タップ**でオン／オフ切り替え、**0.5 秒長押し**で詳細設定（ピーキング感度、ゼブラしきい値、グリッド種類、拡大倍率）が開きます。
- **カスタマイズ**：「その他」右上の歯車アイコンから入れ替えできます。配置可能な項目：ピーキング、ゼブラ、水準器、グリッド、拡大、ヒストグラム、露出インジケーター、タップ撮影、撮影前 AF、スマホへコピー、プレビュー保存、星空モード、ライブプレビュー、セルフタイマー。

### 「その他」ドロワー
「その他」をタップすると半透明パネル（縦画面では下から、横画面では横から）が開き、ライブビューを見ながら操作できます。3 つのタブがあります：
- **アシスト**：ライブプレビュー、ピーキング、白飛び警告（ゼブラ）、水準器、グリッド線、ヒストグラム、露出インジケーター、拡大フォーカス、星空モード。
- **撮影**：撮影前 AF、タップ撮影、AF エリアモード、1 枚ごとにスマホへコピー、プレビュー保存。
- **ツール**：ゴーストオーバーレイ、マルチショットチェックリスト、ヒント。

### 撮影アシスト（スマホ画面上の表示のみで、記録写真には影響しません）
| 機能 | 説明 |
|---|---|
| 水準器 | カメラの傾きセンサーを読み取り、誤差 0.5° 未満で緑色に変わります。左右の傾きと前後の煽り角度も表示します |
| ヒストグラム | タップすると「輝度＋RGB オーバーレイ」と「RGB セパレート」を切り替えられます |
| ゼブラ（白飛び警告） | しきい値を超えた明るい部分に斜線を表示します。しきい値は 85 / 90 / 95 / 100%（初期値 95%） |
| フォーカスピーキング | ピントが合っている輪郭に色を付けます（赤・黄・青・白）。感度は低 / 中 / 高から選べ、MF 時に便利です |
| 露出インジケーター | Nikon のファインダー風縦型露出計（1/3 EV 刻み）。M モードでは適正露出との差、P / A / S モードでは露出補正値を表示します |
| グリッド線 | 3 分割、4×4 分割、黄金比、黄金螺旋、対角線、センタークロス |
| 拡大 | カメラ側が対応している場合（Zf など）は**カメラ本体側で拡大**するため、実際のピクセル等倍を確認できます（50% / 100% / 200% / 400%）。画面タップまたは ◀ ▲ ▼ ▶ で位置移動、下部の `近 ◀◀ ◀ ▶ ▶▶ 遠` で MF の微調整も可能です。非対応機種ではアプリのデジタル拡大（2× / 4× / 8×）になります |

> ライブビューはカメラで圧縮された映像のため、これらのアシスト表示は目安として使い、最終的な露出は撮影した画像のヒストグラムで確認してください。

### 撮影モード
シャッターボタン横の **撮影** をタップして選びます。選択するとボタンが黄色になり、シャッターの上に設定バー（例：`インターバルタイマー撮影　5 秒ごと · 10 枚`）が現れます。バーをタップすると詳細調整と **開始** ボタンが開き、横の × で通常撮影に戻ります。実行中は画面上部に進捗が表示され、**停止** でいつでも中止できます。

| 撮影モード | 設定 | 説明 |
|---|---|---|
| 通常撮影 | 枚数 1～9 | セルフタイマーと組み合わせると、カウントダウン後に約 1 秒間隔で連続撮影します |
| **セルフタイマー** | オフ、2、5、10 秒 | 「撮影」メニューの最上段にあり、すべての撮影モードと動画録画で併用できます。画面中央に大きな数字が表示され、もう一度シャッターを押すとキャンセルします |
| バルブ | 露光秒数 1～3600 | カメラを M モードにし、シャッター速度を Bulb または Time に設定してください。設定時間が来ると自動終了します |
| インターバルタイマー撮影 | 枚数 2～999、間隔 1～3600 秒 | 一定間隔で自動撮影し、合計所要時間も表示します。「1 枚ごとにスマホへコピー」と組み合わせるとタイムラプス確認に便利です |
| オートブラケティング | 枚数 3 / 5 / 7 / 9、ステップ幅 0.3～3.0 EV | 現在の露出補正値を中心に段階的に露出を変えて撮影し、終了後に元の値へ戻します |
| フォーカスシフト撮影 | 枚数 2～300、フォーカスステップ幅 | 一番手前の被写体にピントを合わせて開始すると、1 枚ごとに少しずつ無限遠側へピントを移動して撮影します。AF レンズが必要で、深度合成はパソコンで行います |
| パノラマ | グリッド数または「フリー」 | 重ねながら複数枚を撮影し、パノラマ写真に結合します（下記参照） |
| 手持ち連写合成（ノイズ低減） | 4 枚または 8 枚 | 手持ちで連写した複数枚を合成し、ノイズの少ない 1 枚に仕上げます（下記参照） |

> マルチショットツールの実行中は、AF とタップフォーカスが一時停止します。リモート撮影画面を離れる際は確認ダイアログが表示されます。

#### パノラマ（結合）
- **グリッド**：分割数を選ぶと各コマで回転すべき角度をアプリが計算し、カメラを動かしてシャッターを切るだけでガイドしてくれます。重なり具合の判定（「撮影OK / もう少し回せます / 重なり不足の可能性」）と、前のコマの端の半透明ガイドが表示されます。
- **フリー**：グリッドを決めず、前の写真と約 30% 重なるように好きな方向へ動かしながら自由に撮影できます（最大 30 枚）。
- 2 枚以上撮影すると **結合** をタップしてスマホ上で 1 枚の大判写真に合成できます。1 周ぐるりと撮ると 360° パノラマとして出力されます。撮影時の水準器データをもとに水平が自動補正されます。
- 撮影した元写真はスマホの写真アルバム内で 1 つのスタックにまとめられ、後から再結合することもできます。詳しくは[第 6 章](06-edit.md#画像処理パノラマ結合ノイズ低減合成pro)をご覧ください。

#### 手持ち連写合成（ノイズ低減）
- センサーシフト機能がないカメラでも「複数枚合成による高画質化」ができる機能です。手持ち（または三脚）で 4 枚または 8 枚を連写すると、アプリが位置合わせをして平均合成し、ディテールを保ったままノイズを約 3 分の 1（8 枚時）に低減します。
- 撮影後はバックグラウンドで自動合成され（「合成中 %」表示）、元画像と同じ解像度・EXIF 情報付きで `SHAKE_<日時>.JPG` として保存されます。
- 動いている被写体（車、歩行者、木の葉など）は最もシャープな 1 枚だけを採用するため残像（ゴースト）が出ず、ブレが大きすぎるコマは自動除外されます。
- 夜景、暗い室内、高 ISO 撮影に最適です。

### ゴーストオーバーレイ（Pro）
**その他 → ツール → ゴーストオーバーレイ**：参考画像をライブビューの上に**半透明重ね合わせ**または**左右分割**で表示します。透明度の調整や「現在の画面をキャプチャ」してそのまま比較基準にすることもでき、定点撮影や複写、構図合わせに便利です。

### その他の機能
- **1 枚ごとにスマホへコピー**：設定した受信ルール（「RAW から JPEG のみ保存」を含む）に従って自動保存します。
- **最新写真**：右下のサムネイルに直近で撮った写真と実際のシャッター速度・絞り・ISO が表示されます。タップすると今回のセッションで撮った全写真を確認でき、オリジナルや JPEG をスマホへ保存できます。
- **クリーン表示**：ライブビュー以外の操作ボタンをすべて隠します。隅の薄いボタンをタップすると元に戻ります。**画面ロック**：誤操作を防止します。画面のどこかを長押しするとロック解除されます。
- **動画録画**：上部の録画ボタンで開始します。開始前にカメラを「アプリケーションモード」へ切り替え（Zf では必須）、停止後に元へ戻します。録画できない場合は理由が表示されます。USB 接続時は[ビデオモニター](#ビデオモニターcine)の使用がおすすめです。
- **プレビュー保存**：ライブビュー映像を `Pictures/AeroCam/Snapshots/` に保存します（プレビュー画質）。
- **USB リモート撮影**：Wi‑Fi より滑らかなライブビュー表示が可能で（初期値 30 fps、60 fps または無制限に変更可能）、高解像度プレビューや右下の実測 fps 表示にも対応しています。**設定 → 撮影** から調整できます。
- リモート撮影中は初期設定で画面が常時点灯します。

## Bluetooth リモコン（無料）
Wi‑Fi 不要で、ライブビュー表示のないシンプルなリモコンです。ホーム画面の Bluetooth タイル → **Bluetooth リモコン** から開きます。事前に[Bluetooth ペアリング](02-connect.md#ペアリング)が必要です。
- シャッタータップで 1 枚撮影、シャッター長押しでカメラ本体の連写（CL / CH）を行います。
- AF を押しながらシャッターをタップすると素早く連続レリーズでき、3 枚 / 5 枚連写ボタンもあります。
- AF ボタン：長押しでピント合わせ。カメラ側でシャッターボタン半押し AF が有効になっている必要があります（親指 AF をお使いの方はカメラのカスタムメニューをご確認ください）。
- セルフタイマー（カウントダウン）、動画の録画開始／停止、残り撮影可能枚数の表示に対応しています。
- **インターバル撮影**は Pro 機能です。

## ビデオモニター（Cine）
スマートフォンを本格的な動画撮影用フィールドモニターとして使えます。USB 接続時はホーム画面の USB エリアに **🎥 ビデオモニター** が表示されます（最も滑らかで最大約 60 fps）。Wi‑Fi 版はホーム画面の Wi‑Fi エリアにあり、現在は実験的機能です。
- Zf ではカメラの静止画／動画セレクターを**動画**に切り替えておきます。
- **上部バー**：`● REC` 録画経過時間、動画記録サイズ／フレームレート（例：`1080 60p`、タップで変更可能）、ファイル形式（例：`H.265 10bit`、N‑Log を使う場合は H.265 10-bit を選択）、残り録画可能時間、バッテリー残量。
- **下部バー**：動画用のシャッター速度、絞り値、ISO、ISO オート、露出補正、ホワイトバランス、フォーカスモード、測光モード（動画 ISO は M モード時のみ有効）。
- **録画ボタン**：録画中は誤操作防止のため **1 秒間長押し**（赤いリングが一周するまで）しないと停止しません。録画中に戻るボタンを押すと確認ダイアログが出ます。
- **モニタリングツール**：露出インジケーター、ヒストグラム、ウェーブフォーム / RGB パレード、フォルスカラー、ゼブラ（スキントーン用の第 2 ゼブラ対応）、フォーカスピーキング、グリッド線、セーフフレーム、アスペクト比マット（`2.39:1`、`1.85:1`、`16:9`、`9:16`、`4:5`）、タリー赤枠、シャッター開角度表示。
- **LUT**（Android 13 以上）：プレビュー画面にモニタリング用 LUT（内蔵の N‑Log → 標準変換のほか、`.cube` ファイルの読み込みに対応）を適用できます。録画データ自体には焼き込まれません。二重適用を防ぐため、カメラ側の **ビューアシスト**（View assist）はオフにしてください。
- **アナモルフィックデスクイーズ**（`1.33x`～`2.0x`）、**A/B ラックフォーカス**（2 点のピント位置を登録し、滑らかにピント送り）、**ゴーストオーバーレイ**。
- 録画中の誤ったピント移動を防ぐため、初期設定では録画中のタップフォーカスは無効になっています（メニューから有効化可能）。
- **スクリーンショット**：「プレビュー保存」は映像のみ、「スクリーンショット（アシスト込み）」は LUT・ゼブラ・フォルスカラー・アスペクトマットを含めた状態で保存します。

## 星空モード（無料）
天体撮影では暗順応した目を守るため、白い画面の光で瞳孔が縮むのを防ぐ必要があります。星空モードを使うとアプリ全体の配色が暗赤色になります。
1. 有効化：**設定 → 外観と言語 → テーマ →「星空（赤色光）」** を選ぶか、リモート撮影の下段クイックトグルまたは **その他 → アシスト** で「星空モード」をオンにします。
2. さらに暗くしたい場合：**アプリ画面の明るさを最小にする** をオンにします。
3. 写真本来の色を確認したい場合：**「長押しで元の色を表示」を長押し**している間だけ通常の色に戻り、離すと赤色表示に戻ります。リモート撮影、ビデオモニター、全画面プレビュー画面にこのボタンがあります。
4. 星空モードは画面表示だけを変える機能で、保存される写真には一切影響しません。QR Code 共有画面では相手のスマホで読み取れるよう一時的に通常色へ戻ります。
