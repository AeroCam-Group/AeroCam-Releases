# 10. プライバシーと匿名統計

AeroCam にはアカウント登録機能がなく、写真はカメラとスマートフォンの間だけで直接やり取りされ、**いかなるサーバーにもアップロードされません**。端末の外へ送信されるのは、以下に記載するごく少量のデータだけです。

## インターネット通信が発生する機能
| 機能 | 送信される内容 | オフにできるか |
|---|---|---|
| アップデートの確認（Beta） | GitHub に対して最新バージョン情報だけを問い合わせます | 毎日 1 回自動で実行 |
| 匿名使用統計 | 下記を参照 | はい（設定 → サポート） |
| QR Code 共有 | 同一のローカルネットワーク（同じ Wi‑Fi またはスマホのテザリング）内でのみ、QR Code を読み取った相手へ選択した写真を公開します | 「共有を停止」を押すか制限時間が来ると終了 |

## 匿名使用統計
おおよその利用者数、よく使われているカメラ機種や機能、問題が発生しやすい箇所を把握し、今後の開発優先度を決めるために利用します。**第三者へ販売したり、広告目的に利用したりすることは一切ありません。**

- **スイッチ**：**設定 → サポート →「匿名使用統計を送信」**（初期値オン）。
- 初めてカメラに接続した際に一度だけ説明が表示され、「OK」または「オフにする」を選べます。**回答するまでは一切データは送信されません。**
- **オフにした場合**：送信を即座に停止し、下記のランダム ID と未送信データを削除します。再びオンにすると新しい ID が生成されます。
- オフライン時（カメラ自身の Wi‑Fi に接続している間など）は端末内に一時保存され、インターネット接続が回復したときに送信されます。
- Dev（開発者）ビルドでは記録も送信も行いません。

### 送信されるデータ
- **アプリが自動生成するランダム ID**：スマホやカメラの固有情報から作られたものではなく、アプリの再インストールや統計オフ操作で新しい ID にリセットされます。
- カメラ機種名（例：Nikon Z f）— 機種名のみ。
- 接続方式（Bluetooth、Wi‑Fi、USB、FTP）および Wi‑Fi の種類（カメラ自身の Wi‑Fi、スマホのテザリング、ルーター）。
- その日に使用した機能（機能名のみ、1 日 1 回カウント）。ロックされた機能をタップした履歴も含みます。
- 接続の成功・失敗回数。失敗時は分類コード（例：「タイムアウト」）のみを送り、エラーメッセージ本文は送りません。
- カメラ追加の手順：開始、成功、カメラ未検出、失敗理由の分類。
- その日に受信した写真の枚数（JPEG、RAW、動画それぞれの枚数のみ）。
- 各権限が許可されたか拒否されたか。
- 現在のプラン（無料版、Beta キーなど）、アプリバージョン、アプリ言語、Android のメジャーバージョン。
- 国・地域：接続元から判定し、国コードのみを保存します。

### 絶対に送信されないデータ
カメラのシリアル番号、カメラ内に設定された撮影者名や著作権情報、位置情報（GPS）、写真や動画データ、ファイル名、撮影メタデータ（EXIF）、Wi‑Fi 名やパスワード、スマホの端末 ID（IMEI、Android ID、広告 ID）、氏名、メールアドレス、アカウント情報、エラーメッセージの本文。

### データの保持期間
- 端末ごとの日別詳細データは 90 日間保持され、その後は日別の合計数値のみが残ります。
- 約 13 か月間アクセスがないランダム ID は削除されます。
- サーバーが通信を処理する際、仕組み上 IP アドレスは一時的に認識されますが、国判定と不正アクセス防止のみに利用され、**統計データには一切保存されません**。

## 位置情報について
- **カメラへ位置情報を送信（Bluetooth）**：スマホの位置情報をカメラへ送り、カメラが写真ファイルへ記録します。
- **受信した JPEG に位置情報を追加（スマホ）**：初期値オフ。オンにすると、受信セッション中にスマホが記録した位置情報はこの端末内だけに保持され、24 時間後に削除されます。
- どちらのスイッチも **設定 → 受信と通知 → 写真の位置情報** にあります。詳しくは[第 3 章](03-receive.md#写真の位置情報gps)をご覧ください。
- 写真に埋め込まれた位置情報はファイルと一緒に保存されるため、元ファイルを共有すると相手にも見えます。**QR Code 共有では初期設定で位置情報を削除します。**

## 権限の用途
| 権限 | 用途 |
|---|---|
| Bluetooth、付近のデバイス | カメラとのペアリング、Bluetooth 写真転送、Bluetooth リモコン、Wi‑Fi カメラの検索 |
| 位置情報 | カメラへの位置送信または写真への位置追加。Android が Wi‑Fi 名を読み取る際にも必要です |
| 通知 | 受信の進捗、写真の受信完了、転送エラー、カメラのバッテリー低下通知 |
| 写真と動画 | 「スマホの写真」での表示・整理 |

## 診断情報
**設定 → サポート →「診断情報をコピー」** はテキストをクリップボードにコピーするだけの機能であり、**開発者へ送るかどうかはユーザー自身が決められます**。アプリバージョン、スマホとネットワークの状態、カメラ機能情報、直近の接続ログが含まれ、カメラのシリアル番号は下 4 桁のみが記載されます。公開の GitHub Issue に貼り付ける前に、公開したくない情報が含まれていないかご確認ください。
