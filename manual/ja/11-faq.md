# 11. よくある質問とトラブルシューティング

## 全般
**Pro にアップグレードしなくても、カメラの写真をスマホへ送れますか？**
はい、送れます。無料版でも Bluetooth を使って約 200 万画素の縮小版 JPEG を自動受信できるほか、USB ケーブルでカメラのメモリーカードを閲覧し、フルサイズのオリジナル画像を手動で選んでダウンロードできます。

**Beta 版やテストキーにお金はかかりますか？**
いいえ、かかりません。どちらも GitHub の AeroCam-Releases でのみ無料公開しています。料金を請求された場合、それは公式の配布元ではありません。

**アプリを開くと「これは公式バージョンではありません」と表示される**
第三者によって再パッケージ化された非公式 APK です。テストキーが使えないほか、不正なプログラムが含まれている恐れがあります。削除して AeroCam-Releases からダウンロードし直してください。

**アップデート後にペアリング済みカメラやテストキーが消えた**
92.03.09 以降のバージョンは別アプリとしてインストールされるため、旧バージョンからデータが引き継がれません。お手数ですがカメラの再ペアリングとテストキーの再入力を行ってください。

**写真はどこに保存されますか？**
写真は `Pictures/AeroCam`、動画は `Movies/AeroCam`、その他のファイルは `Download/AeroCam` に保存され、Google フォトなどのアプリからも見られます。92.03.09 より前の旧バージョンで保存したファイルは元のフォルダに残っており、移動はされません。

**スマホ側で消してしまった写真をもう一度転送したい**
カメラからもう一度同じ写真を送信すれば、スマホ上にファイルが存在しないことを自動判定して再保存します。

**スマホのゴミ箱から復元した後や、アプリ再インストール後にアルバムへ写真が表示されない**
**設定 → ストレージとバッテリー →「スマホの写真を再スキャン」** を実行してください。

## 接続について
**Wi‑Fi でカメラにいつまでもつながらない**
1. カメラが「PCと接続」画面のまま待機しており、画面に Wi‑Fi アイコンが出ているか確認してください（モニターが消えている場合はシャッター半押しで復帰）。
2. 「接続タイプ」が正しいか確認してください：自動受信・アルバム閲覧＝画像送信、リモート撮影・カードなし撮影＝カメラコントロール。
3. スマホのテザリング方式の場合：テザリングがオンになっており、カメラがそのアクセスポイントに接続しているか確認してください。
4. 同じ Wi‑Fi 方式の場合：スマホとカメラが同じ SSID に接続しているか確認してください（スマホが別の Wi‑Fi やモバイルデータへ自動切替していることがあります）。
5. テザリングもルーターも不要な **ワンタップ接続** をお試しください。
6. **ⓘ** をタップし、接続ガイドの手順どおりに最初から確認してください。

**ホテルや展示会場の Wi‑Fi でカメラが見つからない**
公衆 Wi‑Fi では端末同士の通信（プライバシーセパレーター）が遮断されていることがほとんどです。スマホのテザリングまたはワンタップ接続に切り替えてください。

**カメラに「他の機器とペアリング済みです」と表示される**
そのネットワーク設定が別アプリに紐付いています。カメラ側で新しいネットワーク設定を追加してからペアリングし直してください。

**ワンタップ接続でカメラの Wi‑Fi が見つからない**
カメラは Bluetooth から起動指示を受け取ってから Wi‑Fi を立ち上げるまで 10～30 秒ほどかかり、その間アプリが自動リトライします。それでも失敗する場合は、カメラの Wi‑Fi パスワードが正しいかご確認ください。

**スマホのテザリングが勝手に切れてしまう**
接続機器がインターネット通信を行わないと自動でテザリングをオフにするスマホがあります。スマホ本体のテザリング設定で「自動でオフにする」を無効にするか、ワンタップ接続を使ってください。

**テザリングを入れ直したらカメラが再接続しなくなった**
スマホのテザリング IP アドレスが変わった可能性があります。Wi‑Fi 自動受信であればアプリが自動で見つけ直しますが、FTP の場合はカメラ側に登録したサーバーアドレスを修正してください。

**USB ケーブルを挿しても反応がない**
1. カメラの USB 設定が **MTP/PTP** になっているか確認してください。
2. データ通信対応ケーブルを使っているか確認してください（充電専用ケーブルは不可）。
3. スマホに「アクセスを許可」の確認が出たら許可を押してください。
4. USB タイル右上の `⋮` → **USB テスト** を実行すると、どの段階で失敗しているか確認できます。

**バックグラウンド受信が途中でよく止まる**
**設定 → ストレージとバッテリー** からバッテリーの最適化をオフにしてください。Xiaomi や OPPO などの端末では、さらにシステム設定側で AeroCam のバッテリー制御を「制限なし」に設定する必要があります。

## Bluetooth
**Bluetooth での写真転送が途中で止まる**
- RAW で撮影した写真は、カメラ側で JPEG に変換してから送信されます。転送中にカメラを操作すると送信がキャンセルされるため、撮影後はそのままカメラの電源を切り、バックグラウンドで送信させるのがおすすめです。
- Bluetooth タイルの **切断して再接続**、または **⋮ → Bluetooth サービスを再起動** を試してください（ペアリング情報は消えません）。

**Bluetooth リモコンの AF ボタンを押してもピントが合わない**
カメラ側でシャッターボタン半押しによる AF が有効になっている必要があります。親指 AF（AF‑ON）をお使いの方は、カメラのカスタムメニューで **半押しAFレンズ駆動**（AF activation）が有効になっているか確認してください。

**Bluetooth と Wi‑Fi の両方で同じ写真を受信すると 2 枚保存されますか？**
初期設定では 2 枚になりません。Wi‑Fi でオリジナルを受信すると、Bluetooth で届いていた縮小版は自動削除されます。動作は **設定 → 受信と通知 →「Bluetooth で受信済みの写真」** から変更できます。

## リモート撮影
**シャッター速度や ISO が変更できない**
- シャッター速度は S または M モード、絞りは A または M モードでのみ変更できます。ISO を手動変更する際は先に ISO オートをオフにしてください。
- Zf などの物理ダイヤル機では、シャッタースピードダイヤルを **1/3 STEP**、ISO 感度ダイヤルを **C** に合わせてください。

**画面をタップしてもフォーカスポイントが動かない**
カメラの AF エリアモードをフォーカスポイント移動可能なモード（シングルポイント AF など）にしてください。オートエリア AF ではカメラ側が自動選択します。

**ホーム画面のダッシュボードに一部の項目（レンズ、残り枚数、総レリーズ回数）が出ない**
一部の情報は特定のモードでしかカメラから取得できません。「カメラコントロール」に切り替えてリモート撮影に入ると読み取れるようになります。また、総レリーズ回数の取得にはメモリーカード内に 1 枚以上の写真が必要です。

**色温度（ケルビン値）はどこで見られますか？**
Nikon は実測色温度を暗号化されたメーカーノート領域に記録するため、「詳細」ではホワイトバランスの設定モード名のみが表示されます。

## 保存先とカードなし撮影
**カードを入れていないとシャッターを押しても反応しない**
カメラの **カードなし時レリーズ** が **レリーズ許可** になっていること、および AeroCam と接続済み（ステータスバーに「スマホのみ」表示）であることを確認してください。

**カメラ画面に「DEMO」と表示される**
メモリーカードが入っておらず、かつ AeroCam の「スマホのみ」受信と接続されていない状態では、カメラが写真を「DEMO」扱いにして保存しません。カードを入れるか、AeroCam と接続した状態で撮影してください。

**写真がスマホに届かず、ホーム画面上部に赤いバナーが出ている**
- 「カメラが『画像送信』モードになっています」：カードなし撮影には **カメラコントロール** が必要です。カメラ側で切り替えると再接続され、撮影済みの写真が自動転送されます。
- 「ワンタップ Wi‑Fi：メモリーカードがありません」：ワンタップ接続はカードなし撮影に非対応です。カードを入れるか、スマホのテザリング / 同じ Wi‑Fi へ切り替えてください。

**「接続が切れました」と警告が出る**
「スマホのみ」保存の状態で 10 秒以上接続が切れると警告が表示されます（その間に撮った写真はカードにも残らないためです）。再接続されると自動で復帰します。

## 編集とスタイル
**NEF が開けない・編集できない**
高効率 / 高効率★ 圧縮の NEF は内蔵のフルサイズ JPEG を使って編集されます。小さなプレビュー画像しか入っていないファイルは編集できません。スマホでフル現像を行いたい場合は、カメラ側を **ロスレス圧縮** に切り替えてください。詳しくは[第 6 章](06-edit.md#スマホで編集可能な-rawカメラの-raw-圧縮方式の切り替え)をご覧ください。

**.np3 を適用した色味がカメラと違う**
スマホ版ではトーンカーブと彩度をシミュレーションしており、カラーブレンダーとカラーグレーディングはまだ非対応のため近似的な仕上がりになります。また、撮影時にすでにピクチャーコントロールが適用された JPEG に重ねると効果が二重にかかります。

**.np3 をカメラに書き込んだ後、色が違って見える**
カメラのカスタムスロットが受け取れるのは **ベース＋カーブ＋シャープネス** のみで、彩度・カラーブレンダー・カラーグレーディングは通信経由では書き込めません。完全な再現が必要な場合は、メモリーカード経由でカメラメニューから `.np3` を読み込んでください。

**パノラマ結合が失敗する・一部の写真が抜ける**
隣り合う写真同士で約 30% の重なりが必要です。結合できなかった写真はファイル名が表示され、グリッドパノラマで 1 コマでも欠けている場合は出力されません。

## FTP
**カメラに Err.31 または Err.32 が表示される**
最新の Beta 版へアップデートしたうえで、カメラに入力した IP アドレス、ポート `2121`、ユーザー名 `aerocam`、パスワードが AeroCam の FTP 画面と一致しているか、またパッシブモードがオンになっているか確認してください。

**カメラにログイン失敗と表示される**
パスワードは大文字・小文字を含め AeroCam の FTP 画面どおりに入力する必要があります。「パスワードを再生成」を押した場合は、カメラ側の設定も書き換えてください。

**FTP をオンにしていると、アルバムやリモート撮影につながらない**
カメラが FTP モードで動作している間は、アルバム閲覧やリモート撮影用の Wi‑Fi 接続を受け付けません。USB ケーブルを使うか、FTP 受信を停止してカメラ側を「PCと接続」に戻してください。

## その他
**アプリが強制終了（クラッシュ）した**
アプリを開き直して **設定 → サポート →「診断情報をコピー」** を押し、[問題の報告](12-report.md)時に貼り付けてください。最後のクラッシュ箇所のエラー情報が含まれています。

**匿名使用統計をオフにするには？**
**設定 → サポート →「匿名使用統計を送信」** をオフにしてください。詳しくは[プライバシーと匿名統計](10-privacy.md)をご覧ください。
