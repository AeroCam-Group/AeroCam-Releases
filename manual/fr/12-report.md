# 12. Signaler un problème

Rendez-vous sur [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) et choisissez un formulaire :

| Formulaire | Utilité |
|---|---|
| Rapport de bug | Une fonction ne marche pas correctement ou l'application plante |
| Demande de fonctionnalité | Idées de nouvelles fonctions, améliorations ou meilleurs réglages par défaut |
| Erreur de traduction | Texte mal traduit ou peu naturel |
| Rapport d'appareil photo | Résultats de tests avec d'autres modèles d'appareils photo |

## Merci de joindre
- Version d'AeroCam (en haut à gauche de l'accueil, ou dans Paramètres → Assistance)
- Modèle du téléphone et version d'Android
- Modèle de l'appareil photo et version du firmware
- Méthode de connexion (Bluetooth / Connexion en un geste / Point d'accès mobile / Même Wi‑Fi / USB / FTP)
- Étapes pour reproduire, résultat attendu et résultat constaté
- **Infos de diagnostic** : **Paramètres → Assistance → « Copier les infos de diagnostic »**, à coller dans le formulaire

## Remarques
- Les Issues sont **publiques** — ne publiez jamais de mots de passe Wi‑Fi, numéros de série complets d'appareils photo, comptes ou autres données personnelles.
- Pour toute demande confidentielle (suppression de données, faille de sécurité, etc.), écrivez à **aerocam.lab@gmail.com**.
