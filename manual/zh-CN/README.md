# AeroCam 使用手册（简体中文）

> 对应 **Beta 92.04.08.10**（2026-11-15 更新）。标 📷 的地方之后补充截图。

AeroCam 可以让相机的照片直接传到 Android 手机，也能用手机遥控相机、在手机上修图，并把风格写入相机。目前支持 **Nikon Z 系列**，之后会支持更多品牌。

AeroCam 是独立开发的第三方 App，与 Nikon 及其他相机厂商没有任何合作或授权关系。

## 支持的相机

| 机型 | 自动接收、相机相册 | 远程拍摄 | 状态 |
|---|---|---|---|
| Z9、Z8、Z6III、Zf、Z5II、Z50II、ZR 等菜单里有“连接类型”（Connection type）的机型 | ✅ | ✅ | Zf 已实测，其他欢迎反馈 |
| Z6、Z7、Z6II、Z7II、Z5、Z50、Zfc、Z30 等较早的机型 | ✅ | ❌（这些机型的连接方式不支持） | 欢迎反馈 |
| Canon、Sony、Fujifilm | 准备中 | 准备中 | |

如果用其他机型测试过，请通过[机型报告](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose)告诉我们哪些功能可用、哪些不行。

## 需要
- Android 10 以上的手机。
- Nikon Z 系列相机。

## 术语说明
| 本手册用词 | 含义 |
|---|---|
| 相机相册 / 相机存储卡 | 相机存储卡上的照片，通过连接在手机上浏览 |
| 手机相册 | 已经保存到手机上的照片 |
| RAW | Nikon 的 NEF 文件 |
| JPEG.S | 压缩过的 JPEG（从 RAW 提取的 JPEG、手机重新压缩的 JPEG、蓝牙传来的缩小版），文件名以 `_S.JPG` 结尾 |
| 优化校准（Picture Control） | 相机的色彩风格，例如标准、平坦；自定义的存放在 C1～C9 |
| Pro / Cine | 付费等级；Beta 期间输入免费测试密钥即可使用，见[第 9 章](09-tiers.md) |
