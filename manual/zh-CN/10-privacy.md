# 10. 隐私与匿名统计

AeroCam 没有账号系统，照片仅在你的相机和手机之间直接传输，**不会上传到任何服务器**。只有下面列出的极少量数据会离开手机。

## 会联网的功能
| 功能 | 发送内容 | 能否关闭 |
|---|---|---|
| 检查更新（Beta） | 仅向 GitHub 查询最新版本号 | 每天自动执行一次 |
| 匿名使用统计 | 见下文 | 可以，设置 → 支持 |
| QR Code 分享 | 仅在你的局域网（同一 Wi‑Fi 或手机热点）内，供扫码者查看你选中的照片 | 你点击停止或倒计时结束即关闭 |

## 匿名使用统计
用于了解大约有多少人在使用、常用哪些相机机型和功能、哪里容易出现问题，从而决定下一步开发重点。**绝不会出售给任何人，也不用于广告用途。**

- **开关**：**设置 → 支持 →“发送匿名使用统计”**，默认开启。
- 首次连接相机时会提示说明一次，可选择“好”或“关闭”。**在做出选择前不会发送任何数据。**
- **关闭后**：立即停止发送，并删除下文所述的随机 ID 及尚未发送的缓存数据。重新开启会生成新的 ID。
- 处于无网络状态时（例如正连接着相机自身的 Wi‑Fi），数据先暂存在手机本地，恢复网络后再发送。
- Dev 开发版不记录也不发送统计数据。

### 会发送的数据
- **App 自行随机生成的 ID**：非获取自手机或相机硬件，重装 App 或关闭统计后即更换为新 ID。
- 相机型号（例如 Nikon Z f），仅包含型号名称。
- 连接方式（蓝牙、Wi‑Fi、USB、FTP）、Wi‑Fi 类型（相机自身 Wi‑Fi、手机热点、路由器）。
- 每天使用了哪些功能（仅记录功能名称，每天计一次），包括点击了哪些未解锁的付费功能。
- 连接成功或失败的次数，失败时仅发送分类代码（例如“超时”），不发送具体报错信息。
- 添加相机的步骤：开始、成功、找不到相机、失败原因分类。
- 每天接收的照片数量（JPEG、RAW、视频各自几张，仅记录数量）。
- 权限状态是允许还是拒绝。
- 当前方案（免费、Beta 密钥等）、App 版本、App 语言、Android 大版本号。
- 国家 / 地区：通过网络连接判断，仅保存国家代码。

### 绝不发送
相机序列号、相机内设置的拥有者或版权名称、位置（GPS）、照片和视频、文件名、拍摄参数（EXIF）、Wi‑Fi 名称和密码、手机硬件 ID（IMEI、Android ID、广告 ID）、姓名、Email、账号、具体错误信息文本。

### 数据保留期限
- 单台设备的每日明细记录保留 90 天，之后仅保留每日汇总总数。
- 超过约 13 个月未活跃的随机 ID 会被自动删除。
- 服务器处理网络请求时必然会看到 IP，仅用于判断国家归属和防止接口滥用，**绝不会存入统计数据库**。

## 位置信息
- **发送位置给相机（蓝牙）**：手机将位置发送给相机，由相机写入照片。
- **为收到的 JPEG 补充位置（手机）**：默认关闭。开启后，接收期间手机记录的位置仅保存在本机、24 小时后自动删除。
- 两个开关均位于 **设置 → 接收与通知 → 照片位置**，见[第 3 章](03-receive.md#照片位置gps)。
- 写入照片的位置信息会随文件保留，分享原图时对方也能看到。**QR Code 分享默认会移除位置信息**。

## 权限用途
| 权限 | 用途 |
|---|---|
| 蓝牙、附近的设备 | 与相机配对、蓝牙传照片、蓝牙遥控、搜索 Wi‑Fi 相机 |
| 位置 | 发送位置给相机或补充进照片；Android 读取 Wi‑Fi 名称也需要 |
| 通知 | 接收进度、收到照片、传输异常、相机低电量提醒 |
| 照片和视频 | 在手机相册中显示、整理照片 |

## 诊断信息
**设置 → 支持 →“复制诊断信息”** 仅将文本复制到剪贴板，**由你自行决定**是否粘贴发送给我们。内容包含 App 版本、手机与网络状态、相机能力、最近的连接日志，相机序列号仅保留末 4 位。粘贴到公开的 GitHub Issue 前，请再次检查确认没有不想公开的内容。
