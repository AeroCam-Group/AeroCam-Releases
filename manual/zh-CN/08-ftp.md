# 8. FTP 接收（Pro）

相机拍完照片后，**自动通过 FTP 推送到手机**，无需在相机上挑选照片，也不用打开相册。实测 Nikon Zf 每张 RAW（约 18 MB）大约 1 秒即可传到手机。

AeroCam 本身内置了 FTP 服务器，**无需额外搭建任何服务器**。

## 适用场景
- 活动、婚礼、体育摄影：边拍边把照片实时传到手机。
- 拍完想立刻在手机上审片、发朋友圈或社交平台。

## 准备工作
- 相机具备内置 FTP 上传功能（Nikon Z f、Z 8、Z 9、Z 6III 等）。
- 手机开启**个人热点**，相机连接该热点（或手机和相机连接同一台路由器）。
- 相机必须插入存储卡：FTP 传输的是存储卡上的照片。

## 首次设置
1. 打开手机热点。
2. AeroCam 首页 **FTP** → 点击最上方 **开始接收**。界面会显示相机需要填写的参数，每一项都可以点击直接复制：
   - 服务器地址（例如 `10.14.29.30`）
   - 端口：`2121`
   - 用户名：`aerocam`
   - 密码：App 自动生成的 8 位密码（可点击“重新生成”）
   - 被动模式（PASV）：**开**
3. 相机：**MENU → 网络菜单 → 连接至 FTP 服务器（Connect to FTP server）→ 网络设置 → 创建配置文件**：
   - Wi‑Fi 选择手机开启的热点。
   - 服务器类型选 `FTP`，依次填入上述地址、端口、用户名、密码，并开启被动模式。
4. 在相机上启用这组 FTP 连接。当 AeroCam 的 FTP 状态显示“已连接”即配置完成。
5. 在相机的 FTP 菜单中开启 **自动发送**（Auto send / 拍摄后自动传送），之后每次按快门都会自动传输。

不确定如何设置时，点击 FTP 卡片旁的 **ⓘ** 可查看图文教程。

## 使用期间
- 状态指示灯：关闭、运行中・等待相机、已连接、接收中、出错。
- 通知栏会显示“FTP 接收中・已收 N 张”以及当前文件名和传输速度。
- 照片遵循 **设置 → 接收与通知** 中的规则保存（文件夹、文件名、仅收 JPEG、RAW 仅存 JPEG 等），记录中来源标注为 `FTP`。
- 若传输中途断开或相机突然关机，未接收完整的文件会自动删除，相册里不会留下损坏的残缺文件。
- 相机关机后约 1 分钟内状态会变为未连接；相机重新开机连回后会自动接管传输。
- **闲置自动关闭**：**设置 → 接收与通知 →“FTP 多久未收到照片自动关闭”**（不自动关闭、5、10、30 分钟）。从最后一张照片开始计时，传输过程中不会关闭，自动关闭时会发送通知。

## 注意事项
- **热点必须保持常开**。部分手机在检测到无上网流量时会自动关闭热点，请前往手机热点设置关闭“自动关闭热点”功能。
- 热点关闭再重新打开后，手机分配的 IP 地址可能会变化，需核对相机里填写的地址。
- FTP 接收和 **Wi‑Fi 自动接收同一时间只能开启一个**，开启其中一个时另一个会自动停止。
- 开启 FTP 期间，相机处于 FTP 模式，**相册和远程拍摄无法通过 Wi‑Fi 连接**。如需使用请改接 USB 数据线，或先停止 FTP 接收并在相机上切回“连接至计算机”。
- FTP 服务器仅在热点或本地 Wi‑Fi 局域网内监听，绝不会暴露到公网。
- “一键连接”不能搭配 FTP 使用（一键连接是相机自己开 Wi‑Fi，而 FTP 需要相机连入手机网络）。

## 直接传到 NAS
相机的 FTP 也可以直接配置为你家的 NAS 地址，无需经过手机。这是相机自身的功能，不需要 AeroCam。
