# 3. 自动接收与保存

## 相机仪表盘
连上相机后，首页上方会显示相机当前的状态：

| 项目 | 内容 |
|---|---|
| 机型、镜头 | 例如“Nikon Z f”“NIKKOR Z 24–120 mm f/4” |
| 电量 | 百分比（20% 以下变红） |
| 连接方式 | 手机热点、同一 Wi‑Fi、相机 Wi‑Fi、USB |
| 存储卡 | 每张卡的已用 / 总容量、剩余可拍张数；双卡槽分开列出 |
| 图像品质 | 例如 `RAW`、`JPEG 精细★ L`；在相机上更改画质或插拔卡时自动更新 |
| 存储位置 | 例如“存储：存储卡 ✓”，见下方[存储位置与无卡拍照](#存储位置与无卡拍照) |
| 传输 | 当前状态，右上角“记录 ›” |
| 相机风格 | 上次读取到的 C1～C9，见[第 6 章](06-edit.md#相机风格-c1c9pro) |

相机在特定模式下不提供的参数不会显示。切换到“照相机控制”并进入远程拍摄后，通常能读取到更多信息。

### 管理相机
展开仪表盘下方的 **管理相机 (n)**，可以编辑、删除或添加相机。每台相机的“详细信息”页包含：
- 型号、序列号（中间部分隐藏，点击可显示完整号码）、固件版本、**快门次数**及读取日期。
- **每月快门数**：最近 6 个月的柱状图（从开始记录后才有数据）。
- 上次连接的时间、方式、镜头、电量、存储卡剩余容量。
- 传到手机的文件数、首次连接日期、已保存的网络配置。

快门次数是从存储卡上最新一张照片的信息中读取的，因此存储卡上必须至少有一张照片。

### 低电量提醒
相机电量降至设定阈值（默认 15%）时发送一条通知；电量回升到阈值 +5% 以上后才会再次提醒。阈值可在 **设置 → 接收与通知** 中调整或关闭。

## 自动接收（Pro）
1. 首页 Wi‑Fi → **开始接收**。App 会在后台保持与相机的连接（通知栏可见）。
2. 在相机回放照片时按 **i → 发送至计算机 / 选择发送**（Send to PC / Select to send，菜单名称因机型而异），照片就会传到手机。

如果想拍完立刻自动推送过来，请使用 [FTP 接收](08-ftp.md)。插着 USB 数据线时，接收会自动切换走 USB。

### 暂停接收
Wi‑Fi 自动接收连接期间，点击首页“传输”卡片右上角的 **⏸ 暂停** 或通知栏的“暂停”，可以暂时暂停：
- Wi‑Fi 保持连接，相册、远程拍摄照常使用。
- 相机待传的照片先留在相机里；点击 **继续接收** 后按顺序补传。正在传输的那张会先传完。
- 点击“继续”、停止接收、从最近任务列表划掉 App、Wi‑Fi 断开、相机关机或插上 USB 时会自动恢复。

### 断开连接时
- 连接中断会自动重连；多次重试失败后，会通过相机识别码重新搜索，即使相机 IP 变了也能找到。
- **相机改用蓝牙传照片**：相机只有一套无线芯片，通过蓝牙传照片时会先关闭 Wi‑Fi。此时首页会提示“相机正在通过蓝牙传输照片…传完会自动重连 Wi‑Fi”，这不属于异常断线。
- **相册 / 远程拍摄借用相机**：相机同一时间只接受一条连接。进入相册或远程拍摄时，自动接收会让出连接，退出后自动恢复。
- **Wi‑Fi 搜索不到相机时**：超过设定时间（默认 3 分钟）会自动停止接收并发送通知，避免持续耗电。超时时间可在 **设置 → 接收与通知** 中调整。

## 接收规则
在 **设置 → 接收与通知** 中调整，Wi‑Fi、USB、FTP 均遵循这些保存规则。

### 接收类型
选择要保存的文件类型：全部文件、仅 JPG、JPG + RAW、照片 + 视频，或自定义（JPEG、RAW、HEIF、TIFF、视频、其他）。

另外三个开关（Pro）：

| 开关 | 说明 |
|---|---|
| **RAW 仅存 JPEG** | 收到 RAW 时只保存相机内嵌在文件中的全尺寸 JPEG（通常 2～5 MB，而非 20～50 MB 的 RAW），分辨率不变，拍摄参数完整保留，存为 `DSC_1234_S.JPG`。适合发社交平台、日常浏览 |
| **JPEG 存压缩版** | 收到相机的 JPEG 时，由手机重新压缩后保存（`_S.JPG`，像素尺寸不变，画质遵循相册设置） |
| **原图收到时替换压缩版** | 保存 JPEG 原图时，自动删除手机上同一张照片的压缩版 |

> 若要接收 RAW 文件，需将相机的图像品质设为 RAW 或 RAW+JPEG，并在相机“连接至计算机”的上传选项中选择 RAW+JPEG（不要选“仅 JPEG”）。具体菜单名称因机型而异。

### 其他规则
| 规则 | 说明 |
|---|---|
| 接收模式 | 持续接收，或收到一张就停止 |
| 大型视频 | 超过阈值（默认 1024 MB）的视频不自动接收，记录为“已过滤”，需手动下载 |
| 存储文件夹 | 按相机、按日期、按相机和日期、按文件类型 |
| 文件名 | 相机原文件名（`DSC_1234.NEF`）、加日期前缀（`20261011_DSC_1234.NEF`）、加日期时间前缀（`20261011_153012_DSC_1234.NEF`，多台相机也能按拍摄时间排序）。仅对之后保存的文件生效 |

### 保存路径
- 照片：`Pictures/AeroCam/…`
- 视频：`Movies/AeroCam/…`
- 其他文件：`Download/AeroCam/…`

系统相册等其他 App 也能直接看到。卸载重装 App 后，之前保存的照片可通过 **设置 → 存储空间与电池 →“重新扫描手机照片”** 找回相册记录。

### 重复文件判断
- 依据相机序列号、文件名、文件大小、拍摄时间和文件内容进行判断，重复文件不会再次保存，记录中标记为“重复”。
- 在手机上删除（包括移入回收站）的照片，再次发送时会重新保存。
- 重发同一张照片时，无需先停止再重新开始接收。

### 蓝牙和 Wi‑Fi 收到同一张照片
Wi‑Fi 传输的文件更完整（全尺寸），因此以 Wi‑Fi 为准：
- Wi‑Fi 先收到、蓝牙后传过来：忽略蓝牙版本，不再保存。
- 蓝牙先收到、之后 Wi‑Fi 收到同一张照片，根据 **设置 → 接收与通知 →“蓝牙已接收过的照片”** 处理：
  - **Wi‑Fi 收到时替换为原图**（推荐）：保存全尺寸原图，自动删除手机上的蓝牙缩小版。
  - **Wi‑Fi 不再下载**。
  - **两份都保留**。
- RAW 原文件一律正常接收。

## 存储位置与无卡拍照
决定按下快门后照片保存到哪里。App 会检测相机是否插卡并自动切换：
- **相机有卡**：按照 **设置 → 拍摄 → 存储位置** 的设置执行：
  - **存储卡**：保存在相机的存储卡中。
  - **存储卡＋手机**（Pro）：保存到存储卡，同时复制一份到手机。
- **相机无卡**（Pro）：自动切换为 **仅存手机（无卡拍摄）**。相机快门照常可以按下，照片直接传到手机，文件名以拍摄时间命名（例如 `AC_20261025_193805.JPG`）。插卡后自动恢复。

首页、相册、远程拍摄均可使用，Wi‑Fi 和 USB 均支持。

**首次使用前需设置：**
1. 相机自定义设定菜单中的 **空插槽时快门释放锁定**（Slot empty release lock）改为 **启用释放**（Enable release），否则未插卡时相机无法按下快门。
2. Wi‑Fi 连接时，相机的连接类型需设为 **照相机控制**（Camera control）。若处于“图像传输”模式，拍完第一张约 3 秒后 App 会提醒切换；照片会暂留在相机缓存中，切换后自动传过来。USB 连接无此限制。
3. 一键连接不支持无卡拍照，请改用手机热点或同一 Wi‑Fi。

**看懂状态栏**（首页和相册上方）：

| 显示内容 | 含义 |
|---|---|
| 存储：存储卡 ✓ | 保存在相机存储卡中 |
| 存储：存储卡＋手机 ✓ | 保存在存储卡中，同时复制到手机 |
| 存储：仅存手机（相机没有存储卡） | 照片直接传输到手机 |
| 相机处于“图像传输”模式…（红字） | 请切换为“照相机控制” |
| 一键 Wi‑Fi：没有存储卡，无法拍照（红字） | 请插卡，或改用热点 / 同一 Wi‑Fi |
| 存储卡已满（红字） | 请换卡或清理空间（不会自动切换为仅存手机） |
| 相机没有存储卡，无法拍照（红字） | 免费版，或手机剩余空间不足 1 GB |

> 未插卡时相机无法录像；连拍速度会变慢（每张需等待传到手机）。

## 照片位置（GPS）
**设置 → 接收与通知 → 照片位置** 中有两个开关：
- **发送位置给相机（蓝牙）**（默认开启）：相机开机或通过蓝牙传照片时，手机将位置信息发给相机，由相机拍照时直接写入照片。
- **为收到的 JPEG 补充位置（手机）**：通过 Wi‑Fi、USB、FTP、相册下载或远程拍摄收到的 JPEG，由手机按拍摄时间匹配并写入当时的地点。首次开始接收时会询问一次。
  - RAW 文件不会被修改；已有位置信息的照片保留原坐标。
  - 接收期间手机记录的位置仅保存在本机，24 小时后自动删除。
  - 拍摄时间无法匹配时不写入，宁可留空也不写错位置。
  - 需要在 AeroCam 打开的状态下开始接收，才能记录位置。

> 照片内嵌的拍摄地点会随原图一起分享，发送原文件时对方也能看到。使用 QR Code 分享时默认会移除位置信息，见[第 4 章](04-gallery.md#qr-code-分享)。

## 记录
首页“传输”卡片右上角 **记录 ›**。列出所有接收、相册下载、远程拍摄保存的结果：成功、重复、跳过、失败，每条均附带缩略图。
- 点击可在 App 内全屏预览。
- 支持搜索、按相机筛选、清空记录。清空记录不会删除手机上的照片文件。
