# 1. 安装与开始使用

## 安装
1. 前往 [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest) 下载最新的 Beta APK（`…-Beta-xx.xx.xx.apk`）。
2. 在手机上打开 APK。首次安装时会提示允许“安装未知应用”，请点击允许。
3. 以后有新版本时，直接下载安装即可覆盖更新，配对信息和设置都会保留。

> 请仅从 AeroCam-Releases 下载。其他渠道的 APK 可能被篡改过。打开 App 时如果弹出“这不是官方版本”，说明该 App 被第三方重新打包过：它不会接受测试密钥，也可能被植入了其他代码，请卸载后前往 AeroCam-Releases 重新下载。

> 使用过 **92.03.09 之前旧版 Beta** 的用户：新版会安装为独立的新 App，需要重新配对相机、重新输入测试密钥，确认正常后再卸载旧版。

## 权限
App 仅在使用相关功能时才会申请权限，不需要的可以拒绝：

| 权限 | 用途 |
|---|---|
| 蓝牙、附近的设备 | 蓝牙配对、蓝牙传照片、蓝牙遥控；Android 13 以上搜索 Wi‑Fi 相机也需要 |
| 位置 | 将手机位置发送给相机写入照片、为收到的 JPEG 补充位置；Android 读取 Wi‑Fi 名称也需要 |
| 通知 | 接收进度、收到照片、传输异常、相机低电量提醒 |
| 照片和视频 | 显示、整理手机上的照片 |

每项权限的详细说明见[隐私与匿名统计](10-privacy.md)。

## 界面导览
底部有四个标签页：

| 标签页 | 内容 |
|---|---|
| **首页** | 相机仪表盘（电量、镜头、存储卡、连接状态）、四种连接方式（Wi‑Fi、USB、蓝牙、FTP）、传输状态与记录、相机风格、管理相机 |
| **相机相册** | “手机相册”和“相机存储卡”两个子标签页，见[第 4 章](04-gallery.md) |
| **远程拍摄** | 用手机查看相机实时画面、调整设置、拍照录像，见[第 5 章](05-remote.md) |
| **设置** | 五个分类，见[第 7 章](07-settings.md) |

不知道怎么连接相机时，点击首页连接状态旁边、或“添加相机”每一步右上角的 **ⓘ**，即可打开对应连接方式的图文教程。

## 测试密钥（解锁 Pro、Cine）
Beta 默认为免费版。
1. 前往 [AeroCam-Releases 首页](https://github.com/AeroCam-Group/AeroCam-Releases)复制当前的测试密钥。在 App 中点击 **设置 → 支持 →“获取免费密钥”** 会直接打开该页面。
2. 进入 **设置 → 支持 →“输入测试密钥”**，粘贴整段文字后点击“应用”。点击上锁的功能时，弹窗里也有“输入测试密钥”按钮。
3. 每组密钥有效期为 14 天，每周更换一次。到期后会恢复为免费版，重新粘贴新密钥即可。

> Beta 和测试密钥均完全**免费**，且只在 GitHub 的 AeroCam-Releases 发布。如果有人向你收费，那不是官方渠道。

## 检查更新
Beta 每天首次打开时会自动检查更新。也可以在 **设置 → 支持 →“检查更新”** 手动检查。

## 语言
界面支持繁体中文、简体中文、日文、英文、한국어、Deutsch、Français、Español、Tiếng Việt、ไทย、Bahasa Indonesia。默认跟随手机系统语言，也可以在 **设置 → 外观与语言 → 语言** 中切换。

英文、繁中、日文保证完整翻译；其他语言的新功能可能会先显示英文，之后统一补齐翻译。如果发现翻译不准确的地方，欢迎通过“翻译错误”表单[报告问题](12-report.md)。

## 匿名使用统计
首次连接相机时，App 会提示一次“发送匿名使用统计”，你可以选择“好”或“关闭”，在做出选择前不会发送任何数据。之后随时可以在 **设置 → 支持** 中关闭。具体发送哪些、绝不发送哪些内容，见[隐私与匿名统计](10-privacy.md)。
