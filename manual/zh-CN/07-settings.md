# 7. 设置逐项说明

**设置**分为五个大类，点击进入查看详细选项。免费版会自动隐藏用不到的高级设置。如有建议或觉得某些默认值需要优化，欢迎[报告问题](12-report.md)。

## 接收与通知

### 接收
| 设置 | 选项 | 默认 | 说明 |
|---|---|---|---|
| 接收类型 | 全部文件 / 仅 JPG / JPG + RAW / 照片 + 视频 / 自定义；另有 RAW 仅存 JPEG、JPEG 存压缩版、原图收到时替换压缩版（Pro） | 全部文件 | 见[第 3 章](03-receive.md#接收类型) |
| 存储文件夹 | 按相机 / 按日期 / 按相机和日期 / 按文件类型 | 按相机和日期 | 照片在 `Pictures/AeroCam`、视频在 `Movies/AeroCam` 下的子目录分类方式 |
| 文件名 | 相机原文件名 / 加日期前缀 / 加日期时间前缀 | 相机原文件名 | 仅对之后保存的文件生效；重复判断仍以相机原文件名为准 |
| 接收模式（Pro） | 持续接收 / 单张接收 | 持续接收 | 单张＝收到一个文件就停止 |
| 大型视频不自动接收（Pro） | 数值（MB） | 1024 MB | 超过阈值的视频记为“已过滤”，需手动下载 |
| Wi‑Fi 搜索不到相机时 | 30 秒 / 1 / 2 / 3 / 5 / 10 分钟 / 不限 | 3 分钟 | 超时后自动停止接收，避免持续重试耗电 |
| FTP 多久未收到照片自动关闭 | 不自动关闭 / 5 / 10 / 30 分钟 | 不自动关闭 | 从最后一张照片开始计时，传输过程中不会关闭 |
| 蓝牙已接收过的照片 | Wi‑Fi 收到时替换为原图 / Wi‑Fi 不再下载 / 两份都保留 | 替换为原图 | 蓝牙收到的是约 2 MB 的缩小版 |

### 照片位置
| 设置 | 默认 | 说明 |
|---|---|---|
| 发送位置给相机（蓝牙） | 开 | 相机开机或通过蓝牙传照片时，手机把位置发给相机写入照片 |
| 为收到的 JPEG 补充位置（手机） | 关（首次接收时会询问） | Wi‑Fi、USB、FTP 收到的 JPEG 由手机按拍摄时间写入地点；RAW 不修改 |

详见[第 3 章 照片位置](03-receive.md#照片位置gps)。

### 相册
| 设置 | 选项 | 默认 | 说明 |
|---|---|---|---|
| 压缩 JPEG 的画质（Pro） | 60 / 70 / 80 / 90% | 80% | 手机重新压缩的 JPEG 画质（24 MP 约 3～4 MB） |
| 下载 / 删除后的选择状态 | 每次询问 / 一律保留 / 一律清除 | 每次询问 | 防止保留选中状态而误点“从相机删除” |
| 询问倒计时 | 3 / 5 / 8 / 10 秒 | 5 秒 | 选择“每次询问”时，倒计时结束未操作则自动清除选择 |
| QR Code 分享多久后停止 | 15 / 30 / 60 分钟 | 30 分钟 | 到期后分享链接自动失效 |

### 通知
| 设置 | 默认 | 说明 |
|---|---|---|
| 免打扰 | 关 | 关闭所有 AeroCam 通知（“接收中”的常驻通知仍会保留，此为 Android 系统规定） |
| 开始传输时 | 关 | |
| 收到照片时 | 开 | |
| 传输异常 | 开 | 卡住、相机取消、手机存储空间不足 |
| 隐藏常驻通知 | — | 跳转至 Android 系统通知设置，在系统中关闭显示；后台接收照常运行 |
| 相机低电量提醒 | 开，15% | 阈值可选 10 / 15 / 20 / 30%；仅在连接相机时检查 |

## 拍摄

### 存储位置
| 设置 | 选项 | 说明 |
|---|---|---|
| 存储位置 | 存储卡 / 存储卡＋手机（Pro） | 相机有卡时采用的模式；无卡时自动切换为仅存手机（Pro）。连接相机时会显示当前插卡状态。见[第 3 章](03-receive.md#存储位置与无卡拍照) |

### 远程拍摄
| 设置 | 选项 | 默认 | 说明 |
|---|---|---|---|
| 进入远程拍摄时默认开启 | 拍前对焦、直方图、过曝警告、峰值对焦、曝光表 | 拍前对焦、曝光表 | 拍摄过程中仍可随时切换 |
| 曝光表颜色 | 自动 / 白 / 黑 | 自动 | 自动＝根据画面背景亮度自适应 |
| 峰值对焦颜色 | 红 / 黄 / 蓝 / 白 | 红 | 被摄主体偏红时切换其他颜色更醒目 |
| 远程拍摄时屏幕常亮 | 开 / 关 | 开 | 间隔拍摄、长曝光期间保持手机屏幕不熄灭 |
| 左手模式 | 开 / 关 | 关 | 横屏握持时快门移至左下角 |

### 有线连接（USB‑C）
| 设置 | 选项 | 默认 | 说明 |
|---|---|---|---|
| USB 预览帧率 | 30 / 60 fps / 不限 | 30 fps | 30 帧更省电不发热；60 帧更顺滑 |
| USB 大尺寸预览 | 开 / 关 | 开 | 画面更清晰，帧率可能略降；相机不支持时自动回退 |
| 插上 USB 线自动开始接收（Pro） | 开 / 关 | 开 | 插线后自动启动 USB 接收 |
| 连接时同步相机时间 | 开 / 关 | 开 | 时差超过 2 秒才校准；相差 1 天以上会先弹窗询问 |
| 有线连接时保持相机唤醒 | 开 / 关 | 开 | 每 10 秒发送一次心跳指令；闲置 30 分钟或低电量时停止 |

## 外观与语言
| 设置 | 选项 | 默认 |
|---|---|---|
| 主题 | 跟随系统 / 浅色 / 深色 / 星空（红光） | 跟随系统 |
| App 屏幕亮度调至最低 | 开 / 关（星空模式下） | 关 |
| 语言 | 跟随系统 / 繁中 / 简中 / 日文 / 英文 / 韩文 / 德文 / 法文 / 西班牙文 / 越南文 / 泰文 / 印尼文 | 跟随系统 |

## 存储空间与电池
| 项目 | 说明 |
|---|---|
| 缩略图缓存 | 显示当前占用大小，支持一键清除（需要时会重新从相机读取） |
| 未完成下载临时文件 | 显示当前占用大小，支持一键清除 |
| 重新扫描手机照片 | 找回重新出现在手机上的照片，例如从回收站恢复的、重装 App 前保存的 |
| 电池优化 | 建议关闭（显示“未优化 ✓”），否则后台接收容易被系统中断 |

## 支持
| 项目 | 说明 |
|---|---|
| 复制诊断信息 | 报告问题时粘贴使用：包含 App 版本、手机与网络状态、相机能力、最近指令记录、最后一次崩溃堆栈。相机序列号仅保留末 4 位 |
| 清除日志 | 删除本次、上一次的运行日志和崩溃记录 |
| 检查更新 | 手动检查新版本；下方显示当前版本号 |
| 测试密钥 | “获取免费密钥”打开 AeroCam-Releases；“输入测试密钥”粘贴密钥；显示当前方案及到期日 |
| 开源许可 | 使用的第三方开源组件（例如用于 RAW 显影的 LibRaw） |
| 发送匿名使用统计 | 单个开关，默认开启。见[隐私与匿名统计](10-privacy.md) |
