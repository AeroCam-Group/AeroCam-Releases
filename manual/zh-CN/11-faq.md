# 11. 常见问题与故障排除

## 常规问题
**不升级 Pro，能把相机照片传到手机吗？**
可以。免费版可以通过蓝牙自动接收约 200 万像素的缩小版 JPEG，也可以通过 USB 数据线在相机相册中手动挑选并下载全尺寸原图。

**Beta 或测试密钥需要付费吗？**
不需要。两者均仅在 GitHub 的 AeroCam-Releases 免费发布。如果有人向你收费，那不是官方渠道。

**打开 App 弹出“这不是官方版本”**
说明该 APK 被第三方重新打包过，不会接受测试密钥，也可能被植入了其他程序。请卸载后前往 AeroCam-Releases 重新下载。

**更新后找不到已配对的相机、测试密钥不见了**
自 92.03.09 起新版会安装为独立的新 App，不会继承旧版数据。请重新配对相机并重新输入测试密钥。

**照片保存在哪里**
照片保存在 `Pictures/AeroCam`、视频在 `Movies/AeroCam`，其他文件在 `Download/AeroCam`。系统相册等 App 也能直接看到。92.03.09 之前旧版保存的文件仍在原文件夹中，不会移动。

**手机上删除了照片，想重新传输**
直接在相机上再传一次即可，App 会自动识别手机上已无该文件并重新保存。

**从手机回收站恢复、或重装 App 后，相册里看不到照片**
前往 **设置 → 存储空间与电池 →“重新扫描手机照片”**。

## 连接问题
**一直连不上相机（Wi‑Fi）**
1. 确认相机停留在“连接至计算机”界面，屏幕上有 Wi‑Fi 图标；相机息屏时半按快门唤醒。
2. 确认连接类型正确：自动接收、相册＝图像传输；远程拍摄、无卡拍照＝照相机控制。
3. 手机热点方式：确认热点已开启，且相机连接的是这个热点。
4. 同一 Wi‑Fi 方式：确认手机和相机连接的是同一个 Wi‑Fi 名称（手机有时会自动切换到其他 Wi‑Fi 或移动数据）。
5. 尝试 **一键连接**，无需开热点也无需路由器。
6. 点击 **ⓘ** 按照连接教程逐步核对操作。

**酒店、展会现场的 Wi‑Fi 一直找不到相机**
公共 Wi‑Fi 通常开启了 AP 隔离，禁止设备之间互相通信。请改用手机热点或一键连接。

**相机提示“已与其他设备配对”**
这组相机网络配置文件正在被其他 App 占用。请在相机上新建一组配置，再重新配对。

**一键连接找不到相机 Wi‑Fi**
相机收到蓝牙指令后需要 10～30 秒开启自身 Wi‑Fi，App 会自动重试。若仍失败，请核对相机 Wi‑Fi 密码是否输入正确。

**手机热点总是自动断开**
部分手机在检测到连接设备没有上网流量时会自动关闭热点。请前往手机热点设置关闭“自动关闭热点”，或改用一键连接。

**热点重启后相机连不回来**
手机热点的 IP 地址可能已发生变化。使用 Wi‑Fi 自动接收时 App 会自动重新搜索；使用 FTP 则需核对并更新相机里填写的服务器地址。

**插上 USB 后没有反应**
1. 确认相机的 USB 设置为 **MTP/PTP**。
2. 数据线必须支持数据传输（部分充电线没有数据线芯）。
3. 手机弹出“允许访问”提示时需点击允许。
4. 点击 USB 卡片右上角 `⋮` → **USB 测试**，查看具体卡在哪一步。

**后台接收经常中断**
前往 **设置 → 存储空间与电池** 关闭电池优化。小米、OPPO 等手机还需在系统设置中将 AeroCam 设为“无限制”省电策略。

## 蓝牙
**蓝牙传照片卡住**
- 拍摄 RAW 时相机需要先将其转换为 JPEG 再发送；传输中操作相机会导致相机取消发送。建议拍完直接关机，让它在后台自动传输。
- 点击蓝牙卡片的 **断开并重新连接**，或 **⋮ → 重启蓝牙服务**，配对信息会保留。

**蓝牙遥控按 AF 无法对焦**
相机需允许半按快门触发对焦。习惯使用 AF‑ON 的用户，请确认相机自定义设定中的 **快门释放按钮AF启用**（AF activation）处于开启状态。

**蓝牙和 Wi‑Fi 收到同一张照片，会存两份吗？**
默认不会：Wi‑Fi 收到原图时，会自动删除蓝牙传来的缩小版。可在 **设置 → 接收与通知 →“蓝牙已接收过的照片”** 中修改此行为。

## 远程拍摄
**快门或 ISO 调不动**
- 快门速度需在 S / M 模式下调节，光圈需在 A / M 模式下调节；手动调 ISO 前请先关闭自动 ISO。
- Zf 等配备物理拨盘的机型：请将快门速度拨盘转至 **1/3 STEP**、ISO 拨盘转至 **C**。

**点击画面没有移动对焦点**
相机的 AF 区域模式需选择可移动对焦点的模式（例如单点 AF）。自动区域模式下由相机自动决定对焦点。

**首页仪表盘缺少部分参数（镜头、剩余张数、快门次数）**
部分信息相机仅在特定模式下提供，切换到“照相机控制”并进入远程拍摄后通常即可读取。快门次数要求存储卡上至少有一张照片。

**色温（K 值）在哪里查看？**
Nikon 仅在照片中以加密格式记录实际测得色温，因此“详情”里只显示白平衡预设模式。

## 存储位置与无卡拍照
**相机没插卡，按快门没反应**
确认相机的 **空插槽时快门释放锁定** 已设为 **启用释放**，且 App 已连接相机（状态栏显示“仅存手机”）。

**照片出现“演示”字样**
相机未插卡、且未连接 App 开启“仅存手机”接收时，相机会将照片标记为“演示”（DEMO）且不保存。请插入存储卡，或连接 AeroCam 后再拍摄。

**照片没传进手机，首页上方出现红色横幅**
- 提示“相机处于‘图像传输’模式”：无卡拍照需使用 **照相机控制**。切换后相机会重新连接，已拍摄的照片会自动传过来。
- 提示“一键 Wi‑Fi：没有存储卡”：一键连接不支持无卡拍照，请插卡或改用手机热点 / 同一 Wi‑Fi。

**弹出“连接中断”提示**
仅存手机模式下断线超过 10 秒才会触发提醒。这段时间内在相机上拍摄的照片可能无法写入存储卡，重新连上后 App 会自动恢复。

## 编辑与风格
**NEF 打不开、无法编辑**
高效率 / 高效率★ 压缩的 NEF 会改用内嵌的全尺寸 JPEG 进行编辑；仅含小预览图的文件无法编辑。若想在手机上完整显影 RAW，请将相机切换为 **无损压缩**，见[第 6 章](06-edit.md#手机可编辑-raw切换相机的-raw-压缩方式)。

**.np3 套用的效果和相机不一样**
手机端目前模拟的是曲线和饱和度，混色器和色彩分级尚未模拟，因此属于近似效果。JPEG 拍摄时如果已经套用过相机风格，效果会叠加。

**.np3 写入相机后颜色不一样**
相机的自定义槽位仅接收 **基底＋曲线＋锐化**，饱和度、混色器、色彩分级无法通过连接写入。要获得完整效果，请通过存储卡在相机菜单中导入 `.np3`。

**拼接失败或漏掉几张照片**
每张照片需与相邻照片保持约 30% 的重叠区域。未能接上的照片会列出文件名；网格拼贴若缺少一格则不会输出。

## FTP
**相机显示 Err.31 或 Err.32**
请更新至最新版 Beta。同时检查相机填写的 IP 地址、端口 `2121`、用户名 `aerocam`、密码是否全部正确，并确认已开启被动模式。

**相机显示登录失败**
密码必须与 AeroCam FTP 界面显示的一致（区分大小写）。如果点击过“重新生成”密码，相机端也需要同步修改。

**开着 FTP 时，相册或远程拍摄连不上**
相机处于 FTP 模式时，不提供相册和远程拍摄的 Wi‑Fi 连接。请改接 USB 数据线，或先停止 FTP 接收并在相机上切回“连接至计算机”。

## 其他
**App 闪退**
重新打开后前往 **设置 → 支持 →“复制诊断信息”**，[报告问题](12-report.md)时粘贴附上，其中包含最后一次闪退的错误堆栈信息。

**如何关闭匿名使用统计？**
前往 **设置 → 支持 →“发送匿名使用统计”** 关闭即可，见[隐私与匿名统计](10-privacy.md)。
