# 12. 报告问题

前往 [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) 选择一种表单：

| 表单 | 用途 |
|---|---|
| Bug 报告 | 功能异常、闪退崩溃 |
| 功能建议 | 希望新增或改进的功能、设置的默认值 |
| 翻译错误 | 文字翻译错误或表达不通顺 |
| 机型报告 | 使用其他相机型号测试的结果 |

## 请附上以下信息
- AeroCam 版本号（首页左上角，或设置 → 支持）
- 手机型号、Android 版本
- 相机型号、固件版本
- 连接方式（蓝牙 / 一键连接 / 手机热点 / 同一 Wi‑Fi / USB / FTP）
- 操作步骤、预期结果、实际结果
- **诊断信息**：设置 → 支持 →“复制诊断信息”，直接粘贴在表单中

## 注意事项
- Issue 是**公开可见的**，请勿粘贴 Wi‑Fi 密码、相机完整序列号、账号等个人隐私信息。
- 不方便公开的内容（例如请求删除数据、安全漏洞反馈），请发送邮件至 **aerocam.lab@gmail.com**。
