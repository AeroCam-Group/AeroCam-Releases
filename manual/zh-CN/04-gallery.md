# 4. 相册

底部“相机相册”标签页上方有两个子标签：**手机相册**（已经保存在手机上的照片）和**相机存储卡**（直接浏览相机里的照片）。

## 相机存储卡
在手机上直接浏览相机存储卡（支持双卡槽），**无需先在相机上挑选照片**，也不用先点击“开始接收”。
- USB 数据线免费；Wi‑Fi 为 Pro 功能。
- 进入页面时不会自动占用相机，点击“连接并浏览存储卡”后才建立连接。相机同一时间只接受一条连接，因此自动接收会暂时暂停，退出后自动恢复。
- 切换到其他标签页或查看大图时，连接会保留 20 秒，返回即可继续浏览；App 退到后台时会立即释放相机（正在下载的文件会先下载完成）。
- 打开相册期间用相机拍照，新照片约 1～2 秒内会自动出现在最顶部（USB 最快）。

### 浏览与筛选
- 按拍摄日期分组；右上角日历图标可快速跳转到指定日期（年 → 月 → 日）。
- 筛选：全部、RAW、JPEG、视频、**尚未下载**（仅列出手机上还没有的文件）、已评星。选择“尚未下载”或“已评星”时，底部会显示“全选这 N 张”。
- **每行张数**：点击右上角网格图标可选择 2～7 张，或双指缩放切换；横屏时每行多显示一半。
- 视频仅读取文件头，无需下载整个视频：缩略图左下角 `▶ 0:12` 为时长，左上角 `1080 24p` 为规格。

### 缩略图角标
筛选栏最右侧的 **ⓘ** 提供完整图例说明：

| 位置 | 含义 |
|---|---|
| 左上 | 第二张存储卡（`SD2`）或视频规格 |
| 右上 | 星级评分 |
| 左下 | 格式：`RAW`（琥珀色）、`JPEG`（灰色）、`▶` 视频时长 |
| 右下 | 手机上已有的版本：**✓RAW**、**✓JPEG**、**✓JPEG.S**，可同时叠加多个。绿色＝相机原文件，蓝色＝副本；无标签＝尚未下载到手机 |

### 选择照片
- 长按一张后**直接拖动**，即可连续选中一整片；拖到屏幕边缘会自动滚动。
- 每个日期标题右侧有“选择”按钮，可一键全选当天。
- 多选状态下底部导航栏会收起，变为操作栏（下载、评星、删除）；点击左上角 **✕** 取消选择。

### 下载
选中后点击 **下载**，每个选项旁都会标注**将占用的手机存储空间**，最下方显示手机剩余空间：
- **原始文件**：完整的 RAW、JPEG 或视频文件。
- **仅 JPEG**（Pro）：从 RAW 中提取内嵌的全尺寸 JPEG；JPEG 原图则由手机重新压缩（分辨率不变）。均保存为 `DSC_1234_S.JPG`，保留完整拍摄参数。压缩画质可在 **设置 → 接收与通知 → 相册** 中选择 60 / 70 / 80 / 90%（默认 80%）。
- 下载任务会进入队列，可查看进度并随时停止；手机上已有的文件会自动跳过，结果同步记入“记录”。
- 下载完成后会提示“是否保留当前选择？”，倒计时结束自动清除，防止误点“从相机删除”。可勾选“记住我的选择”。

### 从相机删除（Pro）
选中后点击**红色**的“从相机删除（N）”，确认后将从存储卡中**永久删除**，无法恢复。尚未下载到手机的照片会额外弹出警告；带保护锁（🔑）的照片相机不会删除。

> 只有红色实心按钮会操作相机存储卡，其他删除操作仅影响手机本地文件。

### 查看大图
点击缩略图即可全屏预览，左右滑动切换照片，双指缩放或双击放大。
- **竖屏**：顶部显示文件名、时间、大小；照片下方显示拍摄参数（快门 · 光圈 · ISO · 焦距）；操作按钮位于最底部。
- **横屏**：照片铺满屏幕，参数信息显示在右侧，点击照片可隐藏或显示信息层。
- 勾选 **详情**：显示 RGB 直方图、优化校准、白平衡、镜头、尺寸、文件大小，直接从相机文件读取，无需先下载。

### 星级评分
在相册中为照片标记 1～5 星，通过“已评星”筛选后只下载选中的照片；星级会写入下载文件的 EXIF Rating 字段，Lightroom 等后期软件可直接识别。

## 手机相册
显示已经保存到手机的照片，无需连接相机。
- 仅显示仍留在手机上的文件：在系统相册等 App 中删除后，返回这里也不会再显示；从回收站恢复后会自动重新出现。
- 按拍摄时间排序，筛选栏包含“已编辑”“拼贴”“摇摇乐”等标签。
- **查看大图**：显示拍摄参数和 **详情**（拍摄时间、传输时间、RGB 直方图、优化校准、白平衡、镜头、尺寸、文件类型、来源）。底部提供 **分享**、**用其他 App 打开**、**编辑**、**删除**。
- **删除**：选中后点击 **删除**，可选择“删除手机上的全部”“仅删 RAW”“仅删 JPEG（含 S）”“仅删视频”。文件会移入手机**回收站**，30 天内可在系统相册中恢复；**相机存储卡完全不受影响**。
- **图像处理**：选中多张照片后，将底部操作栏向上滑动，展开“图像处理”，包含**拼接**（全景）和**降噪合成**（摇摇乐），见[第 6 章](06-edit.md#图像处理全景拼接降噪合成pro)。
- 照片未显示：**设置 → 存储空间与电池 →“重新扫描手机照片”**。

## 存储卡备份（Pro）
将相机存储卡备份到手机，入口位于 USB 卡片的“备份存储卡”或相册右上角的“备份”。
- **范围**：整张存储卡，或自定义（拍摄日期、仅备份手机上还没有的文件、SD1 / SD2）。
- **类型**：RAW＋JPEG、仅 RAW、仅 JPEG、RAW 仅存 JPEG，可选择是否包含视频。
- 点击 **计算** 可查看文件数量、总大小、预计耗时和手机剩余空间；通过 Wi‑Fi 备份 RAW 或视频时会提前提示耗时较长。
- 支持后台运行（可在通知栏暂停），中断后下次打开会询问是否继续。
- 每个文件保存后都会回读校验。完整且无失败的备份完成后，可选择 **从相机删除已备份的文件**：仅删除本次校验通过的文件，且需要两次确认。

## QR Code 分享
让身边的人用手机相机扫一下，就能在浏览器里查看并下载你的照片，**对方无需安装任何 App**。

### 如何分享
1. 在 **手机相册** 长按选择照片 → 点击操作栏第一个按钮 **分享**。仅支持分享手机上已有的照片（JPEG、RAW），暂不支持视频。
2. 屏幕会显示大尺寸 QR Code 和短网址（例如 `192.168.43.1:8080/k7Qx2mPa`），对方用手机相机扫码即可打开。
3. 也可以点击 **复制链接** 或 **发送链接**（微信、LINE、Messenger 等）。

> **对方必须连接同一个 Wi‑Fi，或连接你的手机热点。** 酒店、咖啡馆等公共 Wi‑Fi 通常禁止设备之间互相访问，打不开时请改用手机热点。

### 分享选项
- **设置密码**（默认关闭）：对方需先输入 4 位数密码才能查看。密码不会包含在分享出去的文字消息中，请当面告知对方。
- **画质**：免费版分享缩小版 JPEG（长边 2048 px），需单张下载。Pro 版支持**原尺寸**、**同时提供 RAW 文件**，且对方可多选并一键打包下载为 zip。
- **保留位置信息（GPS）**（默认关闭）：默认下载的 JPEG 会移除拍摄地点，网页上也永远不会显示地点。手机上的原文件不会被修改。
- 分享自动停止时间：**设置 → 接收与通知 → 相册**（15 / 30 / 60 分钟，默认 30 分钟）。

### 分享过程中
- 离开界面或锁屏都会继续分享；通知栏提供“显示 QR Code”和“停止分享”按钮。
- 网络短暂断开会等待 30 秒；手机 IP 地址变化后会沿用同一组链接代码，并提示对方重新扫码。
- 对方打开的网页会根据其手机语言自动显示繁体中文、简体中文、日文或英文，支持查看大图、查看拍摄参数，下载失败可一键重试。
- **安全性**：链接带有 8 位随机字符，暴力猜解会被锁定；仅开放你选中的照片；对方只能查看和下载，无法上传或删除。点击 **停止分享** 后链接立即失效。

> 小米、OPPO 等手机可能会强制清理后台进程，分享页面会提醒你将 AeroCam 设为“无限制”省电策略。
