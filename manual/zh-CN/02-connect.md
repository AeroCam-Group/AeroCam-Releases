# 2. 连接相机

AeroCam 提供四种连接方式，可以同时配置，App 会自动选用当前可用的方式。首页的四个按钮（Wi‑Fi、USB、蓝牙、FTP）会显示各自的状态。

> 看不懂怎么连接？点击首页连接状态旁边、或“添加相机”每一步右上角的 **ⓘ**，即可打开图文教程（手机热点、同一 Wi‑Fi、一键连接、USB、蓝牙、FTP 各一页），手机和相机的界面都有截图，末尾还附有“连不上时检查”清单。

## 如何选择

| 你的需求 | 推荐方式 |
|---|---|
| 相机关机也能收照片、省心免操作 | **蓝牙**（缩小版 JPEG，免费） |
| 户外拍摄、不想开热点，需要原图、相册、远程拍摄 | **一键连接**（Pro） |
| 拍完立刻自动传到手机，无线速度最快 | **[FTP 接收](08-ftp.md)**（Pro，需开启热点） |
| 最稳定、录像监控、长时间远程拍摄 | **USB 数据线**（手动挑选下载免费） |
| 在家或工作室 | **同一 Wi‑Fi**（Pro） |

## 速度参考（Nikon Zf、Pixel 10 Pro 实测）

| 方式 | 单张 RAW（约 18 MB） |
|---|---|
| FTP 接收 | 约 1 秒（约 17 MB/s） |
| Wi‑Fi 相册下载 | 约 1.3 秒（约 13 MB/s） |
| USB | 通常比 Wi‑Fi 快，视数据线规格而定（USB 2.0 线约 35 MB/s） |
| 蓝牙 | 缩小版 JPEG（约 2 MB），每张 15～20 秒 |

## 首页的连接状态灯
Wi‑Fi、USB、蓝牙、FTP 四个按钮会根据状态显示不同颜色，未连接时为灰色：

| 颜色 | 含义 |
|---|---|
| 🟢 绿 | 已连接或就绪（蓝牙浅绿＝待命，“关闭时发送”就绪） |
| 🔵 蓝 | 传输中 |
| 🟠 橙 | 连接中（闪烁），或需要处理（权限、卡住、出错） |
| 🔴 红 | 手机的 Wi‑Fi 或蓝牙已关闭 |

## 蓝牙（免费，替代 SnapBridge）

### 配对
1. 相机：**MENU → 网络菜单 → 连接至智能设备（Connect to smart device）→ 配对（蓝牙）→ 开始配对**。
2. 如果相机之前和 SnapBridge 配对过，请先在 SnapBridge 中删除，并在手机蓝牙列表里取消配对（两个 App 不能同时配对同一台相机）。
3. AeroCam 首页“蓝牙”→ **配对相机** → 开始。手机和相机会显示同一组数字，两边都按确认。相机上会显示为 `AeroCam_手机型号`。

📷 截图：蓝牙卡片

### 配对之后
配对后会自动保持启用；要停止只能取消配对（操作前会提示确认）。
- AeroCam 平时只在后台**监听**相机的蓝牙广播，不会唤醒休眠中的相机。
- **相机开机时**：连接一次，同步时间和手机位置（相机拍照时将位置写入照片），随后断开。
- **相机有照片要传时**：在相机“连接至智能设备”菜单中开启 **关闭时发送**（Send while off），相机会自动通过蓝牙把照片传过来，关机状态下也能传。
- 收到的是相机生成的约 2 MB JPEG（拍 RAW 也会先由相机转为 JPEG），每张约 15～20 秒。需要原图请使用 Wi‑Fi、USB 或 FTP。
- 想立刻接收，可点击蓝牙卡片的 **立即接收**。
- 开关手机蓝牙、重启手机或更新 App 后会自动恢复。等待期间通知栏会有一条低优先级的常驻通知（Android 系统要求），可在系统设置中隐藏。

### 蓝牙卡片的状态
🟢 相机在附近・开机中 / 🟢 浅绿 待机（关闭时发送就绪）/ ⚪ 搜索不到相机（显示上次发现时间）/ 🔵 传输中 / 🟠 似乎卡住了 / 🔴 手机蓝牙已关闭。

蓝牙并非持续保持连接，这里显示的是“是否检测到相机”以及“当前正在执行的操作”。

### 卡住时如何处理
- 传输过程中 30 秒没有数据，App 会自动断开，相机稍后会重试；20 秒无动静时卡片会变黄提示“似乎卡住了”。
- **断开并重新连接**：仅断开本次传输。
- **⋮ → 重启蓝牙服务**：重启整个蓝牙后台服务，配对信息保留。
- 拍摄 RAW 时，相机需要先转换为 JPEG 再发送；传输中操作相机（半按快门、拍照）会导致相机取消传输。建议拍完直接关机，让它在后台自动传输。

## Wi‑Fi（Pro）：三种方式

| 方式 | 工作原理 | 适用场景 |
|---|---|---|
| **一键连接**（推荐） | 通过蓝牙让相机开启自身 Wi‑Fi，手机自动连上 | 户外拍摄、不想开热点 |
| **手机热点**（教程推荐） | 相机连接手机开启的热点 | 一键连接不稳定、需要使用 FTP 或无卡拍照时 |
| **同一 Wi‑Fi** | 手机和相机连接同一台路由器 | 在家、工作室 |

### 一键连接
1. 先完成**蓝牙配对**。
2. 首页 Wi‑Fi →“一键连接”。
3. 首次连接需要输入相机 Wi‑Fi 的**密码**（网络名称由 App 自动填入，类似 `NIKON_…`），密码仅保存在你的手机本地。
4. Android 系统询问是否允许连接时选择允许。
5. 显示“已连上相机 Wi‑Fi”后，相册、远程拍摄、自动接收都会走这条连接。点击“断开”可切回原来的 Wi‑Fi。

相册或远程拍摄尚未连接时，界面上也会直接出现“通过相机 Wi‑Fi 连接”按钮。

> - 连着相机 Wi‑Fi 时，手机上网会自动改走移动数据。
> - 一键连接**不能搭配 FTP 使用**，也**不支持无卡拍照**（相机未插卡时请改用手机热点或同一 Wi‑Fi）。

📷 截图：一键连接卡片、已连接状态

### 手机热点 / 同一 Wi‑Fi（首次需配对）
1. 相机：**MENU → 网络菜单 → 连接至计算机（Connect to PC）**，创建网络配置文件（连接手机热点或家里的 Wi‑Fi）。
   - 新机型（菜单里有“连接类型”）：将“连接类型”（Connection type）设为 **图像传输**（Image transfer）。
   - 较早的机型：直接选择“连接至计算机”即可。
2. AeroCam：**首页 →“＋”添加相机**，选择连接方式（同一 Wi‑Fi 或手机热点）。App 会检查网络并自动搜索相机；找不到时也可以手动输入 IP。
3. 相机屏幕出现 **4 位数验证码**，在手机上输入，再到相机上按 OK。
4. 完成后会保存为一个“相机配置文件”，以后打开 App 就能直接连接。可以保存多台相机、多组网络；App 更新后**无需重新配对**；相机 IP 变化后也会自动重新找到。

> 相机提示“已与其他设备配对”时，说明这组相机网络配置正在被其他 App 使用。请在相机上新建一组配置再配对。

📷 截图：添加相机向导、验证码

### 连接前检查
- 点击“开始接收”、或进入相册、远程拍摄时，App 会先检查网络状态。如果配置的是“手机热点”但热点未开启，或者配置的是“同一 Wi‑Fi”但手机未连接该网络，界面会出现黄色提示框（例如“请先开启手机热点”）并附带“热点设置”“Wi‑Fi 设置”快捷按钮。开启后返回 AeroCam，提示框会自动消失。
- 在 Wi‑Fi 和热点上都找不到相机时，首页会提示“网络上找不到相机”，多半是相机的“连接至计算机”未开启，旁边有“查看连接教程”按钮。

### 相机的“连接类型”（Connection type）
新机型（Z9、Z8、Z6III、Zf、Z5II、Z50II…）：**MENU → 网络菜单 → 连接至计算机 → 连接类型**
- **图像传输**（Image transfer）：用于自动接收、浏览相机存储卡。
- **照相机控制**（Camera control）：用于远程拍摄、无卡拍照。

切换后相机 Wi‑Fi 会短暂断开，AeroCam 会自动重新连上，无需重新配对。相机还停留在“图像传输”模式时进入远程拍摄，App 会显示切换步骤。

## USB 数据线
比 Wi‑Fi 更快、更稳，**无需配对**，也不用事先添加相机。
1. 相机 USB 设置选择 **MTP/PTP**（不要选“iPhone”或“UVC/UAC”）。
2. 使用**支持数据传输**的 USB‑C 线（部分数据线仅支持充电）。标有 5Gbps / 10Gbps 的 USB 3 数据线速度更快。
3. 首页 USB 卡片出现“检测到 Z f・需要允许访问”→ 点击“允许访问”，Android 系统会弹窗确认一次。

### USB 卡片的颜色
| 颜色 | 含义 |
|---|---|
| ⚪ 灰 | 未检测到相机（或数据线仅支持充电） |
| 🟠 橙 | 检测到相机，需要授予访问权限 |
| 🔴 红 | USB 设置不是 MTP/PTP、未授予权限或测试失败（会显示具体原因） |
| 🟢 绿 | 已通过数据线连接 |

### 插着数据线时
- 相册、远程拍摄、自动接收都会**自动切换走 USB**；拔掉数据线自动切回 Wi‑Fi。正在 Wi‑Fi 远程拍摄时插线也会无缝切走 USB（间隔拍摄、包围曝光、B 门进行中不会切换）。
- **USB 接收**（Pro）：点击 USB 卡片的“开始接收”，新拍的照片和相机上“发送至计算机”的照片都会保存到手机。默认插上线就自动开始（设置 → 拍摄 →“插上 USB 线自动开始接收”）。
- **时间同步**：插线时同步一次相机时间（误差超过 2 秒才校准；相差 1 天以上会先询问）。
- **保持唤醒**：打开相册或远程拍摄时，每 10 秒发送一个极小的指令防止相机休眠；闲置 30 分钟或相机低电量时停止。
- 手机可能会通过 USB 给相机供电，长时间使用建议外接充电宝。
- **USB 测试**（USB 卡片右上角 ⋮）：测试连接状态、相机信息、存储卡、实时取景帧率、读取速度。
