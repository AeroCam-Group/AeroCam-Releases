# 9. 免费 / Pro / Cine

| 等级 | 功能 |
|---|---|
| **免费** | 蓝牙传照片、蓝牙遥控（对焦、拍照、录像、连拍、自拍倒计时）、USB 相机相册（手动挑选下载原图）、手机相册、挑片评星、照片编辑（含 .np3 风格预览、手机编辑 RAW、切换为无损 RAW）、照片位置、QR Code 分享（缩小版）、星空模式 |
| **Pro** | 免费版的全部功能，加上：Wi‑Fi（含一键连接、Wi‑Fi 相册）、FTP 接收、自动接收（Wi‑Fi、USB）、远程拍摄、拍摄辅助、拍摄工具（B 门、间隔拍摄、包围曝光、对焦变化拍摄）、远程拍摄倒计时、叠影比对、蓝牙遥控的间隔拍摄、RAW 仅存 JPEG、压缩 JPEG、存储卡备份、从相机删除、无卡拍照（仅存手机）、相机风格 C1～C9、QR Code 分享原尺寸与 RAW、全景拼接、摇摇乐（降噪合成） |
| **Cine** | Pro 版的全部功能，加上：录像监控、LUT、变形镜头反挤压、A/B 拉焦、录像监控的叠影比对 |

点击上锁的功能时，会弹出所需等级提示以及“输入测试密钥”按钮。

## Beta 期间
- Beta 默认为免费版。输入[测试密钥](01-install.md#测试密钥解锁-procine)即可免费体验 Pro 和 Cine 的全部功能。
- 测试密钥每周更新、每组有效 14 天，且仅在 GitHub 的 AeroCam-Releases 免费发布。
- 测试版结束后，最后一组密钥到期即恢复为免费版。
