| 方式 | 连接 | 实时画面 | 等级 |
|---|---|---|---|
| [远程拍摄](#远程拍摄pro) | Wi‑Fi 或 USB | ✅ | Pro |

## 远程拍摄（Pro）
用手机查看相机实时取景画面、点击屏幕对焦、调整参数并拍照录像。**Wi‑Fi 和 USB 均可使用**，插上 USB 数据线时会自动切换走 USB。

**前提条件**
1. 菜单中包含“连接类型”（Connection type）的机型（见[支持的相机](README.md#支持的相机)）。
2. 使用 Wi‑Fi 连接时，相机的“连接类型”需切换为 **照相机控制**（Camera control，见[连接相机](02-connect.md#相机的连接类型connection-type)）。如果仍停留在“图像传输”模式，App 会显示切换步骤，切好后自动重连。

远程拍摄为全屏界面，底部导航栏会隐藏，点击左上角 **←** 或按手机返回键即可回到首页。

📷 截图：远程拍摄界面（竖屏、横屏）

### 界面布局
| 位置 | 内容 |
|---|---|
| 顶部 | 相机参数：模式、快门、光圈、ISO、自动 ISO、曝光补偿、白平衡、对焦模式、AF 区域、测光、优化校准、画质。竖屏排两行，横屏排一行（可左右滑动） |
| 顶部第三行 | 返回、录像、纯净画面、锁定、存储位置、电量 |
| 中间 | 实时取景画面（完整不裁切），对焦框、水平仪、曝光表等辅助线叠加其上 |
| 下方 | 6 个快捷开关（支持自定义）＋“更多” |
| 最底部 | “拍摄”（选择拍摄方式）、快门、AF、最新照片缩略图与剩余可拍张数 |

横屏握持手机时，快捷开关会移至左侧黑边，快门位于右下角；开启 **左手模式**（设置 → 拍摄）可将快门移至左下角。

### 调整相机设置
点击顶部的参数数值，底部会弹出调节栏，不会遮挡实时画面。
- 曝光模式仅作显示（P / S / A / M 需在相机上切换）。快门在 S、M 模式下可调，光圈在 A、M 模式下可调。
- 开启自动 ISO 时，ISO 显示为 `AUTO`。曝光补偿旁提供 `0` 按钮一键归零。
- 白平衡选择 `K` 时可手动调节色温。优化校准会显示相机当前使用的名称，包括自定义配方。
- **无法调节时**会提示具体原因。Zf、Zfc 等配备物理拨盘的机型，请将快门速度拨盘转至 **1/3 STEP**、ISO 拨盘转至 **C**。

### 对焦与快门
- **点击屏幕对焦**：点哪里就对焦到哪里。相机的 AF 区域需设为可移动对焦点的模式（如单点 AF）；自动区域模式下由相机自动决定。
- 屏幕上会实时绘制相机的实际对焦框：单点、动态区域、自动区域、跟踪均可显示；合焦变绿，失败变红。
- **快门**：点击即拍；**按住＝半按快门对焦**（外框变绿），松开即拍。
- **AF 按钮**：在当前对焦点重新对焦。
- **拍前对焦**（默认开启）：关闭后按快门直接拍摄，适合手动对焦或已提前对好焦的场景，响应更快。
- **点屏拍摄**：开启后，点击取景画面＝对焦到该位置并立即拍摄一张。
- 预览画面左右边缘（系统侧滑返回手势区域）点击不会触发对焦，防止滑动返回时误触。

### 下排快捷开关（支持自定义）
默认为峰值、斑马纹、水平仪、网格、放大和一个空位，最右侧固定为“更多”。
- **单击**开启或关闭；**长按半秒**弹出详细设置（峰值灵敏度、斑马纹阈值、构图线样式、放大倍率）。
- **自定义**：点击“更多”右上角的齿轮图标。可选项目包括：峰值、斑马纹、水平仪、网格、放大、直方图、曝光表、点屏拍摄、拍前对焦、复制到手机、截图、星空模式、实时预览、倒计时。

### 更多抽屉
“更多”是一个半透明抽屉面板（竖屏从底部展开、横屏从侧边展开），取景画面始终可见。分为三个标签页：
- **辅助**：实时预览、峰值、过曝警告、水平仪、构图线、直方图、曝光表、放大对焦、星空模式。
- **拍摄**：拍前对焦、点屏拍摄、AF 区域、每拍一张复制到手机、预览截图。
- **工具**：叠影比对、多张拍摄检查、提示。

### 拍摄辅助（仅在手机屏幕显示，不影响照片本身）
| 功能 | 说明 |
|---|---|
| 水平仪 | 读取相机内置水平传感器，倾斜小于 0.5° 时变绿，并显示左右横滚和前后俯仰角度 |
| 直方图 | 点击可在“亮度＋RGB 叠加”和“RGB 分离”之间切换 |
| 斑马纹（过曝警告） | 在亮度超过阈值的区域叠加斜纹，阈值可选 85 / 90 / 95 / 100%（默认 95%） |
| 峰值对焦 | 为合焦清晰的边缘描边上色（红、黄、蓝、白），支持低 / 中 / 高灵敏度，适合手动对焦 |
| 曝光表 | 类似 Nikon 取景器的竖向曝光指示条，每格 1/3 EV。M 模式下显示与测光的偏差，P / A / S 模式下显示曝光补偿 |
| 构图线 | 九宫格、十二宫格、黄金比例、黄金螺旋、对角线、居中十字 |
| 放大 | 相机支持时（例如 Zf）由**相机机身端直接放大**，可查看 1:1 实际像素：50% / 100% / 200% / 400%，点击画面或按 ◀ ▲ ▼ ▶ 移动查看区域，下方 `近 ◀◀ ◀ ▶ ▶▶ 远` 可微调手动对焦。不支持的相机则使用 App 数码放大（2× / 4× / 8×） |

> 实时预览经过相机压缩，这些辅助工具仅供参考，最终曝光请以实拍照片的直方图为准。

### 拍摄方式
点击快门旁的 **拍摄** 进行选择。选中后按钮变黄，快门上方出现状态条（例如 `间隔拍摄　每 5 秒 · 10 张`），点击可展开调节参数并按 **开始**；点击旁边的 × 恢复普通拍摄。执行过程中屏幕上方显示进度，按 **停止** 可随时中止。

| 拍摄方式 | 设置 | 说明 |
|---|---|---|
| 普通拍摄 | 张数 1～9 | 配合倒计时使用时，倒计时结束后连拍，每张间隔约 1 秒 |
| **倒计时** | 关、2、5、10 秒 | 位于“拍摄”菜单最上方一栏，所有拍摄方式和录像均可先倒计时；屏幕中央显示大号数字，再按一次快门取消 |
| B 门 | 曝光秒数 1～3600 | 相机需置于 M 模式且快门设为 Bulb 或 Time，到达设定时间自动结束 |
| 间隔拍摄（Interval timer shooting） | 张数 2～999、间隔 1～3600 秒 | 按固定间隔连续拍摄，面板显示总耗时；可搭配“每拍一张复制到手机”实时预览延时素材 |
| 包围曝光 | 张数 3 / 5 / 7 / 9、步长 0.3～3.0 EV | 以当前曝光补偿为中心依次增减曝光，拍摄结束后自动恢复原值 |
| 对焦变化拍摄（Focus shift shooting） | 张数 2～300、每步距离 | 先对焦在最近处主体，App 每拍一张自动向远处微调焦点。需使用自动对焦镜头，拍摄后请在电脑上进行景深合成 |
| 拼贴 | 网格数或“自由” | 拍摄多张照片后拼接成全景图，见下文 |
| 摇摇乐 | 4 或 8 张 | 手持连拍多张，合成为一张噪点更低的照片，见下文 |

> 多张拍摄工具运行期间，AF 和点屏对焦会暂时禁用。退出远程拍摄前会弹出确认提示。

#### 拼贴（全景）
- **网格模式**：选定网格行列数后，App 会计算每一格需要旋转的角度，由你转动相机并按快门。面板会提示重叠度是否足够（“可以拍摄 / 还可以再转 / 可能不够”），并半透明叠加前一张的边缘方便对齐。
- **自由模式**：无需按固定网格，只需保证每张与上一张重叠约 30%，向任意方向转动、拍摄任意张数均可（最多 30 张）。
- 拍满 2 张以上即可点击 **拼接**，在手机上直接合成为一张大图；旋转拍满一圈会输出 360° 全景。成品水平线绝对平直（拍摄时会记录相机水平仪数据）。
- 拍摄的素材会归入手机相册的同一组叠放中，日后也可重新拼接，见[第 6 章](06-edit.md#图像处理全景拼接降噪合成pro)。

#### 摇摇乐（降噪合成）
- 让没有像素位移功能的机型也能实现“多帧合成提升画质”：手持（或使用三脚架）连拍 4 或 8 张，App 自动对齐后做平均合成，噪点大约降至三分之一（8 张时），细节保持锐利。
- 拍完自动在后台合成，界面显示“合成中 %”。成品保存为 `SHAKE_<时间>.JPG`，与原图同分辨率并保留拍摄参数。
- 画面中的移动物体（车辆、行人、树叶）仅采用最清晰的一帧，不会产生重影；抖动过大的废片会自动剔除。
- 非常适合夜景、室内暗光及高 ISO 场景。

### 叠影比对（Pro）
**更多 → 工具 → 叠影比对**：将参考画面以**半透明叠加**或**左右分屏**的方式覆盖在实时取景画面上，可调节透明度，也支持“截取当前画面”作为参考。适合定点重拍、翻拍及构图对齐。

### 其他功能
- **每拍一张就复制到手机**：按照接收规则自动保存，支持“RAW 仅存 JPEG”。
- **最新照片**：右下角缩略图显示刚拍的一张及实际快门、光圈、ISO；点击可浏览本次拍摄的所有照片，直接保存原文件或 JPEG 到手机。
- **纯净画面**：隐藏所有控件只留取景画面；点击角落的半透明按钮恢复。**锁定**：防止误触，长按屏幕任意位置解锁。
- **录像**：顶部的录像按钮。开始前会将相机切入“应用程序模式”（Zf 必需），停止后自动切回；无法录像时会提示原因。使用 USB 连接时建议使用[录像监控](#录像监控cine)。
- **预览截图**：保存至 `Pictures/AeroCam/Snapshots/`（预览分辨率）。
- **USB 远程拍摄**：实时画面比 Wi‑Fi 更流畅（默认 30 fps，可调至 60 fps 或不限），支持开启大尺寸预览，右下角小字显示实时帧率。可在 **设置 → 拍摄** 中调整。
- 远程拍摄期间屏幕默认保持常亮。

## 蓝牙遥控（免费）
无需 Wi‑Fi，无实时取景画面。首页蓝牙卡片 → **蓝牙遥控**。需先完成[蓝牙配对](02-connect.md#配对)。
- 点击快门拍一张；按住快门触发相机自身的连拍（CL / CH）。
- 按住 AF 再点快门可快速连按；支持 3 张 / 5 张连拍按钮。
- AF 按钮：按住对焦。相机需允许半按快门对焦（习惯使用 AF‑ON 的用户请确认相机自定义设置）。
- 支持自拍倒计时、录像开始 / 停止、显示剩余可拍张数。
- **间隔拍摄**为 Pro 功能。

## 录像监控（Cine）
把手机变成专业的录像监视器。插着 USB 时首页 USB 区域会显示 **🎥 录像监控**（最流畅，最高约 60 fps）；Wi‑Fi 版本位于首页 Wi‑Fi 区域，目前为实验性功能。
- Zf 需将拍照 / 录像选择器拨至 **录像** 档。
- **顶部栏**：`● REC` 录制时间、视频规格（例如 `1080 60p`，点击可切换）、文件类型（例如 `H.265 10bit`，使用 N‑Log 需先选 H.265 10 位）、剩余可录制时间、电量。
- **底部栏**：录像专用的快门、光圈、ISO、自动 ISO、曝光补偿、白平衡、对焦模式、测光。录像 ISO 仅在 M 模式下可调。
- **录像键**：录制中需要**按住 1 秒**（红色圆环转满）才会停止，防止误触。录制中按返回键会先弹出确认。
- **监看工具**：曝光表、直方图、波形图 / RGB 分量图、假色、斑马纹（含第二段肤色斑马纹）、峰值对焦、构图线、安全框、遮幅（`2.39:1`、`1.85:1`、`16:9`、`9:16`、`4:5`）、Tally 提示红框、快门角度显示。
- **LUT**（Android 13 以上）：在预览画面实时套用监看 LUT（内置 N‑Log 转标准色彩，支持导入 `.cube` 文件），不会烧录进视频文件。请关闭相机上的 **查看辅助**（View assist），避免重复套用两次。
- **变形镜头反挤压**（`1.33x`～`2.0x`）、**A/B 拉焦**（设定两个焦点位置，平滑转移焦点）、**叠影比对**。
- 录制期间默认禁用点击屏幕对焦（避免把拉焦过程录进视频），可在菜单中开启。
- **截图**：“预览截图”仅保存干净画面，“截图（含辅助工具）”会连同 LUT、斑马纹、假色、遮幅一起保存。

## 星空模式（免费）
拍摄星空时人眼需要适应黑暗环境，白光屏幕会导致瞳孔收缩。星空模式可将整个 App 界面切换为暗红色。
1. 开启方式：**设置 → 外观与语言 → 主题 →“星空（红光）”**，或在远程拍摄的下排快捷开关、“更多 → 辅助”中开启“星空模式”。
2. 需要更暗的亮度：开启 **App 屏幕亮度调至最低**。
3. 查看照片真实色彩：**按住“按住看原色”**，松开即恢复红光界面。远程拍摄、录像监控、查看大图界面均配有此按钮。
4. 星空模式仅改变屏幕显示效果，照片本身不受影响。使用 QR Code 分享时会暂时恢复正常色彩，确保对方能顺利扫码。
