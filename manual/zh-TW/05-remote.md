## 遠端拍攝（Pro）
用手機看相機的即時畫面、點畫面對焦、調整設定、拍照錄影。**Wi‑Fi 和 USB 都可以**，插著 USB 線時自動改走 USB。

**需要**
1. 選單裡有「連接類型」的機型（見[支援的相機](README.md#支援的相機)）。
2. Wi‑Fi 連線時，相機的「連接類型」切到 **相機控制**（見[連接相機](02-connect.md#相機的連接類型)）。還在「圖像傳送」時，App 會顯示切換步驟，切好後自動重連。

遠端拍攝是全螢幕畫面，底部分頁會隱藏，按左上的 **←** 或手機的返回鍵回到首頁。

### 畫面配置
| 位置 | 內容 |
|---|---|
| 上方 | 相機設定：模式、快門、光圈、ISO、自動 ISO、曝光補償、白平衡、對焦模式、AF 區域、測光、優化校準、畫質。直拿時排兩行，橫拿時一行（可以左右滑） |
| 上方第三行 | 返回、錄影、乾淨畫面、鎖定、存檔位置、電量 |
| 中間 | 即時畫面（完整不裁切），對焦框、水平儀、曝光表等疊在上面 |
| 下方 | 6 格開關（可以自訂）＋「更多」 |
| 最下面 | 「拍攝」（選拍攝方式）、快門、AF、最新照片與剩餘張數 |

橫拿手機時，開關移到左側黑邊、快門在右下角；**左手模式**（設定 → 拍攝）會把快門移到左下角。

### 調整相機設定
點上方的數值，下方會彈出調整列，不會蓋住即時畫面。
- 模式只顯示（P／S／A／M 要在相機上切）。快門在 S、M 可調，光圈在 A、M 可調。
- 自動 ISO 開著時 ISO 顯示「AUTO」。曝光補償旁邊有「0」一鍵歸零。
- 白平衡選 K 時可以另外調色溫。優化校準會顯示相機上的名稱，包括你自訂的。
- **調不動時**會說明原因。Zf、Zfc 這類有實體轉盤的機型，請把快門轉盤轉到 **1/3 STEP**、ISO 轉盤轉到 **C**。

### 對焦與快門
- **點畫面對焦**：點哪裡就對哪裡。相機的 AF 區域要選可以移動的模式（例如單點）；自動區域模式下由相機決定。
- 畫面上會畫出相機實際的對焦框：單點、動態區域、自動區域、追蹤都看得到；對到變綠，失敗變紅。
- **快門**：點一下就拍；**按住＝半按對焦**（外框變綠），放開就拍。
- **AF 按鈕**：在目前的對焦點重新對焦。
- **拍前對焦**（預設開）：關掉時快門直接拍，手動對焦或已經對好焦時比較快。
- **點畫面拍攝**：打開後，點畫面＝對焦到那裡並直接拍一張。
- 預覽左右邊緣（返回手勢的範圍）點擊不會對焦，滑動返回不會誤觸。

### 下排開關（可以自訂）
預設是峰值、斑馬、水平、網格、放大和一格空的，最後一格固定是「更多」。
- **點一下**開或關；**按住半秒**跳出細項（峰值靈敏度、斑馬門檻、構圖線樣式、放大倍率）。
- **自訂**：「更多」右上角的齒輪。可以放：峰值、斑馬、水平、網格、放大、直方圖、曝光表、點拍、拍前對焦、複製到手機、截圖、星空模式、即時預覽、倒數。

### 更多
「更多」是一個不透明的抽屜（直拿從下方、橫拿從側邊），取景畫面一直看得到。分三頁：
- **輔助**：即時預覽、峰值、過曝警告、水平儀、構圖線、直方圖、曝光表、放大對焦、星空模式。
- **拍攝**：拍前對焦、點擊拍攝、AF 區域、每拍一張複製到手機、預覽截圖。
- **工具**：疊影比對、多張拍攝檢查、提示。

### 拍攝輔助（只在手機上顯示，不影響照片）
| 功能 | 說明 |
|---|---|
| 水平儀 | 讀相機的水平感測器，誤差小於 0.5° 時變綠，並顯示左右傾斜和前後俯仰角度 |
| 直方圖 | 點一下切換「亮度＋RGB 疊加」和「RGB 分開」 |
| 斑馬紋（過曝警告） | 亮度超過門檻的地方疊斜紋，門檻 85／90／95／100%（預設 95%） |
| 峰值對焦 | 對焦清楚的邊緣上色（紅、黃、藍、白），靈敏度低／中／高，適合手動對焦 |
| 曝光表 | 像 Nikon 觀景窗的直式曝光指示，每 1/3 EV 一格。M 模式顯示和測光的差距，P／A／S 顯示補償 |
| 構圖線 | 九宮格、十二宮格、黃金比例、黃金螺旋、對角線、居中構圖 |
| 放大 | 相機支援時（例如 Zf）由**相機自己放大**，看到實際像素：50%／100%／200%／400%，點畫面或按 ◀ ▲ ▼ ▶ 移動位置，下方「近 ◀◀ ◀ ▶ ▶▶ 遠」微調手動對焦。不支援的相機用 App 的數位放大（2×／4×／8×） |

> 預覽是相機壓縮過的影像，這些輔助只能當參考，最後請以照片的直方圖為準。

### 拍攝方式
點快門旁的「**拍攝**」選擇。選了以後按鈕變黃，快門上方出現設定條（例如「間隔定時拍攝　每 5 秒 · 10 張」），點一下展開調整和「開始」；旁邊的 × 回到一般拍攝。執行中畫面上方會顯示進度，按「停止」隨時中止。

| 拍攝方式 | 設定 | 說明 |
|---|---|---|
| 一般拍攝 | 張數 1～9 | 搭配倒數時，倒數完連拍，每張間隔約 1 秒 |
| **倒數** | 關、2、5、10 秒 | 在「拍攝」最上面一列，所有拍攝方式和錄影都能先倒數；畫面中間顯示大數字，再按一次快門取消 |
| B 門 | 曝光秒數 1～3600 | 相機要在 M 模式、快門設 Bulb 或 Time，時間到自動結束 |
| 間隔定時拍攝 | 張數 2～999、間隔 1～3600 秒 | 依固定間隔連續拍，面板顯示總時間；可搭配「每拍一張複製到手機」做縮時 |
| 包圍曝光 | 張數 3／5／7／9、間距 0.3～3.0 EV | 以目前的曝光補償為中心依序改變，結束後恢復原本的值 |
| 對焦位移拍攝 | 張數 2～300、每步距離 | 先對焦在最近的主體，App 每拍一張往遠處移一點。需要 AF 鏡頭。合成請在電腦上做 |
| 拼貼 | 格數或「自由」 | 拍多張再拼成全景，見下方 |
| 搖搖樂 | 4 或 8 張 | 手持連拍幾張，合成一張雜訊比較少的照片，見下方 |

> 工具執行中，AF 和點畫面對焦會暫停。離開遠端拍攝前會先確認。

#### 拼貼（全景）
- **格狀**：選格數，App 算出每一格要轉幾度，你自己轉相機、按快門。面板會告訴你重疊夠不夠（「可以拍／還可以再轉／可能不夠」），並半透明顯示上一張的邊讓你對齊。
- **自由**：不用排格子，每張和上一張重疊約 30% 就好，往哪個方向轉、拍幾張都可以（最多 30 張）。
- 拍到 2 張以上就能按「**拼接**」，在手機上拼成一張大圖；拍滿一圈會輸出 360°。成品一定是水平的（拍攝時的水平儀會記下來）。
- 照片收在手機相簿的同一疊裡，之後也能重新拼接，見[第 6 章](06-edit.md#影像處理全景拼接降噪合成pro)。

#### 搖搖樂（降噪合成）
- 讓沒有像素偏移的機型也能「多拍幾張換畫質」：手持（或腳架）連拍 4 或 8 張，App 把它們對齊後平均，雜訊大約降到三分之一（8 張時），細節不變。
- 拍完自動在背景合成，畫面顯示「合成中 %」。成品存成 `SHAKE_<時間>.JPG`，和原圖同尺寸、帶拍攝資訊。
- 會動的東西（車、人、樹葉）只用最清楚的那一張，不會疊出重影。晃太多的照片不採用。
- 適合夜景、室內暗處、高 ISO。

### 疊影比對（Pro）
「更多 → 工具 → 疊影比對」：把參考畫面以**半透明疊加**或**左右分割**放在即時畫面上，可以調透明度、「截取當前畫面」當參考。適合定點重拍、翻拍、對位。

### 其他
- **每拍一張就複製到手機**：照接收規則存檔，包含 RAW 只存 JPEG。
- **最新照片**：右下角縮圖顯示最新一張和實際的快門、光圈、ISO；點開可以看這次拍的所有照片，直接存原檔或 JPEG 到手機。
- **乾淨畫面**：只留預覽；點角落的淡色按鈕叫回。**鎖定**：防止誤觸，長按畫面任何地方解鎖。
- **錄影**：上方的錄影按鈕。開始前會把相機切進「應用程式模式」（Zf 必需），停止後切回；錄不了時會說明原因。用 USB 時建議用[錄影監控](#錄影監控cine)。
- **預覽截圖**：存到 `Pictures/AeroCam/Snapshots/`（預覽畫質）。
- **USB 遠端拍攝**：即時畫面比 Wi‑Fi 順（預設 30 fps，可調 60 fps 或不限），可以開大尺寸預覽，右下角小字顯示實際幀率。在 **設定 → 拍攝** 調整。
- 遠端拍攝時螢幕預設保持常亮。

## 藍牙遙控（免費）
不用 Wi‑Fi，沒有即時畫面。首頁藍牙卡片 →「**藍牙遙控**」。需要先完成[藍牙配對](02-connect.md#配對)。
- 點快門拍一張；按住快門用相機自己的連拍（CL／CH）。
- 按住 AF 再點快門可以快速連按；連拍 3／5 張。
- AF 按鈕：按住對焦。相機要允許半按快門對焦（使用 AF‑ON 的人請確認相機設定）。
- 自拍計時（倒數）、錄影開始／停止、剩餘張數。
- **間隔拍攝**是 Pro。

## 錄影監控（Cine）
把手機當錄影的監看螢幕。插著 USB 時首頁 USB 區有「🎥 錄影監控」（最順，最高約 60 fps）；Wi‑Fi 版在首頁 Wi‑Fi 區，目前是實驗功能。
- Zf 要把拍照／錄影撥桿撥到**錄影**。
- **上方**：● REC 錄影時間、錄影規格（例如「1080 60p」，點一下可改）、檔案類型（例如「H.265 10bit」，N‑Log 要先選 H.265 10 位元）、剩餘錄影時間、電量。
- **下方**：錄影用的快門、光圈、ISO、自動 ISO、曝光補償、白平衡、對焦模式、測光。錄影 ISO 只在 M 模式有效。
- **錄影鍵**：錄影中要**按住 1 秒**（紅環轉滿）才會停止，避免誤觸。錄影中按返回會先確認。
- **輔助工具**：曝光表、直方圖、波形圖／RGB 分量、假色、斑馬紋（含第二段膚色斑馬）、峰值對焦、構圖線、安全框、遮幅（2.39:1、1.85:1、16:9、9:16、4:5）、Tally 紅框、快門角度顯示。
- **LUT**（Android 13 以上）：預覽套用監看 LUT（內建 N‑Log 轉一般，可以匯入 `.cube`），不會錄進影片。請關閉相機的「檢視輔助」避免套兩次。
- **變形鏡頭解壓縮**（1.33x～2.0x）、**A/B 拉焦**（設定兩個對焦點，平順地轉移焦點）、**疊影比對**。
- 錄影中預設不能點畫面對焦（避免拉焦錄進去），可以在選單打開。
- **截圖**：「預覽截圖」只存畫面，「截圖（含輔助工具）」連 LUT、斑馬紋、假色、遮幅一起存。

## 星空模式（免費）
拍星空時眼睛要適應黑暗，白光會讓瞳孔縮小。星空模式把整個 App 變成暗紅色。
1. 打開：**設定 → 外觀與語言 → 主題 →「星空（紅光）」**，或在遠端拍攝的下排開關、「更多 → 輔助」打開「星空模式」。
2. 想再暗一點：打開「**App 畫面亮度調到最低**」。
3. 想看照片真正的顏色：**按住「按住看原色」**，放開就變回紅色。遠端拍攝、錄影監控、相片大圖都有這個按鈕。
4. 星空模式只改變畫面顯示，照片本身不受影響。QR Code 分享時會暫時恢復原色，否則對方掃不到。
