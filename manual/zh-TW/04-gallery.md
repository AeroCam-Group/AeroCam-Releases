# 4. 相簿

底部「相機相簿」分頁上方有兩個分頁：**手機相簿**（已經在手機上的照片）和**相機記憶卡**（直接瀏覽相機裡的照片）。

## 相機記憶卡
在手機上直接瀏覽相機記憶卡（雙卡槽都支援），**不用先在相機上選照片**，也不用先按「開始接收」。
- USB 線免費；Wi‑Fi 是 Pro。
- 進入時不會自動佔用相機，按「連線瀏覽記憶卡」才連。相機一次只接受一條連線，所以自動接收會暫停，離開後自動恢復。
- 切到其他分頁或看大圖時，連線保留 20 秒，回來可以接著瀏覽；App 退到背景時會立刻放開相機（正在下載的會先下載完）。
- 開著相簿時用相機拍照，新照片約 1～2 秒內自己出現在最上面（USB 最快）。

### 瀏覽與篩選
- 依拍攝日期分組；右上角日曆可以快速跳到某一天（年 → 月 → 日）。
- 篩選：全部、RAW、JPEG、影片、**尚未下載**（只列出手機上還沒有的）、已評星。選「尚未下載」或「已評星」時，下方有「全選這 N 張」。
- **每列張數**：右上角格子圖示選 2～7 張，或兩指縮放切換；橫拿時每列多一半。
- 影片只讀檔頭，不用整個下載：格子左下「▶ 0:12」是長度，左上「1080 24p」是規格。

### 縮圖的標記
篩選列最右邊的 ⓘ 有完整說明。

| 位置 | 意思 |
|---|---|
| 左上 | 第二張卡（SD2）或影片規格 |
| 右上 | 評星 |
| 左下 | 格式：RAW（琥珀色）、JPEG（灰色）、▶ 影片長度 |
| 右下 | 手機上已經有的版本：**✓RAW**、**✓JPEG**、**✓JPEG.S**，可以疊好幾個。綠色＝相機的原檔，藍色＝複本；沒有標籤＝還沒在手機上 |

### 選取
- 長按一張後**直接拖曳**，一次選一整段；拖到畫面邊緣會自動捲動。
- 每個日期標題右邊有「選取」，選整天。
- 選取時底部導覽列會收起，換成選取列（下載、評星、刪除）；按左上「✕」取消。

### 下載
選取後按「下載」，每個選項旁邊會寫**會佔手機多少空間**，最下面是手機剩餘空間：
- **原始檔**：完整的 RAW、JPEG 或影片。
- **只要 JPEG**（Pro）：RAW 取出內嵌的全尺寸 JPEG；JPEG 原檔則由手機重新壓縮（解析度不變）。都存成 `DSC_1234_S.JPG`，帶完整拍攝資訊。壓縮品質在 **設定 → 接收與通知 → 相簿** 選 60／70／80／90%（預設 80%）。
- 下載會排進佇列，可以看進度、隨時停止；手機上已經有的會自動跳過，結果也記在「紀錄」。
- 下載後會問「要保留這些選取嗎？」，倒數結束自動清除，避免留著選取誤按「從相機刪除」。可以勾「記住我的選擇」。

### 從相機刪除（Pro）
選取後按**紅色**的「從相機刪除（N）」，確認後從記憶卡**永久刪除**，無法復原。還沒下載到手機的照片會另外警告；有保護鎖（🔑）的照片相機不會刪。

> 只有紅色實心按鈕會動到相機。其他刪除都只動手機。

### 大圖
點一下全螢幕預覽，左右滑換張，雙指或雙擊放大。
- **直拿**：上方是檔名、時間、大小；照片下方是拍攝參數（快門 · 光圈 · ISO · 焦距）；按鈕在最下面。
- **橫拿**：照片佔滿畫面，資訊在右側，點照片可以隱藏或顯示。
- 勾「**詳細**」：RGB 直方圖、優化校準、白平衡、鏡頭、尺寸、檔案大小，直接從相機上的檔案讀，不用先下載。

### 評星
在相簿裡替照片打 1～5 星，用「已評星」篩選後只下載選中的；星等會寫進下載的檔案（EXIF Rating），Lightroom 等軟體讀得到。

## 手機相簿
顯示已經存到手機的照片，不用連相機。
- 只顯示還在手機上的檔案：在 Google 相簿等 App 刪掉的，回到這裡就不會再出現；從垃圾桶還原後會自動回來。
- 依拍攝時間排序，篩選列有「已編輯」「拼貼」「搖搖樂」等。
- **大圖**：拍攝參數和「詳細」（拍攝時間、傳輸時間、RGB 直方圖、優化校準、白平衡、鏡頭、尺寸、檔案類型、來源）。下方有 **分享**、**用其他 App 開啟**、**編輯**、**刪除**。
- **刪除**：選取後按「刪除」，可以選「刪除手機上的全部」「只刪 RAW」「只刪 JPEG（含 S）」「只刪影片」。檔案會移到手機**垃圾桶**，30 天內可以從系統相簿還原；**相機記憶卡完全不受影響**。
- **影像處理**：選取幾張照片後，把底部操作列往上滑，展開「影像處理」，有**拼接**（全景）和**降噪合成**（搖搖樂），見[第 6 章](06-edit.md#影像處理全景拼接降噪合成pro)。
- 照片沒出現：**設定 → 儲存空間與電池 →「重新掃描手機照片」**。

## 記憶卡備份（Pro）
把記憶卡備份到手機，入口在 USB 卡片的「備份記憶卡」或相簿右上角「備份」。
- **範圍**：整張卡，或自訂（拍攝日期、只備份還沒在手機上的、SD1／SD2）。
- **類型**：RAW＋JPEG、只 RAW、只 JPEG、RAW 轉 JPEG，可以含影片。
- 按「計算」看檔案數、大小、預估時間和手機剩餘空間；用 Wi‑Fi 備份 RAW 或影片會先警告要很久。
- 背景執行（通知列可以暫停），中斷後下次會問要不要接著做。
- 每個檔案存好後都會讀回來比對。完整、沒有失敗的備份做完後，可以「**從相機刪除已備份的檔案**」：只刪這次驗證過的檔案，要確認兩次。

## QR Code 分享
讓旁邊的人用手機相機掃一下，就能在瀏覽器裡看、下載你的照片，**對方不用裝 App**。

### 怎麼分享
1. 「手機相簿」長按選取照片 → 選取列第一個「**分享**」。只能分享手機上已經有的照片（JPEG、RAW），影片暫不支援。
2. 畫面會顯示大的 QR Code 和短網址（例如 `192.168.43.1:8080/k7Qx2mPa`）。對方用手機相機掃描就能打開。
3. 也可以「**複製網址**」或「**傳送網址**」（LINE、Messenger…）。

> **對方要連同一個 Wi‑Fi，或連你的手機熱點。** 飯店、咖啡廳的公共 Wi‑Fi 常常禁止裝置互連，打不開時改開手機熱點。

### 選項
- **設定密碼**（預設關）：對方要先輸入 4 位數密碼。密碼不會放進傳出去的訊息，請當面告訴對方。
- **畫質**：免費版是縮小版 JPEG（長邊 2048 px），一張一張下載。Pro 可以給**原尺寸**、「**同時提供 RAW 檔**」，對方還能多選、一次下載成 zip。
- **保留位置資訊（GPS）**（預設關）：預設下載的 JPEG 會移除拍攝地點。網頁上永遠不顯示地點。手機上的原檔不會被修改。
- 分享多久後自動停止：**設定 → 接收與通知 → 相簿**（15／30／60 分鐘，預設 30）。

### 分享中
- 離開畫面、關螢幕都會繼續分享；通知列有「顯示 QR Code」和「停止分享」。
- 網路短暫消失會等 30 秒；手機位址換了會沿用同一組網址代碼，並提示對方重新掃描。
- 對方網頁依手機語言顯示繁中、簡中、日文或英文，可以看大圖、拍攝資訊，下載失敗可以一鍵重試。
- **安全**：網址帶 8 碼亂碼，亂試會被鎖；只開放你選的照片；對方只能看和下載，不能上傳或刪除。按「停止分享」後網址馬上失效。

> 小米、OPPO 等手機會強制關背景程式，分享畫面會提醒你把 AeroCam 設成「不限制耗電」。
