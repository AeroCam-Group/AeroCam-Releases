# 9. 免費／Pro／Cine

| 等級 | 功能 |
|---|---|
| **免費** | 藍牙傳照片、藍牙遙控（對焦、拍照、錄影、連拍、自拍計時）、USB 相機相簿（手動挑選下載原檔）、手機相簿、挑片評星、照片編輯（含 .np3 風格預覽、手機編輯 RAW、切換成無損 RAW）、照片位置、QR Code 分享（縮小版）、星空模式 |
| **Pro** | 免費的全部，加上：Wi‑Fi（含一鍵連線、Wi‑Fi 相簿）、FTP 接收、自動接收（Wi‑Fi、USB）、遠端拍攝、拍攝輔助、拍攝工具（B 門、間隔定時、包圍曝光、對焦位移）、遠端拍攝倒數、疊影比對、藍牙遙控的間隔拍攝、RAW 只存 JPEG、壓縮 JPEG、記憶卡備份、從相機刪除、無卡拍照（只存手機）、相機風格 C1～C9、QR Code 分享原尺寸與 RAW、全景拼接、搖搖樂（降噪合成） |
| **Cine** | Pro 的全部，加上：錄影監控、LUT、變形鏡頭解壓縮、A/B 拉焦、錄影監控的疊影比對 |

在上鎖的功能點下去，會跳出需要的等級和「輸入測試金鑰」。

## Beta 期間
- Beta 預設是免費版。輸入[測試金鑰](01-install.md#測試金鑰開啟-procine)就能免費使用 Pro 和 Cine。
- 測試金鑰每週更新、每組有效 14 天，只在 GitHub 的 AeroCam-Releases 免費發佈。
- 測試版結束後，最後一組金鑰到期就回到免費版。
