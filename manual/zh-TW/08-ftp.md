# 8. FTP 接收（Pro）

相機拍完照片，**自己用 FTP 推到手機**，不用在相機上選照片、也不用打開相簿。實測 Nikon Zf 每張 RAW（約 18 MB）大約 1 秒就到手機。

AeroCam 本身就是 FTP 伺服器，**不用另外架設任何東西**。

## 適合
- 活動、婚禮、運動：邊拍邊把照片送到手機。
- 拍完想馬上在手機上看、發社群。

## 需要
- 相機有內建 FTP 上傳功能（Nikon Z f、Z 8、Z 9、Z 6III 等）。
- 手機開**熱點**，相機連上這個熱點（或手機和相機連同一台路由器）。
- 相機要插記憶卡：FTP 傳的是記憶卡上的照片。

## 設定（第一次）
1. 手機開熱點。
2. AeroCam 首頁 **FTP** → 最上方「**開始接收**」。畫面會顯示相機要填的設定，每一項都可以點一下複製：
   - 伺服器位址（例如 `10.14.29.30`）
   - 連接埠：`2121`
   - 帳號：`aerocam`
   - 密碼：App 產生的 8 碼（可以「重新產生」）
   - 被動模式（PASV）：**開**
3. 相機：**MENU → 網路選單 → 連接到 FTP 伺服器 → 網路設定 → 建立設定檔**：
   - Wi‑Fi 選手機的熱點。
   - 伺服器類型選 FTP，填入上面的位址、連接埠、帳號、密碼，被動模式開。
4. 相機上啟用這組 FTP 連線。AeroCam 的 FTP 狀態顯示「已連線」就完成了。
5. 在相機的 FTP 選單打開**拍攝後自動傳送**，之後拍照就會自動傳。

不確定怎麼設定時，FTP 卡片旁的 **ⓘ** 有圖文教學。

## 使用時
- 狀態燈號：關閉、運作中・等待相機、已連線、接收中、錯誤。
- 通知列顯示「FTP 接收中・已收 N 張」和目前的檔名與速度。
- 照片照 **設定 → 接收與通知** 的規則存檔（資料夾、檔名、只收 JPEG、RAW 只存 JPEG 等），紀錄裡標示來源 FTP。
- 傳輸中斷或相機中途關機時，沒收完的檔案會自動刪除，相簿裡不會留下殘缺的檔案。
- 相機關機後約 1 分鐘內會顯示未連線；相機重新開機連回來時直接接手。
- **閒置自動關閉**：**設定 → 接收與通知 →「FTP 多久沒收到照片就自動關閉」**（不自動關閉、5、10、30 分鐘）。從最後一張開始計時，傳輸中不會關，關閉時會通知。

## 要注意
- **熱點要一直開著**。有些手機沒流量時會自動關熱點，請到手機的熱點設定把「自動關閉」關掉。
- 熱點關掉再打開後，手機的位址可能會變，要對照相機裡填的位址。
- FTP 接收和 **Wi‑Fi 自動接收只能開一個**，開其中一個時另一個會自動停止。
- 開著 FTP 時，相機是在 FTP 模式，**相簿和遠端拍攝不能用 Wi‑Fi 連**。要用的話請接 USB 線，或停止 FTP 接收，並在相機切回「連接到電腦」。
- FTP 伺服器只開在熱點或 Wi‑Fi 區域網路上，不會對外開放。
- 「一鍵連線」不能搭配 FTP（一鍵連線是相機自己開 Wi‑Fi，FTP 要相機連到手機）。

## 直接傳到 NAS
相機的 FTP 也可以直接設定成你家的 NAS，不經過手機。這是相機本身的功能，不需要 AeroCam。
