# 8. FTP 接收（Pro）

> Beta **92.04.01** 之後的版本才有。

相機拍完照片，**自己用 FTP 推到手機**，不用在相機上選照片、也不用打開相簿。實測 Nikon Zf 每張 RAW（約 18 MB）大約 1 秒就到手機。

AeroCam 本身就是 FTP 伺服器，**不用另外架設任何東西**。

## 適合
- 活動、婚禮、運動：邊拍邊把照片送到手機。
- 拍完想馬上在手機上看、發社群。

## 需要
- 相機有內建 FTP 上傳功能（Nikon Z f、Z 8、Z 9、Z 6III 等；其他品牌的中高階機多半也有）。
- 手機開**熱點**，相機連上這個熱點（或手機和相機連同一台路由器）。

## 設定（第一次）
1. 手機開熱點。
2. AeroCam 首頁 **FTP** 區塊 → 展開 → 按「開始」。畫面會顯示相機要填的設定：
   - 伺服器位址（例如 `10.14.29.30`）
   - 連接埠：`2121`
   - 帳號：`aerocam`
   - 密碼：App 產生的 8 碼
   - 被動模式：開
3. 相機：**MENU → 網路選單 → 連接到 FTP 伺服器 → 網路設定 → 建立設定檔**：
   - Wi‑Fi 選手機的熱點。
   - 伺服器類型選 FTP，填入上面的位址、連接埠、帳號、密碼，被動模式開。
4. 相機上啟用這組 FTP 連線。AeroCam 的 FTP 區塊顯示「相機已連線」就完成了。
5. 在相機的 FTP 選單打開**拍攝後自動傳送**，之後拍照就會自動傳。

📷 截圖：FTP 區塊展開後的設定畫面

## 使用時
- 通知列顯示「FTP 接收中・已收 N 張」和目前的檔名與速度。
- 照片照「設定 → 接收與通知」的規則存檔（資料夾、檔名、只收 JPEG 等）。
- 開著「RAW 轉 JPEG」時，RAW 會抽出內嵌的 JPEG 存進相簿。

## 要注意
- **熱點要一直開著**。有些手機沒流量時會自動關熱點，請到手機的熱點設定把「自動關閉」關掉。
- FTP 接收和 **Wi‑Fi 自動接收只能開一個**，開其中一個時另一個會自動停止。
- 開著 FTP 時，相機是在 FTP 模式，**相簿和遠端拍攝不能用 Wi‑Fi 連**。要用的話請接 USB 線，或停止 FTP 接收，並在相機切回「連接到電腦」。
- FTP 是把**記憶卡上**的照片傳出來，相機一定要插卡。
- 「一鍵連線」不能搭配 FTP（一鍵連線是相機自己開 Wi‑Fi，FTP 要相機連到手機）。
