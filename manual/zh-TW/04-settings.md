# 4. 設定逐項說明

**設定**分成五頁。免費版看不到用不到的設定。有建議或覺得預設值不好，歡迎[回報](07-report.md)。

## 接收與通知

| 設定 | 選項 | 預設 | 說明 |
|---|---|---|---|
| 接收類型 | 全部檔案／僅 JPG／JPG + RAW／照片 + 影片／自訂 | 全部檔案 | 自動接收要收哪些檔案 |
| 存檔資料夾 | 依相機／依日期／依相機與日期／依檔案類型 | 依相機與日期 | 照片在 `Pictures/AeroCam`、影片在 `Movies/AeroCam` 底下的分法 |
| 檔名 | 相機原檔名／加日期前綴／加日期時間前綴 | 相機原檔名 | 只套用到之後存的檔案 |
| 接收模式（Pro） | 持續接收／單檔接收 | 持續接收 | 單檔＝收到一個就停止 |
| 大型影片不自動接收（Pro） | 數值（MB） | 1024 MB | 超過的影片記為「已過濾」，要手動下載 |
| 藍牙已收過的照片 | Wi‑Fi 收到時換成原檔／Wi‑Fi 不再下載／兩份都保留 | 換成原檔 | 藍牙收到的是約 2 MB 的縮小版 |
| 壓縮 JPEG 的品質（Pro） | 60／70／80／90% | 80% | 只影響手機重新壓縮的 JPEG（24 MP 約 3–4 MB） |
| 下載／刪除後的選取 | 每次詢問／一律保留／一律清除 | 每次詢問（5 秒） | 避免留著選取誤按「從相機刪除」 |
| 勿擾 | 開／關 | 關 | 關掉所有 AeroCam 通知（「接收中」的常駐通知仍會保留，Android 規定） |
| 開始傳輸時通知 | 開／關 | 關 | |
| 收到照片時通知 | 開／關 | 開 | |
| 傳輸問題通知 | 開／關 | 開 | 卡住、相機取消、手機空間不足 |
| 相機低電量提醒 | 開／關，電量門檻 | 開，15% | 與相機連線時才會檢查 |

## 拍攝

| 設定 | 選項 | 預設 | 說明 |
|---|---|---|---|
| 進入遠端拍攝時預設開啟（Pro） | 拍前對焦、直方圖、過曝警告、峰值對焦、曝光表 | 拍前對焦、曝光表 | 拍攝時仍可在工具列切換 |
| 曝光表顏色 | 自動／白／黑 | 自動 | 自動＝依後方畫面亮度 |
| 峰值對焦顏色 | 紅／黃／藍／白 | 紅 | |
| 遠端拍攝時螢幕常亮 | 開／關 | 開 | 間隔拍攝、長曝光時手機不關螢幕 |
| 左手模式 | 開／關 | 關 | 橫拿時快門移到左下角 |
| USB 預覽頻率 | 30／60 fps／不限 | 30 fps | 30 省電不燙；60 較順 |
| USB 大尺寸預覽 | 開／關 | 開 | 較清楚，幀率可能略降 |
| 連線時同步相機時間 | 開／關 | 開 | 相差超過 2 秒才改；相差 1 天以上會先詢問 |
| 有線時讓相機保持喚醒 | 開／關 | 開 | 每 10 秒送一個小訊息；閒置 30 分鐘或低電量時停止 |
