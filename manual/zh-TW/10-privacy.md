# 10. 隱私與匿名統計

AeroCam 沒有帳號，照片只在你的相機和手機之間傳輸，**不會上傳到任何伺服器**。只有下面列出的少量資料會離開手機。

## 會連網的地方
| 功能 | 送出什麼 | 可以關嗎 |
|---|---|---|
| 檢查更新（Beta） | 只向 GitHub 查詢最新版本 | 每天自動一次 |
| 匿名使用統計 | 見下方 | 可以，設定 → 支援 |
| QR Code 分享 | 只在你的區域網路（同一個 Wi‑Fi 或手機熱點）內，給掃描的人看你選的照片 | 你按停止或時間到就結束 |

## 匿名使用統計
用來了解大約有多少人在用、用哪些相機和功能、哪裡常出問題，決定接下來先做什麼。**不會賣給任何人，也不用於廣告。**

- **開關**：**設定 → 支援 →「傳送匿名使用統計」**，預設開。
- 第一次連上相機後會說明一次，可以選「好」或「關閉」。**回答之前什麼都不送。**
- **關掉後**：不再傳送，並刪除下面說的隨機 ID 和還沒送出的資料。再打開會產生新的 ID。
- 沒有網路時（例如連著相機的 Wi‑Fi），資料先存在手機，有網路時再送。
- Dev 開發版不記也不送。

### 會送出的資料
- **App 自己隨機產生的 ID**：不是從手機或相機取得的，重裝 App 或關掉統計後就換一個。
- 相機型號（例如 Nikon Z f），只有型號。
- 連線方式（藍牙、Wi‑Fi、USB、FTP）、Wi‑Fi 的種類（相機自己的 Wi‑Fi、手機熱點、路由器）。
- 每天用了哪些功能（只記名稱，一天一次），包括點了哪些被鎖住的功能。
- 連線成功或失敗的次數，失敗時只送分類代碼（例如「逾時」），不送錯誤訊息。
- 新增相機的步驟：開始、成功、找不到相機、失敗原因。
- 每天收到幾張照片（JPEG、RAW、影片各幾張，只有數量）。
- 權限是允許還是拒絕。
- 目前方案（免費、Beta 金鑰…）、App 版本、App 語言、Android 大版本。
- 國家：由連線判斷，只存國家代碼。

### 絕不傳送
相機序號、相機裡設定的擁有者或版權名稱、位置（GPS）、照片和影片、檔名、拍攝資訊（EXIF）、Wi‑Fi 名稱和密碼、手機的 ID（IMEI、Android ID、廣告 ID）、姓名、Email、帳號、錯誤訊息內容。

### 保存
- 每支手機每天的明細保留 90 天，之後只留每天的總數。
- 超過約 13 個月沒出現的 ID 會被刪除。
- 伺服器處理連線時必然會看到 IP，只用來判斷國家和防止濫用，**不會存進統計資料**。

## 位置資訊
- **傳位置給相機（藍牙）**：手機把位置傳給相機，由相機寫進照片。
- **收到的 JPEG 補上位置（手機）**：預設關。打開後，接收期間手機記下的位置只存在這支手機、24 小時後刪除。
- 兩個開關都在 **設定 → 接收與通知 → 照片位置**，見[第 3 章](03-receive.md#照片位置gps)。
- 照片裡的位置會跟著照片走，分享原檔時對方也看得到。**QR Code 分享預設移除位置**。

## 權限用途
| 權限 | 用途 |
|---|---|
| 藍牙、附近的裝置 | 和相機配對、藍牙傳照片、藍牙遙控、尋找 Wi‑Fi 相機 |
| 位置 | 傳給相機或補進照片；Android 讀取 Wi‑Fi 名稱也需要 |
| 通知 | 接收進度、收到照片、傳輸問題、相機低電量 |
| 相片和影片 | 在手機相簿顯示、整理照片 |

## 診斷資訊
**設定 → 支援 →「複製診斷資訊」**只會複製到剪貼簿，**由你決定**要不要貼給我們。內容包含 App 版本、手機與網路狀態、相機能力、最近的連線紀錄，相機序號只保留末 4 碼。貼到公開的 GitHub Issue 前，請再看一次有沒有不想公開的內容。
