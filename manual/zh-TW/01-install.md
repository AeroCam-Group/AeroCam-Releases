# 1. 安裝與開始使用

## 安裝
1. 到 [Releases](https://github.com/AeroCam-Group/AeroCam-Releases/releases/latest) 下載最新的 Beta APK（`…-Beta-xx.xx.xx.apk`）。
2. 在手機上打開 APK。第一次會要求允許「安裝未知應用程式」，請允許。
3. 之後有新版本，直接下載安裝就能覆蓋更新，配對和設定都會保留。

> 只從 AeroCam-Releases 下載。其他地方的 APK 可能被改過。打開 App 時如果跳出「這不是官方版本」，代表這個 App 被別人重新包裝過：它不接受測試金鑰，也可能被加了其他程式，請移除後到 AeroCam-Releases 重新下載。

> 用過 **92.03.09 以前的舊版 Beta**：新版會裝成另一個 App，要重新配對相機、重新輸入測試金鑰，確認沒問題再移除舊版。

## 權限
App 會在用到時才詢問，不需要的可以不給：

| 權限 | 用途 |
|---|---|
| 藍牙、附近的裝置 | 藍牙配對、藍牙傳照片、藍牙遙控；Android 13 以上找 Wi‑Fi 相機也需要 |
| 位置 | 把手機位置傳給相機寫進照片、幫收到的 JPEG 補上位置；Android 讀取 Wi‑Fi 名稱也需要 |
| 通知 | 接收進度、收到照片、傳輸問題、相機低電量 |
| 相片和影片 | 顯示、整理手機上的照片 |

每個權限的詳細說明見[隱私與匿名統計](10-privacy.md)。

## 畫面導覽
底部有四個分頁：

| 分頁 | 內容 |
|---|---|
| **首頁** | 相機儀表板（電量、鏡頭、記憶卡、連線狀態）、四種連線方式（Wi‑Fi、USB、藍牙、FTP）、傳輸狀態與紀錄、相機風格、管理相機 |
| **相機相簿** | 「手機相簿」和「相機記憶卡」兩個分頁，見[第 4 章](04-gallery.md) |
| **遠端拍攝** | 用手機看相機的即時畫面、調設定、拍照錄影，見[第 5 章](05-remote.md) |
| **設定** | 五個分類，見[第 7 章](07-settings.md) |

不知道怎麼連相機時，按首頁連線狀態旁邊、或「新增相機」每一步右上角的 **ⓘ**，會打開對應連線方式的圖文教學。

## 測試金鑰（開啟 Pro、Cine）
Beta 預設是免費版。
1. 到 [AeroCam-Releases 首頁](https://github.com/AeroCam-Group/AeroCam-Releases) 複製目前的測試金鑰。App 裡 **設定 → 支援 →「取得免費金鑰」** 會直接打開那個頁面。
2. **設定 → 支援 →「輸入測試金鑰」** 貼上整串文字，按「套用」。在上鎖的功能點下去時，對話框裡也有「輸入測試金鑰」。
3. 每組金鑰有效 14 天，每週換新。到期後回到免費版，貼上新的就好。

> Beta 和測試金鑰都是**免費**的，只在 GitHub 的 AeroCam-Releases 發佈。如果有人向你收費，那不是官方管道。

## 檢查更新
Beta 每天第一次開啟時會自動檢查。也可以在 **設定 → 支援 →「檢查更新」** 手動檢查。

## 語言
介面支援繁體中文、簡體中文、日文、英文、한국어、Deutsch、Français、Español、Tiếng Việt、ไทย、Bahasa Indonesia。預設跟隨手機的系統語言，也可以在 **設定 → 外觀與語言 → 語言** 切換。

英文、繁中、日文一定完整；其他語言的新功能可能先顯示英文，之後統一補翻。翻得不好的地方歡迎用「翻譯錯誤」表單[回報](12-report.md)。

## 匿名使用統計
第一次連上相機後，App 會說明一次「傳送匿名使用統計」，可以選「好」或「關閉」，回答之前什麼都不送。之後隨時可以在 **設定 → 支援** 關閉。送哪些、絕不送哪些，見[隱私與匿名統計](10-privacy.md)。
