# 11. 常見問題與疑難排解

## 一般
**不升級 Pro，能把相機照片傳到手機嗎？**
可以。免費版可以用藍牙自動接收約 200 萬像素的縮小版 JPEG，也可以用 USB 線在相機相簿手動挑選、下載原檔。

**Beta 或測試金鑰要付錢嗎？**
不用。都只在 GitHub 的 AeroCam-Releases 免費發佈。有人向你收費，那不是官方管道。

**打開 App 跳出「這不是官方版本」**
這個 App 被別人重新包裝過，不接受測試金鑰，也可能被加了其他程式。請移除，到 AeroCam-Releases 重新下載。

**更新後找不到相機、測試金鑰不見了**
92.03.09 起新版會裝成另一個 App，資料不會從舊版帶過來。請重新配對相機、重新輸入測試金鑰。

**照片存到哪裡**
照片在 `Pictures/AeroCam`、影片在 `Movies/AeroCam`，其他檔案在 `Download/AeroCam`。Google 相簿等 App 也看得到。92.03.09 以前的舊版存的檔案還在原本的資料夾，不會搬移。

**手機上刪了照片，想重新傳**
直接再傳一次，App 會發現手機上的檔案已經不在。

**從手機垃圾桶還原、或重裝 App 後，相簿裡看不到照片**
**設定 → 儲存空間與電池 →「重新掃描手機照片」**。

## 連線
**一直連不上相機（Wi‑Fi）**
1. 相機停在「連接到電腦」畫面，螢幕上有 Wi‑Fi 圖示；相機螢幕關掉時半按快門喚醒。
2. 連接類型正確：自動接收、相簿＝圖像傳送；遠端拍攝、無卡拍照＝相機控制。
3. 手機熱點方式：熱點有開，相機連的是這個熱點。
4. 同一個 Wi‑Fi 方式：手機和相機連的是同一個網路名稱（手機有時會自動切到別的 Wi‑Fi 或行動數據）。
5. 試試**一鍵連線**，不用熱點也不用路由器。
6. 按 **ⓘ** 照著連線教學再做一次。

**飯店、展場的 Wi‑Fi 一直找不到相機**
公共 Wi‑Fi 通常禁止裝置互連。請改用手機熱點或一鍵連線。

**相機說「已和其他裝置配對」**
這組相機網路設定是別的 App 在用。請在相機上新增一組設定，再重新配對。

**一鍵連線找不到相機 Wi‑Fi**
相機收到指令後要 10～30 秒才開好 Wi‑Fi，App 會自動重試。還是失敗的話，確認密碼正確。

**熱點一直斷**
有些手機在沒有裝置上網時會自動關熱點。到手機熱點設定關閉「自動關閉熱點」，或改用一鍵連線。

**熱點重開後相機連不回來**
手機的熱點位址可能變了。用 Wi‑Fi 自動接收時 App 會自己找；FTP 要對照相機裡填的位址。

**插上 USB 後沒反應**
1. 相機 USB 設定是 **MTP/PTP**。
2. 線要能傳資料（有些線只能充電）。
3. 手機跳出「允許存取」要按允許。
4. USB 卡片右上角 ⋮ →「USB 測試」看哪一步失敗。

**背景接收常常中斷**
到 **設定 → 儲存空間與電池** 關閉電池最佳化。小米、OPPO 等手機還要在系統設定把 AeroCam 設成「不限制耗電」。

## 藍牙
**藍牙傳照片卡住**
- 拍 RAW 時相機要先轉成 JPEG 再傳；傳輸中操作相機會讓相機取消。建議拍完直接關機讓它在背景傳。
- 藍牙卡片「中斷並重新連線」，或「⋮ → 重新啟動藍牙服務」，配對會保留。

**藍牙遙控按 AF 不會對焦**
相機要允許半按快門對焦。使用 AF‑ON 的人，請確認相機自訂設定裡「快門釋放鈕 AF 啟動」是開的。

**藍牙和 Wi‑Fi 收到同一張，會存兩份嗎？**
預設不會：Wi‑Fi 收到原檔時，自動刪掉藍牙的縮小版。可以在 **設定 → 接收與通知 →「藍牙已收過的照片」** 改。

## 遠端拍攝
**快門或 ISO 調不動**
- 快門要在 S／M 模式，光圈要在 A／M 模式；調 ISO 前先關自動 ISO。
- Zf 等有實體轉盤的機型：快門轉盤轉到 1/3 STEP、ISO 轉盤轉到 C。

**點畫面沒有移動對焦點**
相機的 AF 區域要選可以移動的模式（例如單點）。自動區域模式下由相機決定。

**首頁儀表板少了某些項目（鏡頭、剩餘張數、快門次數）**
有些資訊相機只在特定模式提供，切到「相機控制」並進入遠端拍攝後通常讀得到。快門次數需要記憶卡上至少有一張照片。

**色溫（K 值）在哪裡看？**
Nikon 只在照片裡以加密格式記錄實際色溫，所以「詳細」只顯示白平衡模式。

## 存檔位置與無卡拍照
**相機沒插卡，按快門沒反應**
確認相機的「空插槽時快門釋放鎖」是「允許釋放快門」，而且 App 連著相機（狀態列顯示「只存手機」）。

**照片出現「示範」字樣**
相機沒插卡、又沒有用 App 的「只存手機」接收時，相機會把照片標成「示範」且不存檔。請插卡，或連著 AeroCam 拍。

**照片沒進手機，首頁上方有紅色橫幅**
- 寫「相機是『影像傳送』模式」：無卡拍照要用「相機控制」。切換後相機會重新連線，已經拍的照片會自動傳過來。
- 寫「一鍵 Wi‑Fi：沒有記憶卡」：一鍵連線不支援無卡拍照，請插卡或改用熱點／同一個 Wi‑Fi。

**跳出「連線中斷」**
只存手機時斷線超過 10 秒才會提醒。這段時間在相機上拍的照片可能不會存進記憶卡，重新連上後 App 會自動修正。

## 編輯與風格
**NEF 打不開、不能編輯**
高效率／高效率★ 壓縮的 NEF 會改用內嵌的 JPEG 編輯；只有小預覽圖的檔案不能編輯。想在手機上完整顯影，可以把相機切成「無損壓縮」，見[第 6 章](06-edit.md#手機可編輯-raw切換相機的-raw-壓縮)。

**.np3 套用的效果和相機不一樣**
手機模擬的是曲線和飽和度，混色器和色彩分級還沒模擬，所以是近似效果。JPEG 拍攝時已經套過相機風格的話，效果會疊加。

**.np3 寫進相機後顏色不一樣**
相機的自訂格子只收「基底＋曲線＋銳化」，飽和度、混色器、色彩分級寫不進去。要完整效果，請用記憶卡在相機選單匯入 .np3。

**拼接失敗或少了幾張**
每張要和相鄰的照片重疊約 30%。接不上的照片會列出檔名；格狀拼貼缺一格時不輸出。

## FTP
**相機顯示 Err.31 或 Err.32**
請更新到最新的 Beta。也確認相機填的位址、連接埠 `2121`、帳號 `aerocam`、密碼都正確，被動模式要開。

**相機顯示登入失敗**
密碼要跟 AeroCam FTP 顯示的一模一樣（大小寫有差）。按過「重新產生密碼」的話，相機那邊也要改。

**開著 FTP，相簿或遠端拍攝連不上**
相機在 FTP 模式時不提供相簿和遠端拍攝的 Wi‑Fi 連線。請接 USB 線，或停止 FTP 接收、在相機切回「連接到電腦」。

## 其他
**App 閃退**
重新開啟後到 **設定 → 支援 →「複製診斷資訊」**，[回報問題](12-report.md)時貼上，裡面有最後一次閃退的錯誤位置。

**怎麼關掉匿名使用統計？**
**設定 → 支援 →「傳送匿名使用統計」** 關掉即可，見[隱私與匿名統計](10-privacy.md)。
