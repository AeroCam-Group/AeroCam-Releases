# AeroCam 使用手冊（繁體中文）

> 對應 **Beta 92.04.08.10**（2026-11-15 更新）。標 📷 的地方之後補截圖。

AeroCam 讓相機的照片直接傳到 Android 手機，也能用手機遙控相機、在手機上修圖，並把風格寫進相機。目前支援 **Nikon Z 系列**，之後會支援更多品牌。

AeroCam 是獨立開發的第三方 App，與 Nikon 及其他相機廠商沒有任何合作或授權關係。

## 支援的相機

| 機型 | 自動接收、相機相簿 | 遠端拍攝 | 狀態 |
|---|---|---|---|
| Z9、Z8、Z6III、Zf、Z5II、Z50II、ZR 等選單裡有「連接類型」的機型 | ✅ | ✅ | Zf 已實測，其他歡迎回報 |
| Z6、Z7、Z6II、Z7II、Z5、Z50、Zfc、Z30 等較早的機型 | ✅ | ❌（這些機型的連線方式不支援） | 歡迎回報 |
| Canon、Sony、Fujifilm | 準備中 | 準備中 | |

用其他機型測過的話，請用[機型回報](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose)告訴我們哪些功能可以、哪些不行。

## 需要
- Android 10 以上的手機。
- Nikon Z 系列相機。

## 用詞
| 本手冊用的詞 | 意思 |
|---|---|
| 相機相簿／相機記憶卡 | 相機記憶卡上的照片，透過連線在手機上瀏覽 |
| 手機相簿 | 已經存到手機上的照片 |
| RAW | Nikon 的 NEF 檔 |
| JPEG.S | 壓縮過的 JPEG（RAW 取出的 JPEG、手機重新壓縮的 JPEG、藍牙傳來的縮小版），檔名結尾 `_S.JPG` |
| 優化校準（Picture Control） | 相機的色彩風格，例如標準、平淡；自訂的放在 C1～C9 |
| Pro／Cine | 付費等級；Beta 期間輸入免費測試金鑰就能使用，見[第 9 章](09-tiers.md) |
