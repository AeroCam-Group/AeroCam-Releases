# AeroZ 使用手冊（繁體中文）

> **初稿**（2026-10-17，對應 Beta 92.03.08）。標 📷 的地方之後補截圖。

AeroZ 讓相機的照片直接傳到 Android 手機，也能用手機遙控相機。目前支援 **Nikon Z 系列**，之後會支援更多品牌。

AeroZ 是獨立開發的第三方 App，與 Nikon 及其他相機廠商沒有任何合作或授權關係。

## 支援的相機

| 機型 | 狀態 |
|---|---|
| Nikon Zf | 已實測 |
| 其他 Nikon Z 系列 | 大部分功能應該可以用，**歡迎回報** |
| Canon、Sony、Fujifilm | 準備中 |

用其他機型測過的話，請用[機型回報](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose)告訴我們哪些功能可以、哪些不行。
