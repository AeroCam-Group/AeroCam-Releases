# 7. 回報問題

到 [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) 選一種表單：

| 表單 | 用途 |
|---|---|
| Bug 回報 | 功能不正常、閃退 |
| 功能建議 | 希望新增或改進的功能、設定的預設值 |
| 翻譯錯誤 | 文字翻錯或不通順 |
| 機型回報 | 用其他相機測試的結果 |

## 請附上
- AeroCam 版本（首頁左上角）
- 手機型號、Android 版本
- 相機型號、韌體版本
- 連線方式（藍牙／一鍵連線／手機熱點／同一個 Wi‑Fi／USB）
- 怎麼操作、預期結果、實際結果
- **診斷資訊**：設定 → 支援 →「複製診斷資訊」，貼在表單裡

## 注意
- Issue 是**公開的**，請不要貼 Wi‑Fi 密碼、相機完整序號、帳號等個資。
- 不方便公開的事（例如要求刪除資料、安全問題），請用 [聯絡方式待補] 聯絡。
