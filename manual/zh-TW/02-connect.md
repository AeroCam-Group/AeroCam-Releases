# 2. 連接相機

三種連法可以同時設定，App 會自動用能用的那一種。

| 連法 | 適合 | 速度 | 需要 |
|---|---|---|---|
| **藍牙** | 隨身、相機關機也能收照片、藍牙遙控 | 慢（約 2 MB 的 JPEG，每張 15–20 秒） | 免費 |
| **Wi‑Fi** | 原檔、相機相簿、遠端拍攝 | 快 | Pro |
| **USB 線** | 最快最穩、錄影監控 | 最快 | 手動下載免費，自動接收 Pro |

## 藍牙配對
1. 相機：**MENU → 網路選單 → 連接到智慧型裝置 → 配對（藍牙）→ 開始配對**。
2. 相機和 SnapBridge 配對過的話，先在 SnapBridge 刪除，並在手機藍牙清單取消配對（兩個 App 不能同時配對同一台相機）。
3. AeroCam 首頁「藍牙」卡片 → **配對相機** → 開始。手機和相機出現同一組數字，兩邊都按確認。

配對後：
- 相機開機時自動同步時間和位置。
- 相機開啟「**關機時傳送**」後，關機時會用藍牙把照片傳到手機。

## Wi‑Fi：三種方式

| 方式 | 怎麼運作 | 什麼時候用 |
|---|---|---|
| **一鍵連線**（建議） | 用藍牙叫相機開自己的 Wi‑Fi，手機自動連上 | 戶外、不想開熱點 |
| 手機熱點 | 相機連上手機開的熱點 | 一鍵連線不穩時 |
| 同一個 Wi‑Fi | 手機和相機連同一台路由器 | 在家、工作室 |

### 一鍵連線
1. 先完成**藍牙配對**。
2. 首頁 Wi‑Fi 區塊 →「一鍵連線」。
3. 第一次要輸入相機 Wi‑Fi 的**名稱和密碼**（相機選單看得到，名稱類似 `NIKON_…_SnapBridge`），只存在你的手機。
4. Android 詢問是否允許連線時選允許。
5. 顯示「已連上相機 Wi‑Fi」後，相簿、遠端拍攝、接收都走這個連線。按「中斷」回到原本的 Wi‑Fi。

相簿或遠端拍攝連不上時，畫面上也會直接出現「用相機的 Wi‑Fi 連線」。

> 連著相機 Wi‑Fi 時，手機上網會改走行動數據。

### 手機熱點／同一個 Wi‑Fi（第一次要配對）
1. 相機：**MENU → 網路選單 → 連接到電腦**，新機型的「連接類型」選 **圖像傳送**。
2. AeroCam：**首頁 → 新增相機**，選連線方式，App 會自動找相機。
3. 相機螢幕出現 **4 位數驗證碼**，在手機輸入，再到相機上按 OK。

相機回覆「已和其他裝置配對」時，表示這組相機網路設定是別的 App 在用，請在相機上新增一組設定再配對。

📷 截圖：新增相機精靈、驗證碼

### 相機的「連接類型」
新機型（Z9、Z8、Z6III、Zf、Z5II、Z50II…）：**MENU → 網路選單 → 連接到電腦 → 連接類型**
- **圖像傳送**：自動接收、相機相簿。
- **相機控制**：遠端拍攝。

切換後 AeroCam 會自動重新連上，不用重新配對。

## USB 線
1. 相機 USB 設定選 **MTP/PTP**。
2. 用**能傳資料**的 USB‑C 線（有些線只能充電）。
3. 首頁 USB 區塊出現「需要允許存取」→ 按「允許存取」。

插著線時，相簿、遠端拍攝、自動接收都會自動改走 USB；拔線自動回到 Wi‑Fi。不用配對。
