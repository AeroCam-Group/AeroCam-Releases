# 2. 連接相機

AeroCam 有四種連線方式，可以同時設定，App 會自動用能用的那一種。首頁的四個按鈕（Wi‑Fi、USB、藍牙、FTP）顯示各自的狀態。

> 看不懂怎麼連？按首頁連線狀態旁邊、或「新增相機」每一步右上角的 **ⓘ**，會打開圖文教學（手機熱點、同一個 Wi‑Fi、一鍵連線、USB、藍牙、FTP 各一頁），手機和相機的畫面都有截圖，最後有「連不上時檢查」。

## 怎麼選

| 你想要 | 建議 |
|---|---|
| 相機關機也能收照片、不想管 | **藍牙**（縮小的 JPEG，免費） |
| 戶外、不想開熱點，要原檔、相簿、遠端拍攝 | **一鍵連線**（Pro） |
| 拍完立刻自動到手機，速度最快 | **[FTP 接收](08-ftp.md)**（Pro，要開熱點） |
| 最穩、錄影監控、長時間遠端拍攝 | **USB 線**（手動挑選下載免費） |
| 在家或工作室 | **同一個 Wi‑Fi**（Pro） |

## 速度參考（Nikon Zf、Pixel 10 Pro 實測）

| 方式 | 一張 RAW（約 18 MB） |
|---|---|
| FTP 接收 | 約 1 秒（約 17 MB/s） |
| Wi‑Fi 相簿下載 | 約 1.3 秒（約 13 MB/s） |
| USB | 通常比 Wi‑Fi 快，視線材而定（USB 2.0 線約 35 MB/s） |
| 藍牙 | 縮小的 JPEG（約 2 MB）每張 15～20 秒 |

## 首頁的連線燈號
Wi‑Fi、USB、藍牙、FTP 四個按鈕依狀態上色，沒連接時是灰色：

| 顏色 | 意思 |
|---|---|
| 🟢 綠 | 已連線或就緒（藍牙淡綠＝待命，關機傳送就緒） |
| 🔵 藍 | 傳輸中 |
| 🟠 橘 | 連線中（閃爍），或需要處理（權限、卡住、錯誤） |
| 🔴 紅 | 手機的 Wi‑Fi 或藍牙關閉 |

## 藍牙（免費，取代 SnapBridge）

### 配對
1. 相機：**MENU → 網路選單 → 連接到智慧型裝置 → 配對（藍牙）→ 開始配對**。
2. 相機和 SnapBridge 配對過的話，先在 SnapBridge 刪除，並在手機藍牙清單取消配對（兩個 App 不能同時配對同一台相機）。
3. AeroCam 首頁「藍牙」→ **配對相機** → 開始。手機和相機會顯示同一組數字，兩邊都按確認。相機上會顯示為 `AeroCam_手機型號`。

📷 截圖：藍牙卡片

### 配對之後
配對後就一直啟用；要停止只能解除配對（會先確認）。
- AeroCam 平常只在背景**聽**相機的藍牙訊號，不會喚醒睡眠中的相機。
- **相機開機時**：連一次，同步時間和手機位置（相機拍照時把位置寫進照片），然後斷開。
- **相機有照片要傳時**：在相機「連接到智慧型裝置」選單打開「**關機時傳送**」，相機會自己用藍牙把照片送過來，關機也可以。
- 收到的是相機產生的約 2 MB JPEG（拍 RAW 也會先轉成 JPEG），每張約 15～20 秒。要原檔請用 Wi‑Fi、USB 或 FTP。
- 想馬上收，按藍牙卡片的「**立即接收**」。
- 手機藍牙關開、手機重開機、App 更新後會自動恢復。等待期間通知列有一則低優先順序的常駐通知（Android 規定），可以在系統設定隱藏。

### 藍牙卡片的狀態
🟢 相機在附近・開機中／🟢 淡綠 待機（關機傳送就緒）／⚪ 看不到相機（顯示最後看到的時間）／🔵 傳輸中／🟠 好像卡住了／🔴 手機藍牙已關閉。

藍牙不是一直連著，這裡顯示的是「有沒有聽到相機」和「現在在做什麼」。

### 卡住時
- 傳輸中 30 秒沒有資料，App 會自動斷線，相機之後會重傳；20 秒沒動靜時卡片會變黃「好像卡住了」。
- 「**中斷並重新連線**」：只斷掉這次傳輸。
- 「⋮ → **重新啟動藍牙服務**」：整個藍牙背景服務重開，配對保留。
- 拍 RAW 時，相機要先轉成 JPEG 再傳；傳輸中操作相機（半按快門、拍照）會讓相機取消。建議拍完直接關機，讓它在背景傳。

## Wi‑Fi（Pro）：三種方式

| 方式 | 怎麼運作 | 什麼時候用 |
|---|---|---|
| **一鍵連線**（建議） | 用藍牙叫相機開自己的 Wi‑Fi，手機自動連上 | 戶外、不想開熱點 |
| **手機熱點**（教學推薦） | 相機連上手機開的熱點 | 一鍵連線不穩、要用 FTP 或無卡拍照時 |
| **同一個 Wi‑Fi** | 手機和相機連同一台路由器 | 在家、工作室 |

### 一鍵連線
1. 先完成**藍牙配對**。
2. 首頁 Wi‑Fi →「一鍵連線」。
3. 第一次要輸入相機 Wi‑Fi 的**密碼**（網路名稱由 App 自動帶入，類似 `NIKON_…`），只存在你的手機。
4. Android 詢問是否允許連線時選允許。
5. 顯示「已連上相機 Wi‑Fi」後，相簿、遠端拍攝、接收都走這個連線。按「中斷」回到原本的 Wi‑Fi。

相簿或遠端拍攝連不上時，畫面上也會直接出現「用相機的 Wi‑Fi 連線」。

> - 連著相機 Wi‑Fi 時，手機上網會改走行動數據。
> - 一鍵連線**不能搭配 FTP**，也**不支援無卡拍照**（相機沒插卡時請改用手機熱點或同一個 Wi‑Fi）。

📷 截圖：一鍵連線卡片、已連上的狀態

### 手機熱點／同一個 Wi‑Fi（第一次要配對）
1. 相機：**MENU → 網路選單 → 連接到電腦**，建立網路設定檔（連手機的熱點，或你家的 Wi‑Fi）。
   - 新機型（選單裡有「連接類型」）：「連接類型」選 **圖像傳送**。
   - 較早的機型：選「連接到電腦」即可。
2. AeroCam：**首頁 →「＋」新增相機**，選連線方式（同一個 Wi‑Fi 或手機熱點）。App 會檢查網路，並自動搜尋相機；找不到時可以手動輸入 IP。
3. 相機螢幕出現 **4 位數驗證碼**，在手機輸入，再到相機上按 OK。
4. 完成後存成一個「相機設定檔」，之後開 App 就能直接連。可以存多台相機、多組網路；App 更新後**不用重新配對**；相機換了 IP 也會自動找到。

> 相機回覆「已和其他裝置配對」時，表示這組相機網路設定是別的 App 在用。請在相機上新增一組設定再配對。

📷 截圖：新增相機精靈、驗證碼

### 連線前檢查
- 按「開始接收」、或進入相簿、遠端拍攝時，App 會先檢查網路。設定檔是「手機熱點」但熱點沒開、或是「同一個 Wi‑Fi」但手機沒連上，會出現黃框（例如「請先開啟手機熱點」）並附「熱點設定」「Wi‑Fi 設定」按鈕。開好回到 AeroCam，黃框會消失。
- Wi‑Fi 和熱點上都找不到相機時，首頁會出現「網路上找不到相機」，多半是相機的「連接到電腦」沒打開，旁邊有「查看連線教學」。

### 相機的「連接類型」
新機型（Z9、Z8、Z6III、Zf、Z5II、Z50II…）：**MENU → 網路選單 → 連接到電腦 → 連接類型**
- **圖像傳送**：自動接收、相機相簿。
- **相機控制**：遠端拍攝、無卡拍照。

切換後相機 Wi‑Fi 會斷一下，AeroCam 會自動重新連上，不用重新配對。相機還在「圖像傳送」時進遠端拍攝，App 會顯示切換步驟。

## USB 線
比 Wi‑Fi 快、穩，**不需要配對**，也不用先新增相機。
1. 相機 USB 設定選 **MTP/PTP**（不是「iPhone」或「UVC/UAC」）。
2. 用**能傳資料**的 USB‑C 線（有些線只能充電）。標示 5Gbps／10Gbps 的 USB 3 線比較快。
3. 首頁 USB 出現「偵測到 Z f・需要允許存取」→ 按「允許存取」，Android 會問一次。

### USB 卡片的顏色
| 顏色 | 意思 |
|---|---|
| ⚪ 灰 | 沒有相機（或線只能充電） |
| 🟠 橘 | 偵測到相機，需要允許存取 |
| 🔴 紅 | USB 設定不是 MTP/PTP、沒有允許存取、或測試失敗（會顯示原因） |
| 🟢 綠 | 已用線連上 |

### 插著線時
- 相簿、遠端拍攝、自動接收都**自動改走 USB**；拔線自動回到 Wi‑Fi。正在 Wi‑Fi 遠端拍攝時插線也會改走 USB（間隔、包圍曝光、B 門進行中不會切換）。
- **USB 接收**（Pro）：USB 卡片「開始接收」，新拍的照片和相機上「傳送到電腦」的照片都會存到手機。預設插上線就自動開始（設定 → 拍攝 →「插上 USB 線自動開始接收」）。
- **時間同步**：插線時同步一次相機時間（相差超過 2 秒才改；相差 1 天以上會先問）。
- **保持喚醒**：開著相簿或遠端拍攝時，每 10 秒送一個很小的訊息讓相機不休眠；閒置 30 分鐘或相機低電量時停止。
- 手機可能正在供電給相機，長時間使用建議接行動電源。
- **USB 測試**（USB 卡片右上角 ⋮）：測連線、相機資訊、記憶卡、預覽幀率、讀取速度。
