# 3. 自動接收與存檔

## 相機儀表板
連上相機後，首頁上方會顯示相機目前的狀態：

| 項目 | 內容 |
|---|---|
| 機型、鏡頭 | 例如「Nikon Z f」「NIKKOR Z 24–120 mm f/4」 |
| 電量 | 百分比（20% 以下變紅） |
| 連線方式 | 手機熱點、同一個 Wi‑Fi、相機 Wi‑Fi、USB |
| 記憶卡 | 每張卡的已用／總容量、還能拍幾張；雙卡分開列 |
| 畫質 | 例如 `RAW`、`JPEG 精細★ L`；在相機上改畫質、插拔卡時自動更新 |
| 存檔位置 | 例如「存檔：記憶卡 ✓」，見下方[存檔位置與無卡拍照](#存檔位置與無卡拍照) |
| 傳輸 | 目前狀態，右上角「紀錄 ›」 |
| 相機風格 | 上次讀到的 C1～C9，見[第 6 章](06-edit.md#相機風格-c1c9pro) |

相機在某個模式下不提供的項目就不顯示。切到「相機控制」並進入遠端拍攝後，通常能讀到更多項目。

### 管理相機
儀表板下方的「**管理相機 (n)**」展開後，可以編輯、刪除、新增相機。每台相機的「詳細資訊」頁有：
- 型號、序號（中間遮住，點一下顯示完整）、韌體、**快門次數**和讀取日期。
- **每月快門數**：最近 6 個月的長條圖（從開始記錄後才有資料）。
- 上次連線的時間、方式、鏡頭、電量、記憶卡剩餘容量。
- 傳到手機的檔案數、第一次連線日期、已存的網路設定。

快門次數是從記憶卡上最新一張照片的資訊讀出來的，記憶卡上要至少有一張照片。

### 低電量提醒
相機電量降到門檻（預設 15%）時發一則通知；電量回到門檻 +5% 以上才會再提醒。門檻在 **設定 → 接收與通知** 調整或關閉。

## 自動接收（Pro）
1. 首頁 Wi‑Fi →「**開始接收**」。App 在背景保持和相機的連線（通知列看得到）。
2. 在相機播放照片時按 **i → 傳送到電腦／選擇傳送**，照片就會傳到手機。

想拍完立刻自動推過來，請用 [FTP 接收](08-ftp.md)。插著 USB 線時，接收會自動改走 USB。

### 暫停接收
Wi‑Fi 自動接收連著時，首頁「傳輸」方塊右上的「⏸ 暫停」或通知的「暫停」，可以先暫停：
- Wi‑Fi 保持連著，相簿、遠端拍攝照常用。
- 相機要傳的照片先留在相機上；按「**繼續接收**」後照順序補傳。正在傳的那張會先傳完。
- 按「繼續」、停止接收、從最近使用清單滑掉 App、Wi‑Fi 斷線、相機關機、插上 USB 時會自動恢復。

### 斷線時
- 連線中斷會自動重連；重試幾次都失敗，會用相機識別碼重新搜尋，相機 IP 變了也找得到。
- **相機改用藍牙傳照片**：相機只有一組無線晶片，用藍牙傳照片時會先關掉 Wi‑Fi。這時首頁顯示「相機正在用藍牙傳照片…傳完會自動重連 Wi‑Fi」，不算斷線。
- **相簿／遠端拍攝借用相機**：相機一次只接受一條連線。進入相簿或遠端拍攝時，自動接收會讓出連線，離開後自動恢復。
- **Wi‑Fi 找不到相機時**：超過設定的時間（預設 3 分鐘）自動停止接收並通知，避免一直耗電。時間在 **設定 → 接收與通知** 調整。

## 接收規則
在 **設定 → 接收與通知** 調整，Wi‑Fi、USB、FTP 都照這些規則存檔。

### 接收類型
選要存哪些檔案：全部檔案、僅 JPG、JPG + RAW、照片 + 影片，或自訂（JPEG、RAW、HEIF、TIFF、影片、其他）。

另外三個開關（Pro）：

| 開關 | 說明 |
|---|---|
| **RAW 只存 JPEG** | 收到 RAW 時只存相機嵌在檔案裡的全尺寸 JPEG（通常 2～5 MB，而不是 20～50 MB 的 RAW），解析度不變，拍攝資訊完整保留，存成 `DSC_1234_S.JPG`。適合發社群、日常瀏覽 |
| **JPEG 存壓縮版** | 收到相機的 JPEG 時，由手機重新壓縮再存（`_S.JPG`，像素不變，品質照相簿設定） |
| **原檔收到時取代壓縮版** | 存下 JPEG 原檔時，刪掉手機上同一張的壓縮版 |

> 要接收 RAW，相機的影像品質要設成 RAW 或 RAW+JPEG，並在相機「連接到電腦」的上傳選項選 RAW+JPEG（不要選「僅 JPEG」）。選單名稱依機型而異。

### 其他規則
| 規則 | 說明 |
|---|---|
| 接收模式 | 持續接收，或收到一個就停止 |
| 大型影片 | 超過門檻（預設 1024 MB）的影片不自動接收，記為「已過濾」，要手動下載 |
| 存檔資料夾 | 依相機、依日期、依相機與日期、依檔案類型 |
| 檔名 | 相機原檔名（`DSC_1234.NEF`）、加日期前綴（`20261011_DSC_1234.NEF`）、加日期時間前綴（`20261011_153012_DSC_1234.NEF`，多台相機也會依拍攝時間排序）。只套用到之後存的檔案 |

### 存放位置
- 照片：`Pictures/AeroCam/…`
- 影片：`Movies/AeroCam/…`
- 其他檔案：`Download/AeroCam/…`

Google 相簿等其他 App 也看得到。刪掉 App 再重裝後，之前存的照片可以用 **設定 → 儲存空間與電池 →「重新掃描手機照片」** 放回相簿。

### 重複檔案
- 用相機序號、檔名、大小、拍攝時間和檔案內容判斷，重複的不會再存一次，紀錄裡標「重複」。
- 你在手機上刪掉（包括丟進垃圾桶）的照片，再傳一次會重新存。
- 同一張照片重送，不需要停止再重新開始接收。

### 藍牙和 Wi‑Fi 收到同一張
Wi‑Fi 的檔案比較完整（全尺寸），所以以 Wi‑Fi 為準：
- Wi‑Fi 先收到、藍牙又送來：藍牙版不存。
- 藍牙先收到、之後 Wi‑Fi 收到同一張，依 **設定 → 接收與通知 →「藍牙已收過的照片」**：
  - **Wi‑Fi 收到時換成原檔**（建議）：存全尺寸，自動刪掉手機上的藍牙縮小版。
  - **Wi‑Fi 不再下載**。
  - **兩份都保留**。
- RAW 原檔一律照收。

## 存檔位置與無卡拍照
決定按下快門後照片存到哪裡。App 會讀相機有沒有插卡，自動選擇：
- **相機有卡**：照 **設定 → 拍攝 → 存檔位置** 選的方式：
  - **記憶卡**：存在相機的記憶卡。
  - **記憶卡＋手機**（Pro）：存進記憶卡，同時複製一份到手機。
- **相機沒卡**（Pro）：自動改成 **只存手機（無卡存取）**。相機快門照常可以按，照片直接傳到手機，檔名是拍攝時間（例如 `AC_20261025_193805.JPG`）。插卡後自動改回。

首頁、相簿、遠端拍攝都能用，Wi‑Fi 和 USB 都支援。

**第一次要先設定：**
1. 相機自訂設定選單的「**空插槽時快門釋放鎖**」改成「**允許釋放快門**」，否則沒卡時相機不讓你按快門。
2. Wi‑Fi 連線時，相機的連接類型要用「**相機控制**」。用「圖像傳送」時，拍第一張後約 3 秒 App 會提醒切換；照片會留在相機裡，切換後自動傳過來。USB 沒有這個問題。
3. 一鍵連線不支援無卡拍照，請改用手機熱點或同一個 Wi‑Fi。

**看懂狀態列**（首頁和相簿上方）：

| 顯示 | 意思 |
|---|---|
| 存檔：記憶卡 ✓ | 存在記憶卡 |
| 存檔：記憶卡＋手機 ✓ | 存在記憶卡，也複製到手機 |
| 存檔：只存手機（相機沒有記憶卡） | 照片直接傳到手機 |
| 相機是「影像傳送」模式…（紅字） | 請切換成「相機控制」 |
| 一鍵 Wi‑Fi：沒有記憶卡，無法拍照（紅字） | 請插卡，或改用熱點／同一個 Wi‑Fi |
| 記憶卡已滿（紅字） | 請換卡或清出空間（不會自動改成只存手機） |
| 相機沒有記憶卡，無法拍照（紅字） | 免費版，或手機剩不到 1 GB |

> 沒插卡時相機不能錄影；連拍會變慢（每張要等傳到手機）。

## 照片位置（GPS）
**設定 → 接收與通知 → 照片位置** 有兩個開關：
- **傳位置給相機（藍牙）**（預設開）：相機開機或用藍牙傳照片時，手機把位置傳給相機，相機拍照時自己寫進照片。
- **收到的 JPEG 補上位置（手機）**：Wi‑Fi、USB、FTP、相簿下載、遠端拍攝收到的 JPEG，由手機依拍攝時間寫入當時的地點。第一次開始接收時會問一次。
  - RAW 不會被修改；已經有位置的照片保留原本的。
  - 接收期間手機記下的位置只存在這支手機，24 小時後刪除。
  - 拍攝時間對不上時不寫，寧可沒有位置也不寫錯。
  - 要在 AeroCam 開著時開始接收，才能記錄位置。

> 照片會記下拍攝地點，分享原檔時對方也看得到。用 QR Code 分享時預設會移除位置，見[第 4 章](04-gallery.md#qr-code-分享)。

## 紀錄
首頁「傳輸」方塊右上角「**紀錄 ›**」。列出所有接收、相簿下載、遠端拍攝存檔的結果：成功、重複、略過、失敗，每筆都有縮圖。
- 點一下在 App 內全螢幕預覽。
- 可以搜尋、依相機篩選、清除紀錄。清除紀錄不會刪手機上的檔案。
