# 5. 免費／Pro／Cine

| 等級 | 功能 |
|---|---|
| **免費** | 藍牙傳照片、藍牙遙控（對焦、拍照、錄影、連拍、自拍計時）、USB 相機相簿（手動挑選下載原檔）、手機上的照片 |
| **Pro** | 免費的全部，加上：Wi‑Fi（含一鍵連線）、USB 自動接收、遠端拍攝、藍牙遙控的間隔拍攝、RAW 轉 JPEG、壓縮 JPEG、Film Frame、記憶卡備份、從相機刪除、拍攝輔助、拍攝工具 |
| **Cine** | Pro 的全部，加上：錄影監控、LUT |

測試期間輸入[測試金鑰](01-install.md#測試金鑰開啟-procine)就能免費使用 Pro 和 Cine。測試版結束後，最後一組金鑰到期就回到免費版。
