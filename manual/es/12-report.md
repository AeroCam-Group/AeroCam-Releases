# 12. Informar de un problema

Ve a [Issues](https://github.com/AeroCam-Group/AeroCam-Releases/issues/new/choose) y elige un formulario:

| Formulario | Uso |
|---|---|
| Informe de error (Bug) | Una función no va bien o la app se cierra |
| Sugerencia de función | Ideas para nuevas funciones, mejoras o valores por defecto |
| Error de traducción | Texto mal traducido o poco natural |
| Reporte de cámara | Resultados tras probar con otra cámara |

## Por favor incluye
- Versión de AeroCam (esquina superior izquierda de Inicio o en Ajustes → Soporte)
- Modelo de teléfono y versión de Android
- Modelo de cámara y versión de firmware
- Método de conexión (Bluetooth / Conexión en un toque / Zona Wi‑Fi del teléfono / Mismo Wi‑Fi / USB / FTP)
- Pasos realizados, resultado esperado y resultado real
- **Información de diagnóstico**: Ajustes → Soporte → «Copiar información de diagnóstico», pegada en el formulario

## Ten en cuenta
- Los Issues son **públicos**; no pegues contraseñas Wi‑Fi, números de serie completos, cuentas ni datos personales.
- Para asuntos privados (por ejemplo, solicitar borrado de datos o problemas de seguridad), escribe a **aerocam.lab@gmail.com**.
